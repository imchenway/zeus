# Chrome Web Store 审核清单

- [ ] 生产扩展首次上传后记录真实 extension ID，并由签名发布配置写入 Native Messaging `allowed_origins`。
- [ ] 验证 ZIP 根目录直接包含 `manifest.json`，无私钥、rendezvous、固定端口或长期令牌。
- [ ] 逐项核对权限理由、隐私说明、单一用途和远程代码政策。
- [ ] 使用商店安装版本验证站点拒绝、可选权限拒绝、断连、浏览器重启与标签复用。
- [ ] 捕获真实商店安装 UI 截图；不得用概念宣传图冒充产品截图。
- [ ] 公开隐私说明 URL、支持 URL 与版本发布说明。
- [ ] 本任务不登录、不上传、不提交审核。
