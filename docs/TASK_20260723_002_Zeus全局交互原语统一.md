# TASK_20260723_002 Zeus 全局交互原语统一

## 目标

- 将下拉框、抽屉和 source-list 行收敛为可执行的通用交互原语，避免页面级 CSS 反复覆盖核心状态。
- 项目名称左对齐，移除展开箭头；单击项目名称只切换展开或折叠。
- 项目导航首次默认展开，之后按项目记忆用户行为并跨应用重启保留。
- 项目更多菜单参考用户提供的 Codex 菜单，统一位置、尺寸、圆角、阴影、图标行与 hover，并新增“在 Finder 中显示”和“重命名项目”。
- 表单型弹窗、全局设置和项目设置统一为 Codex / Apple 式单一纯色表面，移除灰白条带与装饰横线，通过留白建立层级。
- 项目设置使用与任务详情一致的透明点击层和右侧悬浮抽屉，不再将主工作区染成灰色。
- 项目行与“任务 / 代码 / 会话”子行复用同一套 hover、selected、focus、圆角和动效 token，但按语义选择不同表面范围。
- 抽屉外部点击覆盖整个窗口，抽屉宽度按剩余工作区自适应，壳层不出现横向滚动条。
- 全局滚动条参考 Codex App，使用透明轨道和低对比度滑块状态。
- 项目列表只保留纵向滚动，项目子导航移除装饰竖线并缩短缩进。
- 任务页移除“视图控制”和“默认视图”两条摘要行，保留能力但不保留冗余层级。

## 领域边界

- `Select`、`Drawer`、`SourceListRow` 是三类独立交互原语，不合并为一个万能组件。
- 交互原语拥有结构、状态、键盘语义和视觉 token；业务页面只选择明确变体并提供内容。
- 项目导航展开状态是本机界面偏好，不等同于当前项目、当前页面或项目扫描状态。
- 抽屉的 `floating / sheet` 与 `transparent / dimmed` 由类型化属性声明，不再从业务 class 名推断。
- 项目显示名称与项目本地路径是两种独立事实；重命名只更新显示名称，Finder 动作只定位真实本地目录。
- 单一纯色表面只移除容器 chrome 的装饰分层；输入、选择、列表、表格、焦点、错误与危险确认仍保留功能边界。

## 已确认决策

- 项目设置抽屉采用透明点击命中层；点击空白处、关闭按钮或按 Esc 均可关闭。
- 项目子菜单首次默认展开；用户折叠后持久化保存。
- 项目名称承担展开/折叠，子菜单承担页面导航，设置与更多按钮保持独立。
- 本次采用结构性收口，不只增加一轮页面级 CSS 最终覆盖。
- 项目根行使用整行圆角灰底并包含设置与更多操作槽；两个图标保留独立点击目标，但不再绘制自己的 hover 背景，项目内页面入口继续使用整行灰底。
- 抽屉正常模式使用明确可感知的右侧滑入滑出；系统减少动态效果时只保留短透明度过渡。
- 点击侧栏或工作区任意抽屉外区域只关闭当前抽屉，不穿透触发底层导航。
- 抽屉壳层只负责纵向滚动；业务确需横向滚动时必须放在内容内部的局部容器。
- 滚动条颜色由全局语义 token 管理，默认、hover、active 三态逐级增强。
- 项目菜单保持在“···”右侧顶部对齐；菜单采用参考图的图标行和中性 hover，仅删除二次确认使用危险色。
- “在 Finder 中显示”使用 Electron Main 的 `shell.showItemInFolder`；Renderer 与 Main 都校验路径，Main 额外校验发送窗口与真实目录。
- “重命名项目”只提交 `name` 字段，不携带旧表单中的路径、描述或备注，避免旁路覆盖。
- 表单弹窗统一使用纯色表面 token 与 `20px` 水平边距；标题、正文和动作区不再使用不同灰度或横线。
- `WorkspaceDrawer` 的 chrome 与 content 使用同一底色；全局设置和项目设置行移除装饰分割线，以标题、留白和控件轮廓分组。
