# TASK_20260725_001 任务表全列排序与可保存自定义布局

## 任务状态

列内容锚点返修与隔离包真实运行验收已完成；当前正式包因用户存在未保存布局草稿，尚未覆盖。

## 用户目标

- 任务表 14 个业务数据列都支持排序，批量选择复选框列不参与排序。
- 列头排序采用升序、降序、取消排序三态；默认不排序，取消排序恢复服务端原始顺序。
- 表头支持直接拖拽改变列位置和列宽，不保留“窄 / 中 / 宽”快速预设。
- 列显隐、列位置、列宽和当前排序状态统一作为布局草稿。
- 草稿保存时询问“当前项目 / 全部项目”；全部项目保存会清除项目级覆盖。
- 未保存草稿在页面切换、项目切换和关闭应用时提示“保存并离开 / 放弃更改并离开 / 继续编辑”。
- 全局设置新增“任务列表”页，可拖动定义优先级、管理状态和运行状态的升序顺序。

## 已确认交互

- 移除工具条旧“排序”下拉框，排序只从列头发起。
- 同一时间只激活一个排序列；切换列从升序开始。
- 当前排序状态随布局保存；没有布局偏好时默认不排序。
- 有未保存草稿时，“保存”占用现有“更多”按钮的位置；保存完成或放弃草稿后恢复“更多”。
- “当前项目”只写当前项目覆盖；“全部项目”更新全局默认并清除全部项目覆盖。
- 历史列宽预设在读取时换算为像素宽度，避免已有本机偏好丢失。

## 交互返修

- 指针拖动列时实时重排表头与数据列，并显示明确插入线；松手才写入布局草稿，取消拖动恢复原顺序。
- 列换位把手与列宽把手默认隐藏，只在当前列 hover、focus-within、键盘移动或实际拖动时显示。
- 未排序列不显示排序图标；列标题仍可点击，并保留“当前未排序”的可访问名称。
- 离开确认必须覆盖在当前任务页之上，不能让全屏 portal 背景把原页面遮成独立页面。
- 离开确认动作按“继续编辑 / 放弃更改并离开 / 保存并离开”排列；三个动作统一使用全局按钮原语，放弃按钮使用低饱和危险底色和清晰危险边框。

## 按钮原语返修

- 新增全局 `Button` React 原语，类型化约束 `primary / secondary / danger` 语义变体和 `compact / regular` 尺寸。
- 原语统一按钮高度、圆角、内边距、边框、hover、active、focus-visible、disabled 和 loading 状态。
- 任务表“离开确认”和“保存作用范围”两个弹窗已迁移到全局原语，不再借用创建任务按钮 class。
- 删除任务表弹窗的一次性无边框危险按钮样式；本轮不批量迁移其他页面，避免扩大任务范围。

## 列内容锚点返修

- 复核确认表头与数据行仍共享同一套列宽轨道，错位不是列宽或拖动结果丢失。
- 根因是视觉隐藏的换位把手仍占用 `24px` 流内宽度，排序按钮又为标题增加不对称内边距，导致表头标题与数据内容使用了不同水平锚点。
- 换位把手改为绝对定位，不再参与标题排版；左对齐列把操作区放在尾端，右对齐列把操作区放在首端。
- 普通文本列标题与数据共用左边缘，创建时间和更新时间标题与数据共用右边缘；排序激活与控件显隐不再推动标题。
- 右对齐列的排序箭头显示在标题前侧，左对齐列继续显示在标题后侧，确保箭头出现后语义内容锚点仍保持不变。
