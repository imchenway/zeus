## 用户确认

- 任务可以推送到新会话，并在任务详情查看此前推送过的全部会话。
- 点击历史会话后进入会话页并打开所选会话；任务详情不内嵌完整对话。
- “推送到新会话”保留模型、推理强度、工作模式、权限和首条消息确认弹窗，确认后强制创建新会话。
- 列表和详情共用任务管理状态，可直接通过下拉框修改。
- 删除“标记完成”；“已完成”通过任务管理状态选择。
- 删除“取消任务”按钮及任务级 Runtime 取消入口；“已取消”只是任务管理状态，不会停止会话。
- 会话执行停止只由会话输入区的停止按钮负责。
- 任务详情删除 AI CLI、Runtime 会话和运行命令／状态字段。

## 源码事实

- 任务列表当前展示 `managementStatus`，已有单独的 `/api/tasks/:taskId/management-status` 更新接口。
- 旧“标记完成”修改内部 `TaskStatus`，旧“取消任务”调用 `/api/tasks/:taskId/cancel` 并尝试停止旧 Runtime；两者与任务列表管理状态不是同一事实源。
- 现有任务推送弹窗提交 `mode: create`，已具备强制创建新会话的底层契约。
- `conversations.task_id` 允许同一任务关联多个会话，Renderer 已持有按任务加载的会话选择快照。
