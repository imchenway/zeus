架构节点说明

这些细节同时标出 Zeus 当前缺口与建议落点。

统一输入入口

两个会话输入框共享同一交互能力：原生选择器接受多文件与目录；paste/drop 先区分图片、普通文件、目录与纯文本；正文为空但资源非空时也允许发送。当前两个输入框均缺少资源 paste/drop，且发送逻辑要求正文非空。

输入资源控制器

建议新增 ComposerInputResourceController 与共享 reducer。它只保存编辑器草稿、资源条目、错误和冻结发送快照，不授权任意路径；新建会话与既有会话必须走相同状态机，避免功能漂移。

会话资源 Broker

建议新增会话域 IPC：choose / readClipboard / materialize / validate。复用 taskClipboard 的底层解析能力，但抽离任务命名。显式选择的既有路径经 realpath 校验后可引用；剪贴板位图与 Pasted text.txt 写入会话专用资源目录。

Codex 会话传输

Provider 映射保持窄接口：图片 → localImage；文件、目录、长文本 → mention。只有服务端返回持久化回执后才清空草稿与资源；所有文件可附加不等于承诺解析所有二进制格式。

参与者与消息契约

点击任意参与者或消息查看职责边界。

用户与操作系统

输入源不直接授予渲染层路径信任。选择器取消是无操作；Finder、截图工具和 Paste.app 都应作为真实验收来源。

输入资源控制器

控制器负责将多入口事件收敛为同一资源数组，维护 collecting / ready / invalid / sending / send_failed 状态，并生成幂等发送快照。

主进程资源 Broker

Broker 校验 sender、realpath、存在性和资源种类。目录只允许通过明确选择或拖放进入；不静默抓取远程 URL。

会话服务

本地服务与 app-server 只接收已校验的 provider 输入；它不负责 UI 预览，也不应把任意文件可选择误解释为任意二进制可解析。

提交输入事件

DOM paste 能提供资源时直接收集；macOS 未触发 DOM paste 时通过原生剪贴板兜底。普通短文本保持在编辑器中。

归一化与物化

统一返回逐项结果：成功资源进入 ready，失败资源带错误原因保留在 UI；生成文本落盘失败时原文本不得从编辑器消失。

校验并发送

冻结 displayText、resources 和 idempotencyKey 后发送；发送期间的新编辑继续留在下一份草稿，不改变在途请求。

返回持久化回执

只有持久化成功才消费冻结快照。回执需要能关联当前发送尝试，避免重试导致重复或错误清空。

逐项错误并恢复

失败时恢复冻结快照并保留用户后续编辑；无效资源阻止发送，用户修复或删除后再重试。

状态节点说明

核心不变量：只有服务端持久化成功才能消费冻结快照。

编辑器草稿

短文本留在编辑器；达到 5000 字符的粘贴文本候选转成文本资源。若物化失败，原文继续留在草稿。

已收集资源

每个资源有稳定 id、kind、source、name、localPath 和校验状态。图片预览失败可降级为普通文件，但资源本身不得静默消失。

在途发送包

发送动作复制当前草稿和 ready 资源形成不可变快照；后续输入写入下一草稿，确保在途请求可重试。

持久化用户消息

持久化消息是唯一可消费草稿的确认点。发送失败、超时或回执不匹配时回滚到已收集资源态。

恢复节点说明

每一种失败都必须明确回答：用户看见什么、原数据在哪里、怎样继续。

捕获输入事件

选择器取消直接结束；普通输入事件进入归一化。短文本不转资源，继续由编辑器处理。

归一化并物化

路径先 canonicalize/realpath，再校验存在性和类型；位图、无稳定路径数据与长文本写入会话专用资源目录。

加入就绪资源

成功资源立即以统一资源条目显示。图片有缩略图；普通文件和目录显示名称、类型、大小或路径范围。

显示无效条目

失败项保留可见错误。长文本落盘失败保留原文；预览失败降级为普通文件；失效路径在发送前阻止提交。

冻结并提交快照

发送时冻结 displayText、resources、draftScope 与 idempotencyKey。资源单独发送合法，空正文且空资源仍然禁止。

确认或原样恢复

持久化成功后清空对应快照；失败恢复正文和资源。人工修复从捕获或校验阶段重试，不新建隐式重复消息。
