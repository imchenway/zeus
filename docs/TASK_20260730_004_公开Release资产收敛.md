# TASK_20260730_004 公开 Release 资产收敛

## 1. 任务目标

将 Zeus 的公开 GitHub Release 下载区收敛为用户实际需要的两项资产：

- `Zeus-<version>-<arch>.dmg`；
- `zeus-release-manifest.json`。

ZIP、Shell 安装脚本、独立校验文件和 Homebrew Cask 不再作为公开 Release 附件。

## 2. 真实依据

- 0.1.2 Release 初始公开 6 个资产：DMG、ZIP、manifest、`install.sh`、`SHA256SUMS`、`zeus.rb`；
- Zeus 检查更新真实读取
  `https://github.com/imchenway/zeus/releases/latest/download/zeus-release-manifest.json`，因此 manifest 必须保留；
- Homebrew 用户真实读取 `imchenway/homebrew-tap` 的 `Casks/zeus.rb`，Release 中的 `zeus.rb` 没有独立消费方；
- `install.sh` 下载未公开上传的 `Zeus-latest-arm64.dmg`，当前链路不可用；
- `SHA256SUMS` 包含未公开上传的 latest 别名，不能作为完整可用链路；
- 用户明确确认 ZIP 也不需要。

## 3. 已确认边界与取舍

- 公开 Release 只保留 DMG 与 manifest；
- macOS 打包只生成 DMG，不再生成 Zeus ZIP；
- Homebrew Cask 继续在构建过程中生成并同步独立 Tap，但不出现在 Release 下载区；
- Release notes 改为仓库内 `docs/releases/v<version>.md` 的显式文件；新 Release 缺少该文件时拒绝发布；
- 不删除历史任务文档中的当时事实，只修正当前发布规范和当前 0.1.2 状态；
- 当前环境没有暴露项目规则要求的 `domain-modeling` 技能，本任务以“公开资产 / 内部发布工件 / 消费方”三类真实对象完成等价建模。

优点是公开下载区清晰、失效入口被移除、打包和上传时间下降；缺点是取消 ZIP 便携分发和 Shell 一键安装，只保留 DMG 与 Homebrew 两种安装方式。

## 4. 修改记录

- electron-builder 和 `package:mac` 只构建 DMG；
- manifest 生成器只发现版本化 DMG，并移除失效的 `installScriptUrl`；
- release-core 移除 ZIP 产物和 Shell 安装计划模型；
- `verify:release` 不再生成 latest 别名、`SHA256SUMS` 和 `install.sh`；
- Release workflow 的 Actions artifact 与公开 Release 只上传 DMG 和 manifest；
- 删除不再使用的 `scripts/generate-install-script.mjs`；
- 新增 `docs/releases/v0.1.2.md`，并让未来公开发布强制读取版本对应的 Release notes 文件。
