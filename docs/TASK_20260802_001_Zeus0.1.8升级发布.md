需求澄清、发布阻断修复和仓库正式包真实界面验收已经完成。当前正在执行完整发布门禁；尚未执行远端提交、合入、标签、GitHub Release 或 Homebrew 写操作。

## 已确认决策

### 发布阻断项

真实界面交互与仓库正式包验收是本次发布阻断项。未完成这些验收时，不进入公开发布阶段；静态检查、构建、隔离 API 验证或远端 CI 成功不能替代这两项证据。

该决策的优点是避免把未验证的任务编辑交互直接交付给公开用户；缺点是浏览器或桌面运行环境不可用时会推迟发布时间。

### 目标版本与发布范围

- 目标版本为新的公开稳定版 `v0.1.8`，不覆盖或替换已经公开的 `v0.1.7`。
- 发布基线限定为当前 `main` 相对 `v0.1.7` 已存在的任务编辑能力，以及真实界面和正式包验收发现的发布阻断缺陷修复。
- 不夹带批量编辑、富文本、附件实体删除、已有会话内容改写、Apple 公证、应用内自动安装、差分更新或其他无关能力。

该范围的优点是变更边界清晰、Release notes 与代码事实容易对账；缺点是本轮不会顺带扩展任务编辑之外的产品能力。

### 发布写操作授权

用户已明确授权在发布阻断项通过后执行完整发布链路：创建发布分支、修改版本与 Release notes、提交、推送、创建并合入 PR、创建不可变标签和 GitHub Release，并更新 Homebrew Tap。

本次不执行强推、历史改写、同版本二进制替换或未经验证的远端发布。

## 待确认决策
