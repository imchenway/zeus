# Zeus 0.1.9 升级发布

## 当前阶段

Zeus `0.1.9` 已完成实现、完整发布门禁、真实桌面交互、远端 CI、`main` 合入、Git 标签、GitHub Release、公开资产回拉和 Homebrew Tap 对账，现为公开稳定版。

## 任务目标

将代码交付流程修复升级为新的公开稳定版，并保持源码版本、Release notes、Git 标签、GitHub Release、更新清单和 Homebrew Cask 一致。

## 现场基线

- 根包、桌面包和公开稳定版基线均为 `0.1.8`。
- 发布开始前 `main` 与 `origin/main` 均位于 `f98d4a8d1d71e4ae7bd882a7654c8935c87afe53`。
- 当前工作区只包含本次代码交付流程实现、领域文档和任务文档，没有夹带其他仓库改动。
- `v0.1.9` 标签与同名 GitHub Release 在发布开始前不存在。
- 目标版本为新的公开稳定版 `0.1.9`，不覆盖已经公开的 `0.1.8` 制品。

## 发布范围

- 代码交付入口不再受任务管理状态限制。
- `ready / failed` 分支从代码交付进入完整提交审查、推送、远端校验和 worktree 回收。
- 分支选择器使用真实 Git 分支名和生命周期标签，不显示内部 TaskWorkspace ID。
- 交付准备取消或完成后回到同一代码交付上下文，不修改任务管理状态。
- 中文界面对已知 Git 合入门禁错误提供可操作说明，服务端真实安全门禁保持不变。

优点：开发中的任务也能完成真实代码处置，手工提交或推送后的分支有明确恢复路径，任务状态保持纯粹的进度语义。

代价：代码交付继续保留准备与合入两个显式步骤；当前公开包仍为 ad-hoc 签名且未公证，不能启用静默应用内安装。

## 已完成验证

- `pnpm lint`、`pnpm typecheck`、`pnpm build` 与 `git diff --check` 已通过。
- `pnpm package:mac:test` 已通过，生成仓库隔离包。
- 已使用版本为 `0.1.9`、最低系统版本为 macOS 13.0 的隔离包真实验证“任务详情 → 代码交付 → 审查并准备交付 → 取消返回”链路；任务状态保持“待开始”，界面没有显示 `task_workspace_*`。
- 隔离验收没有执行提交、推送、worktree 回收或合入，临时 TaskWorkspace 记录已清理。
