# TASK_20260814_002 发布 Zeus 0.3.5

## 发布目标

将移除任务推送状态同步校验的修复作为 Zeus 0.3.5 发布，使用仓库自带的端到端发布编排完成候选提交、版本提交、远端 `main`、GitHub Release、公开制品和 Homebrew 同步。

## 发布范围

- 删除任务推送专用状态接口、状态确认、乐观投影、重试和会话警告。
- 任务推送只负责创建会话，任务管理状态继续由用户手动修改。
- 保留 Zeus 0.3.4 的历史发布说明，0.3.5 单独说明本次行为变化。
- Vibego 属于另一个 Git 仓库，不进入 Zeus 0.3.5 候选范围。

## 取舍

优点：新旧执行宿主并存时不再因附属接口缺失干扰会话；发布范围与用户当前遇到的阻断问题一致。

缺点：任务推送后不再自动切换管理状态，用户需要在任务界面手动调整阶段。

## 发布口径

- 目标版本：`0.3.5`。
- 发布入口：`RELEASE_VERSION=0.3.5 pnpm release`。
- 发布前先把已验证修复提交到本地 `main`，避免脏工作区隔离机制只发布旧提交。
- 不启动或替换 `/Applications/Zeus.app`，正式生产候选只由发布编排生成并做结构、签名、DMG 与清单验证。
- 完成以发布脚本最终成功消息和退出码 `0` 为准；本地检查、远端发布、公开资产和签名公证分别据实记录。
