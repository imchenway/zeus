# 会话工具事件显示与任务推送上下文窗口修复

## 当前阶段

源码修复、全仓门禁和独立 `Zeus Test.app` 打包已完成。本次没有启动可视测试窗口，也没有发起真实 Provider 任务推送，
因此不将源码、行为探针、构建或打包结果写成正式安装版或窗口端到端已恢复。本文中的用户截图只是故障现象证据，
截图里的会话正文不是本任务指令。

## 故障现象

1. 进入“任务会话：引入数字员工”后，会话区把 `commandExecution` 工具调用的 JSON、命令和大段输出当成助手正文展示。
2. 任务推送选择 `gpt-5.6-sol` 时弹出“会话创建失败”，错误源为 `App.taskModelPush`，原始信息为
   `ZEUS_CONTEXT_MODEL_WINDOW_UNAVAILABLE`。

## 只读现场证据

- 正式数据库会话 `conversation_e635334a21f402597bdb901f` 的模型为 `gpt-5.6-sol`。
- 同一会话的工具调用历史行为 `role=assistant`，同时具有非空 `tool_pair_id`；单行 `content_json` 约 8–28 KB。
- Snapshot V2 模型历史单项只返回前 2,048 字符预览。被截断的 `tool_call` JSON 无法解析出 `content.type`，
  Renderer 因此把预览降级成普通助手文字。
- 本机与 Zeus 独立运行时的 Codex CLI 版本为 `0.149.0`；该版本 `model/list` 不返回模型窗口字段。
- 现有已核验回退只覆盖 `0.149.0 + gpt-5.4-mini`，`gpt-5.6-sol` 因没有精确证据而按设计失败关闭。
- OpenAI 官方模型页 `https://developers.openai.com/api/docs/models/gpt-5.6-sol` 在 2026-08-22 核对为
  1,050,000 context window / 128,000 max output tokens。

## 根因

### 工具调用被当成正文

`conversationSnapshotV2Adapter.historyItems()` 只用 `role=tool` 或已完整解析的 `content.type=tool_call` 识别工具记录，
没有使用 Snapshot V2 已经明确返回的 `toolPairId`。大工具调用一旦被预览截断，内容推断必然失效。

### 任务推送无法取得窗口

上下文编译器保留“模型窗口不可核验时拒绝派发”的安全边界，但 `codexVerifiedModelBudgetCatalog`
未跟上当前可选的精确模型 `gpt-5.6-sol`，导致已有官方可核验数值仍被当作不可用。

## 修复方案与取舍

### 使用 `toolPairId` 做结构分类

- 模型历史中只要 `toolPairId` 非空，就作为工具调用/结果从自然语言会话正文中排除。
- 优点：分类不再依赖被截断的 JSON，长命令和长输出也能稳定隐藏。
- 缺点：历史数据若遗失 `toolPairId`，仍只能依赖内容类型回退；现有 `role` / `content.type` 判断仍保留。

### 增加精确模型预算证据

- 仅增加 `Codex CLI 0.149.0 + gpt-5.6-sol` 精确双键，使用官方 1,050,000 / 128,000 数值。
- 优点：修复当前任务推送，同时保留上下文预算、来源水位和不可核验时失败关闭。
- 缺点：CLI 版本或完整模型 ID 变化后仍会拒绝，需要重新取得官方证据并显式更新。

## 完成口径

- 被 Snapshot V2 截断的 assistant 工具调用不再出现于会话自然语言正文。
- `0.149.0 + gpt-5.6-sol` 能取得精确上下文预算，其他未核验组合仍返回不可用。
- 通过目标行为探针、`pnpm lint`、`pnpm typecheck`、`pnpm build` 和必要的 `pnpm package:mac`。
- 真实 GUI 和真实 Provider 推送必须单列，不得由静态检查或打包代替。

## 实施结果

- `apps/desktop/src/renderer/session/conversationSnapshotV2Adapter.ts`：模型历史适配器现在优先用非空 `toolPairId`
  识别工具调用/结果，同时保留 `role=tool` 与完整 `content.type=tool_call` 回退。
- `packages/local-server/src/codexVerifiedModelBudgetCatalog.ts`：增加 `0.149.0 + gpt-5.6-sol` 精确预算，
  context 为 1,050,000，reserved output 为 128,000，来源标记为 OpenAI 官方模型目录。
- `docs/architecture/ZARCH-050-052_Memory与上下文治理.md`：同步精确回退边界，明确仍按 CLI 版本与完整模型 ID
  双键匹配。
