# TASK_20260825_004 子智能体会话展示与关联会话时间语义修复

## 用户问题

1. Subagent 详情使用独立扁平列表逐条渲染 Provider item，导致普通会话已有的轮次分组、处理过程折叠、活动聚合和终态思考摘要隐藏规则全部失效；大量“文件变更 / 技术详情”和英文 reasoning 直接铺满页面。
2. 任务详情的关联会话直接显示 `conversations.updated_at`。打开历史会话会触发水合、Provider 元数据和 Token 快照回填，这些维护动作会推进该字段，所以界面把“最近一次被维护”误写成“会话时间”。

## 已确认口径

- Subagent 仍是只读独立线程，但转录展示必须复用普通会话的同一套投影：同轮操作聚合，完成轮次的过程默认折叠，终态 reasoning 不回显，最终正文和交付资源保持在过程之后。
- 关联会话时间表示最近一次真实会话活动，取会话创建、消息、轮次、提交、用户请求和计划确认中的最新时间；被取消或删除的提交只保留用户最初发起时间，不使用后续批量收口时间。打开、水合、统计刷新、权限配置和归档维护不参与。
- 点击“打开会话”只导航和读取，不应改变任务详情可见时间。

## 方案与取舍

- Subagent 详情把自身 turns/items 投影成只读 `NativeSessionState`，直接复用 `ConversationTranscript`。优点是普通会话与子线程永久共享分组和终态规则；缺点是需要维护一层只读状态适配，但不复制第二套 UI 算法。
- 活动时间在 Storage 通过已有索引按需派生，不新增 25 GB 正式库的数据迁移，也不让历史水合时间污染结果。优点是旧数据立即正确；缺点是会话列表读取多一次轻量聚合查询。

## 验收计划

- 源码核对 Subagent 终态、进行中态、文件变更聚合和 reasoning 投影。
- 用正式库只读查询记录 ZEUS-0315 各关联会话的维护时间与真实活动时间差异。
- 使用独立数据目录的 `Zeus Test.app` 验证 Subagent 分栏/全宽详情及任务关联会话时间；打开一条会话前后时间必须一致。
- 通过 `pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm package:mac` 与 `git diff --check`，不引入单元测试体系。

## 2026-08-25 补充：子智能体任务指令可见性

### 新增问题

子智能体详情虽然已经复用普通会话转录，但页面只展示执行过程和最终回复，没有说明该智能体究竟接收了什么任务。用户无法区分“子任务指令”和“从父线程继承的主任务上下文”。

### 现场证据与边界

- Sartre 子线程 `01a037f4-f903-7861-938d-bad5f37f3a0b` 的 Provider 状态库确认其来源是父线程派生，路径为 `/root/renderer_contract_review`。
- 子线程 JSONL 中存在发给该智能体的 `NEW_TASK` 协作消息，但正文按 Provider 规则保存为 `encrypted_content`；当前 `thread/read` 和 `thread/list` 没有返回可验证的原始子任务正文。
- Provider 状态库的 `preview / first_user_message` 是继承的 `# 代码审查任务` 主任务提示词，不是 Renderer 子任务原文。它可以作为“上层任务上下文”展示，但不得冒充子任务指令。
- Zeus 正式会话投影只保留了后续 `collabAgentToolCall: wait`，没有该历史线程的 `spawn` 事件，因此不能从现有数据库倒推出明文。

### 修复方案

- 子智能体详情新增首屏“任务指令”区域，位于运行信息和转录正文之前。
- 新增结构化 `taskInstruction` 契约：优先读取 Zeus 已持久化的 `collabAgentToolCall` 创建指令，其次读取 Provider 未来可能在子线程 source 中直接给出的明确指令字段。
- 无权威原文时返回 `unavailable`，界面明确显示“原始子任务指令不可读取”；不再用 `preview` 代替。
- 新增独立 `inheritedContext` 契约，Provider 的主任务预览放入“查看上层任务上下文”折叠区。
- 列表摘要补读 Provider source 中的 `agent_path`，历史线程缺少活动投影时仍能显示真实子智能体路径。

### 取舍

- 优点：语义真实、历史缺失失败关闭；新协议或新事件提供明文后无需改 UI 即可展示完整原指令。
- 缺点：Provider 没有暴露明文的旧线程无法补写，只能如实显示不可读取；Zeus 不尝试自行解密 Provider 的私有持久化内容。

### 补充验收

- 历史缺失态：显示“原始子任务指令不可读取”，上层上下文保持折叠，不把主任务提示词放进子任务正文。
