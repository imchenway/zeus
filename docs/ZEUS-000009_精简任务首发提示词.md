## 最终目标

Zeus 发起正式任务会话时，用户输入只包含：

1. 任务标题；
2. 任务描述；
3. 任务附件。

不再把任何固定系统话术、项目配置或来源上下文 JSON 拼进用户消息。

当前任务的目标可见内容为：

```text
任务标题：从 Zeus 发出去的描述太冗长了，去除多余的提示词
任务描述：未提供
```

图片继续作为独立附件发送并显示附件卡片，不在正文中复制附件路径、名称、MIME、大小或 JSON。

## 被否决的旧方案

上一版方案在任务描述为空时省略描述，又过滤了来源字段，导致当前任务只剩标题和一行固定底线。用户已明确指出这是裁剪过度，该口径已经撤销，不得实施。

以下概念不再属于本任务目标：

- “有效来源上下文”；
- 一行真实性底线；
- 根据 Adapter 决定是否把工作模式写入正文；
- 项目名、项目路径或项目默认提示词的正文副本。

## 真实依据

### 改动前冗长文本来自 prompt builder

基线提交中 `packages/ai-runtime/src/index.ts` 的 `buildAiRuntimePrompt()` 拼接：

- AI Runtime 固定身份；
- 固定真实性要求；
- 项目名与项目路径；
- 任务标题；
- 任务描述或“未提供”；
- 完整 `sourceContext` JSON；
- 项目默认工作模式与默认任务提示；
- 显式要求或默认执行要求。

截图中的文本顺序与该 builder 一致，问题发生在发送前组装，不是消息气泡渲染。

### Codex 附件已有独立传输

- `packages/local-server/src/index.ts:11771-11817` 从任务记录校验并构造附件数组。
- `packages/local-server/src/index.ts:11056-11075` 把 `prompt` 与 `attachments` 分别传给 native coordinator。
- `packages/local-server/src/codexNativeConversationCoordinator.ts:775-800` 把消息 input、协作模式、cwd、审批和 sandbox 分字段发送给 app-server。

因此 Codex 用户正文无需复制附件 JSON，也无需复制运行配置。

### 非 Codex Adapter 的真实限制

Claude、Gemini 和 Generic 当前通过 CLI prompt 启动，没有与 Codex native 相同的结构化附件输入。实施时必须明确处理附件：只允许在 Adapter 真实支持的情况下发送附件；不得静默丢弃，也不得重新把完整 `sourceContext` JSON 塞回正文。若当前 Adapter 不支持附件，应返回真实不支持状态。

## 目标契约

### 正文

正文固定为两个字段：

```text
任务标题：{task.title}
任务描述：{task.description 非空时使用原文，否则使用“未提供”}
```

本次推送补充信息如果继续保留，应合并进“任务描述”，不能形成第四类提示词字段。

### 附件

- Codex native：使用现有结构化附件数组。
- 正文和会话摘要不得复制附件 JSON。
- 附件缺失、越界、格式不支持时保持现有 fail-closed 行为，不创建缺附件的伪完整会话。
- 非 Codex Adapter 没有真实附件能力时明确拒绝或显示不支持，不能假装附件已发送。

### 明确删除

- `你是 Zeus 本地优先 AI 研发工作台中的 AI Runtime。`；
- 固定真实性提示；
- 项目名；
- 项目路径；
- 来源上下文；
- 项目默认工作模式；
- 项目默认任务提示词；
- 默认执行要求；
- 任务正文中的附件元数据或 JSON。

运行所需 cwd、权限、sandbox、协作模式和附件授权继续通过已有结构化参数或 Runtime 启动参数传递，但不展示成用户输入。

## 方案优缺点

优点：

- 用户消息只表达用户确认的三类任务内容；
- 当前空描述任务仍明确显示“任务描述：未提供”，不会退化成只有标题；
- 附件卡片与正文职责清晰，不再重复路径和 JSON；
- Codex 的 cwd、权限和协作模式仍走真实结构化协议。

缺点：

- 项目默认任务提示词不再影响正式任务首发；如果产品仍需要该配置，必须另行定义非用户消息的传输位置，不能借本任务继续塞回正文。
- 非 Codex Adapter 当前缺少结构化附件能力，带附件任务可能需要明确阻断，直到对应 Adapter 提供真实附件协议。
- 图谱或 Runtime 派生任务的 `sourceContext` 不再自动进入首发；需要执行的信息必须已经写入任务描述或作为任务附件提供。

不创建 ADR：该变化是可回退的消息组装策略，不满足“难以逆转”的条件。

## 实施计划
