# ZEUS-000012 会话当前目录与分支显示

## 问题

任务 `ZEUS-000012` 已在独立 worktree 和分支中创建会话，但首条任务内容同时包含项目主路径。会话实际 `cwd` 正确时，界面没有直接展示执行目录和分支，用户无法在开始工作前发现模型是否错误切回主工作区。

## 真实依据

- 当前任务 worktree：`/Users/david/hypha/.zeus-worktrees/zeus-e2e-oBLuqT/ZEUS-000012/611f32223bc30039`。
- 当前任务分支：`zeus/ZEUS-000012-task-01`。
- `packages/local-server/src/index.ts` 的任务推送链路把 `workspace.worktreePath` 作为 `projectLocalPath` 传入原生会话。
- `packages/local-server/src/codexNativeConversationCoordinator.ts` 把 `projectLocalPath` 持久化到 submission context，并在 `thread/start`、`thread/resume` 和 `turn/start` 中作为 `cwd` 发送。
- 会话页现有 `SessionRuntimeDetails` 已在标题下展示模型、服务档位与 Token 用量，但未展示 cwd 和分支。

## 领域与显示规则

“会话执行现场”由两项事实组成：

1. 当前目录：从会话持久 submission context 的 `projectLocalPath` 读取，不从项目记录或任务来源上下文猜测。
2. 当前分支：Local Server 在返回会话快照时，对上述目录执行只读 Git 查询；目录不存在或不是 Git 仓库时明确显示“非 Git 目录”。

任务工作区记录只作为旧数据缺少 submission context 时的目录回退，不用记录中的 `branchName` 冒充当前 Git 分支。任务会话同时缺少持久目录和工作区记录时显示“不可用”，不能回退到项目主路径；普通项目会话仍以项目本地路径作为其配置执行根。

## 修改范围

- `packages/git-core/src/index.ts`：增加只读工作目录 Git 分支查询。
- `packages/local-server/src/index.ts`：向原生会话快照加入 `executionContext`。
- `apps/desktop/src/renderer/session/sessionTypes.ts`：声明会话执行现场类型。
- `apps/desktop/src/renderer/session/SessionWorkspace.tsx`：在 Token 用量下一行展示当前目录与当前分支。
- `apps/desktop/src/renderer/session/session.css`：为两行 Runtime 摘要增加长路径省略和窄屏约束。
- `CONTEXT.md`、`DESIGN.md`：固化“会话执行现场”术语和界面契约。

## 优缺点

优点：

- 用户进入会话即可核对真正执行目录和分支。
- 展示值来自持久会话上下文和真实 Git 查询，不依赖 prompt 文案。
- 长 worktree 路径保留完整 tooltip，并在有限宽度内省略，不挤压状态操作。

代价：

- 每次读取原生会话快照会增加两次轻量只读 Git 子进程调用。
- 分支是快照读取时的状态；外部切换分支后，需要下一次会话快照刷新才能更新界面。
