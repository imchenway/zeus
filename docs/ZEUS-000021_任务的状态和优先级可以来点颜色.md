# ZEUS-000021 任务的状态和优先级可以来点颜色

## 当前阶段

实现与验证已完成：任务状态和优先级采用低饱和轻底标签，运行状态复用会话列表动效。

## 原始需求

- 任务标题：任务的状态和优先级可以来点颜色
- 任务描述：未提供

## 已确认边界

- 任务管理状态、Coding Agent 运行状态和任务优先级都需要颜色辅助。
- 三类字段继续显示完整文字，颜色不是唯一识别手段。
- 任务管理状态与运行状态仍是两套独立事实，不能因为共用颜色而合并语义。
- 任务优先级 P0 至 P4 只表达处理顺序，不自动启动会话或执行轮次。
- 用户确认除运行状态动效外其余视觉方案无异议；运行状态必须与会话列表动效一致。

### 方案 A：轻底标签（推荐）

使用低饱和浅底、同色文字和细边界。优点是扫读明显、适合长时间使用，并能在浅色和深色主题中维持稳定层级；缺点是对极弱显示器或强光环境的强调度有限。

### 方案 B：左侧色标

使用窄色标配合普通文字，不铺设标签底色。优点是最克制、表格视觉密度最低；缺点是颜色面积小，快速扫读能力弱于方案 A。

### 方案 C：符号强调标签

使用更明显的色块和符号。优点是优先级和异常状态最醒目；缺点是色彩噪音最高，状态较多时容易形成“彩色后台”观感。

## 最终方案

- 采用方案 A 的低饱和轻底标签，保留完整状态文字和优先级文字。
- 任务管理状态：待开始、已取消使用中性色；开发中使用蓝色；测试中使用紫色；待验收使用琥珀色；已阻塞使用红色；已完成使用绿色。
- 运行状态：连接、重连、运行中使用蓝色；等待用户、等待授权、暂停使用琥珀色；失败使用红色；空闲使用绿色；未启动和旧会话只读使用中性色。
- 优先级：P0 红色、P1 橙色、P2 琥珀色、P3 蓝色、P4 中性色。
- 连接、重连、运行中、等待用户和等待授权复用会话列表的 `CircleNotch` 旋转标记及 `session-conversation-state-spinner` 样式；其他状态不播放动效。
- 系统开启“减少动态效果”时，运行状态标记停止旋转，文字和颜色仍可识别状态。

优点是任务页与会话列表对同一运行事实使用同一动效，扫读更快且没有重复维护两套动画；缺点是活跃状态会比静态状态更醒目，需要严格限制只有真实活跃或等待状态才播放。

## 本轮实现范围

- 修改浏览器批注所指向的任务表：任务状态下拉触发器、运行状态、优先级列。
- 更新交互式 HTML 对比稿，使运行中和等待用户回复显示与会话列表一致的 900ms 匀速旋转标记。
- 任务详情和创建任务弹窗不在本轮批注指向的页面范围内，暂不扩张改动；后续如需全入口统一，可复用本轮语义色规则。
