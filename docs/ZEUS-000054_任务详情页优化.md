# ZEUS-000054 任务详情页优化

## 任务目标

1. “最近事件”和“任务事件”不再展示 `task.*` 等内部事件编码。
2. 任务详情内的即时保存字段不再展示“正在保存”和“已保存”文字。

## 共同口径

- 调整范围覆盖任务状态、优先级、标题、说明、标签和附件。
- 保存中在当前控件内显示小型加载动效，并临时阻止重复操作。
- 保存成功后不再增加独立文字，字段的最终值就是结果反馈。
- 保存失败或发生并发冲突时，继续显示原因、重试和载入最新值入口。
- 内部事件编码仍保留在数据与审计链路中，只从任务详情的可见界面移除。

## 方案权衡

### 优点

- 页面不再因短暂的保存文案产生跳动，信息噪音更低。
- 加载动效与正在操作的控件绑定，用户仍能判断当前操作尚未结束。
- 事件区只保留标题和时间，阅读更直接。

### 代价

- 成功后没有额外确认文字，用户需要从字段最终值判断结果。
- 事件编码不再可直接从页面复制；需要排障时仍应从本机数据或审计记录查看。
