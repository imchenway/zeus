# ZEUS-000057 默认选中上次选中的来源分支

## 任务目标

用户在“推送到新会话”弹窗中新建任务环境时，每个仓库的来源分支默认选中该项目下该仓库最近一次成功使用的来源分支，减少重复选择。

## 已确认边界

- 来源分支偏好按“项目 + 仓库”分别记忆，并在应用重启后继续有效。
- 只有新会话真正启动成功后才更新偏好；取消弹窗、创建失败或消息尚未发送都不更新。
- 复用已有任务环境时没有实际使用新的来源分支，因此不改写来源分支偏好。
- 记忆中的分支已经不在当前本地分支列表时保持未选择，继续要求用户手动确认，不猜测其他分支。
- 来源分支偏好只影响下次新建任务环境的表单默认值，不改变已有任务工作区冻结的来源分支和来源提交。

## 方案与取舍

沿用现有任务推送本机偏好，不新增数据库表或服务端接口。偏好对象增加按仓库标识保存的来源分支映射；打开弹窗读取真实仓库分支列表后，只恢复仍然存在的值。

优点：改动集中、沿用现有“首轮成功后保存”的事实链，并且天然支持多仓项目逐仓记忆。

代价：偏好属于当前设备的 Zeus 用户数据，不跨设备同步；仓库重新登记后如果仓库标识发生变化，会被视为新仓库并要求重新选择一次。
