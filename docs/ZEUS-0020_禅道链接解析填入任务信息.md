# ZEUS-0020 禅道链接一键解析并自动填入任务信息

## 目标

在创建任务弹窗中粘贴禅道缺陷/需求/任务详情页链接，一键解析并自动填入标题、任务类型与正文草稿，减少手动搬运信息。

## 范围与假设

- 首轮只解析链接与页面内容；第二轮升级为 REST 优先：按链接 host 匹配已配置实例时先走禅道 REST API，失败自动回退 HTML 抓取；不写入禅道数据。
- 识别现代路径 `/bug-view-123.html` 与旧版参数 `?m=bug&f=view&bugID=123` 两种链接形式。
- 类型映射：禅道缺陷 → Zeus 缺陷；禅道需求、任务 → Zeus 需求（Zeus 无独立“任务”类型）。
- 优先级不自动映射：禅道各版本优先级口径不一致，避免错误暗示；后续有真实实例时可补充。

## 实现

- `packages/shared/src/index.ts`：`parseZentaoTaskUrl`、`extractZentaoTaskLink`、`zentaoTaskType` 与 `ZentaoTaskExtract` 类型。
- `apps/desktop/src/main/zentaoTaskExtract.ts`：主进程抓取页面（先默认会话，再内置浏览器会话复用登录 cookie），检测登录页，解析 `<title>` 与正文字段标签，返回可填入表单的字段。
- IPC `zeus:zentao:parse-link` 经 preload 暴露为 `window.zeus.parseZentaoTaskLink`。
- `TaskCreateModal` 新增“禅道链接”输入行：粘贴链接自动解析（标题栏直接粘贴链接同样触发），按钮与 Enter 可手动重试；成功、需登录、非禅道链接、失败四种提示状态。
- 字段填入策略：缺陷填现状/复现步骤/预期；需求与任务填描述；非空覆盖，保留用户已填的父任务、优先级、标签与附件。

## 已知限制

- 外部浏览器（Chrome/Safari）中的禅道登录态无法复用；仅复用 Zeus 内置浏览器会话。
- REST 访问令牌只存在主进程内存、不落盘；应用重启或实例密码变更后解析时重新换取。
- REST 仅对「host 匹配且已配置账号密码」的实例生效；同 host 只保留一个实例配置。
- 禅道页面结构差异较大，正文按常见字段标签（重现步骤/描述/期望结果等）尽力提取，其余内容保留原文供人工调整。

## 第二轮：凭据配置与 REST 优先解析（2026-08-20）

### 设计

- 设置页新增「集成 → 禅道」分类，支持配置多个禅道实例，按链接 host 自动匹配。
- 账号密码分离存储：实例地址、basePath、账号存本地 SQLite settings（键 `zentao.instances`）；密码只写入 macOS 钥匙串（服务名 `Zeus`，账户名 `zentao:<实例 id>`）。列表/详情响应只含元数据与 `passwordConfigured` 状态，密码永不出主进程，日志不落凭据。
- 允许实例只配置地址不配置账号：解析走 HTML 抓取路径，保持首轮行为；账号为空时密码输入禁用，保存会自动清除该实例旧密码。
- 解析链路 REST 优先：`POST /api.php/v1/tokens` 用账号密码换 token（仅内存），`GET /api.php/v1/{stories|bugs|tasks}/{id}` 带 `Token` 头取详情；详情 401/403 自动重换一次 token 再试。REST 失败（凭据无效、接口未开启、404、网络失败）一律回退现有 HTML 抓取，登录页场景沿用 `login_required` 提示。
- 解析状态扩展：`ZentaoTaskExtract.failed` 增加可区分原因 `credential_missing` / `auth_failed` / `network`，`ok` / `login_required` / `failed` 原有形状不变，现有调用方无需改动。
- REST 字段映射沿用首轮口径：需求 `title/spec/verify` → 标题/描述；缺陷 `title/steps`（按 `[步骤][结果][期望]` 分段）→ 标题/复现步骤/现状/预期；任务 `title/desc` → 标题/描述。任务类型映射不变（缺陷 → 缺陷；需求、任务 → 需求）。

### 实现

- `packages/shared/src/index.ts`：`ZentaoInstanceRecord`、`SaveZentaoInstanceRequest`、`ZentaoInstanceVerifyResult`、`zentaoSecretAccount`、`parseZentaoInstanceBaseUrl`、`zentaoInstanceApiBase`，及 `ZentaoTaskExtract` 失败原因扩展。
- `packages/local-server/src/zentaoCredentialService.ts`：SQLite 元数据 + SecretStore 密码分离读写、换 token 验证登录；路由 `GET/POST/PUT/DELETE /api/zentao-instances`、`DELETE /api/zentao-instances/:id/password`、`POST /api/zentao-instances/:id/verify`。
- `apps/desktop/src/main/zentaoApi.ts`：`exchangeZentaoToken`、`fetchZentaoDetail`、`attemptZentaoRestDetail`（token 仅内存，12 秒超时）。
- `apps/desktop/src/main/zentaoTaskExtract.ts`：`extractZentaoTaskInfo` 增加实例匹配与 REST 优先/回退；`main.ts` 的 `zeus:zentao:parse-link` 注入 `loadZentaoExtractServices()`，preload 签名不变。
- `apps/desktop/src/renderer/settings/ZentaoSettingsPane.tsx`：实例列表（地址、账号、密码状态徽标）、新建/编辑/删除、验证登录、清除密码；删除确认明确提示「删除后会失去该实例配置，任务解析将回退为浏览器登录或手动填写。」。
- `TaskCreateModal` 状态行区分提示：未配置密码 → 引导去设置补全或内置浏览器登录；凭据失效 → 引导检查账号密码；网络失败 → 沿用原有提示；https 链接保留「在浏览器中打开」入口。
