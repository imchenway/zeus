# ZEUS-0058 你这都是些什么玩意儿在里面

## 任务背景

用户在项目图谱扫描完成后提供真实截图：系统架构图画布为空，页面同时显示“已加载 16 个节点 / 20 条关系”；打开图谱问答工具后，搜索历史和会话内容被挤成单字纵排。需求描述为“拉完了”，结合截图判断，目标是修复扫描完成后的真实图谱呈现，而不是重新触发扫描或伪造数据。

## 故障链

1. 图谱引擎把 workspace `package.json` 识别为 `package` 节点，并把这些节点放入系统架构视图。
2. 分层架构画布只适用于已经形成 Maven/Spring 层级的 `module` 和运行组件，不适合直接表达同层 workspace package 依赖。
3. Zeus 自身是 TypeScript workspace；16 个真实 package 节点没有形成 Maven/Spring 分层，因此分层模型只剩项目标题推导出的边界，界面显示“1 个架构对象”，画布也只剩空边界。
4. `GraphCanvas` 对所有 `architecture` 视图无条件启用分层画布，即使分层模型没有任何业务、共享或基础模块，也没有回退到通用真实关系图。
5. 图谱问答工具的宽度最多为 420px，但内部仍使用面向整页的双列、三列布局；响应式规则只看窗口宽度，不看浮层宽度，所以在宽窗口的窄浮层内发生横向挤压和逐字换行。

## 修复方案

### 架构图

- 新增分层模型可渲染判断：至少存在一个真实业务、共享或基础模块时才使用分层画布。
- 如果扫描结果不满足 Maven/Spring 分层模型，保留相同真实节点和关系并回退到通用关系图，不再显示空项目边界，也不把 workspace package 误称为“共享契约”。
- 顶部可见数量和底部状态栏与实际采用的画布一致；分层不可用时显示真实节点与关系数量。

优点：TypeScript workspace 能完整看到 package 依赖，Maven/Spring 项目继续使用分层画布；识别不足时仍有可靠降级。缺点：不同技术栈的系统架构图会采用不同画布表达，但不会伪造统一外观。

### 图谱工具

- 图谱工具浮层内的问答、历史搜索、历史行和详情固定按浮层宽度单列排版。
- 操作按钮从右对齐改为从左顺排，输入和正文明确允许收缩与换行。

优点：不依赖整个应用窗口断点，浮层在宽屏和窄屏下都可读。缺点：工具内纵向长度会增加，但浮层已有独立纵向滚动，不会挤压主画布。

## 修改范围

| 文件 | 修改内容 |
|---|---|
| `apps/desktop/src/renderer/graph/ArchitectureGraphCanvas.tsx` | 提供分层模型可渲染判断，避免只有项目边界时继续使用分层画布。 |
| `apps/desktop/src/renderer/App.tsx` | 复用已计算的分层模型；模型不足时回退通用真实关系图。 |
| `apps/desktop/src/renderer/styles.css` | 收敛图谱工具浮层内部问答与历史布局。 |

不修改扫描接口、图谱数据库、缓存、Git 流程和打包身份；不会丢弃或重写已经拉取的图谱数据。

## 验证口径

- 静态质量：`pnpm lint`、`pnpm typecheck`、`pnpm build`、`git diff --check`。
- 真实渲染：系统架构视图只有 workspace package、分层模型只剩项目边界时，必须回退到通用节点关系图并保留真实关系。
- 浮层布局：图谱问答工具打开后，搜索历史标题、输入框、按钮和会话正文不得逐字纵排或横向溢出。
- 主题与交互：浅色、深色、跟随系统继续使用现有语义 token；键盘焦点、Escape 关闭和减少动态效果行为不变。

## 风险与回滚

- 风险：workspace 架构视图会从分层图变为通用关系图。该变化是明确降级，优先保证真实节点与依赖同时可见。
- 回滚：还原上述三个前端文件即可；没有数据库或数据迁移需要回滚。

## 实施与验证记录

### 已实施

- `CodeMapView` 只在分层模型至少包含一个真实业务、共享或基础模块时把模型传给分层画布。
- `GraphCanvas` 在 `architecture` 视图没有可用分层模型时继续走既有通用 SVG 关系画布，因此真实节点、关系、平移、缩放、小地图、节点选择和关系选择能力都保留。
- 图谱工具浮层内的问答、历史搜索、历史行和详情使用局部单列布局，不再依赖整个窗口小于 860px 才收敛。

- 全仓 `pnpm format:check` 未通过，失败清单是当前分支原有的 34 个文件，本次修改的两个 TypeScript 文件不在清单；没有批量格式化无关文件。仓库的全仓格式脚本不检查 CSS，新增 CSS 已用现有代码风格人工复核。
- 使用 Zeus 内置浏览器打开临时视觉检查页后，最终页面的快照、截图和关闭调用连续超时，已终止调用并删除临时检查文件；没有改用外部 Playwright。
