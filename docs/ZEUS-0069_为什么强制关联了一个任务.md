# ZEUS-0069 为什么强制关联了一个任务

## 结论

截图中的任务并没有真正关联 ZEUS-0001。关联任务数量为 0，“添加关联”按钮也处于禁用状态；问题是关联任务下拉框把第一个候选项错误显示成了当前值。

## 根因

关联任务选择状态初始值为空字符串，表示用户尚未选择任务。共享 `ZeusSelect` 在受控值找不到匹配选项时，会回退显示 `options[0]`，所以界面显示了第一个候选任务，但没有改变选择状态，也没有发起关系保存请求。

## 修改

- 共享 `ZeusSelect` 只在受控值确实匹配选项时显示选中项，不再把第一个选项当作兜底值。
- 关联任务下拉增加“请选择要关联的任务 / Select a task to relate”禁用占位项。
- 删除父任务时的替代父任务下拉增加对应禁用占位项，并在没有候选时禁用控件，避免出现同类误导。
- 任务关系接口、数据库结构、双向关联和保存时机保持不变；只有用户选择任务并点击“添加关联”才会建立普通关联。

## 验收口径

- 无关联任务时显示占位文案，不显示第一个候选任务。
- 初次打开详情或下拉不会发起关系 PATCH 请求。
- 用户选择候选任务后，关联数量仍保持不变；点击“添加关联”后才更新数量和列表。
- 已有关联、无候选任务、删除父任务、中文/英文、键盘操作和窄抽屉场景不再出现误导性预选。
