# ZEUS-0073 进行中会话切换与回答历史显示

## 任务目标

修复会话页的三个连续交互问题：

- 切换到进行中会话后没有直接显示底部最新内容；
- 发送消息后没有自动显示刚发送的最新消息；
- 回答普通用户询问后，对话历史缺少已折叠的问题和用户答案。

## 当前阶段

产品边界已确认，业务代码已实现；静态门禁、测试身份打包和真实 Renderer 交互验证通过。完整桌面应用界面验收被另一任务正在运行的同身份 `Zeus Test.app` 单实例占用阻塞。

## 已确认口径

### 会话切换与最新消息跟随

- 每次打开、切换或重新切回任一已有会话，都忽略上一次离开时的阅读位置，首帧直接显示最新消息；
- 用户停留在当前会话底部时，自己刚发送的消息和随后新增的智能体内容持续保持可见；
- 只有用户在当前会话主动上滚阅读历史后才暂停自动跟随，并保留“返回最新消息”入口；
- 切换会话不继承上一会话或上一次停留形成的暂停跟随状态。

优点：切回进行中会话立即看到真实进展，发送后也能马上确认自己的消息已经进入对话。

缺点：用户离开前正在阅读的历史位置不会在下次切回时恢复。

### 已回答询问记录

- 普通（非敏感）用户询问提交后，必须在对话时间线保留一条已回答询问记录；
- 记录默认折叠，摘要同时显示问题和用户实际提交的答案；
- 用户可以展开查看完整问题与实际答案；
- 一次询问包含多个问题时只形成一条折叠记录，展开后按 provider 原顺序展示全部问答；
- 已回答记录只用于回看，不重新创建普通用户消息，也不能再次提交。

优点：问题、回答和后续智能体处理保持连续，默认折叠不会让长会话被问答卡淹没。

缺点：Renderer 需要从持久事实中恢复已解决请求，并与仍待回答的底部交互坞区分。

- 无。

## 既有安全约束

- “敏感问题”不是本任务新增分类，也不由 Zeus 根据问题内容或关键词推断；它来自 Codex canonical `request_user_input` 每题必填的 `isSecret` 字段；
- 当前存储层对包含敏感题目的响应只保存脱敏摘要，真实答案不会进入会话记录或草稿；
- 已回答询问记录可以保留敏感问题的题目，但答案位置只显示“敏感回答已提交”，不得保存、回显或尝试恢复真实答案。

## 已核对事实

- `CONTEXT.md` 和既有 `ZEUS-000024` 已定义会话初始阅读位置固定为最新消息；
- 当前 `ConversationTranscript` 缺少既有任务记录中的首次历史就绪后即时定位逻辑；
- 当前滚动控制器会把距离底部超过阈值的进行中会话判为历史阅读状态，随后消息不再自动跟随；
- 普通用户询问当前只占用底部交互坞，解决后交互坞卸载，尚未形成可见的已回答历史投影。

## 实现记录

### 会话滚动

- 历史快照首次可用后，在浏览器绘制前以无动画方式把会话容器定位到真实末尾；
- 用户新发送消息时显式恢复最新消息跟随，并立即定位到底部，不再让此前的历史阅读状态或平滑动画压住本次明确发送动作；
- 后续智能体增量继续遵守“停留底部自动跟随、主动上滚暂停”的既有状态机；
- 减少动态效果下使用即时滚动，避免 `scroll-behavior: smooth` 让 `auto` 仍产生滑动。

### 已回答询问历史

- 复用权威会话快照已经返回的 resolved server request，不新增数据库表或第二事实源；
- Renderer 把已解决的 canonical `request_user_input` 与普通消息按时间合并，默认折叠显示问题和答案摘要；
- 一次请求只形成一条记录，多问题在展开区按原顺序展示；
- 历史记录不可再次提交，不伪装成普通用户消息。

### 敏感答案

- 新解决的混合问卷只把 `isSecret: false` 的答案写入 `publicAnswers`；敏感题答案继续只保留计数和脱敏标记；
- 历史全量脱敏记录没有 `publicAnswers` 时显示“回答已提交，历史内容已脱敏”，不推断或恢复原答案；
- 请求重放仍以 `containsSecret` 拒绝恢复敏感答案，不改变既有安全门禁。
