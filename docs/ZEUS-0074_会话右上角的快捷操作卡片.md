# ZEUS-0074 会话右上角的快捷操作卡片

## 任务目标

参考用户提供的 Codex App 环境信息卡，在 Zeus 会话右上角增加一个紧凑入口，把当前会话的执行目录、真实 Git 分支、工作区变更、提交、推送、分支比较和会话来源集中到同一处。

## 产品边界

- 卡片只汇总已有真实事实和已有能力，不在 Renderer 执行 Git 命令或猜测工作区状态。
- 当前目录与分支继续以会话快照的 `executionContext` 为权威；任务工作区只补充变更、来源分支和操作入口。
- “变更”和“提交或推送”复用既有任务 Git 审查弹窗，保留格式化、冲突阻断、远端校验和活动会话风险提示。
- “比较分支”复用既有代码交付入口，不在卡片中创建第二套合入流程。
- 项目自由对话没有任务工作区时仍展示执行目录与分支，但 Git 写操作保持不可用并说明真实边界。
- 来源来自当前输入附件和会话中已有的结构化资源；添加来源复用会话附件授权流程。

## 方案取舍

优点：

- 用户无需离开会话即可核对执行现场并进入已有 Git 主路径。
- 卡片不会绕开提交、推送或合入安全门禁，也不会因为远端读取失败阻断本地目录与分支展示。
- 窄窗口下入口收敛为图标，卡片保持在当前会话上方，不挤压对话内容。

代价：

- 首次打开任务卡片需要读取一次本地任务工作区快照，变更统计会短暂显示加载状态。
- “本地”和“分支”是当前会话执行事实，不提供会话中途切换；切换工作区会改变执行现场，仍应通过创建或选择正确会话完成。
- 卡片只展示结构化来源，普通正文中的任意 URL 不会被当作来源收集。

## 实现范围

- `SessionQuickActionsCard.tsx`：卡片交互、真实工作区加载、变更统计、来源汇总和键盘关闭。
- `SessionWorkspace.tsx`：把卡片挂到会话标题右侧，并向卡片提供现有会话与 Git 动作。
- `App.tsx`：把任务工作区读取、提交/推送弹窗和代码交付入口传入会话组件。
- `session.css`：卡片在浅色、深色、窄窗口和减少动态效果下的样式。
