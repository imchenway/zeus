# ZEUS-0086 任务列表运行状态会话抽屉

## 当前阶段

已完成源码、文档、整仓静态检查、构建、独立测试身份打包和真实 `Zeus Test.app` 界面验收。

## 任务目标

任务列表的运行状态有真实来源会话时，点击后不再切换到会话页，而是在任务列表上层打开对应会话的宽抽屉。用户可以在抽屉中查看并继续完整会话，关闭后回到原任务列表现场。

## 用户确认

- 抽屉承载完整会话交互，不是只读预览。
- 点击运行状态后继续停留在任务列表，不切换主导航或页面地址。
- 同一任务关联多个会话时，继续打开当前运行状态所依据的最近更新会话，不增加二次选择。
- 抽屉支持查看消息、继续输入、回答问题、审批和停止当前执行。
- 关闭抽屉不停止会话，并保留任务筛选、滚动位置和选中状态。
- “未启动”没有对应会话，继续显示为不可点击状态，不创建会话。

## 源码事实

- `resolveTaskAgentRunStatusConversation()` 已统一解析运行状态及其最近关联会话，状态与入口目标来自同一事实。
- 当前 `TaskWorkspace` 点击运行状态会调用 `openTaskConversation()`；后者选择会话后切换到会话页并改写页面地址。
- 会话页根据会话类型使用 `ConnectedSessionWorkspace` 或 `SessionWorkspace` 展示完整交互，但当前渲染分支只属于会话页。
- `WorkspaceDrawer` 已具备遮罩、自动聚焦、Escape 关闭和关闭后焦点恢复能力，可承载新的会话抽屉。

## 实现设计

1. 为任务列表运行状态增加独立的会话抽屉打开处理，只记录准确的任务和会话身份，不复用会话页导航动作。
2. 从当前会话页分支提取可复用的会话工作区渲染路径，让会话页和抽屉消费同一状态、缓存与操作，不复制一套会话逻辑。
3. 抽屉打开时选择对应真实会话并加载必要内容，但不修改主导航、项目分区或页面地址。
4. 抽屉使用宽尺寸和完整会话布局；加载、错误、只读历史与原生可继续会话沿用现有真实状态。
5. 关闭抽屉只清理抽屉展示状态，不中断执行、不清除已加载会话，也不改变任务列表现场。

## 取舍

### 完整交互抽屉

- 优点：用户无需离开任务列表即可查看进展并立即处理回答、审批或停止，处理多个任务时上下文切换更少。
- 缺点：抽屉内容较重，必须复用现有会话状态与缓存，否则容易出现会话页和抽屉状态不一致。

### 不采用只读预览

- 优点：只读预览实现更轻，抽屉职责更单一。
- 缺点：用户看到待处理状态后仍需跳到会话页操作，多一步导航，不符合本次优化目标。

### 不继续沿用会话页跳转

- 优点：整页会话拥有最大内容宽度，现有实现路径成熟。
- 缺点：会丢失任务列表的当前工作现场，连续处理多个运行状态时来回切换成本高。

## 验收口径

- 点击有真实来源会话的运行状态后，任务列表保持在原页面，右侧打开对应会话抽屉。
- 抽屉中的会话身份与运行状态使用的最近关联会话一致。
- 原生可继续会话可以查看消息、输入、回答、审批和停止；历史只读会话保持真实只读状态。
- 抽屉加载失败时展示可理解的错误状态，不跳页、不伪造会话。
- 关闭按钮、Escape 和点击遮罩可以关闭抽屉，并把焦点还给原运行状态入口。
- 关闭抽屉不停止活动执行；再次打开能继续显示最新真实状态。
- 点击任务行其他区域仍打开任务详情抽屉；“未启动”不可点击且不创建会话。
- 不新增或恢复单元测试、组件测试、DOM/CSS 契约测试和 TDD 流程。
- `pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm package:mac` 与真实 `Zeus Test.app` 检查分别记录，不能互相冒充。
