# ZEUS-0101 选项框的优化

## 任务目标

收敛普通用户询问的布局、输入、键盘和反馈行为，解决按钮覆盖、双输入区并存、文字错位、悬停表面重叠和点击反馈迟缓。

## 已确认口径

- 普通用户询问显示期间暂时隐藏底部普通会话输入框；回答、跳过或关闭后恢复。
- 点击自定义回答的铅笔或输入行任意位置都会启用并聚焦输入。
- Enter 提交当前询问答案，Shift+Enter 换行；中文输入法选字期间的 Enter 不提交。
- 跳过和提交回到输入行下方的正常布局，不覆盖输入内容。
- 同一组选项共享补充说明起点，标题区和说明按各自行中线垂直居中。
- hover 表面之间保留独立间距；按下与提交等待立即显示状态反馈。
- 自定义答案提示使用 Zeus 作为产品主体，不显示“告诉 Codex”。

## 方案取舍

优点：

- 同一时刻只有一个输入主路径，避免用户把普通消息误认为询问答案。
- 整行点击、Enter 提交和即时忙碌反馈缩短操作路径。
- 说明起点统一，长短选项更容易纵向扫描。

代价：

- 询问未处理前不能发送普通会话消息。
- 长答案需要使用 Shift+Enter 换行。
- 标题区会按整组选项中最宽内容预留空间，窄窗口下说明区域相应变窄。
