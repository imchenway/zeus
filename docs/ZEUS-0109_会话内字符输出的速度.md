# ZEUS-0109 会话内字符输出的速度

## 任务目标

消除会话回答、过程说明和文件路径按字符缓慢增长的等待感。在不伪造上游生成进度的前提下，让已有完整内容立即可读，让真实流式内容按语义块自然追赶。

## 用户现场

- 最终回答按一个字一个字的节奏出现，完整内容已经到达时仍需要等待展示。
- 文件路径按字母增长，用户必须等待整条路径吐完才能判断目标文件。
- 固定输出速度无法同时适配慢流、快流、长答案和结构化内容。
- 期望参考 Codex App 的内容显现方式，并保留克制的局部动效。

## 已核对事实

- Renderer 会为每个 `conversation.item.delta` 更新累计正文；最终回答当前没有展示缓冲，因此上游逐字事件会直接变成逐字重渲染。
- 过程说明已有 80–180ms 合并，但只识别句末和换行，且最终回答没有复用该策略。
- 条目进入完成态后，Renderer 已经持有完整快照，可以立即展示，不需要模拟打字速度。
- 文件变更、命令和工具结果已有独立条目类型，可以与自然语言流分开处理。
- 本机当前 ChatGPT/Codex 前端资源使用内容条目或内容块进入动效：透明度与垂直位移过渡约 120–220ms；结构化内容按独立条目进入，不采用逐字符打字机动画。
- Zeus 现有会话过程说明使用 140ms、2px 的轻量显现，并在系统“减少动态效果”开启时关闭动效。
- 旧展示缓冲把系统“减少动态效果”同时当成关闭内容合并的条件；当前机器开启该偏好后，过程说明也会退化为每个 delta 直接显示，这是现场逐字输出的共同根因之一。

## 已确认产品口径

2026-08-07 用户逐项确认：

1. 核心策略采用“完整答案立即显示，真实流式输出自适应追赶”，不通过调高固定逐字速度解决。
2. 自然语言回答和过程说明使用自适应追赶；文件路径、链接、代码、命令和工具结果按结构化内容整块更新。
3. 新自然语言块使用轻量分块淡入，系统“减少动态效果”开启时完全关闭。
4. 参考 Codex App 的内容块进入方式，不复制品牌资源；路径等未闭合结构化片段短暂暂存，闭合、停顿或完成时整块显示。
5. 完成答案和历史答案同一渲染周期完整显示；流式正文正常情况下最多落后约 180ms，积压明显时立即追赶。

## 方案比较

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 每个事件立即渲染 | 事件延迟最低，实现最简单 | 上游逐字事件会直接变成逐字输出，Markdown 频繁重排 | 不采用 |
| 固定字符速度 | 节奏可预测 | 已有完整答案仍要等待，不适配不同上游速度 | 不采用 |
| 固定时间分块 | 可减少重渲染 | 快流与慢流使用同一等待，路径仍可能分段增长 | 不单独采用 |
| 自适应追赶与结构化分流 | 完整内容立即可读，流式体验自然，路径不再逐字增长 | 需要维护语义边界和未闭合片段识别 | 采用 |

## 实现边界

- 只改变 Renderer 的展示节奏，不改写、截断或重新排序 provider 正文。
- 完成、失败、历史恢复或前缀不兼容时立即采用最新完整快照；系统减少动态效果只关闭淡入位移，不关闭自适应追赶。
- 回答和过程说明共享自适应追赶策略；命令、工具调用、文件变更和请求面板保持直接更新。
- 句末、换行、Markdown 块闭合和明显积压可以触发立即追赶；短暂停顿负责收口没有标点的普通文本。
- 未闭合路径、链接和代码片段不按字符主动刷新；流结束时必须无损显示。
- 动效只作用于新显现的内容块，不对完整历史消息重新播放。
- 本项目不新增或恢复单元测试体系；使用 `pnpm lint`、`pnpm typecheck`、`pnpm build` 和必要的真实运行检查验证。

## 验收口径

- 已完成或历史恢复的回答一次完整出现，不播放逐字或逐句动画。
- 上游逐字发送普通正文时，界面按句子、停顿或积压批量追赶，不表现为固定每字速度。
- Markdown 路径、链接和行内代码在形成期间不会按单个字符持续增长，闭合或完成后完整可读。
- 文件变更、命令和工具结果继续按结构化事件直接展示。
- 新内容块显现动效克制，系统减少动态效果开启时无位移和淡入。
- 自动滚动、复制完整正文、Markdown 渲染和会话恢复不退化。

## 实施结果

- 最终回答和过程说明统一进入自适应追赶：句末、换行、可读批次、大块 delta、明显积压和完成状态分别触发不同追赶路径，不存在每字固定速度。
- Markdown 链接、普通路径和行内代码的未闭合尾部会暂存；闭合后整块进入，持续停顿 1.2 秒时才保守释放现场，完成或失败时立即无损收口。
- 完成答案、历史答案和不再兼容前缀的权威快照直接显示，不播放模拟生成过程。
- 文件变更、命令、工具结果和请求面板保持原有直接更新，不被自然语言节奏拖慢。
- 系统减少动态效果只控制动画，不再绕过内容合并。
- `SafeMarkdown` 使用稳定组件边界；原始 delta 变化但可见批次未变化时，不重复解析和重建整棵 Markdown 内容。
