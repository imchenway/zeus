# ZEUS-0121 标题不需要加粗和变更按钮收紧

## 任务目标

优化会话内文件变更卡片的视觉密度，让文件标题和顶部操作更精致，同时保持现有撤销、重新应用和审核行为不变。

## 现场判断

截图对应 `TurnChangeCard`，不是任务创建入口。卡片标题使用强调标签并设置为 580 字重；撤销/重新应用与审核按钮共用至少 36px 高度、较大的图标和内边距，因此在高分辨率截图中显得松散。

## 实现口径

- 文件变更标题改为普通文本元素，保持 15px 字号和 22px 行高，字重改为 400。
- 撤销/重新应用与审核按钮限定在变更卡片内调整为 28px 紧凑控件。
- 操作按钮使用 13px 字号、15px 图标、较小间距和内边距；审核按钮继续保留边框语义。
- 保留现有 hover、focus-visible、disabled、处理中、深色模式、高对比度和窄屏行为。
- 不修改任务创建入口、操作回调、数据结构或 API。
- `session.css` 中存在两份相同的变更卡片规则，本次按原有结构同步修改两处，不做无关样式清理。
