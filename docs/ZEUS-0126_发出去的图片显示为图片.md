# ZEUS-0126 发出去的图片显示为图片

## 任务目标

会话消息中的图片附件显示为消息内图片缩略图，不再以普通文件卡片呈现；普通文件继续使用文件名、类型摘要和“打开方式”卡片。

## 根因

- Local Server 已将图片附件归一化为 `previewKind: image`，并提供受信的会话资源图片预览接口。
- `ConversationResourceCards` 对所有卡片资源使用相同的文件卡片 DOM，只显示 `FileImage` 图标和“图片”摘要。
- `SessionWorkspace` 已持有 `onLoadResourcePreview`，但 `ConversationTranscript` 没有把该能力传给消息项，因此会话消息中的资源卡片无法使用图片预览。

## 实施范围

- 补齐 `SessionWorkspace`、`ConversationTranscript`、`ThreadItemView` 的图片预览回调传递。
- 共用会话 Markdown 图片的懒加载预览逻辑，新增资源卡片图片分支。
- 图片资源成功加载时显示受限尺寸、等比例缩略图，点击缩略图进入既有 Zeus 图片预览。
- 图片预览失败或预览能力不可用时回退为普通资源卡片，保留文件名、打开方式和失败提示。
- 非图片资源、附件存储、Provider 映射、数据库结构和资源授权边界保持不变。
- 使用会话资源样式约束图片尺寸、焦点态、多图片排列和窄窗口布局。

## 设计取舍

图片成功时不再显示普通文件名卡片，直接突出图片内容，以对齐用户提供的期望截图。图片名称仍保留在替代文本和悬浮提示中，预览失败时回到文件卡片，避免资源无声消失。

优点：发送后的图片更容易确认，且复用既有受信预览和打开流程。

代价：图片首次显示需要异步读取预览；预览失败时仍会短暂显示加载状态，然后回退到文件卡片。
