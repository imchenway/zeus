# ZEUS-0131 子任务的推送

## 需求口径

- “推送到新会话”只在当前任务存在祖先时展示“父任务上下文”。祖先顺序固定为根任务到直接父任务，最多两级。
- 父任务、内部会话和父任务附件每次打开弹窗均默认不选，不写入项目偏好。
- 选择父任务只发送任务编码、标题、类型和当前类型专属内容；会话与附件仍需逐项选择。
- 会话只发送 app-server 明确返回、当前真实存在的普通 JSONL 文件绝对路径；不推测路径。
- 父任务附件只走结构化附件通道。Renderer 只持有服务端选择标识，不接收或回传可信路径。
- 当前任务附件保持既有规则；当前附件与父附件按服务端确认的真实路径去重。
- 祖先关系或资源在弹窗打开后发生变化时拒绝创建，并要求刷新确认。

## 方案优缺点

### 优点

- 用户可以只携带解决当前子任务所需的背景，避免强制发送完整父任务历史。
- 服务端重新校验祖先关系、会话归属和附件归属，Renderer 不能伪造可信资源。
- 预览和真实首发正文共用纯格式化逻辑，降低界面显示与实际发送不一致的风险。

### 代价

- 默认全部不选，用户可能遗漏必要背景。
- 选择会话会把本机 JSONL 绝对路径作为普通提示词发送给运行内核。
- 弹窗打开后资源发生变化会阻断创建，用户需要刷新并重新确认。
