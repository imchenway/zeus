# ZEUS-0146 单独的新任务为什么不可以选择父任务

## 当前阶段

已完成共享选择器修复、静态检查和测试包构建；GUI 交互验收受本机已有测试实例和启动提示阻塞。

## 问题与根因

任务创建表单已经提供父任务选择，并用空字符串表示“无父任务（根任务）”。独立新任务默认 `parentTaskId` 为 `null`，因此选择器当前值为空字符串。

共享 `ZeusSelect` 在打开列表时把空字符串当作无效值直接返回，导致独立新任务无法首次打开父任务列表。选中父任务后再反选为根任务时，也会再次进入相同故障。键盘移动和搜索后的聚焦逻辑也使用真值判断，会跳过空字符串选项。

## 修复内容

- `ZeusSelect` 只把 `undefined` 视为没有可用选项，允许空字符串作为合法且未禁用的选项值。
- 鼠标打开、键盘上下移动以及搜索后的方向键聚焦均支持空字符串选项。
- 禁用的空占位项仍不会被选中，任务类型和来源分支等必选选择器的行为保持不变。
- 任务创建表单、父任务候选过滤、`parentTaskId` API 和数据库结构不变。

## 业务边界

- 独立新任务默认是根任务，可以随时选择父任务、切换父任务或反选回根任务。
- 父任务必须属于当前项目，且新任务不能因此超过三级层级；第三级任务仍不是合法候选。
- 选择父任务保存对应任务 ID；反选根任务保存 `null`。
- 本任务不扩展图谱、运行时或模板等直接创建入口。
