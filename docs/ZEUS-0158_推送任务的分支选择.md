# ZEUS-0158 推送任务的来源分支批量选择

## 任务信息

- 任务标题：推送任务的分支选择
- 任务类型：优化
- 现状：项目目录包含十几个 Git 仓库时，用户需要逐仓重复选择同一来源分支。
- 预期：在逐仓配置顶部按分支名称聚合共同来源，支持一次批量填充后继续逐仓调整。

## 已确认规则

1. 只有 Worktree 模式发现两个及以上仓库时显示批量入口。
2. 批量列表只展示全部仓库都存在的来源分支，不提供部分覆盖，也不清空未匹配仓库。
3. 本地分支按“本地 + 分支名”识别；远端分支按“远端名 + 分支名”识别。同名本地、`origin` 和其他远端互不合并。
4. 批量选择只修改每个仓库的来源引用，保留新任务分支名和“带入未提交内容”选择。
5. 全部仓库仍必须参与本次推送；不允许通过批量入口排除仓库。
6. 逐仓选择保持可用。逐仓修改造成来源不一致时，批量入口明确显示“不一致”。
7. 远端刷新仍由用户逐仓显式触发；刷新期间批量入口不可操作，完成后根据最新本机能力重新聚合。
8. 服务端继续逐仓复验完整 Git 引用，不新增数据库、接口或远端访问行为。

## 方案与取舍

在 `TaskModelPushModal` 内从各仓库现有 `sourceRefs` 派生共同候选，并复用 `ZeusSelect` 提供搜索、分组、键盘操作和 portal 浮层。批量选择不单独持久化，当前显示值始终由逐仓表单事实反推。

优点：常见的 `main`、`develop` 等来源可以一次填满全部仓库；批量结果仍是逐仓明确引用，不绕过现有 Git 校验。

代价：远端名称不同或只存在于部分仓库的分支不会出现在批量列表，用户仍需逐仓选择；项目没有共同来源时只能显示空态。

## 验证口径

- 静态与构建：`pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm package:mac`、`git diff --check`。
- 隔离多仓场景：共同本地/远端来源、部分来源排除、来源类型区分、批量应用、逐仓覆盖、单仓、无共同来源和刷新状态。
- 真实界面：使用独立数据目录的 `Zeus Test.app` 检查搜索、键盘、焦点、中英文、窄窗口、主题和减少动态效果。
- 静态检查、构建和打包结果不替代真实弹窗验收。

## 验证记录

### 静态、构建与测试包

- `pnpm install --frozen-lockfile --offline`：通过，657 个依赖全部复用本机缓存；安装阶段缺少尚未构建的图谱命令产物警告在完整构建后消失。
- 定向 Prettier 检查、`pnpm typecheck`、`pnpm lint`：通过。
- `pnpm build`：通过，15 个工作区项目完成构建，桌面 Renderer 转换 1059 个模块。
- `pnpm package:mac`：通过，只生成 `dist/test/mac-arm64/Zeus Test.app` 与测试 DMG；Bundle ID 为 `dev.hypha.zeus.test`，`codesign --verify --deep --strict` 通过。

### 隔离多仓能力

- 使用独立临时数据根和独立项目根创建 12 个隔离 Git 仓库，没有读取或修改用户真实项目。
- 真实任务推送能力返回 12 个仓库。全仓共同来源为本地 `develop/main`、`origin/develop/main` 和 `upstream/main`；只存在于 5 个仓库的本地及 `origin/feature/partial` 没有进入批量列表。
- 同名 `main` 在本地、`origin` 和 `upstream` 下分别展示，证明来源身份没有被合并。
- 独立执行宿主 `/health` 返回 HTTP 200，`database=ok`、`runtime=ok`。

### 真实界面

- 中文跟随系统浅色界面中，批量入口默认回显 `main · 本地 · 12 个仓库`；展开后按本地、`origin`、`upstream` 分组，未出现部分覆盖的 `feature/partial`。
- 搜索 `upstream` 后使用键盘选择成功，12 个可见仓库表单切换到远端 `main`，新任务分支名仍为原建议值。
- 将单个仓库改回本地 `develop` 后，顶部立即显示“逐仓选择不一致”，并允许重新批量应用或保留逐仓结果。
- 对隔离仓库执行显式远端刷新后得到预期的 `ZEUS_GIT_REMOTE_REFRESH_FAILED`；当前来源、已知远端来源和逐仓结果均保留。
- 单仓项目不显示批量入口；两个仓库分别只有 `alpha`、`beta` 时显示“没有全部仓库共同拥有且来源一致的分支”空态，并保留逐仓选择。
- 英文深色界面完整显示批量标题、仓库数量、来源标签和逐仓提示；约 650 像素宽窗口下工作方式和逐仓字段切换为单列，没有横向溢出。
- 使用 `--force-prefers-reduced-motion` 启动同一测试包完成窄窗口往返；本功能未新增独立动画，选择器继续使用全局减少动态效果规则。
- 测试实例正常停止后，隔离数据库 `PRAGMA quick_check` 返回 `ok`；临时 Git 项目和数据根已移入废纸篓，可恢复。
