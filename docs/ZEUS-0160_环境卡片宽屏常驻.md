# ZEUS-0160 环境卡片宽屏常驻

## 任务目标

会话工作区右侧有足够空闲空间时，直接在右上角展示环境信息卡片；浏览器、计划、源码、代码审查等右侧上下文工作面打开，或会话工作区宽度不足时，自动收起为顶部“环境”按钮。

## 需求补全与取舍

用户未单独提供预期字段，本任务根据标题与现状补全为两种自适应形态：

- 常驻形态：会话工作区宽度不少于 `1440px`，且没有右侧上下文工作面时，卡片直接显示。
- 收起形态：工作区不足 `1440px`，或任一右侧上下文工作面打开时，只显示顶部入口，点击后展示同一张卡片。

优点：

- 利用宽屏会话正文右侧的空闲区域，执行目录、分支和变更状态无需额外点击即可查看。
- 浏览器、计划、源码和代码审查共用现有 `contextWorkspace` 事实，任一工作面打开都会收起卡片，不与主工作面争抢右侧空间。
- 常驻与弹出形态复用同一组件、同一任务工作区读取和同一 Git 操作入口，不产生第二套状态或绕过安全门禁。

代价：

- `1440px` 是按当前 `768px` 正文上限、`300px` 常驻卡片和两侧安全留白确定的产品断点；若以后调整正文或卡片宽度，需要同步复核该断点。
- 宽屏进入会话后会主动读取一次本地任务工作区快照；窄屏和右侧工作面占用时仍只在用户展开卡片后读取。

## 实现范围

- `SessionQuickActionsCard.tsx`
  - 使用 `ResizeObserver` 读取会话工作区自身宽度，不使用整窗宽度猜测。
  - 增加常驻与收起两种呈现；会话切换后重新读取对应任务工作区，单次可见周期内避免重复读取。
  - 常驻卡片使用 `region` 语义；按钮展开形态继续使用 `dialog`、外部点击关闭、`Escape` 关闭和焦点返回。
- `SessionWorkspace.tsx`
  - 以既有 `contextOpen / contextMounted` 生命周期作为强制收起条件，覆盖 browser、plan、source 和 turn diff，并避免右侧工作面退出动画尚未完成时提前恢复卡片。
  - 把环境入口放到会话头部动作区最右侧，使常驻卡片与会话右边缘对齐。
- `session.css`
  - 常驻卡片收窄为 `300px`，保持现有颜色、圆角、阴影、深浅主题和内部滚动规则。
