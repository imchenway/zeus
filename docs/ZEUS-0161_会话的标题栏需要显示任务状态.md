# ZEUS-0161 会话的标题栏需要显示任务状态

## 任务目标

任务会话的顶部标题栏直接显示当前任务管理状态，并与任务列表、任务详情使用同一个 `managementStatus` 事实源、同一份项目状态配置和同一个颜色。

## 现状核对

- 会话标题栏已显示会话运行状态，该状态来自当前 Agent 轮次，不能冒充任务管理进度。
- `App.tsx` 已能按项目解析任务状态名称、自定义颜色和完成/取消角色，会话层不需要建立第二份映射。
- 用户附件文字对应的“环境卡片宽屏常驻”已由上一任务 `ZEUS-0160` 完成，当前分支已包含该实现，本任务不重复修改环境卡。

## 实现方案

1. 扩展 `SessionWorkspaceTask`，携带已按项目配置解析的状态标识、展示名和颜色。
2. 标题栏快照跟随当前任务状态；任务实时更新后，标签随现有任务快照刷新。
3. 任务会话把只读状态标签放在任务标题文字后面；项目自由对话和找不到真实任务记录的历史会话不伪造状态。
4. 狭窗口优先保留任务状态文字，收紧浏览器、会话运行状态和环境入口的低优先级文字占用，图标、可访问名称和操作仍保留。

## 取舍

优点：

- 用户在会话现场能同时看到“任务进度”和“Agent 当前运行情况”，不再需要打开任务详情核对。
- 显示名和颜色来自真实项目配置，自定义状态不会退化为内部编码。
- 标题栏只读，不会绕过任务终态的 Git 工作区处置门禁。

代价：

- 任务标题后增加一个紧凑标签，会进一步压缩窄窗口下的任务标题可见宽度；状态标签优先保留，标题超长时省略。
- 任务状态修改仍需进入任务详情或任务页；这是为了保留完成、取消时的真实处置和确认流程。

## 验收口径

- 任务会话的当前任务管理状态紧跟任务标题，并与任务页名称和颜色一致。
- 会话运行状态仍独立显示，任务状态不会被运行轮次自动改写。
- 任务状态更新后，当前会话标题栏跟随最新任务快照更新。
- 项目自由对话不显示任务状态。
- 窄窗口下标题、状态和快捷入口不重叠、不横向溢出，键盘焦点和减少动态效果保持现有行为。
