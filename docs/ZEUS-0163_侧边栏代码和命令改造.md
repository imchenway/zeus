# ZEUS-0163 侧边栏代码和命令改造

## 任务结论

代码页的信息架构调整为“源码默认、图谱与命令按需切换”。项目侧栏移除“命令”，只保留“任务 / 代码 / 会话”。源码草稿在三个代码模式之间切换时继续保留，离开代码页、切换项目和退出应用统一经过未保存门禁。

## 已实施范围

### 项目导航与代码工作区

- 点击项目“代码”始终进入源码模式，不再自动打开或扫描图谱。
- 代码工作区建立 `source / graph / commands` 三种模式，右上角提供“源码 / 图谱 / 命令”入口。
- 图谱只在首次进入图谱模式时加载；命令模式复用原有命令定义、权限确认、运行历史、日志、产物和停止能力。
- 旧 `#project-commands` 地址会进入代码页命令模式。
- 三种模式使用完整主工作区。已经访问的模式保持挂载，源码标签、草稿和光标位置不会因模式切换丢失。
- 图谱“打开源码”优先切回内嵌编辑器并定位相对路径和行号；无法安全归一为项目相对路径时才回退到既有外部打开能力。

### 源码工作台

- 左侧为按需读取的真实目录树，默认宽度 260px，可在 200–420px 调整；窄窗口改为覆盖层。
- 支持文件名搜索，最多返回 200 项并标记结果截断；不提供全仓正文索引。
- 支持新建文件、新建目录、重命名、移动对话框、Finder 定位和移入 macOS 废纸篓；不提供拖拽移动。
- 右侧使用 CodeMirror 6，提供行号、基础语法高亮、撤销重做、当前文件查找替换、跳转行、缩进、`⌘S` 保存当前文件和 `⌥⌘S` 保存全部。
- 最多恢复 20 个打开文件、当前标签、最多 200 个展开目录和目录宽度；不持久化未保存正文。
- 标签使用圆点表示未保存，感叹号表示磁盘内容变化。关闭脏标签提供“保存全部 / 放弃 / 取消”。
- 外部修改后的保存会被修订值校验阻止；用户可以保留草稿、重新加载或另存为。
- 二进制、无效 UTF-8、超过 2 MiB、符号链接或非普通文件显示只读原因，并提供受 Main 路径校验保护的外部打开操作。

### Main 与 Preload 安全桥接

- 新增共享类型：`ProjectSourceEntry`、`ProjectSourceDocument`、`ProjectSourceRevision`、`ProjectSourceEvent`、`ProjectCodeWorkspacePreference` 及结构写操作输入。
- Renderer 只传 `projectId + 相对路径`。Main 每次通过本地服务读取项目记录，并以当前项目 `localPath` 作为权威根目录。
- 路径拒绝绝对路径、反斜杠、空字节、`.`、`..`、`.git` 和真实路径逃逸。
- 指向项目外的符号链接可以显示、移动、Finder 定位和移入废纸篓，但不能展开、读取或编辑；本次不创建符号链接。
- 文件读取使用 SHA-256 修订值。保存前重新计算并校验，冲突时禁止覆盖。
- 保存保留 UTF-8 BOM、换行风格和文件权限；写入使用同目录独占临时文件、文件同步、原子替换及目录同步。
- 结构写操作拒绝覆盖已有目标。审计日志只记录动作、项目 ID、源相对路径和目标相对路径，不记录源码正文。
- Main 递归监听项目目录。干净标签自动刷新，脏标签标记冲突；目录只刷新事件影响的父节点。
- 未保存门禁从任务表专用入口扩展为按键登记的通用协议，当前登记 `task-table-layout` 与 `project-source`，兼容旧接口。

## 主要取舍

### CodeMirror 6

优点：体积和拆包压力低，足以覆盖本任务的基础专业编辑能力；语言扩展按文件类型加载。

缺点：不提供 IDEA 级智能补全、诊断、跳转定义、重构和语言服务器能力，界面不应暗示这些能力存在。

### 图谱和命令整页切换

优点：图谱画布、命令历史和编辑器都能使用完整空间，窄窗口也不会形成拥挤抽屉。

缺点：不能同时并排查看源码与图谱或命令；用户需要通过顶部模式入口往返。

### 只持久化界面状态

优点：Zeus 数据目录不会形成额外的敏感源码草稿副本。

缺点：进程异常退出时，未保存正文无法恢复，因此正常关闭和升级必须依赖未保存门禁。

### 文件名搜索而非正文索引

优点：进入代码页无需扫描全仓，读取成本和敏感内容复制范围可控。

缺点：无法按源码正文检索；此能力连同语言服务器、终端侧栏和 Git 面板重构不在本任务范围。

### Main 文件能力验收

使用临时真实 Git 项目直接验收 Main 服务，以下场景通过：

- 懒加载目录、普通点文件可见、`.git` 隐藏且拒绝访问。

- 文件与目录变化订阅能够收到受影响相对路径；结构审计不包含源码正文。
