# ZEUS-0166 远程安装的脚本问题

## 任务状态

- 阶段：方案图完成，代码尚未实现。
- 类型：优化。
- 用户现象：Zeus 提供的 Remote Control 专属安装命令调用 OpenAI 官方 `install.sh` 后，脚本询问是否卸载用户已有 Codex。
- 方案图：`docs/ZEUS-0166_远程安装隔离方案图.html`。

## 已确认事实

1. 用户现有 `/Users/david/.local/bin/codex` 仍存在，指向用户 `~/.codex` 中的独立安装版，当前版本为 `0.146.1`。
2. Zeus 专属 `/Users/david/.zeus/providers/codex/packages/standalone/current/codex` 已安装成功，当前版本为 `0.147.0`。
3. 官方脚本的卸载询问默认为 `N`；`CODEX_NON_INTERACTIVE=1` 会跳过询问并采用默认答案。
4. 官方脚本还会把 `CODEX_INSTALL_DIR` 写入 `$HOME` 对应的 Shell profile。当前真实 `~/.zprofile` 已出现指向 Zeus 专属 `bin` 的 Codex installer 标记块。
5. 因此，仅加入非交互参数只能阻止卸载，不能阻止 Zeus 专属命令抢占用户终端 PATH。

## 设计结论

- Zeus 绝不卸载、覆盖或替换用户终端中的 Codex，也不修改用户真实 Shell profile。
- Remote Control 专属命令继续使用 OpenAI 官方安装器，但同时设置 `CODEX_NON_INTERACTIVE=1`、Zeus 独立 `CODEX_HOME`、Zeus 独立 `CODEX_INSTALL_DIR` 和 Zeus 内部 `.installer-shell-home`。
- 设置页、本地服务状态接口和 app-server 恢复提示必须复用同一安全命令生成逻辑；无法确认绝对 Zeus Home 时拒绝提供默认 `~/.codex` 安装命令。
- Zeus 只展示和复制命令，不自动安装、登录或配对。安装完成后由用户刷新，服务端重新读取真实固定入口。

优点：保留官方发布包、摘要校验和固定入口语义，同时隔离卸载询问、Shell profile 与终端 PATH 副作用。

缺点：Zeus 数据目录会增加一个只供安装器使用的隔离 Shell Home；真实安装、登录、设备配对和回答回流仍需独立运行验收。

## 当前副作用边界

真实 `~/.zprofile` 中已经存在的三行 Codex installer 标记块不在本次绘图工作中删除。该文件属于用户环境，只有获得用户明确授权后才能精确清理，并在清理前后复核 `/Users/david/.local/bin/codex` 的解析结果。
