Zeus 设置页

Renderer 只展示本地服务返回的真实能力快照和安全命令。缺少 Zeus 专属固定入口时禁用启用与配对，保留刷新和复制。

本地服务与能力快照

packages/local-server/src/index.ts 负责检测 CODEX_HOME/packages/standalone/current/codex、生成安装命令并在启用前复验。计划把命令生成集中复用。

安全安装命令（计划）

命令加入 CODEX_NON_INTERACTIVE=1，并把 HOME 定向到 Zeus 内部的 .installer-shell-home。这样官方脚本采用卸载默认 N，Shell 配置也只能写进 Zeus 数据目录。

OpenAI install.sh

官方脚本负责解析版本、下载和校验发布包、维护 packages/standalone/current 与 CODEX_INSTALL_DIR/bin/codex。当前脚本还会询问是否卸载其他安装，并尝试写 HOME 下的 Shell profile。

Zeus 专属 Codex 状态

Remote Control 固定使用 /Users/david/.zeus/providers/codex/packages/standalone/current/codex。当前只读检查确认它为 0.147.0，并与用户 Codex 同时存在。

Remote Control 运行链

固定入口启动 remote-control app-server 守护进程，随后启用环境和设备配对。真实手机配对、回答回流和跨世代行为尚未在本任务中验收。

不可触碰边界

计划把“保留用户 Codex、不得写真实 Shell profile、不得抢占 PATH、不得自动安装”固化为 Remote Control 安装契约。当前 ~/.zprofile 已有脚本写入，清理必须另获用户明确授权。

用户命令：~/.local/bin/codex

用户终端的可见 Codex 入口，当前指向用户 ~/.codex 中的独立安装版；Zeus 禁止覆盖或删除。

用户目录：~/.codex

用户自己的 Codex 配置、认证、会话和独立包目录；Zeus Remote Control 不读写此处来替代 Zeus Home。

Shell 配置：~/.zshrc

当前第 112 行把 $HOME/.local/bin 放入 PATH。它属于用户 Shell 配置，Zeus 不修改。

Shell 配置：~/.zprofile

官方脚本已写入把 Zeus bin 放入 PATH 的标记块。这是已观察到的副作用，不会在未授权时自动删除。

managedStandalone

复制安装命令

刷新磁盘事实

readCodexRemoteControlStandalone

commandPath X_OK

installCommand

409 安装门禁

固定入口缺失时返回 ZEUS_CODEX_REMOTE_CONTROL_STANDALONE_REQUIRED，不启动远程宿主。

enable 前复验

点击启用时再次读取磁盘并校验固定入口，避免状态展示与真实启动条件不一致。

恢复提示复用

app-server 启动失败时使用与设置页相同的安全命令，不再散落另一条旧命令。

绝对 CODEX_HOME

仅当 Zeus Home 是可确认的绝对路径时生成安装命令。

无法定位则拒绝

不能确认隔离目录时不回退到默认 ~/.codex，也不提供会污染用户环境的命令。

参数：CODEX_NON_INTERACTIVE=1

OpenAI 官方变量：跳过询问并采用默认答案。卸载提示为 [y/N]，因此默认保留用户 Codex。

目录：HOME=.installer-shell-home

把官方脚本选择的 .zprofile 或其他 Shell profile 限制在 Zeus 内部，不触碰真实用户 Home。

目录：CODEX_HOME=Zeus Home

配置、认证、会话和 standalone 包元数据全部属于 Zeus 专属目录。

目录：CODEX_INSTALL_DIR=Zeus bin

只创建 Zeus 内部的可见 codex 链接，供 Zeus 自己使用。

POSIX 安全引用

所有路径使用单引号安全引用，路径中的空格和特殊字符不会改变命令结构。

先创建隔离 HOME

命令先 mkdir -p Zeus 内部的 installer-shell-home，确保官方脚本写 profile 时不会失败。

卸载默认答案 N

非交互模式不会执行 npm、brew 或 bun 的卸载命令。

不启动交互 Codex

官方脚本最后的 Start Codex now 提示也采用默认 N，避免安装后进入用户交互界面。

仅 Remote Control

非交互和隔离 HOME 只用于 Zeus Remote Control 专属修复命令；普通首次安装保持官方流程。

Zeus 不直接执行

设置页仍只展示和复制命令；用户在终端明确执行，Zeus 不自动下载或登录。

版本解析与下载

官方脚本解析当前平台与目标版本，从 OpenAI 发布源下载匹配资产。

摘要校验

当前脚本在安装前校验发布资产摘要，Zeus 不复制或重写这套逻辑。

packages/standalone/current

官方脚本维护版本目录和 current 链接，Remote Control 依赖这个固定布局。

bin/codex 链接

官方脚本在 CODEX_INSTALL_DIR 下创建可见入口；安全方案把目录限制在 Zeus Home。

packages/standalone/current

Zeus Remote Control 的权威可执行入口位于当前 Zeus CODEX_HOME 下。

bin/codex

Zeus 内部可见链接，不加入用户真实 PATH，也不替代用户 ~/.local/bin/codex。

config 与 auth

Zeus 专属 Codex 登录和配置继续保存在 Zeus Home，与用户默认 Codex 隔离。

sessions 与 logs

Zeus 会话、历史和诊断继续落在 Zeus Home，不借用用户 ~/.codex。

skills 与 plugins

Zeus 的技能和插件目录随 Zeus Home 隔离，避免污染用户个人 Codex。
