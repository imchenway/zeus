# ZEUS-0179 历史消息悬浮操作栏

## 任务信息

- 任务类型：优化
- 当前阶段：实现完成，真实历史消息悬浮验收待补
- 用户现状：历史消息不显示时间和消息操作。
- 用户预期：操作栏不常驻，鼠标移入对应文字区域时显示。

## 已确认事实

1. `ThreadItemView` 已经实现两组消息操作栏：
   - 智能体消息：复制、好评、差评、展开或收起、时间。
   - 用户消息：时间、复制；只有最新一条用户消息可编辑并重新发送。
2. 操作栏 CSS 已默认为透明，消息容器 `hover` 或 `focus-within` 时显示。
3. 当前历史智能体消息不会生成操作栏 DOM；`ConversationTranscript` 只对最后一条智能体答复传入 `showAssistantActions`。
4. 当前最新消息会通过 `is-latest` / `is-latest-assistant` 强制常驻操作栏，与本次“不需要常驻”的表述存在冲突，需要用户确认。
5. 历史设计曾为解决历史智能体消息底部多预留 `20px` 空白，主动收紧为只渲染最后一条。本次恢复历史操作时，必须在稳定尾部安全区和历史密度之间重新取舍。

## 需求确认记录

- 用户已确认整条正文触发、新旧消息统一悬浮、历史用户消息不提供编辑，并确认按完整口径开始实现。

## 已确认需求

1. 鼠标移入整条消息正文的任意可见位置时，显示该条消息的操作栏。
2. 键盘用户聚焦该条消息的操作按钮时，操作栏必须保持可见。
3. 最新消息与历史消息使用同一规则：操作栏都不常驻，只在正文 hover 或操作栏 focus-within 时显示。
4. 历史智能体消息显示复制、好评、差评、展开或收起、时间。
5. 历史用户消息只显示时间和复制；只有最新一条用户消息保留编辑并重新发送。
6. 操作栏的复制、反馈、展开、时间和编辑现有功能边界不重做，本任务只修正历史渲染范围与显隐交互。

## 取舍

- 整条正文区域触发：命中面积大，阅读历史时容易找到操作；代价是鼠标只是经过长消息中部时也会显示底部操作栏。
- 仅操作栏附近触发：界面更安静；代价是隐藏操作本身没有可见命中点，用户很难发现。
- 全部消息统一悬浮：规则一致且完全满足“不常驻”；代价是最新答复的复制与反馈入口不再立即可见。
- 仅历史消息悬浮：保留当前最新回复的高可见性；代价是新旧消息的显隐规则不一致，也不完全符合用户字面上的“不需要常驻”。

## 验证边界

- 项目不新增或恢复单元测试。
- 实现后执行 `pnpm lint`、`pnpm typecheck`、`pnpm build`。
- 需要真实运行时验收时，只允许生成和启动独立身份 `Zeus Test.app`；bundle ID 必须为 `dev.hypha.zeus.test`，并使用独立用户数据目录。

## 实现设计

1. `ConversationTranscript` 不再计算和传递“最后一条智能体消息”；所有独立展示的智能体最终回复都拥有消息操作栏。轮次过程中的 commentary、reasoning、命令和文件活动不扩大为普通消息操作栏。
2. `ThreadItemView` 不再把 `showAssistantActions` 转换为“最新智能体消息”样式类，避免“拥有操作”被误解为“强制常驻”。
3. 操作栏仅在消息容器 `hover` 或 `focus-within` 时可见；移除 `is-latest` 和历史的 `is-latest-assistant` 强制可见规则。
4. 保留操作按钮原有 `28px` 命中区、原生 button 语义、`aria-label`、反馈状态和键盘焦点环。
5. 保留 `has-message-actions` 的 `20px` 稳定尾部安全区，操作栏显示时不推挤下一条消息。

### 优点

- 新旧消息显隐规则一致，用户移入任意正文即可找到该条操作。
- 不新增操作状态和数据通道，复用现有剪贴板、反馈、展开、时间与编辑边界。
- hover 与键盘焦点共用同一显示规则，不会只有鼠标用户能使用。

### 代价

- 历史智能体消息恢复操作栏后，每条都需要稳定尾部安全区，会比当前只有最后一条带操作的布局更疏松。
- 好评和差评仍是单条消息的本地界面状态，不扩大为服务端持久反馈。

## 实现结果

1. 移除 `ConversationTranscript` 中只识别最后一条智能体回复的 `lastAssistantKey`，改为所有不在过程活动区内的智能体最终回复都传入操作栏。
2. 移除 `ThreadItemView` 的 `is-latest-assistant` 样式类，操作栏存在不再等于最新消息常驻。
3. 源码中两处重复的会话页样式片段都已移除 `is-latest` 和 `is-latest-assistant` 强制透明度为 `1` 的规则，仅保留消息 `hover` 与 `focus-within`。
4. 用户消息的现有边界保持不变：历史消息只有时间和复制，最新一条才可编辑并重新发送。
