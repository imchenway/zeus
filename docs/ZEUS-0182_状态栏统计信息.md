# ZEUS-0182 状态栏统计信息

## 任务信息

- 任务类型：优化
- 当前阶段：功能开发完成；静态、构建、测试身份打包与独立数据目录启动检查通过，真实菜单栏点击验收仍待人工确认。
- 用户目标：统计摘要应从 Zeus 窗口顶部移到 macOS 菜单栏的 Zeus 常驻入口中，不在 Zeus 顶部新增按钮。
- 安全边界：不修改 Git 历史或远端；不生成或启动生产身份 `Zeus.app`；不新增单元测试体系。

## 已核实的现状

1. 现有用量摘要由 Renderer 的 `ZeusUsageTitlebarPopover` 展示，入口是 Zeus 窗口标题栏中央的 `Zeus` 按钮。
2. 现有摘要包含计划、今日官方 Token、近 7 日官方 Token、最紧迫配额、近 7 日本地缓存命中率、估算 Credits、API 等价美元和更新时间，并可进入完整统计。
3. macOS 菜单栏的 Zeus 常驻入口由 Electron Main 创建，当前只提供 `Show Zeus`、`New Window`、`Quit Zeus`。
4. 主进程已有访问本地服务的认证配置，可读取 `/api/codex/usage-summary`；不需要把账户凭据或统计明文经由新的 Renderer 写通道回传。
5. macOS 原生菜单适合紧凑文本项和分隔线，不适合复刻现有 2×3 卡片式富弹层。

## 待确认的产品决策

### 入口与内容形态（已确认）

删除 Zeus 窗口顶部的 `Zeus` 按钮及其统计弹层；点击 macOS 菜单栏 Zeus 图标后，打开重新设计的自定义统计浮窗。

优点：入口符合用户预期；统计在窗口隐藏时也能查看；可以重新设计信息层级、留白、颜色及加载和错误反馈。

缺点：需要维护独立浮窗的定位、焦点、失焦关闭、多屏和浅深色行为；外观不再等同于用户截图中的系统原生菜单。

## 术语草案

- **菜单栏 Zeus 入口**：macOS 菜单栏中由 Zeus 主进程维护的常驻图标及其原生菜单。避免称为“状态栏”，以免与窗口内编辑器状态栏混淆。
- **用量摘要**：从 Codex 官方账户快照与 Zeus 本地近 7 日账本派生的只读紧凑统计，不是账单，也不提供购买、重置或消费动作。

术语需要用户确认后再同步到项目领域词汇表。

## 用户追加反馈

- 用户认为现有统计页面视觉效果较差，要求美化。
- 该反馈使“原生菜单”与“自定义统计浮窗”成为必须先确认的路线分歧：原生菜单与用户提供的目标截图一致，但只能使用系统排版；自定义浮窗可以承载重新设计后的信息层级、留白和状态反馈，但外观不会与目标截图中的原生菜单完全一致。
- 用户已确认采用自定义统计浮窗路线；当前继续确认信息层级，尚未进入视觉设计或功能开发。

### 信息层级（已确认）

1. 主信息突出最紧迫配额的剩余百分比与重置时间。
2. 次信息展示今日官方 Token 与近 7 日官方 Token。
3. 辅助信息展示本地近 7 日缓存命中率、估算 Credits 与 API 等价美元。
4. 底部保留“查看完整统计”“显示 Zeus”“退出 Zeus”。
5. “新建窗口”不进入统计浮窗，避免用量查看与窗口管理混杂。

优点：首屏先回答“现在还能否继续使用”，统计主次清楚。

缺点：费用类数据降为辅助信息，不再与配额占据同等视觉权重。

### 菜单栏交互（已确认）

1. 左键点击菜单栏 Zeus 图标，打开或关闭菜单栏用量浮窗。
2. 右键点击图标，打开系统原生应用菜单，保留“显示 Zeus”“新建窗口”“退出 Zeus”。
3. 点击浮窗外部或按 `Escape` 关闭浮窗。
4. 左键统计入口与右键应用管理互不替代。

优点：高频查看统计与低频窗口管理分流，浮窗可以专注信息表达。

缺点：右键应用菜单的可发现性低于左键菜单，需要保留符合 macOS 习惯的行为与文案。

## 开发阶段

- 用户查看设计图后明确要求继续，视为确认按设计图进入开发。
- 本次属于现有设计系统内的紧凑浮窗改造，不生成 raster 概念图；菜单栏图标、文字和控件保持代码原生，避免把静态截图当作产品 UI。
- 实施顺序：先建立主进程浮窗生命周期与左右键分流，再实现独立 Renderer，随后移除旧顶部入口，最后执行静态、构建、测试身份打包和真实运行验证。

## 已完成实现

1. Main 进程新增约 `360 × 520` 的无边框菜单栏用量浮窗，沿用主应用的隔离 preload、安全导航规则与只读本地服务配置。
2. 左键点击菜单栏 Zeus 图标切换浮窗；右键打开原生应用菜单，保留“显示 Zeus”“新建窗口”“退出 Zeus”。
3. 浮窗按当前菜单栏图标所在显示器定位，并夹紧到该显示器工作区；失焦自动隐藏，`Escape` 通过受信任 IPC 隐藏。
4. 浮窗 Renderer 独立分流，不读取 Dashboard；主工作台改为动态加载，菜单栏浮窗只按需加载自身组件和样式。
5. 视觉层级改为配额主信息、今日/近 7 日 Token 次信息、缓存命中/估算点数/API 等价辅助信息；不再使用六宫格卡片墙。
6. 已实现加载骨架、旧值刷新、未登录、登录方式不支持、服务不可用、离线旧数据、字段不可用和重试反馈。
7. “查看完整统计”打开现有 `#settings-usage` 页面；未登录时进入现有 `#settings-runtime` 配置；“显示 Zeus”“退出 Zeus”由 Main 进程执行。
8. Zeus 主窗口顶部的 `Zeus` 按钮、旧统计弹层和对应样式已删除；完整统计设置页保留。

优点：统计入口与 macOS 菜单栏语义一致，窗口隐藏时仍可查看；配额风险优先，常用信息更容易扫读；浮窗不会为显示摘要而读取完整 Dashboard。

缺点：自定义浮窗比原生菜单多一套窗口生命周期和多屏定位逻辑；右键原生菜单的可发现性仍依赖 macOS 使用习惯；真实桌面交互需要在可用的 GUI 控制环境中继续验收。
