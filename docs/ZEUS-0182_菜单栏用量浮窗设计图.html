推荐方案：移除 Zeus 窗口顶部统计按钮，将配额风险、Token 用量与本地估算收进 macOS 菜单栏浮窗；左键看统计，右键管理应用。

交互与视觉细节

点击任一节点可查看它在最终方案中的职责、优点和限制。

Zeus 菜单栏图标

唯一高频入口。优点是窗口隐藏时仍可用；限制是需要处理多屏和菜单栏边缘定位。

浮窗标题区

只显示 Zeus、计划和更新时间，避免重复占据视觉中心。

配额与 Token 主信息

优先回答还能否继续使用，再补充今日与近 7 日消耗。

效率与费用辅助区

缓存和估算费用保持可见，但用更轻的样式弱化。

真实数据来源

官方账户快照与 Zeus 本地账本禁止相加，继续沿用既有口径。

底部动作区

完整统计是主动作；显示和退出是低频次动作。

状态设计

加载、未登录、离线、错误和字段缺失都展示真实状态。

实现与验收边界

设计已确认；运行时多屏、焦点与失焦关闭仍需测试身份应用验证。

左键

切换自定义统计浮窗，不再弹出原生上下文菜单。

右键

弹出系统原生应用菜单，保留显示、新建窗口和退出。

退出键

关闭浮窗并把焦点归还菜单栏入口。

点按外部

浮窗失焦后自然关闭，符合 macOS 临时面板习惯。

账户已连接

成功态只显示连接结果，不暴露邮箱、Token 或认证响应。

更新时间

在标题区弱化展示，用于判断数据新鲜度。

跟随系统外观

浅色和深色使用同一信息层级，不用高饱和大色块。

只读统计

不提供购买 估算点数、使用重置或其他账户变更动作。

今日 Token

官方字段缺失时显示不可用，不伪造为 0。

近 7 日 Token

使用紧凑数值并提供完整统计入口查看精确值。

重置倒计时

重置时间与剩余比例成组出现，帮助判断可用性。

最紧迫窗口

多个限额窗口只在摘要中突出剩余比例最低的一项。

大数值

配额比例使用最大字号，形成唯一视觉锚点。

异常态替换

错误状态替换对应内容，不在正常数据旁堆叠技术错误。

离线旧数据

保留最近一次快照，同时明确标记已过期。

字段缺失

显示“不可用”，避免用户把缺字段理解为零消耗。

缓存命中率

口径固定为缓存读取 Token 除以输入 Token。

估算点数

本地估算值，不称为账户余额或实际扣费。

API 等价

只显示美元估算，不换算人民币，也不称为账单。

费用覆盖率

用于说明有多少可计费 Token 获得了公开价格覆盖。

价格目录日期

让用户知道估算基于哪一天的公开价格快照。

仅 Zeus

本地数据只覆盖 Zeus 启用采集后的使用，不代表全部 Codex 客户端。

估算说明

估算点数 和美元都使用波浪号与说明文案表达估算属性。

更新时间辅助项

底部可再次呈现更新时间，但不得比主要指标更醒目。

离线标记辅助项

使用图标和文字共同表达，不能只依赖颜色。

辅助信息权重

弱边框、小字号和中性色让成本数据不抢配额主视觉。

官方账户快照

提供计划、官方 Token 和配额窗口，只读展示。

Zeus 本地账本

提供缓存、估算点数 与 API 等价估算，只归属于 Zeus。

最紧迫配额窗口

从全部窗口中选择剩余比例最低的一项进入摘要。

价格目录快照

费用估算沿用逐轮费率快照，不用新价格重算历史。

查看完整统计

主动作，显示 Zeus 后进入设置页“用量”分类。

显示 Zeus

恢复主窗口，但不改变当前任务或会话选择。

退出 Zeus

保留明确文字动作，避免只有图标造成误触。

点按外部关闭

与失焦关闭保持一致，不阻断其他应用操作。

退出键 关闭

键盘用户可以快速退出临时浮窗。

焦点返回

关闭后恢复到原触发点，保持键盘操作连续。

加载状态

有旧值时保留旧值并局部刷新；首次加载使用轻量骨架。

未登录状态

说明官方账户未登录，并提供前往配置的动作。

离线状态

显示旧数据、更新时间和离线标签，不伪造刷新成功。

错误状态

说明影响范围和恢复方式，不显示堆栈或密钥。

字段不可用

单项缺失只影响该指标，不让整个浮窗失效。

移除顶部入口

Zeus 窗口标题栏不再出现统计按钮或同类替代入口。

不混入新建窗口

新建窗口只留在右键原生菜单，统计浮窗保持专注。

左键浮窗

左键是高频查看路径，第二次左键关闭。

右键菜单

右键保持系统菜单语义与窗口管理能力。

多屏定位

浮窗锚定当前图标所在屏幕，并在可用工作区内夹紧。

浅色与深色

跟随系统主题，保持对比度和低疲劳阅读。

测试身份应用

运行检查只允许使用 dev.hypha.zeus.test 独立身份和数据目录。

真实运行待验收

lint、类型检查和构建不能证明 macOS 菜单栏交互已经正常。

文本版设计说明
入口：菜单栏 Zeus 图标；窗口顶部入口移除。主浮窗：配额为主、Token 为次、缓存与费用辅助。数据：官方账户与 Zeus 本地账本保持分层。动作：左键查看统计，右键管理应用。边界：只读、无购买和重置；真实运行仍待验收。
