# ZEUS-0183 环境卡片的展示缺陷

## 任务目标

修复会话环境信息卡片中“来源”区域与用户提供的 Codex App 参考图不一致的展示缺陷。

## 当前阶段

实现与静态、测试包验证已完成。真实环境卡片 GUI 验收受 Electron 桥接与隔离数据条件限制，仍需在可进入目标会话的独立测试环境中补验。

## 已核对事实

- 现有组件为 `SessionQuickActionsCard.tsx`，宽屏常驻形态与收起弹层形态共用同一实例。
- 当前“来源”默认只展示前 2 条；参考图默认展示 3 条。
- 当前所有来源统一使用文件图标；参考图中图片来源显示真实缩略图。
- 当前“查看全部”使用下拉箭头、显示总数，并在卡片内展开或收起；参考图使用来源类图标且不显示总数。
- 用户补充确认：来源文件较多时，点击“查看全部”会使卡片超出页面底部。
- 根因不是缺少 `overflow-y`，而是常驻卡片的最大高度只按整个视口估算，没有扣除 Token 摘要等顶部状态后的真实起点；卡片展开后仍可越过视口底部。
- 现有会话资源通道已能按受信资源 ID 读取图片预览，不需要 Renderer 直接读取本机路径。
- 当前来源集合包含输入框中的附件与会话中的结构化资源；用户已确认保持 `ZEUS-0074` 的这一现有口径，本展示缺陷不改变数据范围。
- 仓库中没有现成的“全部来源”独立工作面或弹窗；现有 `SourceWorkspace` 只预览单个受信会话资源。

## 已确认决策

### “查看全部”的展开与越界处理

建议保留卡片内的“查看全部”，但不再让整张卡片随来源数量无限增长：卡片按真实起点限制在可视区内，展开后只有来源列表使用剩余高度滚动，环境操作保持可见。

优点：不新建来源浏览界面，不改变现有打开单个资源的安全通道，文件再多也不会越出视口，并且环境操作不会被顶走。

缺点：来源区会形成一个明确的内部滚动区，需要同时处理键盘滚动、窄窗口和减少动态效果。

### 展示范围

- 默认展示 3 条来源。
- 图片来源显示通过现有受信资源通道读取的真实缩略图；读取中或读取失败时安全降级为对应文件类型图标。
- 非图片来源使用已有资源类型选择合适图标，不再全部显示为通用文件图标。
- “查看全部”不显示来源总数，不使用下拉箭头；卡片内展开和收起行为保留。
- “来源”的数据范围、顺序、添加入口和单资源打开通道保持现状，不在本展示缺陷中重做产品语义。

优点：验收结果可直接与用户参考图和越界现象对照，不引入新的来源数据链路。

缺点：现有“来源”命名和数据口径仍然较宽，如果后续要重做语义，需要作为独立产品任务澄清。

## 领域口径

- “环境卡片来源”已写入根目录 `CONTEXT.md`：它是当前输入附件和会话中已有结构化资源的合并展示，不是 Git 来源分支、Agent 访问记录或独立来源库。
- 这一口径是对已确认现状的记录，不产生新的数据或操作边界。

## 实现范围

- 环境卡片默认来源数量从 2 调整为 3。
- 图片来源通过已有会话资源预览通道或当前输入附件预览通道延迟加载，失败时保留类型图标。
- “查看全部”使用来源类图标且不显示总数，继续支持展开和收起。
- 卡片依据实际顶部和当前可视视口计算剩余高度；展开后标题与环境操作保持可见，来源列表独立滚动。

## 实现约束

- 未新增测试文件或测试脚本。
- 未执行 Git 提交、推送、合入或远端刷新。

### 真实运行边界

- 通过 Zeus 内置浏览器打开本地质检入口后，页面可加载启动界面，但由于浏览器环境没有 Electron 本地桥接，控制台报错 `Electron 本地桥接未就绪`，无法进入会话工作区。因此浏览器结果不能证明环境卡片的缩略图、展开滚动或底部边界已经通过。
- 当前机器已有其他任务的 `Zeus Test.app` 实例；本任务没有停止、复用或污染该实例。
- 已核对的旧隔离测试数据中没有可直接用于本任务的多来源会话。为避免使用共享数据或伪造验收结果，本任务没有启动空白测试包冒充 GUI 验收。
- 后续真实验收应在独立用户数据目录中准备至少 4 条来源，其中包含图片与非图片文件；检查默认 3 条、真实缩略图、无数量的“查看全部”、展开后来源列表独立滚动，以及卡片不越过视口底部。
