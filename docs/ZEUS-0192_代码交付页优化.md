# ZEUS-0192 代码交付页优化

## 任务目标

把代码交付从受主窗口内容区限制的应用内弹层，调整为任务级 macOS 原生子窗口壳，并修复分支辨识和审查顺序：

1. 完整显示任务分支名称，实时标记主窗口当前会话所属开发线。
2. 始终优先显示本机未提交变化，方便先审查即将提交的文件。
3. 提供可缩放、可最大化并记住最近布局的独立交付工作面。

## 已确认的产品口径

### 原生窗口壳

- 使用 Electron `BrowserWindow` 提供 macOS 原生窗口壳，交付内容继续复用现有 React 组件；不使用 AppKit 重写文件树、双栏差异、冲突编辑和 Git 操作。
- 窗口为非模态任务子窗口，主窗口可以继续查看和切换会话。
- 每个任务最多一个交付窗口；重复打开同一任务只聚焦，不重置正在查看的位置。不同任务可以分别打开。
- 首次打开约占当前显示器可用区域九成，允许缩放、最大化和全屏；以后统一复用最近一次交付窗口尺寸与位置，越界时收回当前可用区域。

优点：交付审查拥有独立稳定空间，用户可以边审查边查看会话；现有交付业务逻辑继续复用。

代价：需要新增窗口生命周期、第二 Renderer 装载、跨窗口上下文同步和状态刷新；多个任务窗口会增加内存占用。

### 当前会话开发线

“当前会话开发线”只指主窗口此刻选中会话绑定的任务开发线。主窗口切换会话时，标识实时变化；当前会话不属于本任务时，本交付窗口不显示“当前会话”。多仓开发线把标识放在包含当前会话工作区的分支组上。

优点：标识始终表达实时事实，不会把打开来源或弹窗内选中项冒充当前会话。

代价：主窗口必须把当前任务与工作区身份同步给全部交付窗口，窗口独立装载的任务数据本身不足以推导该事实。

### 审查顺序

- 打开交付窗口、切换任务开发线或 Git 状态刷新后，差异范围都强制回到“本机未提交”。
- 即使本机未提交文件为零，也保留该空态，不自动回退“已提交成果”；空态提供显式查看已提交成果入口。
- 用户可以手动切到已提交成果，但下一次开发线切换或状态刷新会再次回到本机未提交。

优点：本机未提交审查成为一致、可预期的主路径。

代价：刷新可能打断已提交成果的连续查看；空工作区需要用户再点击一次才能看到已提交差异。

### 分支展示

- 分支组标题完整展示真实分支名，允许软换行并提供复制入口。
- “当前会话”使用文字标识并具备可访问名称，不只依赖颜色。
- 用户在交付窗口内选择其他分支只改变审查对象，不移动当前会话标识。

## 实施范围

- Electron Main：任务交付窗口创建、按任务复用、尺寸恢复、可信 IPC 和窗口销毁。
- Preload：打开交付窗口、同步当前会话上下文、交付结果通知和打开冲突处理会话的受控桥接。
- Renderer 启动入口：识别交付窗口 surface，只装载当前任务与交付组件。
- 主窗口：所有代码交付入口改为请求原生窗口；同步当前会话任务与工作区身份；接收交付结果刷新。
- 交付组件：接收当前会话工作区、完整展示分支名、复制分支名、强制本机未提交优先和独立窗口布局。

## 安全与范围边界

- 不修改服务端 Git 写操作门禁，不绕过任务、项目、工作区和合入记录归属校验。
- 不自动执行 commit、push、merge、rebase、revert 或丢弃。
- 不新增、恢复或维护单元测试、组件测试和 TDD 流程。
- 不启动或修改正式 `Zeus.app`；真实运行只使用独立身份 `Zeus Test.app` 与独立数据目录。
- 静态检查、构建和打包成功只作为对应证据，不代替原生窗口真实交互验收。

## 实施计划

1. 建立交付窗口 surface、Main 窗口注册和最近布局持久化。
2. 建立主窗口与交付窗口之间的当前会话、交付变化和会话打开桥接。
3. 把代码交付入口迁移到原生窗口，保留 Electron 桥不可用时的应用内安全降级。
4. 调整分支列表与差异范围，覆盖完整名称、当前会话标识、复制和强制未提交空态。
5. 执行格式检查、lint、类型检查、构建、测试包打包和真实窗口交互验收，回写结果与缺口。

## 实现结果

- 新增任务级代码交付 `BrowserWindow`：同任务只保留一个窗口，重复打开时恢复并聚焦，支持缩放、最大化、全屏和最近布局恢复。
- 新增受控 IPC：只允许已登记主窗口打开交付窗口，只允许交付窗口通知它所属任务的变更或请求打开冲突会话。
- 主窗口实时同步当前会话的任务和工作区身份；交付窗口只在身份属于当前任务时显示“当前会话”。
- 分支标题改为完整软换行，增加复制入口；“当前会话”使用文字标识，不只依赖颜色。
- 打开交付、切换工作区、提交成功或刷新数据后都回到“本机未提交”；空态不自动跳到已提交，只提供显式“查看已提交成果”按钮。
- 本地服务重启时同时刷新主窗口和交付窗口；交付操作完成后通知主窗口重读真实服务状态。
