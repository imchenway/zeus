# ZEUS-0225 项目工作区数字快捷切换

## 当前阶段

实现与验证均已完成。

## 目标

让用户可以通过 macOS 的 Command 与数字组合，在当前项目顶部的五个项目工作区入口之间快速切换。

## 已确认决策

### 名称

截图中的顶部区域统一称为“项目工作区入口”，不称为普通页签。五个入口分别打开完整的任务、Git、源码、图谱和命令工作面。

### 数字映射

- `Command + 1`：任务
- `Command + 2`：Git
- `Command + 3`：源码
- `Command + 4`：图谱
- `Command + 5`：命令

映射与顶部入口从左到右的可见顺序一致。

优点：用户可以依靠位置记忆，数字顺序与界面顺序直接对应。

代价：以后若调整顶部入口顺序，快捷键映射和界面提示也必须同步调整。

## 交互边界

- 主工作面内的输入框或源码编辑器获得焦点时，`Command + 1` 至 `Command + 5` 仍然响应。
- 弹窗或其他阻断式确认打开时暂停响应，不允许快捷键绕过当前流程切换底层工作面。

优点：用户写代码或填写普通工作面内容时仍可快速切换，同时不会误跳过确认或丢下未完成的阻断式操作。

代价：这五组组合键不能留给源码编辑器或普通输入控件承担局部功能；弹窗打开期间同一快捷键会暂时无效。

## 快捷键提示

顶部入口常态不增加数字或组合键文字；鼠标悬停提示和无障碍名称显示对应的 `Command + 数字`。

优点：保留现有顶部区域的低噪音布局，同时让鼠标用户和辅助技术用户能够发现快捷键。

代价：不悬停且不使用辅助技术时，用户无法从常态界面直接看到快捷键。

## 待确认边界

- 无。

## 生效范围

- 只有 Zeus 主窗口存在当前项目且项目工作区入口可见时响应。
- 设置页、独立 Git 窗口和代码交付窗口不响应。
- 快捷键切换与点击对应入口共用同一导航动作和离开保护，不得绕过未保存内容处理。

优点：快捷键行为与屏幕上真实可见的入口一致，并继续遵守既有内容保护。

代价：用户不能从设置页或独立窗口通过数字快捷键直接跳回项目工作面。

## 实现与验证记录

### 实现

- `apps/desktop/src/renderer/App.tsx` 使用单一项目工作区入口清单维护可见顺序、工作面目标和数字快捷键，避免按钮与键盘映射各自漂移。
- 主窗口监听精确的 `Command + 1` 至 `Command + 5`；不把 `Control`、`Option`、`Shift` 组合或长按重复事件当成本功能。
- 响应前复验当前项目、设置页和页面中的模态语义；输入框与源码编辑器不形成排除条件。
- 快捷切换调用与点击相同的 `openProjectSection`，继续经过源码和任务布局的未保存内容保护。
- 五个入口增加本地化悬停提示、无障碍名称和 `aria-keyshortcuts`；可见标签与既有样式保持不变。
- `CONTEXT.md` 新增“项目工作区入口”术语，明确它不是普通页签或主导航。
