# ZEUS-0236 新会话样式优化

## 当前阶段

- 已完成需求澄清、领域命名、实现、静态门禁、测试身份打包和目标界面真机检查。
- 本任务不新增或恢复单元测试，不执行 Git commit、push、merge、revert 等历史或远端写入。

## 用户反馈

新建会话页面看不到会话将在哪个项目和分支中生效。参考 Codex 的新建会话输入框，执行上下文应直接位于输入框顶部，并能从原位切换。

## 已确认产品边界

- 这组信息统一称为“新会话执行上下文”，不再使用含糊的“会话准备”。
- 输入框顶部只展示“项目”和“分支”，不展示“本地”按钮。
- 项目项可以选择 Zeus 项目；选择后立即联动左侧当前项目和会话页，并保留未发送文字、附件和模型配置。
- 分支项使用 Codex 风格的可搜索菜单，展示本地分支、当前分支勾选、不可检出分支禁用状态，以及“创建并检出新分支”入口。
- 选择分支后立即执行真实 Git 检出；失败时保留原分支和新会话输入，并在当前输入区附近展示可读错误。
- 分支列表不自动访问远端，不把本机缓存远端引用冒充为可直接检出的本地分支。
- 项目根不是 Git 仓库时明确显示“非 Git 目录”，不伪造 `main`。
- 这组上下文只属于新建项目对话；已有会话继续使用自身持久执行目录和实时分支，不增加重复选择器。

优点：用户在输入前即可确认真实执行位置，项目、分支和最终会话使用同一事实；菜单形态与 Codex 参考一致。

代价：检出分支会真实改变项目主工作区，可能被未提交变化或其他 worktree 占用拒绝；项目切换还需要在不丢草稿的前提下同步应用导航。

## 已核实代码事实

1. 新建项目对话由 `NewConversationComposer` 渲染，当前输入框顶部没有执行上下文行。
2. 项目对话服务端固定使用所选 Zeus 项目的 `localPath` 作为 `cwd`，所以项目选择可以直接决定真实会话目录。
3. 项目 Git 工作台已经提供本地分支读取、检出和创建分支能力；新会话应复用同一真实能力，不建立第二套 Git 执行器。
4. 现有项目记录只包含项目身份和本机路径，分支必须从项目 Git 快照读取，不能从文案或历史默认值推断。
5. 旧文档曾要求在会话输入区显示项目、本地模式和分支，后续又因界面减负移除；本任务以用户本次确认的“项目 + 分支顶部上下文”覆盖旧视觉取舍。

## 实施方案

1. 为新会话工作区提供项目列表、当前项目、项目 Git 快照与项目切换动作。
2. 扩展项目 Git 快照的本机 worktree 占用事实，使分支菜单能在点击前标识不可检出的分支。
3. 新增新会话执行上下文组件，复用现有 Git 工作台接口完成检出与创建分支。
4. 项目切换时保留输入草稿和会话配置，只刷新项目对应的分支快照与能力目录。
5. 按参考图补齐输入框顶部布局、搜索菜单、当前勾选、禁用原因、创建分支表单、错误、键盘焦点、窄窗口和减少动态效果。

## 实施结果

1. 新建项目对话输入框顶部新增“新会话执行上下文”，只展示 Zeus 项目和项目根仓库当前分支；已有会话和任务对话输入框不受影响。
2. 项目菜单支持按名称或路径搜索，并直接更新当前项目导航；composer 不再因项目变化重新挂载，未发送文字、附件和已选运行配置继续保留。
3. 分支菜单读取项目 Git 工作台真实快照，只展示本地分支；当前分支勾选，已被其他 worktree 检出的分支在点击前禁用并说明原因。
4. 检出与“创建并检出新分支”复用项目 Git 工作台白名单动作。分支动作未完成期间禁止发送；项目中仍有连接、排队、响应、暂停或等待交互的会话时拒绝改变主工作区分支。
5. 项目根不是 Git 仓库时显示“非 Git 目录”；读取或 Git 操作失败时保留原分支和草稿，并在上下文行展示错误。
6. 项目 Git 快照增加所有 worktree 已检出分支集合，Renderer 对旧宿主缺失该字段保持空集合兼容。
