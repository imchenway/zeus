# ZEUS-0237 会话发送图片位置

## 任务目标

普通用户消息发送图片或其他附件后，附件组应显示在消息正文上方；气泡内图片缩略图的最大宽高由 220px 收紧为 165px。

## 已确认范围

- 只调整普通用户消息，不改变任务首发字段图片、正文内嵌图片和助手生成图片。
- 用户消息同时包含图片和普通文件时，全部附件作为同一附件组置于正文上方。
- “减小 1/4”按线性尺寸计算，最大宽高缩为原来的 75%。
- 图片预览、点击打开、失败回退和资源授权继续复用现有能力。

## 设计取舍

附件组整体前置，使用户先确认本次发送的资源，再阅读补充说明；图片缩略图单独收紧，不缩小普通文件卡片的内容控件。

优点：附件与正文层级一致，图片占用空间更克制，混合附件的排序规则也更容易理解。

代价：普通文件卡片会从正文下方移动到正文上方；较窄气泡内的图片换行位置可能随 165px 上限变化。

## 实施记录

- 普通用户消息新增统一的“用户消息附件组”，在正文和编辑框之前渲染。
- 权威会话资源、发送中的本地图片和历史附件投影共用同一前置区域。
- 附件组内图片缩略图最大宽高设为 165px，最小占位高度同步由 112px 收紧为 84px。
- 任务首发与其他消息角色继续使用既有渲染顺序。
