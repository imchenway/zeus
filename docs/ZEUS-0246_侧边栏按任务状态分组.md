# ZEUS-0246 侧边栏按任务状态分组

## 任务目标

在侧边栏“项目”标题右侧增加一个全局切换按钮，让全部项目下的会话可以在“平铺”和“按任务管理状态分组”两种组织方式之间切换。

## 已确认范围

- “任务状态”统一指任务管理状态，不使用会话运行状态分组。
- 项目始终是最外层容器，切换组织方式不会把会话移动到项目之外。
- 没有关联任务的项目对话继续直属原项目，不伪造任务管理状态。
- 分组模式只显示当前确实包含会话的任务管理状态分组。
- 分组顺序遵循项目现有任务管理状态配置顺序，不新增第二套状态顺序。
- 组内会话继续按现有会话阶段更新时间倒序排列。
- 每个任务管理状态分组可以独立展开或折叠；首次全部展开，之后按项目和状态记住选择。
- 平铺与分组是全局统一选择，切换按钮位于侧边栏“项目”标题右侧。
- 全局组织方式跨应用重启保留；没有历史偏好时默认平铺，避免升级后改变现有侧栏。
- 分组标题只显示任务管理状态名称，不显示会话数量。
- 切换按钮随当前模式更换图标：平铺时表达“切到分组”，分组时表达“切到平铺”；提示文案与可访问名称描述点击结果。

## 当前代码事实

- `ProjectConversationTree` 当前把项目对话与全部任务会话合并后统一排序并平铺展示。
- `App.tsx` 已按项目构造项目对话与任务会话数据，并拥有项目任务及任务管理状态配置。
- App Shell 设置已经承载项目展开、任务筛选和任务视图等本机偏好，可以继续作为会话组织偏好的统一事实源。

## 方案取舍

### 全局组织方式

优点：按钮位于“项目”总标题，与一次影响全部项目的范围一致，用户不需要逐项目切换。

缺点：无法让少量会话项目保持平铺、同时让大量会话项目使用分组。

### 可折叠状态分组

优点：长列表可以按工作阶段收纳，并能恢复用户上次的侧栏现场。

缺点：需要维护项目与状态组合的展开偏好，状态被删除或替换时还要安全忽略历史键值。

## 实施结果

1. 在“项目”标题右侧增加组织方式按钮。平铺时按钮表达“按任务状态分组会话”，分组时表达“平铺显示会话”，图标同步切换。
2. `ProjectConversationTree` 同时支持原平铺列表和任务管理状态分组；项目直属会话位于状态组之前，只渲染有会话的状态组。
3. 分组顺序来自项目任务管理状态配置，状态名称复用当前界面语言；组内会话继续按会话阶段更新时间倒序。
4. 状态组支持独立折叠，切换方式和折叠键值都写入 App Shell 本机设置；旧设置缺少字段时回退平铺和全部展开。
5. 设置保存使用串行队列读取最新 Renderer 状态，避免快速连续切换或其他 App Shell 保存响应覆盖新偏好。
6. 设置导入导出、服务端归一化、启动迁移和视觉验收样例同步支持新增字段；非法或过长的项目、状态键会被丢弃。
7. 搜索仍按会话标题过滤，折叠后键盘会话导航只包含当前可见行；分组按钮具备展开状态、目标动作提示和减少动态效果支持。
