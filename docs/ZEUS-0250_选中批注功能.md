# ZEUS-0250 选中批注功能

## 任务目标

在 Zeus 会话回答正文中补齐类似当前 Codex 的文字选区快捷操作，并允许用户在会话右侧文件工作面针对具体代码行留下评论；这些上下文可以进入当前对话或临时侧边聊天。

## 当前代码事实

- Zeus 已有内置浏览器页面批注，但它处理网页元素、网页文字和网页区域，不等同于本任务截图中的会话回答正文批注。
- 当前会话回答正文允许原生选文，但没有与选区绑定的快捷操作条、主会话选区注释或临时侧边聊天。
- 当前会话已有普通输入、排队和引导链路；“添加到对话”仍需明确如何复用该链路而不自动发送。
- 会话右侧上下文工作面当前把普通文件呈现为 `SourceWorkspace`，把执行轮次变更呈现为 `TurnDiffWorkspace`；两者都是逐行渲染，但都没有行尾 `+`、本地评论编辑器或输入框评论集合。

## Codex 当前交互取证

用户提供的真实截图与本机当前 Codex `26.803.61601 (6396)` 只读取证共同确认：

- “添加到对话”在当前主会话正文中留下编号选区锚点，并把注释集合暂存进当前输入框，不自动发送；
- “在侧边聊天中提问”打开侧边聊天，并把选中文字作为已选文本片段带入输入框，等待用户自行输入问题和发送；
- “更多详情”不是查看选区元数据，而是携带选中文字打开 Quick Chat，并自动使用固定问题 `Tell me more about this` 发起提问。

“更多详情”和“在侧边聊天中提问”共享侧聊方向，区别是前者一步自动提问，后者保留用户编辑与发送决定。官方 OpenAI 文档目前没有逐项公开这三个按钮的行为说明，以上结论只作为当前安装版本的可观察参考，不冒充长期协议。

## 已确认口径

### 回答正文直接触发

新增“会话回答文本选区快捷条”：用户在 Zeus 会话的智能体回答正文中选中文字后，紧邻选区显示快捷操作。

优点：用户阅读回答时可以即时引用或追问，符合用户提供的 Codex 参考图。

代价：会话正文选文会新增一层浮动界面，需要避免遮挡选区、消息操作和原生复制行为。

### 快捷条动作

首批只保留“添加到对话”和“在侧边聊天中提问”，不提供“更多详情”。

优点：一个动作面向主会话，一个动作面向临时侧聊，边界清楚，也不会自动发送固定问题。

代价：用户需要自己输入解释类问题，少一个一键“详细讲讲这段内容”的入口。

### 文件行评论

用户明确要求侧边栏打开的文件也可以评论。参考 Codex 交互是在代码行侧边显示 `+`，点击后打开“本地评论”编辑器；保存的评论保留文件和行号，在输入框显示评论数量，仍由用户最终发送。

优点：评论绑定真实文件行，不需要把路径、行号和正文手工复制进输入框。

代价：普通源码与差异视图存在不同的行身份；差异还需要区分旧行和新行，不能只保存屏幕位置或当前显示序号。

## 复刻范围确认

用户要求不再逐项解释 Codex 细节，而是以当前安装版本的真实行为为参考完成实现；结合前述逐项确认，本任务范围固定为：

- 智能体最终回答正文选区出现快捷条，只保留“添加到对话”和“在侧边聊天中提问”；
- “添加到对话”建立指向原回答选区的编号锚点，并把注释集合暂存到主输入框，不自动发送；
- “在侧边聊天中提问”打开关闭后消失的临时侧聊，把所选文字作为上下文带入，等待用户输入并发送；
- 右侧普通源码文件和变更审核差异都支持单行及连续多行本地评论；
- 本地评论包含文件路径、差异侧与真实行号，暂存进主输入框，发送后作为用户消息上下文保留；
- 不实现“更多详情”，不复用网页批注草稿，也不把评论发布到 GitHub 或直接修改代码。

本机 Codex 包进一步表明，普通源码编辑器与差异组件共用同一套评论附件模型；普通源码使用右侧行号，差异行按旧侧 `L`、新侧 `R` 区分。选区注释、文件评论和网页批注虽然都能随消息发送，但属于三种不同上下文，不应混成同一个草稿实体。

## 设计取舍

- 主输入框同时展示选区注释数和文件评论数。优点是用户发送前能统一检查与移除；代价是输入状态需要和普通附件、网页批注一起参与草稿恢复、排队和失败回填。
- 结构化上下文与可读序列化文本同时保留。优点是本地界面能恢复精确锚点，Provider 也能收到完整语义；代价是发送链路需要新增受校验的上下文字段。
- 侧边聊天使用独立只读临时会话，而不是把问题暗中发送到主会话。优点是主会话历史不被污染；代价是每次提问会单独派发临时轮次，关闭侧栏只立即销毁界面内容，已经派发的轮次仍由服务端完成后自动关闭和回收。
- 选区快捷条只挂载在已完成的智能体最终回答正文。优点是锚点稳定，不会随流式文本继续位移；代价是流式生成期间暂不出现快捷条。

## 实现记录

- 新增统一的 `ConversationContextDraft`，分别保存回答选区注释和文件行评论；草稿、失败回填、延迟发送、排队快照和用户消息回显都保留这份结构化上下文。
- 已完成回答正文选区快捷条，只在已完成且允许继续输入的智能体回答中出现，界面只有“添加到对话”和“在侧边聊天中提问”。
- “添加到对话”生成编号锚点并聚焦主输入框，不自动发送；可从编号锚点补充可选说明或删除。
- “在侧边聊天中提问”打开独立临时侧栏；所选文字不会写入主会话，侧栏关闭后本地问答立即消失。
- 普通源码和变更差异复用本地行评论编辑器；单击 `+` 建立单行评论，按住 Shift 再点可覆盖同一侧的连续多行，差异评论保留 `L/R` 行身份和相邻差异片段。
- Provider 输入同时获得可读序列化内容，持久记录保留结构化字段；接口对数量、字段、字符长度和总体积做服务端校验。
