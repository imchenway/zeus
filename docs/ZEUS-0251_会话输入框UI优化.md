# ZEUS-0251 会话输入框 UI 优化

## 当前阶段

产品实现、静态门禁与隔离 GUI 验收已完成；内置浏览器因工具无响应保留单独缺口。

## 原始问题

- 会话输入区的附件、权限、协作模式、上下文占用、速度模式和发送或停止图标视觉不统一。
- 上下文占用浮层受输入区层叠上下文限制，会被上方计划进度遮挡。

## 已确认边界

- 新建会话和已有会话续写输入区使用同一套视觉规则；现有两处渲染入口都需要核对，不能假设完整复用。
- 辅助入口继续使用纯图标，不改成常驻文字标签。
- 常态使用统一中性色；计划模式、Fast 模式等已开启状态使用同一克制强调色，完全访问和上下文告警继续使用真实语义色。
- 上下文占用浮层打开时位于计划进度之上，不推动计划条，也不遮挡输入正文。
- 本任务不改变附件、权限、计划、上下文计算、速度模式、模型、推理强度、发送或停止的业务行为。
- 图标在常态、开启、告警和高风险状态下都不绘制方形背景；只有鼠标悬停或键盘聚焦时短暂出现低对比圆形反馈。
- 辅助图标采用轻盈线性语言，命中区统一为 `32×32px`；验收以肉眼可见的图形大小和重心一致为准，允许对内部留白较大的速度表盘做少量光学补偿。开启态只强化关键线条或局部填充，不增加装饰火花或额外底座。
- 视觉稿必须逐项展示附件、权限、计划、上下文、速度和发送或停止主操作的多种真实状态，不能只画一条理想状态工具栏。

## 视觉方向

- 附件使用短而圆润的回形针，替代容易被理解为“新增任意内容”的加号。
- 权限按只读、自动、完全访问显示眼睛、盾牌勾选、带感叹号的风险盾牌，状态不只依赖颜色。
- PLAN 协作模式使用收敛后的清单勾选图标，替代灯泡和装饰火花。
- 上下文占用保留环形进度，但统一线宽、尺寸和留白。
- Fast 模式使用克制的速度图标；发送和停止使用同尺寸圆形主操作。
- 产品实现继续复用仓库现有 Phosphor 图标体系，不新增另一套图标依赖。
- 所有图标按钮使用不小于 `32px` 的透明命中区，状态只改变图标颜色、线条或填充；保留可见键盘焦点、明确可访问名称和减少动态效果降级。

## 取舍

- 优点：输入区视觉语言统一，普通状态不再争抢注意力；风险和已开启状态仍可快速辨认；浮层信息完整可读。
- 代价：普通状态不再依靠固定彩色区分，初次使用主要通过图形和提示文字理解；浮层提升到应用层需要维护锚点和窗口边界。

## 领域模型

本任务沿用 `CONTEXT.md` 中既有的“会话输入区”“会话权限模式”“PLAN 协作模式”“上下文占用”“速度模式”等术语，没有新增领域概念，因此不修改领域词典，也不新增 ADR。

## 浏览器评审反馈

- 完全访问的盾牌内部明确使用感叹号，避免继续沿用自动权限的勾选语义。
- 上下文占用圆环需要更饱满，不能只是一圈偏细的进度线。
- 速度表盘因图形自身留白较大，需要按实际观感放大，与相邻图标对齐。
- 发送箭头、停止方块和忙碌旋转图形需要增大内部主体并统一视觉重量。

## 实现记录

- 已将新建会话和已有会话的附件入口从文字加号替换为回形针图标。
- 已将权限、计划模式、上下文占用和速度控件调整为风险盾牌、清单、加粗进度环和表盘语义。
- 已将发送、停止和提交中状态替换为真实矢量图形，并统一为 `32×32px` 圆形主操作。
- 上下文详情改为挂载到页面顶层的固定定位浮层，按触发图标测量位置并响应窗口缩放与滚动，不再受输入框层叠上下文限制。
- 图标常态保持透明背景，只有悬停或键盘聚焦时出现低对比圆形反馈；完全访问、计划开启、Fast 开启和上下文风险继续使用各自状态色。
