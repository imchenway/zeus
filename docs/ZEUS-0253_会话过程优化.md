# ZEUS-0253 会话过程优化

## 当前阶段

用户已确认共同口径，实现、静态门禁、构建、独立测试包和可达范围内的真实图形界面验收已完成。

## 用户现场

1. 已回答选项行的圆形单选标记没有随整行高度垂直居中。
2. 自定义回答同时包含文字和图片时，图片位于绿色选中框外；目标是图片位于文字上方、处于同一绿色选中框内，并可点击查看。
3. 待回答选项的第一项长期显示灰色表面，容易被理解为已经选中。

## 已核对事实

- 待回答组件打开后会把键盘焦点放到第一项。
- 当前样式把悬停、键盘焦点、推荐项和真实回答选中项合并为同一灰色表面；第一项带有 `(Recommended)` 时，即使没有被选择也会持续显示灰底。
- 已回答选项行当前按顶部对齐，圆形标记还有额外顶部偏移，因此多行选项中不会随整行居中。
- 自定义回答文字位于绿色选中行内，回答附件却作为选项列表之后的独立区块渲染，因此附件天然落在绿色框外。
- 回答附件复用了会话输入资源卡，可以安全加载缩略图，但已回答记录没有传入图片点击放大动作。

## 已确认口径

### 推荐态、键盘当前项与回答选中态

- 推荐态只保留“推荐”标记，不绘制整行选中底色。
- 键盘当前项使用清晰焦点描边，不绘制整行选中底色。
- 只有用户真实选择的答案使用整行选中表面，并继续保留图标或文字等非颜色反馈。

优点：推荐、操作位置和真实答案不会再互相冒充，用户可以准确判断当前是否已经作答。

代价：推荐答案不再依赖整行灰底强调，视觉存在感会低于当前实现。

### 自定义回答附件归属

- 图片、文件、文件夹和超长粘贴文本都属于自定义回答本体，与回答文字进入同一个绿色“已选择”框。
- 全部附件排在回答文字上方，不再作为选项列表之后的独立区块。
- 图片点击后放大查看；其他资源点击后复用现有受控打开能力，不从 Renderer 直接打开任意本机路径。

优点：文字和资源使用同一回答归属，历史记录不会再出现绿色框外的孤立附件，所有附件类型规则一致。

代价：包含多个附件的自定义回答会明显增加绿色选中框高度；图片放大与其他资源打开需要补齐明确的键盘和焦点返回行为。

### 已回答标记垂直对齐

- 普通预设答案行的圆点和右侧“已选择”按整行实际高度垂直居中；单行与多行说明使用同一规则。
- 带附件的自定义回答不把圆点相对整张大卡片居中，而是在卡片顶部使用独立状态行；状态行以下按“附件、回答文字”的顺序展示。

优点：普通答案直接解决当前偏上问题；附件较高时，选择状态仍位于稳定、易扫读的位置。

代价：普通预设答案和带附件自定义答案不使用完全相同的内部网格，需要明确维护两种内容结构。

## 实施结果

- 待回答选项不再因为“推荐”或获得键盘焦点而显示灰色选中表面；推荐只保留标记，键盘焦点使用清晰描边，真实选中状态独立表达。
- 普通已回答选项的圆形标记与“已选择”按整行高度垂直居中。
- 自定义回答使用顶部状态行，图片、文件、文件夹和超长粘贴文本统一位于绿色选中框内、回答文字上方。
- 回答图片可点击进入原生放大查看层，支持关闭、点击遮罩和 Escape，并在关闭后恢复触发按钮焦点；其他资源复用现有受控打开桥接。
- 资源卡补充回答历史场景的可访问名称，没有改变输入区既有资源卡默认语义。
