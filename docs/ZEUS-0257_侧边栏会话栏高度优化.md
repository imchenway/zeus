# ZEUS-0257 侧边栏会话栏高度优化

## 当前阶段

- 用户已选择样式候选 1“无底色语义图标”。
- 产品代码、静态门禁、独立测试包和真实界面验收均已完成。
- 本任务不新增或恢复单元测试体系，不执行 Git commit、push、merge、revert 等历史或远端写入。

## 用户反馈

- 有状态胶囊的会话行与无状态会话行高度不一致。
- 侧边栏缩到最窄后，图标胶囊仍像大号方按钮，标题被严重挤压。
- 当前彩色胶囊的视觉观感过重，仅缩小尺寸不足以解决问题。

## 已核实代码事实

1. 项目侧边栏在 `styles.css` 中把会话行声明为 `26px` 最小高度，同时又为行与状态控件叠加了纵向内边距。
2. `ProjectConversationTree` 通过 `TaskRunStatusChip` 渲染侧边栏运行状态，直接复用了任务表状态组件。
3. 通用任务状态组件自带背景、边框、圆角、最小高度与内边距；窄态只隐藏了文字，没有切换成侧边栏专用的低噪音表达。
4. 现有 ZEUS-0232 契约要求窄侧边栏保留状态图标和可访问名称，但“必须保留彩色胶囊底”正在被本次用户反馈重新评估。

## 已确认方案

推荐把侧边栏的状态表达从“彩色文字胶囊”改为“无底色语义图标”：

- 使用 `18px` 的固定状态槽位和 `16px` 的图形，不绘制背景与描边。
- 运行使用环形动态图标，等待回复使用气泡图标，待授权使用授权语义图标，失败使用警示图标。
- 图形是主要区分手段，颜色只做辅助；悬停提示与可访问名称保留完整状态文字。
- 有状态、无状态和当前选中行使用同一总行高，状态不再改变列表密度。

优点：会话标题恢复为主角，最窄宽度下仍保留状态，且行高稳定。

代价：宽侧边栏也不再直接显示“运行中”等文字，用户首次识别图标可能需要悬停提示。

## 样式候选稿

2026-08-13 根据用户补充的“画样式”要求，使用宽侧边栏与最窄侧边栏两张真实截图作为参考，生成三张独立样式候选：

1. 无底色语义图标：宽、窄均只显示图标，标题空间最大，文字状态转入悬停提示与可访问名称。
2. 无背景行内状态：宽侧边栏显示小图标和紧凑文字，最窄侧边栏收起文字，兼顾直观与密度。
3. 中性轻胶囊：宽侧边栏保留中性文字胶囊，最窄侧边栏收为小型圆形图标，状态最直观，但占用标题宽度最多。

三张图都保持会话行统一高度，并分别展示常规宽度与最窄宽度。用户已选择候选 1，候选 2 和候选 3 仅保留为决策证据。

## 实现记录

- `ProjectConversationTree` 不再为侧边栏状态复用任务表 `TaskRunStatusChip`，改为侧边栏专用的语义图标投影。
- 会话行固定为 `28px` 总高度，状态槽固定为 `18px`，图形为 `16px`；状态不再通过背景、边框、文字和内边距撑高会话行。
- 运行、等待回复、等待授权、暂停、失败、完成与旧会话只读分别使用 Phosphor 语义图标；普通未读继续使用圆点。
- 状态完整文案保留为图标可访问名称和原生悬停提示；减少动态效果时停止运行图标旋转。
- `DESIGN.md` 新增 ZEUS-0257 契约，明确覆盖 ZEUS-0232 的旧胶囊视觉条款，不改变状态事实、优先级、排序和校准规则。
