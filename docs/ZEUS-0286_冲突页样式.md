# ZEUS-0286 冲突页样式

## 现状

代码交付与冲突处理使用独立 macOS 子窗口，但页面内容仍受通用模态弹窗的四周内边距影响，形成一圈灰色遮罩边缘。窗口左上角还额外渲染了返回按钮，与 macOS 窗口关闭入口和页面底部关闭按钮重复。

## 处理

- 独立代码交付窗口继续复用现有代码交付与冲突处理内容，不改变 Git 操作流程。
- 独立窗口作用域使用更明确的选择器覆盖通用模态弹窗留白，让内容完整铺满原生窗口内容区。
- 移除独立窗口左上角的重复返回按钮，保留 macOS 交通灯和页面底部关闭按钮。
- 顶部任务标题在避让 macOS 交通灯的安全区域内居中，不再被返回按钮推向窗口右侧。

## 取舍

优点：四周不再出现灰色遮罩边缘，顶部只保留一套窗口导航语义，标题位置更稳定。

代价：独立窗口顶部不再提供返回按钮；用户关闭窗口需要使用 macOS 关闭按钮或页面底部关闭按钮。

- `pnpm package:mac`：通过；生成 `dist/test/mac-arm64/Zeus Test.app`，包标识为 `dev.hypha.zeus.test`，包体签名结构校验通过。
