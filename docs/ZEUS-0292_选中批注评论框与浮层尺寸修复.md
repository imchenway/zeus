# ZEUS-0292 选中批注评论框与浮层尺寸修复

## 问题

- 在已完成的智能体回答中选中文字后，可以看到“添加到对话”和“在侧边聊天中提问”，但点击“添加到对话”后没有立即出现评论框。
- 选区浮层按钮固定使用 `44px` 高度、`14px` 字号和较大的水平留白，明显大于会话页的紧凑桌面控件。

## 根因

“添加到对话”只创建选区注释并关闭快捷条，没有把新注释切换为编辑状态。评论编辑器仍然存在，但只能通过再次点击正文旁很小的编号锚点打开，主路径缺少直接反馈。

按钮外观则由会话局部样式写死，没有沿用当前会话页的紧凑尺寸，因此在短文字动作上显得过高、过宽。

## 修复

- “添加到对话”成功创建注释后，立即打开该注释的评论编辑器，并自动聚焦评论输入框；不再由旧逻辑把焦点抢回主输入框。
- 保留原有编号锚点，关闭编辑器后仍可从编号重新打开、修改或删除评论。
- 选区按钮高度收紧到 `30px`，窄窗口为 `28px`；字号调整为 `13px`，并同步收紧圆角、阴影和水平留白。
- 评论框占位文案由“可选评论”改为直接的“添加评论”，避免用户误以为当前操作已经结束。

## 取舍

优点：点击“添加到对话”后立即看到并可输入评论，反馈路径与用户动作连续；紧凑浮层更接近 Codex 的桌面阅读工具外观，也减少遮挡正文。

代价：评论框会主动取得键盘焦点；这是用户明确点击添加动作后的预期结果，但会结束当前正文选区的键盘焦点状态。编号锚点和注释草稿已经持久保留，不影响关闭后继续阅读。
