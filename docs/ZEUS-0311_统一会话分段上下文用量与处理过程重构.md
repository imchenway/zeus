# ZEUS-0311 统一会话分段、上下文、用量与处理过程重构

## 任务目标

本任务吸收 ZEUS-0310 与 ZEUS-0312，一次性重构 Zeus 核心会话链路：

- 产品会话保持稳定身份，Codex thread 与 Pi session 改为可封存的运行分段；
- 同一产品会话可在 Codex 与 Pi 之间继续，不再以 `agentKind` 拒绝发送；
- 未被运行时接受的消息只存在队列，不污染正式时间线和模型历史；
- 工具结果保留完整原文，模型上下文只使用有界投影和可分页句柄；
- 按每次真实模型请求记录 Token、费用、缓存和配置证据；
- 统一 Codex/Pi 思考摘要、工具、重试和上下文整理的处理过程展示；
- 通过候选库、安全回退库、写入围栏和维护页完成一次性结构切换。

## 已确认领域契约

- **产品会话**：用户看到的长期对话，ID、标题、任务归属和时间线稳定。
- **运行分段**：一次可原生连续运行的 Codex thread 或 Pi session。
- **submission**：一次不可变的用户意图；编辑、改路由、重发和引导都创建关联 replacement。
- **turn**：运行时接受的用户输入到本轮终态。
- **模型请求**：turn 内一次真实推理调用，包括工具续跑、重试和上下文压缩。
- **模型历史**：只含运行时已接收且允许交给后续模型的有序事实。
- **便携上下文**：为新分段从模型历史水位编译的确定性输入。
- **处理过程项**：思考摘要、工具、命令、重试、压缩与等待等可展示事件。

## 硬边界

- 不保留双写、双读、按会话开关或旧执行引擎。
- 所有旧 Provider session 在迁移后一律 sealed，升级后首条消息创建新分段。
- 队列项冻结非敏感执行配置；密钥只保留稳定凭据槽位，执行时读取最新密钥。
- 跨 Provider 发送不增加确认弹窗，但目标连接归属必须真实可见。
- 归档保留历史和完整工具结果；本任务不增加永久删除。
- 不新增或恢复单元测试体系。

## 关键取舍复核

- **单次切换而非兼容双轨**：优点是不存在新旧执行引擎相互写坏队列的窗口；代价是升级只能通过安全回退库降级，不能直接让旧版写新库。
- **运行时接纳后才进入时间线**：优点是本地排队不再伪装成 Provider 历史；代价是 Renderer 必须同时展示正式 transcript 与独立队列状态。
- **阻塞队首保持顺序**：优点是不会因余额、认证或未知结果失败而把后续消息送进错误历史；代价是用户必须先重试、取消或创建改路由 replacement。
- **真实模型压缩**：优点是跨模型历史可审计，压缩 Token 与费用不会被藏进普通 turn；代价是超长历史切换会产生额外请求，并可能在压缩成功、首轮失败时只留下可复用检查点。
- **保留旧兼容投影但不作为新事实源**：优点是现有页面和归档能力可以在同一次重构中继续工作；代价是后续应逐步删除只服务旧 UI 的 Provider 顶层字段。新结构代次、运行分段、执行队列、过程和用量已经是权威字段。
