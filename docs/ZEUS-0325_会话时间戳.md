# ZEUS-0325 会话时间戳

## 任务目标

会话气泡的时间戳不再对所有日期只显示时分：今天的消息保持紧凑的时分，今天之前的消息同时显示日期和时分。

## 已核对事实

- 用户气泡和模型气泡共用 `ThreadItemView` 中的 `formatMessageTimestamp`，不需要分别维护两套日期规则。
- 时间戳使用消息已有的 `updatedAt`，并在该值缺失时回退到 `payload.createdAt`；本任务不改变消息时间事实源。
- 时间戳位于消息悬浮操作区，旧消息增加日期不会长期占用正文宽度。

## 产品规则

1. 按用户本机时区的日历日判断“今天”，不使用过去二十四小时代替日期边界。
2. 今天的消息只显示二十四小时制的时和分。
3. 非今天的消息显示完整年、月、日和二十四小时制的时和分。
4. 中英文都使用已选界面语言的本地化顺序和分隔符，不手工拼接固定格式。
5. 无效或缺失的时间仍不显示，不伪造日期。

优点：同一天的消息保持低噪音，跨日和跨年历史可以直接辨认。

代价：旧消息的时间戳会更长；应用跨过零点但没有任何界面更新时，已挂载消息会在下一次正常渲染时按新日期边界更新，本任务不为时间戳引入常驻定时器。

## 实现范围

- 只调整共享消息时间戳格式化函数。
- 不修改 Provider、Reducer、持久化协议、消息排序、气泡布局或悬浮操作。
- 不新增或恢复单元测试体系。

- 静态检查、构建和浏览器页面不冒充 Electron 真实界面验收。

- 用户消息、模型消息和智能体子会话继续复用同一 `ThreadItemView`，日期规则不分叉。
