# ZEUS-0334 全应用页面与会话切换性能优化

## 用户现场与目标

- 点击侧边栏会话后，选中反馈、历史消息、正文、询问选项和底部模型选择分段出现，用户能感知到数据等待和渲染停顿。
- 打开“推送到新会话”时，表单先显示“直接使用项目目录”，能力读取完成后才恢复该项目上次记住的 Worktree，形成一次错误的可见跳变。
- 产品目标不是把骨架动画做顺，而是页面身份先立即切换，已有会话尽可能从内存首帧显示；网络、Provider、Git 和能力校准都在后台收敛，失败再进入统一错误反馈。

## 当前根因

1. 会话热缓存只记录用户已经打开过的会话，普通缓存上限为 10；侧边栏中未打开的会话点击后仍要等待完整快照。
2. 项目级模型能力放在 `ConnectedSessionWorkspace` 内读取。工作面按会话身份重建后，模型能力先回到空值，同一项目也会重复请求。
3. 侧边栏只改变选中行时，每个 Framer Motion 会话行仍参与布局测量；这项同步工作与顶层 `App` 的身份切换提交叠加。
4. 已完成轮次的“处理过程”虽然默认隐藏，内部 React 和 Markdown 节点仍会完整构建；长会话首次显示会为不可见内容支付解析成本。
5. 正文投影订阅整个 `NativeSessionState` 对象，连接、校准等不改变消息的状态也会重新遍历消息列表。
6. 推送弹窗在同步阶段硬编码为项目目录，读取能力后才读取项目偏好并切换到 Worktree。

## 设计决策

### 会话首帧使用有界后台预热

- 当前项目最近 24 个可写原生会话在会话元数据就绪后，以两个低并发后台任务读取权威快照。
- 预热只把快照投影进内存热缓存，不建立 WebSocket、不常驻挂载会话控制器，也不执行 Provider 或外部 AI CLI。
- 点击后立即使用缓存展示；目标会话控制器仍建立真实事件连接并在后台读取权威快照校准。
- 预热失败不改变会话状态，也不抢先弹错；用户真正打开时继续走统一连接和错误契约。

优点：侧边栏可见的近期会话大多在点击前已经具备消息、询问和正文数据，切换不再等待 HTTP 快照。

代价：最多额外保留 24 个普通会话的状态，占用更多内存；首次进入项目后需要短暂后台读取，极早点击或超过上限的旧会话仍可能冷加载。

### 模型能力采用缓存先显示、后台刷新

- 能力缓存按“真实客户端实例 + 项目”隔离，首次读取中的 Promise 合并，避免并发重复请求。
- 同项目切换会话时首帧直接读取缓存，底部模型、推理强度和服务档位不再退回空白。
- 每次真实工作面挂载仍后台刷新能力；刷新失败时保留已有能力，不制造模型选择器闪烁。

优点：模型选择器立即可用，同时仍能收敛设置页或运行内核变化后的新能力。

代价：后台刷新完成前会短暂显示上一次成功能力；真实请求仍由服务端复验，不能把缓存当作权限或执行事实。

### 只为真实布局变化测量会话行

- 会话行的布局动画以会话 ID 集合作为依赖；单纯选择变化不再触发整列位置测量。
- 会话新增、移除和重排仍保留原有动效与 reduced-motion 行为。

优点：点击选中反馈不再承担整列布局计算。

代价：后续若新增不改变 ID 集合但确实改变行位置的排序条件，必须同步更新布局依赖。

### 不构建默认不可见的历史处理过程

- 已完成轮次关闭时只保留“查看处理过程”控制和空容器；用户展开后才构建工具、命令和过程 Markdown。
- 最终回答、计划、文件变化、失败原因、时长和已回答询问仍按原规则首帧显示，不进入延迟范围。

优点：长会话切换不再为大量不可见历史过程解析 Markdown 和创建 DOM。

代价：首次展开某个很长的历史过程时才支付该部分渲染成本；关闭后再次展开会重新构建过程内容。

### 推送弹窗先显示真实记忆

- 打开弹窗时同步读取项目级推送偏好，模型、推理、服务档位、工作模式、权限和 Worktree 选择从第一帧使用记忆值。
- 能力返回后再执行合法模型、仓库、分支和服务档位归一化；缓存偏好不能绕过服务端校验。

优点：上次使用 Worktree 的项目不会先闪现“直接使用项目目录”。

代价：能力读取期间只具备偏好外观，仓库与分支等依赖真实能力的控件仍保持加载状态。

## 实施范围

- `apps/desktop/src/renderer/App.tsx`：近期会话快照预热、项目模型能力预热、推送弹窗同步恢复偏好。
- `apps/desktop/src/renderer/session/sessionHotCache.ts`：快照到首帧状态投影，普通热缓存上限调整为 24。
- `apps/desktop/src/renderer/session/SessionWorkspace.tsx`：项目级能力缓存、请求合并和后台刷新。
- `apps/desktop/src/renderer/session/ProjectConversationTree.tsx`：选择变化跳过整列布局测量。
- `apps/desktop/src/renderer/session/ConversationTranscript.tsx`：消息投影只订阅消息集合与活动轮次。
- `apps/desktop/src/renderer/session/SessionActivity.tsx`：完成轮次的隐藏过程改为展开时构建。
- `DESIGN.md`：新增页面即时切换与后台收敛契约。
