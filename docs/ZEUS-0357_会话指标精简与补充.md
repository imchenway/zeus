# ZEUS-0357 会话指标精简与补充

## 任务目标

- 精简会话运行信息，移除当前轮次、最后请求用量、最后请求缓存明细与目标能力展示。
- 摘要展示会话累计 Token、上下文占用、缓存命中率、最近请求输出速率和 API 等价费用估算。
- 详情按使用与费用、性能与活动、环境分组；代码变更作为活动产出指标展示。
- 缺少真实 Provider 请求边界、时序、价格或变更集时显示不可用或不完整，不使用轮次耗时反推模型速率。

## 已确认口径

1. 最近请求输出速率只统计最近一个边界完整的纯文本模型请求：`非推理输出 Token / 首个文本增量到请求完成的时间`。
2. 首段可见响应延迟按轮次开始到首个实际可见助手内容计算；累计处理耗时排除审批和用户提问等待。
3. 费用是按请求发生时价格快照计算的 API 等价美元估算，不是 ChatGPT、Codex 订阅或最终账单。
4. 费用不完整时只显示已覆盖部分、覆盖率和来源；未知模型不借用相似模型价格。
5. 代码增删行是稳定轮次变更集的累计工作量，不等于当前工作区净差异。
6. 删除项只退出界面展示，底层数据继续服务上下文、缓存、费用和能力判断。

## 设计依据

- [OpenAI 官方模型与价格资料](https://developers.openai.com/api/docs/models/compare)按输入、缓存输入、输出等 Token 类别公布 API 单价；历史请求继续使用落库时的价格快照。
- Claude Code 状态栏公开成本、上下文、耗时和代码改动；[LM Studio](https://lmstudio.ai/docs/developer/rest/endpoints) 与 [OpenRouter](https://openrouter.ai/docs/faq) 提供吞吐和首响应指标；[OpenCode](https://opencode.ai/docs/cli/) 提供 Token、成本、模型与工具统计。
- Zeus Snapshot V2 首屏是有界投影，所有会话级聚合必须由存储层计算，Renderer 不得从已加载的局部历史推断。

## 实现记录

- `conversation_model_requests` 幂等补充 `provider_request_id`、首次可见输出、首次文本输出、完成时间和测量完整性字段；旧记录保留空值，不回填推测时间。
- Codex 以单次 `rawResponse/completed` 的 `responseId` 和精确用量记账；可见文本、推理摘要和非文本响应项只在同一连续请求边界内参与测量。工具型、混合型、错误或缺事件请求的速率保持不可用。
- Pi 以 `message_start`、`message_update`、`message_end` 形成请求边界，保存 `responseId` 和文本增量时序；缺少开始事件、工具调用、错误/中止或用量拆分缺失时不生成速率。Pi 的完整消息已经证明不存在 thinking/tool 内容时，可把 Provider 未提供的 reasoning 拆分精确记为 0；存在 thinking 内容却无拆分时保持不可用。
- `sessionMetrics` 由存储层一次性投影 usage、cost、performance、activity、changeSummary 和完整性。Snapshot V2 直接携带该投影，Renderer 不再从分页历史汇总。
- `conversation.sessionMetrics.changed` 登记为可合并的低频过程事件，只在模型请求完成、工具/命令/重试完成、轮次终态等稳定点更新；流式增量不广播会话聚合。
- 费用继续读取请求发生时固化的费率账本：Codex 官方价格目录日期为 `2026-08-10`，DeepSeek 官方价格目录日期为 `2026-08-15`。推理 Token 是输出 Token 子集，不重复计费；未知模型覆盖率为 0 且费用不可用。
- 累计处理耗时只汇总已有起止时间的终态轮次，并合并扣除审批、提问等服务端请求等待区间；任一必要时间缺失时返回不可用。
- 代码工作量只累计状态稳定的变更集；存在捕获中或不可用变更集时保留已覆盖数值并标注部分统计，无变更集时不展示该行。
- 展开环境区只保留目录、分支、会话 ID、JSONL 和 MCP 启动状态；旧的推理级别证据、缓存请求证据不再作为目标能力或缓存状态的同义展示，底层配置证据未删除。

## 兼容边界

- 旧库打开时只增量补列和索引，不改变既有 schema generation；历史请求没有精确时序，输出速率与首段延迟显示不可用。
- 旧会话已有的 Provider Token 快照仍作为累计 Token、上下文、缓存和费用的兼容来源；不会用当前目录价格重算旧请求。
- 部分价格覆盖时摘要显示“估算不完整”，详情展示已覆盖金额、覆盖率、目录日期与来源；无可信价格时显示“不可用”。
- Snapshot V2 的 `sessionMetrics` 是新增稳定字段；实时事件只替换该整体投影，避免 token 增量引发工作区重渲染。
