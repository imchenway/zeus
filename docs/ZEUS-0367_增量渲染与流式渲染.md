# ZEUS-0367 会话 Markdown 增量与流式渲染

## 目标与边界

- 将会话回复、思考、用户消息、任务首发内容、计划、侧聊、子智能体指令及旧会话正文统一迁移到 `markstream-react@2.0.6`。

- 不修改 Provider、WebSocket、数据库、会话事件协议或现有 16ms Renderer 事件合并。
- 不增加公开 API、持久化字段、迁移或用户设置，不引入 `stream-diffs`、Mermaid、KaTeX 或代码高亮。

- 原事件节流：Renderer 会话事件保持 16ms 合并，本任务不改动。
- 原预算：正文 200,000 字符、单代码块 50,000 字符、顶层块 512、节点 4,096。

## 固定版本与参数

- 运行时：精确固定 `markstream-react@2.0.6`。
- 增量渲染：`maxLiveNodes=0`、`batchRendering=true`、首批 24 节点、后续每批 16 节点、批次间隔 8ms、帧预算 4ms、idle 上限 64ms。
- 平滑流式：首批不等待、60fps、目标延迟 80ms、32ms 进入追赶、单次最多 2,048 字符、完成时立即 flush。
- 动效：关闭框架淡入和尾部光标；系统减少动态效果时关闭占位动画。
- HTML：固定 `htmlPolicy="escape"`。
- 虚拟化：不启用框架内层虚拟窗口，保留完整完成态 DOM，保证批注文本偏移可靠。

## 安全与兼容取舍

- 链接、图片和代码块由 Zeus 自定义节点接管。链接只开放页内锚点或已审计会话资源；图片只加载权威会话资源；代码块保留复制按钮、纯文本展示和长度限制。
- `streaming` 与 `final` 复用同一渲染实例，由框架原位收口。`final` 且批次占位节点清零后才开放回答批注。
- 使用 `ResizeObserver` 合并通知外层滚动控制器，不增加嵌套滚动或内层虚拟窗口。
- 优点：稳定前缀节点复用、未闭合结构解析和分批挂载交由专用运行时管理。缺点：增加第三方运行时、构建体积与后续升级验证成本；单条超长完成消息仍保留完整 DOM。
