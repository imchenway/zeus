ZEUS-0374 自动化开发设计

Zeus 统一接纳人工、时间和领域事件触发；每个项目独立生成可审计结果。独立自动化与员工规则共享调度能力，但分别落到自动化运行和工作执行，独立会话始终归属自动化收件箱。

系统架构｜一次触发如何成为可追踪结果

主链路只回答三个产品问题：谁有权接纳触发、接纳后创建什么对象、用户最后到哪里阅读和继续对话。

对象不合并

独立自动化生成自动化运行；员工规则继续生成工作执行。共享调度不等于共享领域记录。

会话来源不迁移

用户手动追问不会把独立运行会话移动到普通会话列表，也不会改变后续调度配置。

覆盖允许真实重叠

旧 Provider 或外部命令停止结果未知时，旧运行记为未知，最新运行仍立即启动并显式标记可能重叠。

状态机｜一条自动化运行如何结算

阻塞、取消和未知都是不可逆终态。用户解决问题后创建引用旧运行的新运行，系统绝不复活旧记录。

安全重试：同一 run 下新增 attempt 预算阻塞：blocked + blocked_budget 所有终态：不可逆

覆盖旧运行不是撤销

Zeus 会先记录终止请求并清理未开始队列；如果 Provider 或外部命令是否停止仍未知，旧运行进入“结果未知”，最新运行立即启动。

  • 新运行保存被覆盖运行和终止请求身份。
  • 界面持续显示“可能重叠”，不投影成旧运行已停止。
  • 旧运行已经发生的文件、Git、网络或完全访问副作用不会被回滚。
