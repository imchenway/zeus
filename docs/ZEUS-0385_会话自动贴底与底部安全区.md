# ZEUS-0385 会话自动贴底与底部安全区

## 任务目标

- 打开或切换会话后直接显示最新消息。
- 用户停留在底部时，消息增量、异步正文布局和窗口尺寸变化都持续贴底。
- 只有用户主动上滚查阅历史时暂停跟随；用户自己提交新消息或点击“返回最新消息”后无条件恢复贴底。
- 会话末尾保留总计约三行正文高度的可滚动留白安全区。

## 已确认产品口径

- 滚动状态只有“跟随最新内容”和“查阅历史”两种；普通程序滚动、虚拟列表测量及锚点补偿不能进入历史阅读态。
- 用户滚轮、触控、滚动条拖动或滚动按键使会话离底部超过 `24px` 后进入历史阅读态；主动滚回容差内恢复跟随。
- 每次重新切入会话都放弃上次阅读位置，在绘制前即时定位到底部，不播放平滑滚动动画。
- 当前会话内本地提交新消息时，即使用户此前在查阅历史，也立即恢复跟随并定位到底部。
- 会话底部安全区总高度为 `72px`，不在现有 `24px` 基础上继续叠加。

## 实施方案

- 收口 `ConversationTranscript` 与滚动控制器：原始 `scroll` 事件只同步视口和可见性，只有已登记的真实用户滚动意图才允许改写跟随状态。
- 移除新轮次按距底部 `300px` 自动接管的例外；新轮次只沿用当前状态，本地提交由显式提交信号恢复跟随。
- 在 `SessionWorkspace` 维护会话内单调递增的本地提交序号并传入转录区，覆盖普通发送与编辑重发；保留权威用户消息投影作为异步兜底。
- 把虚拟行重新测量、滚动容器尺寸变化与既有 Markdown/图片可见内容变化接入同一个按帧合并的贴底调度器。跟随态定位到底部，历史阅读态继续使用稳定行锚点补偿。
- 用户首次离开底部时保存变更前的稳定行身份与顶部偏移；后续行测量优先使用这份阅读锚点，避免浏览器自动滚动锚定先于虚拟器测量后造成误采样。
- 调度器以 `requestAnimationFrame` 合并高频几何通知；仅当 Electron 窗口被遮挡、帧回调暂停时启用 `80ms` 低频后备，并以最多十二次、连续两帧几何稳定为单轮收敛上限。
- 调整会话正文末尾可滚动内边距为 `72px`。
- 扩展真实 `ConversationTranscript` QA 夹具，并先补齐现有 runtime fixture 缺少的 `serviceTier` 事实字段；不修改 `RuntimeDetails` 产品逻辑。

## 取舍

- 优点：切换、发送、流式增量和延迟布局共享同一状态语义，不再依赖固定三帧或把程序滚动误判为用户操作。
- 代价：转录区需要维护短生命周期的用户滚动意图；尺寸观察会增加少量回调，但统一按动画帧合并，不让 React state 承接逐像素事件。
- 优点：`72px` 留白让末尾消息与 composer 之间更舒适。
- 代价：同一屏可见正文略少。
