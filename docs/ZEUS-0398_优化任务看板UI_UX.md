# ZEUS-0398 优化任务看板 UI/UX

## 目标与边界

在不改变任务事实、`TaskBoardViewSettings`、看板持久化、拖拽并发协议和后端接口的前提下，降低看板视觉重量，补齐活动规则入口、可见操作反馈和空状态恢复路径，并消除子分组卡片栈的嵌套滚动。

明确不做：列内快捷创建、批量操作、新任务状态模型、全局状态、新数据请求、新依赖或品牌重构。

## 设计决策

- 明确采用 macOS/AppKit 视觉语法，不把桌面应用做成网页仪表盘：工具栏使用作用域选择器与紧凑分段控件，列之间以发丝分隔线组织，偏好设置使用单一面板和开放式表单行；不引入大圆角面板、悬浮卡片墙或第三层工具条。
- 复用 Zeus 现有冷中性色、系统字体、原生蓝、Phosphor 图标和控件 token，不增加色系、素材或依赖。首轮偏网页的概念稿未采用，最终实现以 Mac 原生概念稿为视觉目标。
- 工具栏只在已有看板操作区显示活动的“筛选 n / 排序 n / 隐藏 n”紧凑入口，点击直接打开对应设置内部视图。
- 设置面板保持一个草稿和一次保存，内部改为“布局 / 卡片 / 规则”三个视图；“恢复默认显示设置”只重置草稿中的显示设置，不改任务事实或独立保存的手工卡片位置。
- 标题继续是卡片主操作；任务编号、语义属性和低频操作依次降级。状态色仅用于列头圆点、卡片边缘和语义属性，拖动、移动和隐藏操作扩大命中区但降低视觉抢占。
- 子分组模式每列只保留一个纵向滚动区；列头、横向列滚动和窄窗口行为不变。
- 成功反馈约 4 秒消失，隐藏分组反馈约 8 秒可撤销；失败持续显示并提供重试或关闭。界面只显示安全文案，诊断详情仍写入本机日志。

## 优缺点

优点：界面更接近 macOS 工具型应用，列、卡片和设置不再层层套面板；日常扫读、活动状态理解和失败恢复形成完整闭环；稳定数据和并发链路不变。

代价：开放式列布局弱化了单列的容器感；设置面板内部结构变化，需要完整回归全部配置项；可见反馈出现时会短暂占用一行垂直空间。

- 数据目录：`/tmp/zeus-0398-baseline.GLYCtp`，仅包含本任务隔离项目和任务数据。
- 首次窗口：显示器 `3`，日志记录 `targetDisplayId=3`、`actualDisplayId=3`、`corrected=false`，窗口为 `1240×820`。

## 实施结果

- `TaskWorkspace.tsx`：在原工具栏增加活动筛选、排序、隐藏摘要入口，并把入口定向到设置的对应内部视图；没有新增常驻工具条或数据请求。
- `TaskBoardView.tsx`：
  - 设置改为“布局 / 卡片 / 规则”三个内部视图，草稿、保存和取消仍保持原子语义；保存失败时面板保持打开。
  - 增加“恢复默认显示设置”，只恢复 Renderer 显示选项，手工卡片位置不变。
  - 增加普通成功、隐藏撤销、持续失败三类可见反馈；移动失败继续回滚，终态清理取消显示为信息而非失败。
  - 空泳道提示可拖入任务；项目无任务、筛选无结果、全部分组隐藏、读取失败分别提供新建、清除、设置和重读动作。
  - 设置中的关闭、上移、下移改用现有 Phosphor 图标，保留完整辅助标签、焦点环、键盘拖动和 `aria-live`。
- `styles.css`：追加同一任务范围的样式覆盖，复用已有 token，把工具栏、开放式列、6px 卡片、语义属性、反馈条和偏好设置面板统一到 Zeus 的 Mac 冷中性视觉；触屏必要操作继续常显；窄窗口仍保持横向列滚动。
- `useWorkspaceQueryState.tsx`：在已有看板加载 effect 中复用错误状态作为自动重读门禁，避免读取失败后无限自动请求，从而让“重新读取”保持可见且仅由用户触发；未改变接口或请求协议。
- 数据库、HTTP 接口、`TaskBoardViewSettings`、移动并发协议、任务事实和 DnD 独立异步块均未改变；没有增加全局状态、依赖或额外正常路径请求。

## 视觉还原检查

- 构图：实现与最终 Mac 概念稿都使用双层应用导航、紧凑作用域工具栏、开放式列和居中的偏好设置面板；未采用概念稿中不属于现有产品的系统标题栏改造。
- 字体：沿用 Zeus 系统字体和现有字号层级，标题、任务编号、正文属性及低频操作形成四级层次；没有新增网页展示字体。
- 控件：分段选择、原生蓝主按钮、图标按钮、表单行和焦点环与现有 Zeus 控件契约一致；没有自造 SVG 或字符图标。
- 表面与颜色：列背景透明、列间发丝线、卡片仅保留轻微层次和状态边缘；颜色限于已有冷中性色与语义色。
- 动效与响应：只保留短促状态过渡；减少动态效果时卡片、列和拖动控件过渡降至 `0.001s`。`640×820` 下工具栏换行、列横向滚动和设置内容纵向滚动均可用。

### 验收边界

- 保存、移动和读取失败通过隔离测试包 Renderer 中的受控 HTTP 失败注入验证，没有调用或改动真实后端数据。

- 减少动态效果通过真实打包 Renderer 的媒体特性模拟与计算样式验证，不等同于修改宿主 macOS 辅助功能设置。
- 静态检查、构建、打包和截图只作为各自证据；桌面交互结论来自上述独立 `Zeus Test.app`，未用浏览器夹具冒充。
