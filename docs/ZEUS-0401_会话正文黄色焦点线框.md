# ZEUS-0401 会话正文黄色焦点线框

## 任务目标

- 点击会话正文后不再显示包围整个转录区的黄色线框。
- 保留点击正文后使用方向键、Page Up 与 Page Down 滚动的能力。
- 不影响会话内部按钮、输入框和链接的键盘焦点反馈。

## 根因

ZEUS-0385 为了让用户点击正文后可以用键盘滚动，给 `.session-transcript` 保留了 `tabIndex={-1}`，并在鼠标点击非交互内容时调用 `container.focus()`。转录容器没有覆盖 Chromium 的原生焦点轮廓，因而在当前系统焦点色下显示为黄色矩形线框。

## 修复与取舍

- 仅为 `.session-transcript` 明确设置 `outline: none`；不删除程序化聚焦和键盘滚动处理。
- 优点：修复只作用于非 Tab 可达的转录滚动容器，不改变交互流程。
- 代价：该容器被鼠标触发程序化聚焦时不再显示容器级焦点标记；容器内部的可交互控件仍保留既有 `:focus-visible` 样式。

## 验证边界

- 使用现有会话样式 QA 页验证真实 `ConversationTranscript`。
- 检查页面身份、非空渲染、错误覆盖层、点击正文后的焦点元素与线框可见性。
- 执行 Prettier 检查、`pnpm lint`、`pnpm typecheck` 和 `pnpm build`；静态检查与构建不替代真实渲染结论。
