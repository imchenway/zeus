# ZEUS-0415 项目侧栏操作图标视觉优化

## 任务目标

优化侧栏“项目”标题右侧的会话组织方式和新增项目图标，解决两枚图标线条体系、视觉重量和光学尺寸不一致的问题，不改变原有交互和持久化语义。

## 任务依据

- 用户提供的现状截图显示：会话组织图标是手写描边 SVG，新增项目是 Phosphor `Plus`，两者不属于同一绘制体系。
- `docs/ZEUS-0246_侧边栏按任务状态分组.md` 约定：图标表达点击后的目标组织方式，提示文案和可访问名称也描述点击结果。
- 现有 CSS 同时强制 `fill: none` 和 `stroke`，把原本使用填充路径的 Phosphor 图标二次改造成轮廓，是加号发虚的根因。

## 方案与取舍

使用项目已安装的 Phosphor 图标：切换到平铺时使用 `List`，切换到按任务状态分组时使用 `StackSimple`，新增项目继续使用熟悉的 `Plus`；CSS 只约束光学尺寸，不覆盖图标自身的绘制方式。

优点：两枚操作的线条语言、尺寸和颜色继承一致；复用已安装依赖，不增加资产和运行时成本；平铺/分组的目标语义仍可见。

缺点：使用标准图标后不再保留原手写图形的唯一性；`StackSimple` 依赖 title 和 aria-label 补足“按任务状态”的具体粒度。
