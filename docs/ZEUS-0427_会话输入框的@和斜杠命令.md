# ZEUS-0427 会话输入框的 @ 和斜杠命令

## 目标

- 在新建与继续会话的 Composer 中，以 `/` 唤起 Skill、Plugin、Plugin Skill、Computer Use、目标模式和计划模式。
- 以 `@` 点名一个或多个项目数字员工，由会话编排直接扇出为多专家群聊；默认 Agent 不代答，也不创建工作项或 Provider 子 Agent。
- 删除底部旧 `@` 扩展按钮，保留附件、权限、协作模式和目标四个左侧操作。

## 已确认语义

- 有 `@` 时只有被点名专家回答；没有 `@` 时保持现有默认 Agent 行为。
- 点名只对本轮生效，专家执行通道保留上下文；同轮专家使用同一发送前历史水位，下一轮才看到彼此回复。
- 回复按点名顺序预占位置并独立流式更新。
- 员工只提供名称、岗位、领域和人格提示词；本轮模型、推理、权限、计划模式、Skill、Plugin 与 Computer Use 取自 Composer。
- 只读或计划执行并行；可写或 Computer Use 执行按点名顺序串行。
- Skill、Plugin 和员工均使用结构化内联标签；目标模式与同一草稿中的专家点名互斥。
