# ZEUS-0437 会话内容显示错误

## 当前阶段

- 已完成根因复现、共享组件最小修复、浏览器交互回归和全部规定门禁。
- 当前工作区为 `ZEUS-0437`，分支为 `zeus/ZEUS-0437-task-01`，实施前工作树干净。
- 本任务不新增或恢复单元测试；未经用户授权，不执行 Git commit、push、merge 或 revert。

## 用户现象

1. 活动轮次的处理过程已经展开，阶段说明、工具活动和当前思考摘要均可见。
2. 用户查看该组命令期间，最后一个活动从进行中变为完成；外层活动组随即被强制收起，过程内容消失。

## 已确认产品契约

- “处理过程”、活动组和单条命令详情是三个独立层级；切换内层命令详情不得改变任一父级展开状态。
- 活动轮次继续直接展示处理过程；本缺陷不应倒退为给活动轮次新增总折叠入口。
- 普通会话与 Subagent 继续复用共享活动组件，不按截图路径分别打补丁。

## 根因与方案取舍

- 截图前态仍有“正在处理”和“正在整理较早对话”，后态已变为“编辑了文件、运行了命令”，证明交互期间活动从进行中转为完成。
- `SessionActivityGroup` 在 `active: true → false` 时无条件执行 `setOpen(false)`；这条旧的自动收口规则会覆盖用户刚刚打开的活动详情。现有组件夹具同时确认，内层命令详情本身的开关不会折叠父级。
- 删除活动组的完成态强制收起，只保留用户直接操作 `<details>` 得到的状态。优点是修复共享边界、没有新状态或协议；代价是用户主动打开的长活动组会在活动结束后继续展开，直到用户收起或整个轮次进入最终完成态。轮次最终正文到达后的顶层过程自动收起不变。

## 验证边界

- 用共享活动组件 QA 夹具复现“活动组展开 → 最后一个活动完成”，确认修复前详情被强制收起。
- 修复后重复同一交互，并检查父级 `open`、活动明细可见性和控制台错误；再核对内层命令开关仍独立。
- 执行定向格式检查、`git diff --check`、`pnpm lint`、`pnpm typecheck` 和 `pnpm build`；静态检查与构建不冒充真实交互验收。

## 实施结果

- 删除 `SessionActivityGroup` 在活动由进行中变为完成时无条件关闭详情的副作用；活动组现在只响应用户自己的展开或收起操作。
- 保留活动摘要从“正在处理”切换为完成态文案、实时活动行消失和单条命令二级详情，未增加状态、协议或样式。
- 整轮最终正文到达后的顶层“处理过程”默认收起逻辑位于 `ConversationTranscript`，本次未修改。

## 验证结果

- 在 Zeus 内置浏览器打开独立共享组件夹具，修复前稳定复现“展开活动组 → 展开并收起命令 → 最后一个活动完成 → 父级详情消失”。
- 修复后重复同一流程：活动摘要由进行态切换为完成态，命令、网页搜索、文件编辑和工具明细仍保持可见；再次切换单条命令详情不影响父级展开状态。
- `pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm package:mac` 和 `git diff --check` 均通过。
- 测试包为 `Zeus Test.app`，bundle ID 为 `dev.hypha.zeus.test`；严格签名校验和 DMG 校验通过，`dist` 中未生成生产身份 `Zeus.app`。
- 未启动 Electron 应用，未执行真实 Provider 会话验收；该层仍不能由组件夹具、静态检查、构建或打包替代。内置浏览器截图接口超时，因此交互结论来自页面结构快照与逐步点击结果，没有新增截图证据。
