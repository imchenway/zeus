# ZEUS-0443 移除会话输入框灰色焦点边框

## 任务目标

- 移除会话 Composer 输入内容区聚焦时出现的矩形灰色边框。
- 保留外层圆角 Composer 容器、输入能力和强制高对比模式的可见焦点。

## 已核对现状

- 截图中的灰框来自会话页通用 `textarea:focus-visible` 的 `2px` 轮廓，不是外层圆角容器的边框。
- `ZEUS-0427` 引入 `StructuredComposerInput` 后，`textarea` 不再是 `.session-composer-input-frame` 的直属子元素，原有焦点重置选择器因此失效。
- 新建会话和继续会话共用 `StructuredComposerInput`，修正共享样式即可覆盖两个入口。

## 方案与取舍

- 扩展既有 Composer 焦点重置选择器，使其同时匹配结构化输入层；不修改全局键盘焦点规则。
- 强制高对比模式继续恢复 `CanvasText` 轮廓，避免移除必要的无障碍焦点提示。

优点：只修复回归来源，不新增组件、状态或依赖，并保持其他输入控件的焦点反馈。

缺点：普通显示模式下输入内容区不再单独显示焦点环，仍由输入光标与外层 Composer 表达当前输入位置；如后续需要更强的 Composer 焦点反馈，应调整外层圆角容器，而不是恢复内层矩形框。
