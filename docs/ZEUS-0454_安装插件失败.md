## 根因与处理

1. 共用 Git 来源读取器没有解析 GitHub 页面地址，插件安装、更新和市场添加、刷新均受影响。统一解析仓库、分支与子目录，并持久化同一来源身份。
2. 用户仓库根目录是包含多个条目的插件市场，不是单个插件。安装入口识别后展示已有市场条目，由用户选择安装，避免擅自批量启用。
3. 仓库使用 `.claude-plugin/marketplace.json` 和 `.claude-plugin/plugin.json`；现有市场读取强制要求 Codex 的 policy，且错误地把 Claude 市场相对路径根目录上移一级；插件读取仅支持 Codex 清单。
4. 支持此仓库使用的 Claude 默认 `skills/` 插件结构，复用现有目录安全检查、不可变修订和 Skill 快照。不忽略尚未支持的 Claude 专有组件，不更改原始插件文件。
5. 真实更新验证发现原流程会为相同内容重复插入修订，触发数据库唯一约束。内容和安装缓存检查一致时直接沿用已有修订，并保留用户的停用状态和信任状态。
6. 重新打开安装数据库时发现原初始化流程会重建已废弃的“作用域内同名唯一”索引，导致合法的同名不同来源插件阻断启动。删除这条旧索引创建语句，继续使用已有的包含来源身份的唯一索引和迁移账本，不修改数据库记录或另建兼容层。

优点：同一来源只在服务端解释，复用现有市场选择和安装宿主，不增加依赖或第二套插件运行机制。
限制：本次不扩展为完整 Claude 插件运行时；不支持的组件明确拒绝。首次从安装入口识别市场需要再读取一次来源，后续从已添加市场安装使用本地快照。

## 可复跑的真实来源检查

在仓库根目录执行以下命令；它只拉取公开仓库到新的临时目录并检查真实来源，结束后清理，不登记到正式插件目录、不执行插件内容、不增加测试文件或依赖。

```sh
node --import tsx --input-type=module <<'JS'
import assert from 'node:assert/strict';
import { mkdtemp, realpath, rm } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { normalizePluginSource, materializePluginSource, discoverMarketplace } from './packages/local-server/src/zeusPluginSource.ts';
import { inspectZeusPluginDirectory } from './packages/local-server/src/zeusPluginManifest.ts';
// 每次运行独占的临时目录。
const root = await mkdtemp(join(tmpdir(), 'zeus-0454-source-'));
try {
  // 用户提供的原始页面链接。
  const source = { kind: 'git', repositoryUrl: 'https://github.com/humanlayer/skills/tree/main' };
  assert.deepEqual(await normalizePluginSource(source), { kind: 'git', repositoryUrl: 'https://github.com/humanlayer/skills.git', ref: 'main' });
  // 真实 Git 来源，保留完整仓库路径供市场条目解析。
  const repositoryRoot = await materializePluginSource(source, root);
  await assert.rejects(inspectZeusPluginDirectory(repositoryRoot), { code: 'ZEUS_PLUGIN_SOURCE_IS_MARKETPLACE' });
  // 真实市场与插件清单必须在同一个仓库根下解释。
  const catalog = await discoverMarketplace(repositoryRoot);
  assert.equal(catalog.root, await realpath(repositoryRoot));
  assert.ok(catalog.entries.some(entry => entry.name === 'show-me'));
  for (const entry of catalog.entries) {
    assert.equal(entry.source.kind, 'local');
    // 检查市场中的每个真实插件，不执行其 Skill。
    const plugin = await inspectZeusPluginDirectory(entry.source.path);
    assert.equal(plugin.name, entry.name);
    assert.ok(plugin.components.skills.length > 0);
  }
  console.log(`来源检查通过：${catalog.entries.length} 个插件`);
} finally {
  await rm(root, { recursive: true, force: true });
}
JS
```
