# ZEUS-0455 新用户模型接入引导

## 已确认目标

新用户首次打开 Zeus，选择“使用 Codex 订阅”“连接自定义供应商”或“稍后设置”。自定义配置在引导内完成，选定模型成为之后新项目的默认模型；已有项目不改变。完成接入只返回主界面，不自动创建会话或发送消息。

## 根因与方案

- 官方 Codex 登录已经存在，但执行逻辑绑定任务推送；设置页没有报错指引承诺的登录入口。
- 模型供应商保存与项目模型启用是两个动作，只有欢迎弹窗仍不能让新用户开始使用。
- 复用现有登录、配置导入、模型编辑、命令持久化和项目创建事务；增加首次引导及常驻入口。
- 用户选择 Codex 前只读本地状态，不启动外部工具；取消和迟到回执不继续原操作，账号与其他应用隔离。

优点：首次接入路径完整，复用已有安全边界和业务能力。代价：需要持久化引导状态，并将新项目默认模型与项目可用模型同时落库。

## 已实现交互

- 首次弹窗复用 `ModalPortal`、`Button`、`ZeusSelect`，提供两种接入方式和稍后设置。复用弹窗焦点约束及关闭路由；保存期间禁止中断，登录等待期间可以返回或关闭。
- Codex 登录复用官方授权地址、安全打开及返回发起窗口的能力。配置导入单独询问，可跳过；导入后启用失败只重试启用。首次引导完成只保存接入结果，任务推送仍在成功后继续原任务。
- 自定义分支复用供应商编辑器。已保存供应商可重新选择；目录请求失败保留当前输入，可重试或手工添加。协议、能力和目录路径折叠为高级设置。
- 供应商保存、密钥保存、启用模型与默认模型选择均满足后才能完成。显示“配置已保存；实际模型调用尚未验证”，不以目录查询冒充真实推理验证。
- 返回首屏保留普通配置，清除尚未保存的密钥和明文 HTTP 确认快照；密钥不进入引导持久记录。关闭接入层不会切换当前工作面或销毁会话草稿。
- 跳过后保留“连接模型”按钮；设置的模型供应商顶部始终保留 Codex 入口和检查状态操作。未经查询显示“账号状态尚未检查”，不会把引导完成当成仍然登录。
- 登录缺失和新项目默认模型失效错误提供“连接模型”操作，原地打开接入层。Codex 步骤保留官方安装指引、重试登录及返回供应商选择的入口。

## 持久化和模型默认值

- 扩展既有应用设置：`modelSetupStatus` 保存待引导、跳过或完成；`newProjectDefaultModelRef` 保存供应商和模型的完整引用。未新增认证接口或数据库表。
- 创建新数据库时初始化待引导；已有数据库缺少字段时归一化为空，不弹出欢迎。普通设置更新省略这两个字段时保留原值。
- 在共享项目创建入口先检查模型及凭据，再随项目创建事务写入项目可用模型集合和默认模型。明确传入的项目模型优先；已有项目不更新。
- 默认模型的供应商、模型或密钥不可用时拒绝新项目创建，并提示重新选择。不会悄悄切回 Codex。
- Codex 接入清除自定义的新项目默认引用，继续沿用现有真实模型目录的选择逻辑，不硬编码模型名称。

取舍：目录可用和密钥已保存足以完成配置，避免强制用户发起真实模型请求；因此“完成接入”不保证远端权限、余额及实际调用一定成功。供应商删除仍沿用已有的项目引用保护，解除项目引用后才可删除。
