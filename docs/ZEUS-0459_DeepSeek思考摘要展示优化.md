# ZEUS-0459 DeepSeek 思考摘要展示优化

## 已确认目标

- 空思考摘要不显示通用标题，底部已有状态行继续表达正在执行、等待回答、等待审批和连接恢复。
- 真实摘要仍只显示活动轮次最新一条，最终回答开始或本轮结束后隐藏；已有思考详情继续可查看。
- 所有模型共用内容转换规则，不匹配“思考摘要”字样删除内容，不增加模型专属分支、接口、配置或数据迁移。

## 原因与实施

- 过程分页在没有可读文字时，把服务端的通用标题当成摘要正文；全文恢复还可能沿用已经进入预览的标题。
- 共享转换入口让思考的空内容保持为空，覆盖过程分页、模型历史和全文恢复。空回退不再补成单独的省略号。
- 截断预览仅包含空格时也保持空内容，不先附加省略号后再误判为真实摘要。
- 原始记录与标题仍保留；摘要选择、思考详情和独立运行状态继续使用已有组件与生命周期规则。

## 取舍

- 优点：摘要只呈现实际内容，运行进度含义清楚，不新增重复状态或维护分支。
- 代价：没有真实摘要时只表达“正在执行”，不把工具执行或等待响应统一称为“正在思考”。
