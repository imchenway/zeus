# ZEUS-0461 异步提问区域错位修复

## 现状与根因

截图中的问题正文、答复状态及底部“回答问题”入口偏向会话左侧，回答框却单独居中。

`AsyncQuestionMessage` 作为独立时间线行输出，但其外层 `.session-async-question` 未加入时间线行的正文列宽规则。底部答题入口直接复用只提供按钮排列的 `.session-message-delivery-actions`，同样没有正文列宽约束。复用的回答面板又保留独立的 46rem 宽度和状态行间距，导致同一组内容使用两套布局。

问题正文与表单标题重复，是两处组件分别展示原文的现有行为；本次按已确认方案只修正布局，不修改问题内容或答题行为。

## 实施记录

2026-09-07：在 `zeus/ZEUS-0461-task-01` 实施，开始时工作目录干净。

- 异步问题外层与底部答题入口接入既有正文列宽、居中及最小宽度规则。
- 异步表单复用底部询问面板的内部宽度规则，由正文列统一决定尺寸。
- 答复状态与表单保持 10px 间距，表单状态与回答框沿用现有底部询问的 10px 间距。
- 仅修改会话样式；接口、消息投递、问题收起、草稿及提交行为保持原样。

优点：复用现有布局约束，改动集中且覆盖同类问题。局限：不处理题目正文与表单标题的重复展示。
