# ZEUS-0463 上下文整理状态去重

## 目标与确认范围

当前状态只显示一次，过程记录保留供回看。原界面由活动组标题、当前活动摘要和底部运行状态同时表达正在整理，属于展示职责重复。

- 正在整理：仅在底部显示“正在整理较早对话以继续工作”。
- 整理完成：底部恢复实际后续状态，处理记录保留“已整理较早对话”。
- 整理失败：沿用真实错误提示，不归入正常完成记录。
- 单条整理没有额外详情时去掉展开层；整轮结束后随原有处理过程收起。

## 实现与取舍

- 底部状态读取完整会话状态。只有底部实际展示整理状态时，行投影才排除同轮、进行中、类型明确为整理的条目。
- 筛选仅作用于可见行，不删除原始事件，不按文案、时间或正文合并身份，不调整外部接口或存储结构。
- 单条整理没有详情、资源或可加载结果时，复用简洁活动行；有详情或多条记录时保留现有折叠结构。
- 完成后的简洁记录不再作为正在运行的状态播报。
- 优点：当前进度清楚、改动集中、历史仍可追溯。代价：整轮结束后需要展开处理过程查看记录。
