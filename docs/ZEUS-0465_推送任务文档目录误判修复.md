# ZEUS-0465 推送任务文档目录误判修复

## 用户确认的规则

- 任务文档统一从 Zeus 已登记的项目原目录下的 `docs` 读取。
- 项目没有 `docs`，或其中没有对应任务号的文档，继续发送任务已有内容。
- 目录或文档存在但读取失败时报告具体原因，不能当作没有文档而跳过。
- AI 执行代码的位置仍由当前任务工作目录决定。任务分支尚未合入项目原目录的文档不会被本次自动读取。

## 根因与现场证据

- 用户提供的推送标识为 `task-push:2fc23521-7967-41ff-948a-46a3ef821f41:thread`，错误发生于 2026-09-07。
- 按客户端既有身份算法核对，此次推送对应 Athena 项目的 `ZEUS-0003`，会话为 `conversation_5e7aa9e5758f369cfa367528`。
- 该项目原目录的 `docs` 是普通文件夹。Zeus 为前后端仓库建立任务环境时，将它链接到任务环境中的 `docs`。
- 共用派发入口却把任务环境当作文档来源，目录读取器因此抛出 `ZEUS_CONTEXT_SOURCE_PATH_INVALID`。只读调用现有读取器已复现：任务环境报错，项目原目录返回无匹配文档。
- 只读账本记录任务正文派发为 `failed_before_write`，发送标记为空；创建模型会话的命令已有接纳记录，因此这里只确认任务正文尚未发送，不把整个 Provider 流程描述为完全没有发生。

## 实施与取舍

- 在 Codex、Pi 共用的 `compileProviderDispatchContext` 中，文档来源改用项目记录的 `localPath`；与现有上下文预览的来源一致。
- 沿用现有文档目录、主文档选择、分页、文件变化和路径安全检查。
- 共用中英文错误目录补齐文档来源异常；明确区分原目录不可读、文件不存在、路径或格式异常，以及读取期间发生变化。
- 优点：从路径选择处修复，改动集中，不需要增加链接适配或修改目录布局。代价：任务分支中的独立文档需进入项目原目录后才会被此入口自动读取。
- 沿用既有接口、数据结构与恢复入口；未自动重发现场任务，未修改正式数据库、其他工作目录或 Git 历史。

node --input-type=module <<'JS'
import assert from 'node:assert/strict';
import { mkdtemp, mkdir, writeFile, symlink, rm, readFile, chmod } from 'node:fs/promises';
import { tmpdir } from 'node:os';

// 项目原目录和任务工作目录保持不同，以便检出错误的文档来源。
const projectRoot = join(scratch, 'project');
const taskRoot = join(scratch, 'task');
// 临时项目记录和任务记录模拟服务端已登记的身份。

let declaration;
/** 只定位本次修改的共用入口，不执行服务启动和其他后台副作用。 */
function visit(node) {
  if (ts.isFunctionDeclaration(node) && node.name?.text === 'compileProviderDispatchContext') declaration = node;
  ts.forEachChild(node, visit);
}
visit(source);
assert.ok(declaration);
// 只替代外围模型能力和存储端口；目录选择与文档读取使用实际源码。
const ports = {

  tasks: { getById: () => task },
  modelConnections: { listMetadata: () => [] },
  now: () => new Date(),
  nativeApiError: (code, message) => Object.assign(new Error(message), { code }),
  requireCodexDispatchModelBudget: () => ({ contextWindowTokens: 256000, reservedOutputTokens: 8192, checkedAt: null }),
  contextDispatch: {

      assert.equal(input.project.localPath, projectRoot);
      // 按实际服务的同一接口读取主任务文档；这里只隔离预算审计与数据库写入。

const compile = new Function(...Object.keys(ports), ts.transpileModule(declaration.getText(source), { compilerOptions: { target: ts.ScriptTarget.ES2022 } }).outputText + '; return compileProviderDispatchContext;')(...Object.values(ports));
