## 根因与方案

错误详情由 `ApplicationErrorDialogHost` 通过共用 `ModalPortal` 显示，弹窗直接挂载到 `document.body`。原生网页由 Electron `WebContentsView` 承载，独立于应用页面的 CSS 层级。原有 `BrowserWorkspace` 只在分栏拖动或环境弹层打开时隐藏网页，未感知共用弹窗，所以提高弹窗 CSS 层级不能解决遮挡。

在 `BrowserWorkspace.tsx` 的既有布局订阅内，通过原生 `MutationObserver` 观察 `body` 直属节点增删，用已有 `data-zeus-primitive="modal"` 标记读取当前弹窗状态。初次布局、尺寸变化、弹窗增删与下一帧显示回调均走同一布局入口。

- 任一弹窗存在或既有 `suspended` 条件成立时，取消待执行显示回调，立即通过已有 `setBrowserLayout` 隐藏网页。
- 全部弹窗移除且其他隐藏条件解除后，在下一帧重新读取弹窗状态及当前尺寸，再恢复网页。
- 不关闭标签、不销毁或重新加载网页，页面输入、滚动位置与浏览状态继续由同一网页实例持有。
- 标签切换或组件卸载时清理尺寸观察器、弹窗观察器、窗口监听及待执行帧，沿用原有卸载隐藏行为。
- 未增加通信接口、依赖、另一套弹窗状态管理或样式补丁；修改的布局逻辑使用简体中文注释。

优点：在浏览器布局的共用入口解决原生遮挡，一并覆盖使用 `ModalPortal` 的其他弹窗；叠加弹窗以实际挂载状态判断，无需维护计数。

代价：弹窗打开期间原生网页暂时不可见，隐藏与恢复经过已有进程间通信；此规则依赖共用弹窗继续直接挂载到 `body`，其他独立浮层仍使用既有隐藏条件。

工程检查：`pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm package:mac`、`git diff --check`。打包只生成本任务独立测试身份 `Zeus Test.app`，不得用构建通过代替真实界面验收。

1. 浏览器打开网页并输入内容、滚动后查看错误详情，摘要、详情与按钮完整可见，网页不遮挡且不接收穿透点击。
2. 关闭弹窗后原标签、网址、页面输入及滚动位置保持。
3. 连续错误与叠加弹窗中，关闭一个弹窗后仍有弹窗则继续隐藏网页。
4. 快速开关弹窗、弹窗期间缩放与标签更新不会提前显示网页；恢复位置采用最新尺寸。
5. 环境卡片或分栏拖动条件仍成立时，关闭错误弹窗不会提前恢复；全部条件解除后恢复。
