# ZEUS-0469 任务详情布局优化

## 已确认目标

- 推送弹窗使用“模型选择”标题，顶部继续展示项目名和任务编号。
- 六个选择框排列为两行：模型／模型等级／速度，Skill／工作模式／权限模式；列宽为 2:1:1。不支持模型等级时，将其宽度交给模型选择框。
- 模型接入按钮与标题同行，相关提示位于选择框之后，补充信息及附件整体放在模型区与工作区之间。
- 工作方式和新建／继续任务分支改为紧凑分段选择，保留原生单选、键盘焦点、禁用原因和必要确认。
- 本地仓库刷新与标题同行；远端刷新放在各仓库内部标题栏；来源分支和新分支名称并排。
- 创建任务删除父任务下方的中英文层级说明，实际层级限制和错误反馈保持不变。
- 窗口不超过 600px 时按单列展示，底部操作区保持在滚动内容之外。

## 实施边界与取舍

- 复用已有控件和表单状态，不新增依赖、接口或数据迁移；分支刷新、选择、已有环境复用以及附件处理链路保持不变。
- 分段选择的样式仅作用于推送弹窗，避免改变数字员工弹窗共用的卡片样式。
- 优点：减少纵向占用，模型、补充内容、工作区的阅读顺序更直接。
- 代价：两种工作方式的说明不再同时展示；窄窗口优先保证内容可读，不强行保持两行。
