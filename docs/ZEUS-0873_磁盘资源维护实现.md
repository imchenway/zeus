# ZEUS-0873 磁盘资源维护实现

本任务收敛生成数据的回收范围，补齐历史资源、验收副本及数据库维护的执行前保护。维护默认只读，不在应用启动或会话发送时增加目录扫描。

## 变更与取舍

| 范围 | 当前行为 | 优点与代价 |
| --- | --- | --- |
| 精确清理 | 必须提供绝对路径白名单及对应计划摘要，拒绝父子重叠、符号链接、目录替换和整根临时目录删除。 | 删除边界可审阅；每批需要重新核对事实。 |
| 工作区 | 核对终态、全部 owner、活动 Runtime、Git 状态与保全引用，再使用非强制 Git 回收；未知或未提交现场保留。 | 保留代码和任务证据；异常时需对照审计人工收敛文件与数据库状态。 |
| 旧 Skill | 共用当前引用代次；核对迁移摘要、旧 Artifact owner、保留及结构化执行引用，只删除登记资源目录，保留快照根和原 catalog，并写回收凭证。 | 历史名称仍可展示；批准回收的旧资源内容无法再用于原样复现。 |
| 验收副本 | 共用 Test 数据根解析；父进程结束后再次核对物理根、inode 与原验收清单摘要。 | 修正 macOS 重复 home 路径并拒绝删除同名重建目录；缺少有效清单的历史目录仍需另行处理。 |
| 数据库维护 | 共用清理迁移身份、摘要和会话事件保留预算，拒绝旧代及归档残留；正式提升继续要求离线。 | 候选制作与正式提升依据一致；不等于已对正式数据库执行压缩或替换。 |

## 显式在线回收

默认离线策略保留。两个清理入口可在用户明确授权后增加 `--allow-online`，执行模式参与确认摘要。

- 外部在线回收只允许历史验收快照和发布产物，不能在线改写工作区 owner、删除完整 Git 副本或扩大到父目录。
- Skill 在线回收仍核对迁移、所有权、当前引用、目录身份、资源树与原清单；未知内容和更新锁保持受保护。
- 在线摘要固定实际删除事实，不把正式库日常修改时间和无关诊断变化当作新的删除授权。
- 维护入口共用同一数据根的互斥文件及逐项审计；未知执行结果不自动重放。

在线回收的优点是无需中断正式工作。代价是应用尚不识别维护互斥，时点检查不能阻止随后出现新引用；该模式只显式使用，不能作为自动后台垃圾回收机制。正式数据库提升没有在线例外。

## 平台与检查

macOS 按实际目标查询打开文件，不因无关 ChatGPT Codex 进程而阻止历史材料回收；正式 Zeus 运行态仅在明确在线模式下放行。Windows 共用路径、白名单与身份检查，缺少 macOS 的打开文件查询时，依靠进程路径检查及原生删除失败停止；没有 Windows 实机清理证据。

源码已通过相关类型、静态规则、格式及差异检查。本机真实清理完成后，已逐项核对快照根、原清单、回收凭证与排除项。没有新增或执行额外测试，没有压缩或替换正式数据库；安装包行为以发布命令及后续真实运行证据为准。
