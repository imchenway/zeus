# ZEUS-0910 按钮优化

## 已确认范围

- 搜索放在工作区最右上角。
- 右侧增加任务入口，按任务、Git、源码、命令、终端排列，对应 macOS Cmd+1～5、Windows Ctrl+1～5。
- 收起再打开终端不自动新增标签，不重复建立显示连接。
- 用户已确认误关应用的组合键为 Cmd+W。

## 依据与取舍

已读取项目 PROJECT-STYLE.md 及本会话提供的 AGENTS.md；仓库文件检索未发现其他同名规范文件或既有本任务主文档。
复用 WorkspaceView 的项目导航、ProjectTerminalPanel、TerminalTabs 和现有主进程关闭路由，不新增导航或终端后端。
优点：按钮和快捷键指向原操作，标签与连接按当前项目保留。代价：收起后保留一个终端显示实例；切换项目仍释放显示实例并从后端恢复列表。
已结束的标签再次打开保留输出；新 shell 由“＋”显式创建。列表读取失败时不得推断没有终端并创建。

## 调查

- 原工具顺序为源码、搜索、命令、终端、Git；任务入口缺失，终端缺少数字快捷键。
- show 只寻找 running 状态；当前标签已结束时仍自动创建新标签，且未排除列表读取失败。
- MotionPresence 在收起后卸载终端显示端，再打开重新回放并显示“正在连接”。
- TerminalTabs 已接入原生关闭路由，但订阅依赖每次列表和回调变化，反复发送焦点撤销通知；首次连接前面板也未主动取得焦点。这里只确认代码路径风险，尚未实机复现用户误关闭。

## 检查边界

macOS 与 Windows 共用上述 Renderer 和关闭路由；Windows 使用 Ctrl 快捷键，窗口原生标题栏保留。未执行测试用例或测试脚本。实际界面、原生菜单和 Windows 行为尚未验收。

## 实施结果

- 搜索单独固定在内容区右上角，复用现有工具栏按钮样式与全局搜索弹窗；项目工具按任务、Git、源码、命令、终端排列。
- 终端增加 Cmd/Ctrl+5；数字快捷键在捕获阶段处理并停止继续传入 xterm，鼠标与键盘复用同一操作入口。
- 收起保留当前 xterm 实例及选中标签；已结束标签重新打开保留输出，无标签才启动；列表故障禁止自动或显式新建，恢复读取后解除限制。
- 启动请求增加同步互斥，避免 React 更新前的连续操作重复创建。
- 首屏回放之后的输出积压不再被显示为“正在连接”；真正的初次连接、断线及输入失败仍显示状态。
- 收起立即设置 inert 与 aria-hidden，动效结束后隐藏表面；隐藏期间不发送零高度尺寸、不抢回焦点。代价是保留当前显示实例和日志同步，项目切换时释放。
- TerminalTabs 订阅使用最新数据引用，不随轮询反复撤销。旧面板失焦时按真实目标同步，避免覆盖另一终端的焦点归属；项目终端打开即取得焦点。
- 关闭仍复用后台结束进程与移除标签流程。主进程菜单优先级保持原有规则：模态层、焦点终端、上下文标签、窗口。
