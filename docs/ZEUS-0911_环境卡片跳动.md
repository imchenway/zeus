## 原因与取舍

共享 `SessionQuickActionsCard` 在每次刷新前无条件把状态改为 loading，即使同一范围已有成功快照。渲染据此插入变更行的加载提示、替换统计和交付说明、禁用代码审查；外层共享 Collapsible 的自然高度动画继续呈现这些真实高度变化。

读取入口、客户端与事件链已核对：任务工作区读取和普通会话 Git 读取共用该刷新逻辑；卡片打开、回合切换、交付通知、返回窗口和页面重新可见均可触发。任务读取接口本身没有发布交付失效通知。录屏无法确定每次请求具体由哪个事件触发，没有把某一事件写成已实测原因。

采用同一读取范围内保留成功状态及快照的方式，成功响应再更新内容；首次读取和失败后的重试继续显示加载状态，失败继续显示既有错误。切换会话、项目、工作区、环境、目录模式或任务时清空旧快照，避免跨范围复用。

- 优点：修正刷新状态语义，覆盖卡片全部展示方式；复用现有快照、错误处理及动画，不新增缓存或依赖。
- 代价：后台读取期间继续显示上次成功结果，最新变化在读取完成后显示；真实内容变化仍可改变卡片高度。
- 未采用固定卡片高度：会增加空白或压缩来源列表。未删除共享高度动画：它服务于正常展开和内容变化，不能解决错误加载状态。
