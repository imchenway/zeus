# 每次任务推送创建独立工作区

Zeus 将一次“推送到新会话”定义为一条独立任务开发线：每次推送都按本次选择的来源分支和提交创建新分支、新会话与新推送工作区，不读取或继承同一任务其他推送的分支内容。推送工作区路径使用 `.zeus-worktrees/<项目>/<推送标识>/<任务编码>`，以唯一推送标识隔离重复推送，同时让会话 cwd 的最后一级保持为任务编码；旧格式 worktree 不迁移，继续由历史会话使用直至回收。

优点是重复推送可以并行且互不污染，终端目录也能直接识别任务；代价是同一任务可能产生多条需要分别审查和交付的开发线，并占用更多磁盘空间。该决策取代 ADR-0007 中“后续新会话复用既有任务环境”的规则，但保留多仓聚合和逐仓交付边界。
