# 数字员工运行复用普通任务会话

数字员工的 Agent 运行通过统一任务推送建立普通任务会话，不引入“受管会话”或其他会话亚型，也不因工作运行关联而禁止消息、审批或恢复。工作运行只冻结员工配置并关联会话身份；工作项继续拥有正式交付物、验收、返工、重试和未知结果处置。

## Consequences

- 会话的补充信息和审批只保留一份原始待处理请求；任务详情可聚合和处理同一请求，不再复制为 `task_work_decisions`。
- 工作项与会话保持不同生命周期；会话完成不等于交付物已验收，会话后续轮次也不改写已冻结的交付物版本。
- 本决定只取代 ADR-0015 中“受管 Agent 会话拒绝普通消息、任务驾驶舱是唯一交互入口”的结论；独立工作项、冻结运行、正式交付物、上下文隔离和历史保留继续有效。
