# 代码智能

代码智能从项目代码生成可查询、可丢弃并可重建的索引和图谱；它不拥有任务或代码文件本身。

## Language

**代码索引**：
从某个项目代码状态提取的符号、引用和搜索结构。
_避免：代码库、项目、事实数据库_

**代码图谱**：
从索引和项目事实派生的节点与关系投影。
_避免：任务关系、文件系统_

**索引代次**：
一次完整或增量构建形成的可核对索引版本。
_避免：应用版本、Runtime generation_

**图谱视图**：
为特定查询目的从代码图谱派生的有界展示结果。
_避免：完整图谱、Renderer 状态_

**索引缺口**：
索引无法证明覆盖当前代码状态的明确降级状态。
_避免：空项目、没有结果_
