# 会话编排

会话编排负责把用户意图安全、有序地交给运行时，并保存产品会话在排队、执行、切换和恢复中的业务事实。

## Language

**队首**：
当前唯一允许尝试派发的待处理提交。
_避免：最新消息、活动轮次_

**替换提交**：
因编辑、改路由、重试或引导退回而新建，并显式关联原提交的不可变提交。
_避免：修改原消息、覆盖提交_

**切换操作**：
产品会话从来源运行分段过渡到候选分段的一次受控业务操作。
_避免：切换会话、改变模型_

**未知结果**：
请求可能已到达运行时但尚无足够证据判断是否接纳的状态。
_避免：失败、未发送、可自动重试_

**派发尝试**：
把一个已接纳命令交给特定运行时的一次有身份尝试；只有写出前失败或明确拒绝才允许建立下一次尝试。
_避免：命令、提交、自动重试_

**派发回执**：
对一次派发尝试追加的不可变结论，只能是写出前失败、明确拒绝、写出后未知或已接纳；未知可在取得原生证据后追加接纳结论。
_避免：HTTP 响应、日志、可变状态字段_

**同步水位**：
Zeus 已完整接纳并持久化的最新 Provider 历史边界。
_避免：最新 Provider turn、界面最后一项_

**上下文编译结果**：
在明确水位和预算下生成、带来源清单与指纹的确定性模型输入；不拥有其引用的任务文档、Memory 或 Provider 历史。
_避免：完整会话副本、无来源提示词、Renderer 拼接结果_

**阶段上下文清单**：
为一次阶段尝试在固定水位编译的权威输入清单，记录任务事实、已验收交付物、代码现场、确认会话证据与 Skill 的身份、版本、哈希、预算和缺失项；它不拥有这些来源。
_避免：阶段提示词、完整聊天副本、工作管理快照_

**工作流 Skill 选择**：
用户或工作管理为一次任务推送、阶段尝试、代码审查或冲突处理首发确定一个已安装 Skill 的显式调用意图；派发时由目标 Runtime Adapter 编译为原生 Skill 投影，模型或 Provider 切换不得清空选择。
_避免：启用 Skill、模型选择、隐式匹配_

**恢复决策**：
根据持久事实、原生身份和运行时证据确定继续、暂停、降级或失败的结论。
_避免：自动重试、重新创建会话_
