# 执行与资产

执行与资产管理可产生本机副作用的工作以及这些工作产生的完整内容；其他上下文只引用其稳定结果。

## Language

**命令运行**：
一次经过授权、具有确定工作区和终态的命令执行。
_避免：终端、工具调用、任务_

**运行时会话**：
一段可持续产生终端、日志和进度事件的本机执行现场。
_避免：产品会话、原生会话_

**工具结果**：
工具调用产生的完整输出及其受控展示投影。
_避免：处理过程项、命令日志_

**变更集**：
一个轮次或操作产生并可审查、应用、冲突或撤销的文件变化集合。
_避免：Git commit、工作区、diff 文本_

**授权授予**：
允许特定主体在明确范围和时限内读取资产或执行副作用的业务事实。
_避免：绝对路径、永久权限、凭据_

**资产引用**：
定位资产并携带完整性、类型和归属信息的稳定引用。
_避免：文件路径、内联正文、缓存键_
