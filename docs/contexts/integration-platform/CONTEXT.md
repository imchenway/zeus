# 集成与平台

集成与平台提供桌面、本机、远程、安全和升级边界；它只通过公开命令与查询进入业务上下文。

## Language

**远程入口**：
从 Zeus 桌面之外提交受认证命令或读取受控状态的接入边界。
_避免：Provider、远程会话、同步服务_

**配对客户端**：
经用户明确配对并拥有受限远程能力的客户端身份。
_避免：用户、设备文件、永久授权_

**凭据槽位**：
由稳定 ID 引用、内容不可通过业务接口读取的秘密存储位置。
_避免：API Key 字符串、Provider 连接_

**发布候选**：
等待结构、签名、清单和升级门禁确认的不可变应用产物。
_避免：正式版本、测试应用、开发构建_

**本机执行核心**：
在当前用户设备上持续拥有业务写入租约和执行恢复责任的唯一主体。
_避免：Renderer、Electron Main、Provider Worker_

**设备恢复包**：
可在另一隔离资料目录核验并恢复业务事实、资产和经授权 Provider 历史的受控集合。
_避免：复制数据库、缓存备份、实时主备_
