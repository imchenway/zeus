节点说明

点击上方目录或子项可查看职责、边界与迁移后的处理方式。

权威根 · ~/.zeus/

升级完成后，Zeus 只认这一处根目录。六个一级分区按“事实、产物、Provider、备份、运行、用户状态”拆开，避免再次出现职责重叠。

data/：核心事实

保存数据库、配置、附件授权密钥及本地服务日志。数据库运行期间允许出现 WAL 与 SHM 旁路文件，停止后由 SQLite 自行收敛。

artifacts/：业务产物

附件、浏览器批注、轮次变更集、Provider 运行会话和命令记录都归到这里；保留逻辑按产物类别独立执行。

providers/：Provider 家目录

Codex 与 Pi 各自拥有独立目录。Zeus 固定 Provider 根和迁移边界，但 Provider 内部新增的缓存、插件或会话子项由 Provider 自主管理。

profile/：用户状态

浏览器状态和 Electron 用户数据都进入 profile。Chromium 会动态创建缓存、存储、Cookie 与单例锁等文件，不再散落到根目录。

runtime/：运行控制

执行主机、更新下载、安装引导、迁移凭证和隔离区集中在 runtime。这里的短期文件允许在完成后清理，不承载业务事实。

backups/：可回滚证据

数据库快照、Provider 导入事务和旧根删除凭证分开保存。生成型缓存不进入导入备份，避免备份再次膨胀。

完整静态树与规则

页面下方给出逐层静态树。[运行中] 表示进程存活时才出现；[按需] 表示相关能力使用后创建；省略号只代表 Provider 或 Chromium 自主管理的动态内容。

旧根回收结果

目标完成态不会继续保留 旧根路径为 /Users/david/Library/Application Support/@zeus/desktop。校验完成后物理删除旧根，仅在 backups/legacy-roots/ 留一份很小的删除记录。
