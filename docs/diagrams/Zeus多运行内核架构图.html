架构节点说明

点击主节点或内部模块查看职责、事实状态与边界。

Zeus 桌面产品入口

Zeus 产品入口不做模型推理与 agent loop，只提供用户任务、会话和状态交互。

会话体验

会话界面共享主干；具体功能由当前 adapter 的真实 capability 决定。

项目执行现场

执行现场绑定项目、任务、worktree、终端与文件状态，避免回退到错误工作区。

产品会话与状态投影

Zeus 产品会话身份与 Codex thread、Pi session 等原生身份显式绑定。

运行时生命周期与治理

包含 app-server 世代、路由、审批、sandbox、MCP、动态工具和恢复治理。

运行内核适配契约

这是已确认的目标架构契约，不意味着 Pi 或 Claude 适配器已经实现。

Codex Adapter｜当前

当前代码启动用户本机 codex app-server，并调用 thread/* 与 turn/*。

Pi / Claude Adapter｜规划

Pi 是 Grok、Kimi、DeepSeek、GLM 的主要扩展路径；Claude Code 后置。

原生 Harness 与模型供应源

Codex core、Pi agent core、Claude Code 各自保留 agent loop；模型供应源只提供推理能力。

项目与任务

组织项目、任务与会话入口，保持用户工作上下文。

会话导航

在 Zeus 产品会话之间导航，不改变底层原生会话身份。

输入与停止

提交用户输入，并向当前运行内核发送停止请求。

审批交互

展示并回传命令、文件和权限审批结果。

能力驱动界面

只展示当前 adapter 已声明且完成验证的能力。

恢复提示

将不可继续、未发送内容和恢复路径转换成清晰产品状态。

消息主干

统一显示消息、工具事件和运行状态的产品主路径。

输入与附件

收集文字、图片和文件上下文，再交给当前 adapter。

停止与错误

把中断、失败和恢复状态映射成一致用户操作。

状态与用量

显示当前运行内核真实回报的模型、档位和 Token。

项目

保存任务所属项目及其产品配置。

任务 Task

承载用户目标、消息历史和执行入口。

隔离工作区 Worktree

将任务绑定到真实隔离工作区，避免误用项目主目录。

终端

呈现命令执行现场与输出，不替代运行内核的工具决策。

Zeus 会话

提供稳定产品身份，用于导航、标题和产品状态。

用户提交 Submission

记录一次用户提交及其发送、执行和失败状态。

执行轮次 Turn / Item

映射原生执行轮次及消息、命令、文件等细粒度事件。

双层身份

显式绑定 Zeus 会话与 Codex thread、Pi session 等原生身份。

状态投影

将 provider 事件持久化为可恢复、可展示的产品状态。

跨内核承接

切换内核时创建新会话，只携带用户确认的必要上下文。

进程世代

同时管理新旧 app-server 世代，支持安全升级与排空。

Thread 路由

活动或待交互 thread 固定在原世代，空闲后再迁移。

审批

接收运行内核审批请求并回传用户决定。

沙箱 Sandbox

把工作区根、权限策略和执行边界传给运行内核。

MCP

承接 MCP elicitation 等双向请求并保持审计上下文。

动态工具

注册产品提供的动态工具，由运行内核决定何时调用。

适配器注册表 Adapter Registry

按运行内核类型选择 Codex、Pi 或未来 Claude adapter。

能力快照 Capability Snapshot

由 adapter 报告已验证能力，不从模型名称推断。

会话绑定

维护产品会话与原生会话的一对一绑定和来源关系。

事件归一

把不同内核事件映射为共享产品状态，同时保留原始语义。

请求响应

统一审批、用户输入和工具调用的产品侧交互通道。

凭据边界

每个 adapter 独立处理账号、API Key 和原生认证。

错误映射

转换可理解错误，但保留 provider 原始错误证据。

版本兼容

按真实运行时版本维护协议与能力兼容矩阵。

初始化 initialize

启动用户本机 codex app-server 后完成客户端握手。

model/list

读取当前 CLI 实际提供的模型和能力目录。

线程接口 thread/*

创建、读取、恢复和管理 Codex 原生 thread。

轮次接口 turn/*

启动、steer、中断 Codex 原生 turn。

双向审批

处理命令、文件、权限、用户询问和 MCP 请求。

世代排空

保持活动 thread 在原世代，安全排空后关闭旧进程。

Pi 适配器

规划中的通用模型运行内核适配器，尚未实现验收。

Claude 适配器

未来独立接入 Claude Code，当前优先级最低。

模型目录 Provider Catalog

读取 Pi 实际 provider 和模型目录，不能只靠静态列表。

原生会话 Native Session

保留 Pi 或 Claude 的原生 session 身份和恢复语义。

能力验证

每个 provider 需通过凭据、工具、安全和恢复验证。

上下文承接

跨内核新建会话并显式记录来源，不伪装原生续接。

Codex 应用服务器

开源长生命周期进程，托管 Codex core threads 并暴露协议。

Codex 内核

开源内层 harness，负责提示、上下文、工具循环和原生会话。

OpenAI 模型

向 Codex core 提供推理；模型本身不等于 harness。

Pi 智能体内核

规划用于统一承载 Grok、Kimi、DeepSeek 与 GLM 等模型。

Grok 与 Kimi

作为 Pi 的模型供应源候选，必须经过真实目录和运行验证。

DeepSeek / GLM

作为 Pi 的模型供应源候选；GLM 还需核对 ZAI 区域与型号。

Claude Code 原生内核

未来保留独立原生 harness，优先级最低。

供应商接口 Provider API

负责模型推理、认证、配额与速率限制，不负责 Zeus 产品状态。
