# Zeus 0.1.12 更新内容

## 任务首发只发送任务内容

- “推送到新会话”的预览与首条用户消息现在只包含任务标题和任务描述；描述为空时会明确显示“未提供”。
- 可选的本次补充信息会合并到任务描述中，只影响这次推送，不会修改原任务。
- 固定身份说明、项目名称与路径、来源上下文 JSON、工作模式和项目默认任务提示不再混入用户消息。执行目录、权限、模型和协作模式仍通过各自的运行参数传递。
- 项目默认任务提示仍可用于图谱问答等项目级场景，但不再自动加入正式任务首发。需要交给执行模型的信息，应写入任务描述或作为附件提供。

## 附件按 Adapter 能力处理

- 使用 Codex 创建任务会话时，附件继续通过独立附件通道发送，并在推送界面单独预览；正文不再重复附件路径、类型、大小或 JSON。
- Claude、Gemini 和 Generic CLI 当前没有与 Codex 相同的结构化附件能力。使用这些 Adapter 运行带附件任务时，Zeus 会明确拒绝并保持任务未启动，不会静默丢弃附件。

## 发布时可保留未提交工作

- 从存在暂存、未暂存或未跟踪内容的工作区发起发布时，Zeus 会改用本地 `main` 当前已提交快照的隔离副本。
- 原工作区的文件内容、暂存状态和本地分支保持原样；未提交内容不会进入 Release notes、版本提交或安装包，也不会被自动 stash、提交、合并或变基。
- 隔离发布完成后，发布者需要在处理完原工作区内容后显式同步 `origin/main`。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.12-arm64.dmg`，退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需的 `app-server` 能力时，相关 AI 执行不可用。
- 正式任务首发不再自动携带项目默认任务提示或来源上下文。执行所需信息必须已经写入任务描述或作为附件提供。
- Claude、Gemini 和 Generic CLI 暂不支持带附件任务；此类任务会在启动前被阻止。
- 当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在 Finder 中右键 Zeus 并选择“打开”。

## 发布验证

- 当前处于 Release notes 草稿生成阶段；候选提交中的根包和桌面包版本仍为 `0.1.11`，尚未执行 `0.1.12` 版本写入、发布提交、推送、标签创建、正式打包或公开发布。
- 草稿通过后，编排器将写入根包和桌面包的 `0.1.12` 版本及发布正文，并创建与本候选范围绑定的发布提交。
- 随后将执行本地发布门禁，包括格式、lint、类型检查、构建、发布契约、验收矩阵、AI CLI Adapter 检查、正式打包、应用内容健康检查，以及 DMG 完整性、SHA-256、签名、公证状态和 Homebrew Cask 一致性核对；公开前还需完成真实桌面交互回验。
- 本地门禁通过后，编排器将推送 `main` 并等待同一提交的 CI 结果，再创建并推送不可变的 `v0.1.12` 标签并触发 Release Workflow。
- 最后将回验 GitHub Release、`Zeus-0.1.12-arm64.dmg`、发布清单和 Homebrew Tap 的版本与摘要一致性；本草稿不将这些后续动作描述为已经完成。
