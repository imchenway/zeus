# Zeus 0.1.16 更新内容

## 项目仓库选择更稳定

- 修复了在项目设置中勾选或取消扫描到的 Git 仓库时，界面发生错误并导致 Zeus 退出的问题。
- 仓库选择状态现在可以正常更新，用户仍可自行确认哪些仓库需要加入项目任务环境。

## 界面错误可恢复

- Zeus 完成启动后，如果界面发生运行期错误，将显示“界面已安全暂停”恢复页，并提供刷新窗口入口。
- 这类界面错误不再被误判为启动失败，也不会因此退出整个应用；真正的启动失败仍由原有启动保护流程处理。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.16-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 发生运行期界面错误后，当前窗口需要手动刷新才能恢复；本版本不提供组件级局部恢复。
- 项目级 Git 状态、差异、快照和补丁页面暂不支持多仓或嵌套仓库；这些项目需要在任务的代码交付窗口中逐仓操作。
- 新建多仓任务环境会为所有已登记仓库创建 worktree，所需时间和磁盘空间可能随仓库数量增加。
- 共享可写目录会直接修改真实文件，不具备 Git worktree 的隔离与回滚能力。
- 提交或合入某个仓库前，需要先停止仍在写入该仓库工作区的活动会话，并处理已有冲突。
- 当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在 Finder 中右键 Zeus 并选择“打开”。
