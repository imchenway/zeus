# Zeus 0.1.18 更新内容

## 完成任务不再强制代码交付

- 将任务标记为“已完成”或“已取消”时，不再弹出代码交付窗口，也不再要求先提交、推送或放弃任务分支。单个任务和批量状态修改采用相同规则。
- 如果任务工作目录干净且没有活动会话，Zeus 会直接回收物理 Git worktree，并归档关联的 Codex 会话和 Runtime 会话。
- 如果存在未提交或未跟踪的文件、冲突或活动会话，Zeus 会显示一次危险确认。取消确认时，任务状态保持不变；确认继续后，活动会话会被停止并归档，worktree 中未提交和未跟踪的内容会被永久删除。
- 清理不会删除本地任务分支、远端分支、会话消息历史或代码交付记录；代码交付仍可作为独立流程继续处理。

## 任务会话标题更清晰

- 任务会话在左侧列表中只显示任务标题，不再额外拼接任务编号。
- 会话工作区顶部只显示所属任务的标题，不再同时显示会话标题和重复的任务副标题。
- 可以用鼠标点击或键盘操作顶部任务标题，在当前会话中打开任务详情抽屉；关闭抽屉后仍停留在原会话。
- 项目自由对话继续显示自身会话标题，不受任务标题规则影响。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.18-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 同一任务关联多个会话时，这些会话会显示相同的任务标题，需要结合状态、选中位置和会话内容加以区分。
- 确认任务终态清理后，worktree 中尚未提交和未跟踪的文件无法恢复；本地和远端任务分支只保留已经提交的内容。
- 项目级 Git 状态、差异、快照和补丁页面暂不支持多仓或嵌套仓库；这些项目需要在任务的代码交付窗口中逐仓操作。
- 共享可写目录会直接修改真实文件，不具备 Git worktree 的隔离与回滚能力。
- 截至本草稿生成时，当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在 Finder 中右键 Zeus 并选择“打开”。

## 发布验证

- 当前处于 Release notes 草稿生成阶段；候选提交中的根包和桌面包版本仍为 `0.1.17`，尚未执行 `0.1.18` 版本写入、发布提交、正式打包或公开发布。
- 草稿通过后，编排器将写入根包和桌面包的 `0.1.18` 版本及发布正文，并创建与本候选范围绑定的发布提交。
- 随后将执行完整本地发布门禁，包括格式检查、lint、类型检查、构建、发布契约、验收矩阵、AI CLI Adapter 检查、正式打包和应用内容健康检查，以及 DMG 完整性、SHA-256、签名、公证状态和 Homebrew Cask 一致性核对。
- 公开前还将回验任务会话列表与顶部标题、鼠标和键盘打开任务详情、项目自由对话标题，以及关闭详情后保留当前会话现场。
- 任务终态流程将分别回验干净 worktree 直接清理、存在本机变化或活动会话时显示危险确认、取消后保持原状态、确认后停止并归档会话和删除物理 worktree，以及任务分支、会话消息和交付记录继续保留。
- 本地门禁通过后，编排器将推送 `main` 并等待同一提交的 CI 结果，再创建并推送 `v0.1.18` 标签并触发 Release Workflow。
- 最后将回验 GitHub Release、`Zeus-0.1.18-arm64.dmg`、发布清单和 Homebrew Tap 的版本与摘要一致性；本草稿不将这些后续动作描述为已经完成。
