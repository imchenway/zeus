# Zeus 0.1.20 更新内容

## 任务组织与导航

- 任务现在支持最多三级父子关系和同项目内的双向关联；任务页提供层级与平铺视图，并按项目记住视图模式和展开状态。筛选命中子任务时会保留上级路径。
- 删除仍有子任务的父任务时，可以选择更换父任务、连同下级一起删除，或将直接子任务保留为根任务。
- 任务编码改为至少四位数字，例如 `ZEUS-0001`；超过四位后自然增长。现有任务按原序号更新，已有分支、工作树、提交和历史文档不会批量改名。
- 任务列表新增独立的“分支状态”列，不再把 Git 开发线状态混在任务状态下方。优先级统一显示为大写 `P0` 至 `P4`，并可直接在表格内修改。
- 有关联会话的运行状态可以直接打开其对应的最近会话；“未启动”仍保持为不可点击状态。
- 任务详情不再展示内部事件编码；字段保存期间在控件内显示进度，成功后直接以最终值作为反馈，失败和并发冲突仍会明确提示。

## 会话连续性与交互

- 切回本次应用运行期间已经读取过的会话时，会立即显示缓存正文并在后台刷新，不再先退回大面积加载骨架。所有关键会话和最近十个普通会话会保留在运行期热缓存中。
- 打开或重新切回已有会话时，首帧直接定位到最新消息；停留期间的新消息跟随和“返回最新消息”入口保持不变。
- 项目侧边栏会聚合会话状态：运行中的会话显示活动标记，需要用户回答或授权时显示红点，且需要介入的状态优先。
- 排队消息只显示为一个带“排队中”的气泡，并固定在当前回答之后；可编辑、删除、立即发送或调整顺序。模型接收后，气泡会转为普通用户消息并清除排队状态。
- 模型、推理强度、服务档位、权限和计划模式在会话运行或等待交互期间仍可修改。改动不热切换当前轮，只作用于尚未开始的后续轮次；排队消息开始执行时采用会话最新配置。
- 应用恢复会话时不会自动发送尚未进入模型轮次的内容。可安全续接时，内容回到原会话草稿；无法确认原线程可续接时，历史保持只读，并将内容带入底部的新会话输入区。
- 本轮结束后，输入区上方不再残留历史计划进度；正式等待回答或授权的活动轮次仍保留当前计划。
- 跳过问题后会重新同步权威会话状态，继续显示同一轮的后续内容；处理时长不再计入等待用户回答或审批的时间。
- 修复自定义答案输入可能导致界面崩溃的问题，并调整选项说明、推荐标记和自由输入区域的对齐与换行。

## 正文、Markdown 与浏览器

- 会话回复支持常用 GitHub 风格 Markdown，包括表格、任务清单、删除线、嵌套列表、链接、图片和代码块。
- 只有服务端已经授权的项目文件或附件可以作为资源打开。受信图片会显示受限尺寸缩略图并可进入 Zeus 预览；内嵌 HTML、任意本机路径和远程图片不会直接执行或加载。
- 任务说明、会话正文、思考摘要、问题和计划说明会保留原始空格、Tab、换行与连续空行；超宽内容仍会在容器内软换行。
- 每个执行轮次只显示最新一条思考摘要，保留来源原文；轮次结束后留下静态的最终摘要。系统启用“减少动态效果”时会停止旋转动画，但继续保留状态图标和文字。
- 正常的长会话上下文整理不再误报为红色技术错误，而是以低干扰的工作活动显示；真实错误仍按错误处理。
- 新建会话中的普通浏览器请求会优先使用 Zeus 内置浏览器，不再因另一套浏览器插件没有可用实例而直接中断。

## 代码交付与任务工作区

- 每次把任务推送到新会话都会创建独立分支、会话和工作树；工作目录最后一级使用任务编码，重复推送之间互不读取分支或未提交内容。
- 新建任务环境时会按“项目 + 仓库”恢复最近一次成功使用且仍然存在的来源分支；成功启动新会话后才更新这项偏好。
- “代码交付”和“提交审查”的左右差异内容会在各自栏内软换行，连续中文、URL 和无空格长串不再覆盖另一侧；视觉换行不会修改文件内容或行号。
- 合入冲突界面增加三栏语法与差异高亮，每个冲突块可单独采用目标分支、任务分支或两者内容。
- 魔法笔只自动组合能够从共同基线确定为互不覆盖的简单冲突；需要业务判断的冲突会继续保留给用户处理。
- 冲突编辑结果只有在用户保存后才写入文件并加入暂存区。最后一个冲突处理完成后会进入明确的合入确认页，不会自动推送，也不会再显示空白的“冲突文件 0”界面。
- 代码交付弹窗的正文区域可独立滚动，底部操作区固定保留在弹窗内，窗口高度较小时仍可操作。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.20-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 会话热缓存只在当前应用运行期间有效。应用重启后的首次打开仍需读取权威会话数据。
- 浏览器路由改进只适用于注册了 Zeus 浏览器工具的新会话；升级前创建的旧 Provider 会话不会被暗中替换，需要新建会话才能获得该能力。
- 来源分支偏好保存在当前设备，不跨设备同步；记忆中的分支已不存在时会保持未选择。
- 新任务编码和工作树路径规则不会迁移历史分支、工作树、提交或文档，因此历史外部引用可能继续显示旧编码或旧路径。
- 截至本草稿生成时，当前公开制品仍为 ad-hoc 签名且未经过 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在“系统设置 > 隐私与安全性”中选择“仍要打开”。

- 当前处于 Release notes 草稿生成阶段；候选提交中的根包和桌面包版本仍为 `0.1.19`，尚未执行 `0.1.20` 版本写入、发布提交、正式打包或公开发布。
- 草稿通过后，编排器将写入根包和桌面包的 `0.1.20` 版本及本发布正文，并创建与候选范围绑定的发布提交。

- 公开前将回验任务层级与关联、任务列表快捷编辑和会话跳转、会话切换与排队恢复、Markdown 和附件预览、内置浏览器路由、差异软换行、冲突逐块处理及窄窗口底部操作区。

- 最后将核对 GitHub Release、`Zeus-0.1.20-arm64.dmg`、发布清单和 Homebrew Tap 的版本与摘要一致性；以上均为草稿通过后的发布动作。
