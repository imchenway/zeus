# Zeus 0.1.4 更新内容

## 长任务升级保护

- Zeus 将窗口界面与执行宿主分离。关闭或切换界面时，正在进行的执行轮次、待处理交互和 Runtime 不再跟随窗口直接退出。
- 新版界面重新打开后会连接原执行宿主；已经开始的工作继续留在原运行时世代，新工作进入当前世代，避免重放任务或重复产生副作用。
- 存在运行中工作时退出 Zeus，会提供“退出界面，任务继续运行”“停止任务并退出”和“取消”。
- 升级安装包含版本回连握手和失败回滚：新版无法启动或无法重新连接时，会恢复旧应用并重新打开旧界面。
- 未提交的敏感回答不会写入恢复草稿，并会阻止安装，直到用户提交或清空。

## 任务 Git 工作区与代码交付

- 任务可以创建或复用独立的 `zeus/` 分支与 Git worktree；同一任务分支可以由多个后续会话继续使用，主工作区不会被任务切换分支。
- 新增提交审查窗口，可选择文件、查看双栏差异、核对来源分支和远端状态，并执行提交或提交并推送。
- 任务完成和取消前会检查各开发分支；有变更的分支必须推送并核对远端提交，无变更分支无需制造空提交。
- 新增显式代码交付入口，支持 merge 或 squash。无冲突时在隔离 worktree 中准备结果，目标分支或工作区发生变化时会安全停止。
- 冲突可以在可恢复的三方编辑器中处理，支持采用来源、采用任务、合并两侧或手工编辑；不会自动删除远端分支或改写已推送历史。

## 代码图谱工作台

- 系统架构图改为面向架构语义的分层视图，优先展示业务工作负载、共享契约、公共基础模块和真实模块依赖，不再把 Markdown 标题、普通文件或 Maven 目录结构冒充系统架构。
- 服务模块与对应 Spring Boot 启动入口组合显示，聚合包含关系改为空间边界，主画布只突出真实依赖。
- 点击架构对象会进入真实节点关系图，并支持一跳和两跳邻域切换；在局部图中再次选择对象时才打开详情。
- 图谱搜索、缩放、适配、检查器和来源统计继续使用真实扫描结果；旧结构缓存会自动失效并重新扫描。
- Renderer 按 React、会话、任务、设置、图标和动效职责拆分本地资源，消除既有的大于 500KB 构建告警，并保持离线 `file://` 加载。

## 测试版隔离

- 新增独立的 `Zeus Test` 发行配置，使用单独的应用名、Bundle ID、进程、数据库和 Chromium profile。
- 正式版和测试版可以同时运行，测试项目、扫描数据和窗口状态不会覆盖正式版。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.1.4-arm64.dmg` 手动升级。

本次从 `0.1.3` 升级仍属于手动安装。请先确认重要操作已经保存；运行中的长任务不会因为代码已具备无损升级架构，就自动跨越 Homebrew 或 DMG 的外部安装过程。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 当前发布包采用 ad-hoc 签名且未完成 Apple 公证。首次启动可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 因缺少 Developer ID 签名和 Apple 公证，本版本不启用应用内自动安装；应用内检查更新仍会引导到 GitHub Release 下载页。
- 无损升级主链路已经进入应用，但真实 Codex 长轮次审批、Browser Automation 跨界面操作、连续多次自动升级和机器断电恢复尚未完成正式分发验收。
- 任务 Git 写入只会在用户明确触发提交、推送、放弃或合入后执行；真实项目仍应在操作前核对所选分支和文件。
- 代码图谱表达静态源码结构，不等同于运行时调用链、部署拓扑或真实流量方向。
