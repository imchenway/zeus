# Zeus 0.1.7 更新内容

## Fast 服务档位

- 任务推送、项目对话、任务会话首轮和已有会话后续轮次现在都可以选择服务档位。
- 新会话可以选择“跟随 Codex”“标准”或模型目录提供的 Fast 档位；已有会话可以在空闲时切换标准与 Fast。
- Fast 使用同一个模型和推理强度，只提高处理速度并增加用量，不会静默换成其他模型或降低推理强度。
- Zeus 直接读取 Codex 模型目录中的真实档位 ID、名称和说明，不把特定模型或固定字符串冒充通用 Fast 能力。

## 会话档位同步

- Zeus 会区分用户请求、项目偏好和 Codex 实际确认的档位；会话顶部只把 Codex 返回的状态展示为实际生效档位。
- “跟随 Codex”不会向新会话发送档位覆盖；“标准”会显式请求常规档位；Fast 会发送模型目录返回的真实档位 ID。
- 切换到不支持原 Fast 档位的模型时，Zeus 保留所选模型并回到标准档位，同时展示就地提示。
- Codex 没有返回实际档位时显示“未同步”，不会使用用户请求值或本地偏好猜测结果。

## 项目偏好与任务推送

- 每个项目会记住最近一次成功创建新会话时使用的服务档位策略；没有历史偏好的项目继续跟随 Codex。
- 任务详情的“推送到新会话”与普通新建会话复用相同的服务档位选择和项目偏好。
- 已有会话临时切换档位不会改写项目的新会话偏好。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.1.7-arm64.dmg` 手动升级。

从 `0.1.6` 升级仍属于用户确认后的手动安装。建议先停止或保存重要操作；正常退出 Zeus 仍会中断正在执行的轮次，不代表它会在应用退出期间继续后台运行。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 当前发布包采用 ad-hoc 签名且未完成 Apple 公证，首次启动可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 因缺少 Developer ID 签名和 Apple 公证，本版本不启用应用内自动安装；应用内检查更新仍会引导到 GitHub Release 下载页。
- Fast 是否可用及其用量说明由当前 Codex 模型目录决定；没有 Fast 目录项的模型只提供标准档位。
- 浅色、深色、系统主题、窄窗口、键盘操作和真实 UI 点击尚未完成完整视觉验收；服务档位协议、持久化和真实 Local Server 场景已覆盖。
- 无法安全制造“模型目录声明支持、但 provider 拒绝该档位”的现场，因此该拒绝路径仍以 fail-closed 实现与静态检查为证据，不声称已完成真实故障注入。
