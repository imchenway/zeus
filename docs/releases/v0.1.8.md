# Zeus 0.1.8 更新内容

## 任务内容即时编辑

- 任务详情现在可以直接编辑标题、说明和标签；标题支持 Enter 保存，说明保留普通换行，Escape 可以放弃当前修改。
- 任务优先级和任务管理状态通过下拉框选择后立即保存；切换到已完成或已取消时仍遵守既有任务 Git 工作区处置门禁。
- 已完成或已取消的任务仍可修正任务内容，编辑不会自动改变任务管理状态。
- 编辑只更新任务本身以及此后“推送到新会话”读取的任务内容，不改写既有会话历史或正在执行的上下文。

## 附件关联与保存安全

- 任务详情可以添加和移除附件关联；移除成功后提供短时撤销，解除关联不会删除 Zeus 托管的本机文件。
- 标题、说明、优先级、标签和附件通过同一任务更新契约保存，标签会自动去除空白、空值与重复项。
- 同一窗口的连续修改按任务串行提交；其他窗口已经更新任务时，Zeus 会拒绝静默覆盖并让用户选择保留本地内容或载入最新内容。
- 保存失败时保留用户输入与重试入口；没有真实变化时不刷新任务更新时间，也不新增任务事件。
- 任务事件只记录变更字段、标签或附件数量和版本时间，不复制说明正文或本机附件路径。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.1.8-arm64.dmg` 手动升级。

从 `0.1.7` 升级仍属于用户确认后的手动安装。建议先停止或保存重要操作；当前公开包没有启用 Apple 公证和应用内自动安装。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 当前发布包采用 ad-hoc 签名且未完成 Apple 公证，首次启动可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 因缺少 Developer ID 签名和 Apple 公证，本版本不启用应用内自动安装；应用内检查更新仍会引导到 GitHub Release 下载页。
- 任务内容编辑不会追改已有会话；需要补充已有会话时，请在对应会话中单独发送消息。
- 移除附件只解除任务关联，不删除托管文件；托管文件的长期清理仍由独立存储策略负责。
