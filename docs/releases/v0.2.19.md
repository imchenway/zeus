# Zeus 0.2.19 更新内容

## 会话与代码冲突体验

- 会话列表中，模型回复期间底部空间会自动维持：当最新消息内容变化时，若你正位于底部，会保持底部可见，不再因流式输出而跳动。
- 代码冲突解决界面全面改进：
  - 左侧为只读的目标分支，右侧为只读的任务分支，中间是可编辑的合并结果，并基于共同基线自动填充未处理内容。
  - 每个冲突块现在支持在侧栏单独“选入”或“忽略”某侧内容，状态会以标签显示（未处理、已处理、手工处理），重叠修改时会提示需要手工调整。
  - 自动合并能力增强：能识别可安全合并的简单冲突并一键处理；AI 处理冲突时会先序列化冲突块，确保建议准确对应。
  - 编辑中间结果后，受影响的冲突块会自动标记为“手工处理”，且不再显示 “<<<<<<< “、“=======“、“>>>>>>>“ 等冲突标记。

## 任务关联与下拉框

- 新建任务或删除任务时，选择父任务或关联任务的列表增加了占位提示，并在无可选项时正确禁用，避免误操作。
- 下拉框展开浮层现在会根据选项内容自适应宽度，并始终不小于触发器的宽度；当内容超宽时只省略文字，不再换行或横向滚动。

## 发布与数据准备

- 修复了发布流程中的多个问题，提升了发布稳定性。
- 数据根目录准备过程现在会避免多进程同时写入冲突，确保数据一致性。

## 如何升级

- 如果你通过 Homebrew 安装，请运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

- 也可以手动下载版本化 DMG 文件 `Zeus-0.2.19-arm64.dmg`，打开后拖拽 Zeus 到 Applications 完成升级。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 本次公开制品尚未签名或公证，因此应用内自动更新可能不可用，请使用上述手动升级方式。
- 如果你正在使用 Zeus Test 多实例，每个实例的数据目录已按应用路径隔离，并行验收时不会共享数据库。

## 发布验证

- 发布流程会在草稿通过后由编排器执行，包括：写入版本、运行发布门禁（lint、typecheck、build）、打包生成新的 DMG、上传制品并同步 Homebrew。
- 正式制品生成后，会使用用户日常安装的正式 Zeus 进行升级后验证，包括能耗与基本功能回归。
- 在草稿通过前，以上步骤均未执行，也不视为已完成。
