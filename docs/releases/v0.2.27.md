# Zeus 0.2.27 更新内容

## 代码工作台

项目“代码”页面现在默认进入源码工作台，右侧可查看和编辑当前项目中的真实源码。左侧目录树支持展开目录、搜索文件名，并可在项目中新建文件或目录、重命名、移动或移入废纸篓。编辑器提供行号、语法高亮、查找替换、撤销重做和跳转行，还支持打开多个文件标签、调整目录宽度。“源码 / 图谱 / 命令”三种模式在代码页顶部切换，切换不会关闭已打开的标签和未保存草稿。离开代码页、切换项目或退出应用前，如有未保存修改会提示保存全部、放弃或取消。

## Git 任务批量操作

推送和代码交付任务在多 Git 仓库下现在支持批量选择共同来源分支，以及“全部提交”和“全部推送”操作，减少重复操作。分支列表加载和来源校验也做了优化，处理多仓时更快速、更准确。

## 用量统计

新增个人 Token 用量统计：在标题栏可快速查看用量摘要，设置页新增“用量”分类，可查看按时间、项目和模型的用量分析，帮助了解配额消耗。

## 会话与消息修复

修复了排队消息点击“立即发送”后可能消失的问题，现在消息从点击到发送确认全程可见。会话标题栏会显示任务状态，会话中的环境卡片在空间足够时直接显示在右上角。模型生成的图片现在能正确显示在会话中。

## 如何升级

### Homebrew 升级

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

从 Zeus 0.2.27 版本化 DMG 手动升级：

1. 下载 `Zeus-0.2.27-arm64.dmg`。
2. 打开 DMG，将 Zeus 拖入“应用程序”文件夹（或按安装器提示操作）。
3. 如果 Zeus 正在运行，请先退出再完成替换。

当前公开制品仍为 ad-hoc 且未公证，升级请使用上述手动方式，应用内自动安装暂不可用。

## 系统要求与已知限制

- macOS 13.0 或更高版本；此版本仅支持 Apple Silicon（arm64）架构。
- 源码编辑器仅支持 UTF-8 文本，单文件编辑上限为 2 MiB。二进制文件、无效编码文件、符号链接文件和超过上限的文件只能在外部应用中打开或查看。
- 代码图谱仍只展示真实扫描结果；首次进入“图谱”模式时会先扫描项目。
- 批量分支选择仅适用于所有仓库都存在的来源分支；部分仓库独有的分支仍需逐仓选择。
- 升级前建议保存所有未提交的源码修改，并关闭正在运行的任务。
