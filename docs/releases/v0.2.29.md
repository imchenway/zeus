# Zeus 0.2.29 更新内容

## 会话稳定性与恢复

- 改进会话续接行为：现在发送消息只会尝试继续当前原生线程，不再自动创建另一条承接会话。
- 移除“需要恢复”的整会话阻塞状态；单个消息的接收结果不确定时，只阻止该消息自动重发，不会锁死整个会话或输入区。
- 新建会话只能通过明确的“新建会话”入口触发，普通发送、连接失败或解析异常不会静默切换会话身份。
- 会话运行摘要栏现在完整显示 Token 用量、缓存命中率，并可展开运行详情；常驻环境卡片会避让摘要栏，不再遮挡内容。

## 更新与安装

- “检查更新”改为通过 macOS 原生窗口展示进度，不阻塞主界面；下载、校验和重启决策都在该窗口完成。
- 更新预取通过 Homebrew 在后台下载并校验安装包，下载完成前不会替换当前 App；下载完成后由你确认重启才安装。
- 更新安装前会检查未保存的界面更改和敏感回答，确保工作不丢失。
- 更新窗口支持中英文显示，并跟随应用语言设置。

## 其他改进

- 会话归档更便捷：项目对话和任务会话行现在直接显示归档图标，悬停或键盘聚焦时可见，不再需要从“更多操作”菜单进入。
- 打开执行轮次变更审核中的文件时，会按当前工作区状态解析并打开真实文件，而不是历史快照或恢复版本。
- 修复打开 HTML 附件失败的问题，现在可以在内置浏览器或系统默认应用中正常打开。

## 如何升级

- **Homebrew 用户**：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- **手动升级**：从发布页面下载并替换当前应用，文件名：`Zeus-0.2.29-arm64.dmg`。

## 系统要求与已知限制

- 最低支持 macOS 13.0。
- 本次发布产物为手动升级方式，暂不支持应用内自动安装。
- 更新功能依赖 Homebrew 已安装，且当前 Zeus 需由 `imchenway/tap/zeus` Cask 管理；否则更新窗口会提示原因。
- 归档图标在行尾显示，可能使超长标题更早省略。
- 部分消息的接收结果不确定时不会自动重发，请在确认后手动重试。
