# Zeus 0.2.31 更新内容

## 任务附件现在归属于具体字段

- 在任务详情和新建任务的字段中输入图片、文件、文件夹或超长文本时，附件会保留在其所属字段（如“现状”“预期”“标签”），不再作为任务底部的通用附件列表展示。
- 字段区域固定先显示附件、再显示文字；标题字段不接受附件。
- 历史任务中没有字段归属的附件，会根据任务类型自动归类（需求→需求描述，缺陷→缺陷现状，优化→优化现状），迁移结果持久保存，不再显示“未归类附件”区域。
- 移除了新增附件的文件选择按钮和拖放入口，改为通过复制粘贴将资源添加到当前字段。

## 任务首发可以携带关联任务上下文

- 向模型推送任务时，现在可以手动选择关联任务，并逐项勾选其会话和附件作为本次首发的背景信息。
- 父任务和关联任务默认都不选择；任务、会话和附件均需手动勾选，不提供全选或记忆上次选择。
- 推送前会显示结构化预览，清楚展示当前任务、父任务和关联任务的字段内容与附件位置，便于确认发送内容。
- 会话只发送服务端复验后的真实路径，不展开会话正文；同一附件在多个上下文中重复选择时只发送一次。

## 推送消息的展示更贴近发送内容

- 发送后的任务首发消息按照字段顺序展示附件和文字，附件不再堆叠在消息底部。
- Codex 和 Pi 均使用同一份布局快照生成输入，保证推送预览与发送内容一致。

## 如何升级

- 通过 Homebrew 升级：
  ```
  brew upgrade --cask imchenway/tap/zeus
  ```
- 手动升级：从发布页面下载 `Zeus-0.2.31-arm64.dmg`，打开后拖入“应用程序”文件夹覆盖旧版本。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 附件只能通过复制粘贴添加，文件选择器和拖放已移除。
- 同一资源在任务内只能有一个字段归属；重新粘贴到其他字段时，归属会转移到最后粘贴的字段。
- 对于 Pi，由于 SDK 协议限制，图片与文字无法在字节级完全交错，但界面和字段位置仍保持一致。
