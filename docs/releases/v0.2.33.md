# Zeus 0.2.33 更新内容

## 会话请求显示更可靠

在过去，部分合法的会话请求（`request_user_input`）可能因为信封中包含未知的元数据字段而被界面误判为无效，导致已经存在的请求无法显示。本次更新移除了对请求信封字段的“白名单”限制，界面只关心构造回答所必需的问题内容，忽略所有未知元数据。这意味着即使服务端或 Provider 未来增加新的元数据，已持久化的请求也不会被隐藏，界面显示将更加稳健。

同时，我们放宽了对问题项和选项的校验：问题标题（header）现在可选，缺失时自动回退为问题正文；选项描述也变为可选。核心安全检查依然保留：每个问题必须有非空的 ID 和正文、唯一的 ID、布尔类型的“敏感标记”，选项标签必须存在且唯一。这些调整使会话请求的解析更贴近实际使用，同时不影响数据安全。

## 测试与文档同步更新

为了覆盖上述行为，我们在浏览器验收页面中加入了包含未知元数据的测试载荷，验证问题卡片仍能正常显示。相关任务文档和内部上下文说明也同步更新，明确新的解析规则。

## 如何升级

推荐使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

如果你习惯手动安装，可以下载版本化 DMG 文件 `Zeus-0.2.33-arm64.dmg` 进行安装。注意：当前公开制品可能仍是临时构建，尚未进行公证，因此请通过手动下载方式升级，应用内自动安装暂不可用。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 本版本对会话请求的解析已放宽，但若请求缺少必要字段（如问题 ID、问题正文、敏感标记）仍会被视为无效，以确保回答内容可安全映射。
- 本版本为候选版本，尚未正式发布，可能包含未完全验证的行为。
