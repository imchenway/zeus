# Zeus 0.2.35 更新内容

## 菜单栏用量浮窗

- 用量摘要从 Zeus 窗口顶部移到 macOS 菜单栏。点击菜单栏 Zeus 图标即可打开新的用量浮窗，窗口隐藏时也能快速查看配额、Token 用量与估算数据。
- 浮窗以最紧迫的配额剩余为主信息，清晰展示今日与近 7 日官方 Token，并提供本地缓存命中率、估算点数与 API 等价美元等辅助数据。
- 左键点击图标开关浮窗，右键打开原生应用菜单；点击外部或按 Escape 即可关闭浮窗。

## 完全访问确认优化

- 会话中切换到“完全访问”时，原来的内联警告条改为居中确认弹窗。弹窗清楚说明 Zeus 在文件、终端与互联网三类能力上的权限，以及潜在风险，并支持取消与确认操作。

## 会话环境卡片改进

- 环境卡片现在会显示图片资源的缩略预览，便于快速识别。
- 展开全部来源时，列表会独立滚动，不再挤压其他区域。

## 提交流程调整

- 普通代码提交不再因 Git 空白格式报告（如文件末尾多余空行）被强制阻止。你仍可以正常提交，项目自身的 hook、CI 与发布门禁不受影响。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从版本化 DMG 安装，文件名 `Zeus-0.2.35-arm64.dmg`。下载后打开 DMG 并将 Zeus 拖入“应用程序”文件夹，覆盖旧版本。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品仍为 ad-hoc 签名且未公证，仅支持手动升级，应用内自动安装暂不可用。
- 菜单栏浮窗的“查看完整统计”和“前往配置”分别跳转到现有设置页，未提供购买或重置功能。

## 发布验证

发布前需依次完成以下门禁与回验：

1. **版本写入**：在通过评审后，将根包与桌面包版本更新为 0.2.35。
2. **构建与打包**：执行类型检查、lint、构建与 macOS 打包，生成公证后的正式 DMG 与签名制品。
3. **制品健康检查**：确认渲染器、主进程、preload 等入口完整，签名结构有效；对正式 `Zeus.app` 执行 `codesign --verify --deep --strict`。
4. **公开发布**：将正式制品与 Release notes 发布到 GitHub Release，并同步 Homebrew Tap 的 Cask 配置。
5. **回归验证**：在正式制品上验证菜单栏浮窗的开关、多屏定位、失焦关闭，以及完全访问确认弹窗的交互流程。
