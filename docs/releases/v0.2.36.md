# Zeus 0.2.36 更新内容

## 冲突处理会话更清晰可控

本次更新优化了代码交付中的 Git 冲突处理流程，让 AI 辅助解决冲突更加透明、安全。

- **新增权限确认**：点击“AI 处理”后，会先弹出权限选择窗口，您可以在“自动（推荐，仅写入隔离工作区）”和“完全访问（命令不再逐次请求确认，仅建议在信任当前仓库时使用）”之间明确选择一次。服务端会校验权限，不再静默使用固定设置。
- **会话标题更直观**：新建的冲突处理会话会以“冲突处理：”开头（例如“冲突处理：本地合入 分支A → 分支B”），并且在项目会话树、会话页和任务事件中都会保留这一标识，方便您快速识别专用冲突会话。历史“本地合入：”会话仍可正常恢复。
- **首发消息立即显示**：新建冲突处理会话时，您提交的指令会立即出现在会话中，不再需要等待模型回放后才显示。
- **精简提示词**：发送给 AI 的提示词不再重复列出文件清单，但保留处理全部冲突、允许暂存、禁止提交/推送等必要边界。

## 其他改进

- 修复了会话恢复时部分用户消息可能延迟显示的问题。

## 如何升级

推荐使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从发布页面下载版本化 DMG 手动升级：`Zeus-0.2.36-arm64.dmg`。本次升级为手动替换应用，不包含应用内自动安装。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 冲突处理会话的权限选择仅影响本次会话，不会自动授权后续操作。
- 若您曾与 AI 进行过冲突处理会话，旧版本创建的“本地合入：”会话标题仍会保留，不会被强制改名。
