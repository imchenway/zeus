# Zeus 0.2.38 更新内容

## AI 冲突处理：每次新建会话，权限真正生效

修复了在 Git 合入冲突中点击“AI 处理”时，权限选择未实际作用到会话的问题。现在每次点击“AI 处理”都会新建一个独立的冲突处理会话，您为这次新会话选择的权限（自动或完全访问）会直接应用到该会话及其首次模型调用。您不再受旧会话状态影响，也可以在有会话进行时并行发起新的处理。

同时，AI 处理完成后，Zeus 会自动复验并生成本地合入提交，您无需手动处理。如果合入成功，代码交付页面会实时更新为已合入状态；若仍有冲突或失败，也会明确显示真实原因。

## 权限选择弹窗优化

冲突处理前的权限选择弹窗改为更紧凑的单选列表，样式更加克制，与 macOS 工具风格一致。选中状态使用可见圆点和轻量强调色，键盘焦点清晰。选择“完全访问”时，开始按钮会变为危险操作样式，避免误触。

## 代码交付页面实时刷新

当 AI 完成冲突处理或合入状态变化时，已打开的代码交付窗口会立即刷新，无需关闭重开。您看到的始终是真实的合入结果，而不是过时的信息。

## 如何升级

- **Homebrew**：`brew upgrade --cask imchenway/tap/zeus`
- **手动下载**：从发布页面下载 `Zeus-0.2.38-arm64.dmg`，打开并拖拽 Zeus 到“应用程序”文件夹完成替换。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- 当前版本仍为手动升级方式，应用内自动更新尚未启用。
- 并行处理多个冲突会话时，仍会自动生成合入提交，但请避免对同一冲突同时发起过多处理，以免复杂化。
- 权限弹窗的视觉和键盘焦点已优化，但真实环境下的最终视觉效果仍待完整验证。
