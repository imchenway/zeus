# Zeus 0.2.39 更新内容

## 会话关注与未读

- 会话列表现在会显示更明确的关注状态：待批准、需要回复、失败或中断会使用专属标记，普通新回复显示蓝色小圆点。
- 只有当你真正看到最新内容时，未读状态才会被清除；停留在其他页面或应用在后台不会误清。
- 项目侧边栏的“会话”入口会显示未读会话数量，并优先展示需要你操作的会话。
- 当 Zeus 不在前台时，系统通知会提醒你有新回复、需要审批或会话失败，点击通知可直接跳转到对应会话。

## 模型选择与能力识别

- 新建会话时，你可以直接选择模型和推理强度，不再只能使用默认模型。
- Zeus 会根据接入渠道和模型档案自动识别模型能力（如推理等级、工具调用、图片输入），不再需要手动配置技术参数，避免因参数不匹配导致会话异常。
- 模型选择现在使用唯一身份，即使多个连接使用相同模型名，也能准确找到正确的模型。

## 任务推送与历史会话

- 推送任务时，你可以选择当前任务的历史会话作为背景信息，这些会话的 JSONL 路径会随任务发送，帮助模型理解上下文。
- 历史会话选择与父任务、关联任务的选择规则一致，且只提供路径引用，不会复制或改写历史内容。

## 冲突处理与代码交付

- 冲突处理页面改进了信息层级，并支持“AI 处理”完整解决冲突、生成合入提交，再安全更新来源分支。
- 代码交付页现在更清晰地区分了任务级交付和项目级 Git 工作台，避免混淆。
- 冲突处理时，如果本机来源分支更新，自动重建候选并保留已解决的冲突草稿，减少重复工作。

## 更新与启动

- 更新完成后，Zeus 会精确启动刚刚安装的新版本，避免因系统选择而启动旧版本或开发包。
- 如果更新后的应用身份或版本校验失败，会明确提示，而不是错误启动其他应用。

## 其他改进

- 运行日志和命令输出会合并显示进度行，阅读更流畅。
- 修复了会话权限、只读授权、推理等级选择等多项交互问题，提升稳定性。

## 如何升级

- 如果你通过 Homebrew 安装，运行：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载 `Zeus-0.2.39-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹，覆盖旧版本即可。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 手工配置模型能力的方式已移除，模型能力由 Zeus 自动识别；如果某个模型的能力识别不准确，可能会影响会话中的功能可用性。
- 更新后首次启动时，请确保没有其他 Zeus 实例在运行，以免造成冲突。

## 发布验证

本次发布在正式推送前需依次完成以下验证：

- 运行 `pnpm lint`、`pnpm typecheck`、`pnpm build` 和 `pnpm package:mac`，确保静态检查、构建和打包通过。
- 对生成的 dmg 进行签名、公证和磁盘映像校验，并通过 Gatekeeper 测试。
- 在隔离环境中进行真实 GUI 交互测试，验证会话关注、模型选择、任务推送、冲突处理和更新重启等关键流程。
- 更新 Homebrew Cask 和 GitHub Release，但仅当上述验证全部通过后进行。
- 在正式发布前，本版本不会自动推送给用户；用户需通过手动升级方式获取。
