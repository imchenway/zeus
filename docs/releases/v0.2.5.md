# Zeus 0.2.5 更新内容

## Codex 移动端远程接管

- 运行环境设置新增“Codex 远程接管”，可以查看连接状态、启用或关闭远程接管、生成设备配对码、查看已授权设备并撤销授权。
- 配对后的 Codex iOS 或其他授权客户端可以进入 Zeus 当前执行现场，看到并回答同一个阻塞选项框。远端回答后，Zeus 桌面的选项框会同步关闭，原执行轮次继续。
- 等待选项回答时，普通消息不会被误当作选项答案；切换远程执行宿主前也会检查活动轮次和待处理请求，避免中途搬迁正在进行的交互。
- iOS 端可能将 Zeus 和 Codex App 宿主显示为相同的系统机器名，可通过 Zeus 项目名或会话标题区分。

## 独立数据目录与 Codex 配置导入

- 正式版应用数据统一收敛到 `~/.zeus`，Codex 与 Pi 分别使用独立运行目录；测试版和开发环境也与正式数据隔离。
- 从旧版目录首次迁移时会复制稳定数据并保留原件，不复制执行宿主和单实例锁；如果旧执行宿主仍在运行，迁移会延后到正常退出后的下次启动。
- 设置中新增“从 Codex App 导入配置”，可先预览并导入 `config.toml`、全局 `AGENTS.md`、规则、提示词、技能和插件。重复导入前会保留原配置备份，失败时回滚。
- 导入不会复制账号、密钥、认证文件或历史会话；完成后需要重启 Zeus，并从新会话开始使用新配置。
- Pi 可以使用 Zeus 管理的全局 `AGENTS.md` 快照，并继续按项目工作目录读取项目级 `AGENTS.md`；Codex 专属技能、插件和审批语义不会被冒充为 Pi 原生能力。

## 更专注的选项框交互

- 出现普通用户询问时会暂时隐藏底部会话输入框，避免把普通消息误认为当前问题的答案；回答、跳过或关闭后恢复。
- 点击“其他”输入行或铅笔图标即可激活并聚焦自定义回答。
- `Enter` 提交回答，`Shift+Enter` 换行；中文输入法选字期间按下 `Enter` 不会误提交。
- 调整了选项说明的对齐、悬停间距和操作按钮布局，避免按钮覆盖输入内容；按下和提交期间会立即显示状态反馈。

## 升级与历史数据兼容修复

- 修复部分 0.2.4 用户升级后，旧数据库索引与多仓项目数据冲突、导致执行宿主无法启动的问题。
- 不同仓库中的同名任务分支会继续作为合法记录保留，不会通过删除历史工作区来完成迁移。
- 早期会话记录缺少重复保存的项目标识时，可以从其所属会话恢复项目归属，避免旧会话阻断启动或恢复。

## 如何升级

0.2.5 通过全部发布门禁并公开后，可通过 Homebrew 手动升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.2.5-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Codex 执行仍要求本机安装、登录并保持兼容的 Codex CLI；Zeus 不会随应用安装 Codex CLI。
- 远程接管依赖官方独立版 Codex CLI 的 Remote Control 能力、有效登录和网络连接。当前实机主路径使用官方独立版 Codex CLI 0.146.1 完成回验；Homebrew Codex CLI 0.145.0 缀少该能力所需的独立版文件布局，无法建立远程宿主。
- iOS 固定选项的显示、回答和桌面回流主路径已有实机证据；自由输入、跳过、关闭以及多端同时作答尚未完成同等级实机覆盖。
- Codex 的远端决议通知不包含答案正文。手机端回答后，Zeus 可以可靠记录请求已解决，但不能在本地历史中重放远端填写的自由文本或敏感内容。
- Codex App 后续配置变化不会自动同步到 Zeus，需要再次执行配置导入。正在执行的会话不会切换到新配置。
- 当前公开安装包仍是 ad-hoc 签名且未经过 Apple 公证。0.2.5 正式制品的签名和公证状态将在发布门禁后写入发布清单；如果仍未公证，首次打开时可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 发布验证

- 本草稿通过后，发布编排器将把根包和桌面包版本写为 `0.2.5`，写入已审阅的 Release notes，并形成固定且干净的发布候选提交。
- 公开前将执行版本与正文一致性检查、冲突和空白检查、格式检查、lint、类型检查、生产构建、验收矩阵、AI CLI 适配探针及正式 macOS 打包。
- 功能回验将覆盖旧数据目录迁移和延后条件、正式与测试环境隔离、Codex 配置预览与导入、备份和失败回滚、敏感内容排除，以及 Codex 与 Pi 对全局和项目级 `AGENTS.md` 的读取边界。
- 远程接管回验将覆盖启停、配对、设备撤销、选项显示与答案回流，并补验自由输入、跳过、关闭、多端首答和活动轮次期间拒绝切换等分支。
- 选项框回验将覆盖输入框显隐、整行激活、`Enter`、`Shift+Enter`、中文输入法保护、按钮布局、文字对齐、悬停边界和提交反馈。
- 升级回验将使用旧版数据库副本确认跨仓同名分支和历史工作区保持不变、旧索引完成迁移、早期会话可以恢复，并确认执行宿主和应用界面正常启动。
- 发布门禁还将检查应用包结构与可执行文件、严格 codesign、DMG 完整性，以及发布清单、DMG 摘要和 Homebrew Cask 的版本与架构一致性；签名和公证状态以正式清单为准。
- 本地门禁通过后，编排器才会推送 `main` 并等待对应 CI 成功，然后创建不可变的 `v0.2.5` 标签，由发布工作流创建 GitHub Release 并同步 Homebrew Tap。
- 公开后还将重新下载 DMG 和发布清单，复核文件大小、SHA-256、DMG 完整性、Release 资产元数据、Release notes 与 Homebrew Cask；这些步骤完成前不视为发布结束。
