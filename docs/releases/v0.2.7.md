# Zeus 0.2.7 更新内容

## 新会话前的 Codex 登录门禁

- 在“推送到新会话”中选择需要 OpenAI 认证的 Codex 模型时，Zeus 会先检查其专属 Codex 账号状态，避免创建一条必然在首轮失败的会话。
- 未登录时，原弹窗会显示“登录并继续”并打开官方 ChatGPT 登录页。登录完成后，Zeus 会保留已选模型、工作区、权限和补充信息，自动继续创建会话。
- 取消登录、打开登录页失败或等待超时不会创建会话或任务工作区，当前填写内容会保留，用户可以直接重试。
- Zeus 专属 Codex 与 Codex App 保持独立登录状态，不会复制或覆盖 Codex App 的账号信息。
- 真正创建会话前，服务端会再次检查账号状态；即使绕过界面调用创建入口，未登录的 Codex 请求也会被拒绝。已经就绪的 Pi 模型不受此门禁影响。
- 如果登录在真实执行轮次建立后失效，失败会话仍会保留，用户可完成登录后在原会话重试。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可通过 Homebrew 手动升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从 0.2.7 对应的 GitHub Release 下载版本化安装包 `Zeus-0.2.7-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 均为手动升级方式，本版本不声明应用内自动安装可用。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；相关 AI 执行仍依赖本机安装且兼容的 Codex CLI。需要 OpenAI 认证的新会话可通过本版本新增的登录门禁完成 Zeus 专属登录。
- 从旧数据目录升级且首次迁移未成功的用户，仍可能在启动后看到空白项目列表。已确认的一种情况是历史数据仍保留在 `~/Library/Application Support/@zeus/desktop`，而当前数据目录 `~/.zeus` 为空；0.2.7 未加入自动迁移修复。遇到这种情况时，请先退出 Zeus 并保留、备份两个目录；完整恢复还需包含附件、会话文件和命令脚本，不能只替换数据库文件。
- 截至本草稿生成时，当前公开制品仍为 ad-hoc 签名且未经过 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。0.2.7 正式制品的签名与公证状态以发布门禁生成的清单为准。
