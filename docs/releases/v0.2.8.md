# Zeus 0.2.8 更新内容

## 会话失败原因直接显示

- 执行失败后，会话时间线会在对应轮次原位置显示原因卡片，不再只显示“本轮失败”。
- Zeus 会区分认证、限流、网络、模型配置和权限等常见问题，并给出相应的恢复建议。
- 可展开“技术详情”查看错误代码、运行状态和供应商返回的原因；API Key、Bearer 凭据、本机完整路径和堆栈会在展示前脱敏或移除。
- 即使失败轮次没有生成助手消息，原因卡片也会保留。历史失败只有在本地数据库已保存错误内容时才能显示，Zeus 不会补造缺失的供应商错误。

## 更多内置模型供应商

- 模型连接新增 Kimi 和 Z.AI / GLM 内置入口，并继续提供 DeepSeek、阿里云百炼以及自定义兼容供应商。
- 内置入口预设官方服务地址和模型目录。配置时只需填写 API Key、保存连接并获取候选模型，减少误改地址或能力参数的风险。
- 自建服务、代理或其他兼容渠道仍可使用自定义供应商，并继续手工维护服务地址、模型和能力档案。

## 更准确的模型能力选择

- DeepSeek 官方渠道的 V4-Flash 提供 `low`、`high`、`max` 思考深度，V4-Pro 提供 `high`、`max`；默认均为 `high`。
- 阿里云百炼托管的 DeepSeek V4-Flash 和 V4-Pro 仅展示实际可区分的 `high`、`max`，避免把效果相同的别名显示为独立档位。
- 迁移只更新旧系统的精确默认配置；用户手工修改过的能力设置保持不变。
- 模型不支持或尚未确认思考深度时，会话输入框和“推送到新会话”窗口会隐藏深度选择，不再显示无效的 `off` 选项。
- 图片能力尚未确认时仍允许尝试；只有模型被明确标记为不支持图片时才会关闭图片入口。最终是否可用仍取决于具体供应商、模型和协议端点。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可通过 Homebrew 手动升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从 0.2.8 对应的 GitHub Release 下载版本化安装包 `Zeus-0.2.8-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 均为手动升级方式，本版本不声明应用内自动安装可用。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；使用 Codex 模型仍依赖本机安装且兼容的 Codex CLI。
- 历史失败记录只有在本地数据库已经保存错误内容时才能显示详细原因。
- 模型能力由接入渠道、具体模型和协议端点共同决定；一个渠道确认的思考深度、图片或 Responses 能力不能直接套用于其他渠道。
- 从旧数据目录升级且首次迁移未成功的用户，仍可能在启动后看到空白项目列表。一种已确认的情况是历史数据仍保留在 `~/Library/Application Support/@zeus/desktop`，而当前数据目录 `~/.zeus` 为空。遇到这种情况时，请先退出 Zeus并保留、备份两个目录；完整恢复还需包含附件、会话文件和命令脚本，不能只替换数据库文件。
- 截至本草稿生成时，当前公开制品仍为 ad-hoc 签名且未经过 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。0.2.8 正式制品的签名与公证状态以发布门禁生成的清单为准。

## 发布验证

- 当前处于 Release notes 草稿生成阶段；候选提交中的根包和桌面包版本仍为 `0.2.7`，尚未执行 `0.2.8` 版本写入、发布提交、正式打包或公开发布。
- 草稿通过后，编排器将写入根包和桌面包的 `0.2.8` 版本及本发布正文，并形成与候选范围绑定的干净发布提交。
- 随后将执行统一发布门禁，包括冲突与空白检查、变更文件格式检查、lint、类型检查、生产构建、验收矩阵、AI CLI 适配探针及正式 macOS 打包。
- 功能回验将覆盖失败原因卡片的位置与分类、无消息失败轮次、恢复建议、技术详情脱敏，以及认证、限流、网络、配置和权限错误的展示；同时检查四个内置供应商入口、自定义连接、模型目录获取、DeepSeek 与百炼思考深度、已有手工能力配置保留、深度控件隐藏和图片入口规则。

- 本地门禁通过后，编排器才会推送 `main` 并等待对应 CI 成功，然后创建不可变的 `v0.2.8` 标签，由发布工作流创建 GitHub Release 并同步 Homebrew Tap。
