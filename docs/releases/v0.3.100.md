# Zeus 0.3.100 更新内容

本次更新修复了在恢复大体量 Codex 会话时可能出现的误报失败问题。

- 修复了恢复大体量 Codex 会话时可能错误提示“当前操作未完成，请稍后重试”的问题。此前，恢复操作在固定 120 秒内未完成即被判为失败，即使 Provider 仍在正常加载历史数据。现在，Zeus 会等待 Provider 给出明确结果，不再因耗时过长而误报。
- 优化了关闭或切换会话时的处理逻辑，确保在退出时能及时结束等待，不会因恢复操作而卡住。
- 保留了原有的防重复机制，不会自动重试恢复操作或重复发送消息。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从发布页面下载版本化 DMG 文件 `Zeus-0.3.100-arm64.dmg`，打开并拖拽 Zeus 到“应用程序”文件夹。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 如果 Provider 进程持续不返回，恢复中的会话可能一直显示“正在恢复”，直到退出 Zeus 或 Provider 进程结束。这比误报失败更安全，因为协议无法区分慢加载与挂起。

## 发布验证

公开 Release 仅会在固定候选通过以下检查后创建：lint、类型检查、构建、macOS 打包、代码签名验证和公证。当前提供的 DMG 为临时签名、未公证的测试包，仅用于手动升级验证。
