# Zeus 0.3.101 更新内容

## 项目设置优化

- 项目设置拆分为“数字员工”与“可用模型”两个分页，进入页面默认显示“数字员工”，避免两块长内容纵向拼接导致优先内容被推远。
- 切换分页或项目时，未保存的复选状态与搜索内容仍会保留，方便继续调整。
- 页面恢复纵向滚动，滚动条不再被隐藏，长列表可连续浏览；底部操作区常驻，方便随时保存。

## 可用模型管理增强

- “可用模型”页改为单列布局，并新增搜索框，可同时按供应商名称、模型显示名称或模型 ID 过滤，同时显示匹配数量与已选数量。
- 超宽屏下内容居中并限制宽度，避免说明与控件被拉散；窄窗口时自动退回单列，无水平溢出。
- 键盘操作优化：复选框聚焦时不会被底部操作栏遮挡，焦点会完整停在按钮上方。

## 如何升级

- **Homebrew**：在终端运行 `brew upgrade --cask imchenway/tap/zeus`。
- **DMG 手动升级**：下载 `Zeus-0.3.101-arm64.dmg`，打开后将 Zeus 拖入 Applications 文件夹并替换旧版本。

> 当前公开制品仍为 ad-hoc 签名，未进行 Apple 公证，请忽略系统关于“未受信任开发者”的提示，并手动升级。

## 系统要求与已知限制

- 支持 macOS 13.0 或更高版本。
- 若在“项目可用模型”中未选择任何模型，保存区会显示“当前未选择可用模型。”，此时默认模型入口不会出现。
- 搜索功能依赖当前已加载的模型列表；若尚未配置任何可运行模型，搜索框可能不可用，请先到系统设置检查模型供应商。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- `git diff --check`、`pnpm lint`、`pnpm typecheck` 与 `pnpm build` 全部通过。
- macOS 独立测试包构建成功，并通过 `codesign --verify --deep --strict` 验证（测试用临时签名）。
- 测试 DMG 通过 `hdiutil verify`。
- 隔离数据库的完整性检查通过。
- 在真实应用窗口中对宽屏、常规窗口与窄窗口完成界面验收，覆盖默认入口、分页、搜索、滚动、底部操作、键盘焦点与保存读回。
