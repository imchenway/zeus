# Zeus 0.3.15 更新内容

## 修复退出中断会话无法继续

此前，当 Codex 会话在退出时被中断，重新打开 Zeus 后可能无法在原会话中继续发送新消息。此问题源于旧版本将部分会话文件写入了系统默认的 Codex 目录，而 Zeus 0.3.14 开始使用专属 Codex 目录，导致这些历史会话无法被找到。本版本在启动时自动检测并安全迁移这些错位的会话文件到 Zeus 专属目录，复制完成后才会更新数据库记录，且不会删除或移动原始文件。迁移过程具备幂等性和冲突保护，即使中断也能安全重试。迁移后，您仍可在原 Codex 线程中继续对话，新消息将作为下一轮开始，旧轮次以“已中断”状态保留。

## 启动顺序优化

在执行会话迁移时，应用会在创建 Codex 运行时与会话协调器之前完成处理，避免启动后立即触发必然失败的恢复尝试，从而减少无用的错误日志和等待。

## 如何升级

### Homebrew

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动下载

您也可以从 GitHub Releases 页面下载版本化 DMG 文件 `Zeus-0.3.15-arm64.dmg` 进行手动升级。

## 系统要求与已知限制

- 本版本仅支持 macOS 13.0 或更高版本。
- 当前公开 DMG 为 ad-hoc 签名且未公证，因此首次启动时可能需要在“系统设置”中右键打开并确认，或通过“隐私与安全性”允许运行。
- 迁移仅针对指向系统默认 Codex 目录的精确匹配记录，不会扫描或猜测其他历史路径；无路径历史可能仍不可续。
- 迁移完成后，会话文件即位于 Zeus 专属目录，源文件保留。首次启动时因需要复制和校验文件，可能略有延迟，具体取决于受影响文件大小。
