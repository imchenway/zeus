# Zeus 0.3.17 更新内容

## 会话进行中动效优化

本次更新优化了会话进行中的视觉反馈。现在同一轮正文中只有一个明确的活动焦点：思考、工具执行、计划、图片生成或最终回答按真实进度依次接管，已完成、等待用户和失败阶段保持静态，不再同时出现多个循环动画。流式输出末尾增加了一个跟随正文增长的短光标，光标不进入复制内容；未闭合的代码块和表格显示慢速结构骨架，结构完成后光标落在块末尾。冷加载、重连、提交、浏览器和子代理的状态提示统一为低饱和蓝灰的呼吸或细环效果，并保留各自的语义图形。在系统开启“减少动态效果”时，所有循环、扫光和旋转动画都会停止，仅保留静态状态标记和文字。

## 队列等待原因更准确

修复了会话本轮结束后队首后续消息不能及时自动派发，以及界面显示不真实等待原因的问题。现在调度器在轮次结束后会立即重新评估并尝试派发队首消息；如果仍不能派发，系统会把真实阻塞原因持久化并展示在界面中，不再使用“等待其他会话完成”的兜底文案。同时，Zeus 不再自行设置项目级和全局会话并发上限，不同会话直接交给各自供应商处理并发与限流；单个会话内仍然保持一次只有一个活动轮次，后续消息按先进先出顺序自动处理。

## 如何升级

推荐使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从发布页面手动下载版本化 DMG 并拖入 Applications：`Zeus-0.3.17-arm64.dmg`。当前公开制品暂为手动升级，应用内自动安装暂不可用。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前制品尚未公证，首次打开时可能需要通过系统安全提示手动允许运行。
- 移除跨会话并发上限后，供应商的限流或排队将直接反映为会话等待状态；Zeus 会展示真实原因。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- `pnpm lint`、`pnpm typecheck`、`pnpm build` 通过，`git diff --check` 无空白错误。
- `pnpm package:mac` 成功生成 `Zeus-0.3.17-arm64.dmg`。
- 安装包经过严格签名检查，密钥链验证通过。
- 在 macOS 13.0 及以上版本完成启动、创建会话、发送消息和接收回复的冒烟测试。
- 无已知的未解决阻断问题。

如果上述任一检查未通过，则不会创建公开 Release。
