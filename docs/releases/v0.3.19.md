# Zeus 0.3.19 更新内容

## 任务推送与详情错误修复

- 修复了使用 Pi 模型推送任务时，界面可能先提示失败，随后又创建真实会话并停留在“正在思考”的问题。现在会等待 Pi 的真实预检回调，超时或失败后不会残留运行中的会话。
- 修复了任务推送时 Codex 登录状态过期但界面未提前提示的问题。现在会在推送前以权威方式刷新登录状态，登录失效时直接提示并引导登录，避免创建失败的会话。
- 如果推送提交时发现登录已失效，会撤销未完成的乐观界面，恢复你选择的模型、工作区、权限、补充信息和附件，并继续登录流程，不丢失你的输入。
- 修复了打开任务详情时可能重新弹出历史“会话创建失败”错误的问题。现在只在真实失败发生时提示一次，并保留当前工作面的重试入口。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：下载 `Zeus-0.3.19-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹替换旧版本。

> 当前公开制品为手动升级方式，应用内自动安装暂不可用。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 任务推送支持 Pi 和 Codex 模型，但 Pi 模型的真实外部首轮回复未在本次发布中验收；外部模型请求可能消耗额度，请知悉。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 静态检查（lint、typecheck）和生产构建通过。
- 正式打包成功，制品通过磁盘校验。
- 在隔离环境中启动测试包，验证任务推送、登录恢复和详情错误不再出现。
- 发布后保留本地 main 中尚未公开的变更，不进行回退。
