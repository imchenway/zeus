# Zeus 0.3.22 更新内容

## 主要改进

### 会话切换与页面响应更流畅

点击侧边栏会话后，选中状态、历史消息、正文和询问选项能够更早出现，不再被网络与后台校准完全阻塞。Zeus 会在后台为最近会话预热真实快照，并缓存项目级模型能力；同时减少侧边栏选中变化时的布局计算，并延后构建默认不可见的历史处理过程。打开“推送到新会话”时，也会先显示该项目上次记住的模型、Worktree 等选择，而不是先闪现默认值再跳变。

### 上下文用量显示更准确

修复了上下文占用圆环读数失真的问题。此前在部分模型下可能显示超过 100% 的占用，实际最后一次请求的上下文占比远低于该值；现在圆环与运行详情只依据最后一次真实模型请求计算，并采用 K/M 等紧凑单位，精确位数保留在悬停提示与无障碍标签中。

### 思考过程的工具活动合并展示

思考过程中连续出现的非命令工具（MCP、网页搜索、图片查看、文件变更等）会被合并为同一个活动组，并显示“已使用 N 个工具”，不再逐条堆叠“已使用 1 个工具”；命令、失败的工具、思考摘要与上下文整理仍作为分组边界。

### 任务页看板卡片视觉优化

看板卡片上的属性胶囊（优先级、任务状态、类型、执行状态等）现在使用与任务列表一致的语义配色，拖动把手默认隐藏，仅在悬停、键盘聚焦或拖动时显示，触屏设备仍保持常显。

### 任务页工具栏与表格贴顶

修复了任务页在高窗口中工具栏与表格被拉伸、出现大片空白的问题，两行工具条与表头现在紧凑排列。

### 引导消息不再重复显示

修复了任务执行期间发送引导消息后，同一段任务正文又作为纯文本气泡重复出现的问题；引导内容会与首发任务消息保持同一条可见消息身份。

### 模型上下文窗口可配置

在模型连接设置中新增“支持 1M 上下文”选项，并为新模型提供更合理的默认上下文窗口（256K）。支持 1M 上下文的模型会在模型下拉框中显示“1M”标识。

## 如何升级

推荐通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从发布页面手动下载并安装版本化 DMG：`Zeus-0.3.22-arm64.dmg`。当前公开制品为手动升级方式，应用内自动安装不可用。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0 或更高。
- 在模型连接中手动配置的上下文窗口值可能并不代表供应商真实能力；请以供应商文档为准。
- 看板卡片语义配色在极端亮色自定义状态色下，深色主题的对比度依靠自动派生机制，效果可能与浅色主题略有差异。
- 上下文用量百分比基于模型连接配置中的上下文窗口，若该值高于实际窗口，读数会偏小，可能延迟压缩提醒。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 全量 lint、typecheck、build 通过；
- 生成测试用 `Zeus Test.app`，并通过签名与 DMG 校验；
- 发布候选通过隔离环境真实运行验证；
- 触发桌面交互场景的手动验收。

只有在这些门禁全部通过后，才会创建公开 Release。
