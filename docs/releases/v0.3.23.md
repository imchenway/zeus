# Zeus 0.3.23 更新内容

本次更新修复了模型连接配置中的上下文参数问题，并优化了相关界面显示。

## 模型连接配置修正

修复了模型连接配置中，旧版本根据 contextWindow 自动推断 1M 上下文支持的问题。现在“支持 1M 上下文”勾选状态将作为唯一依据：勾选时有效上下文窗口为 1,000,000，未勾选时统一为 256,000。新添加的模型默认不勾选，已保存的配置不会被清除。

## 配置界面调整

根据用户反馈，模型配置界面不再显示旧窗口值（如 128K、205K），只保留“支持 1M 上下文”勾选项，并优化了勾选项的布局与可访问性，避免控件拥挤。

## 如何升级

### Homebrew

执行以下命令升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

从官方发布页面下载最新版本 DMG 文件 `Zeus-0.3.23-arm64.dmg`，打开并拖动 Zeus 到应用程序文件夹完成替换。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 本版本仍为手动升级方式，暂未提供应用内自动更新。
- 旧版配置中若存在基于 contextWindow 的 1M 自动推断，升级后需手动勾选“支持 1M 上下文”以保持相同行为。
