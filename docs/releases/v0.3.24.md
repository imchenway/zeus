# Zeus 0.3.24 更新内容

## 新功能与改进

- **登录与配置导入更清晰**：将“推送到新会话”弹窗中的账号登录和 Codex 配置导入拆分为独立步骤。现在登录过程在单独弹窗中完成，支持导入 Codex 偏好、指令和技能，且不会读取账号信息。取消或返回时会保留已填写的模型、工作区、权限等设置。
- **继续已有任务分支**：在推送任务时，可以选择继续已有的任务分支和 worktree，创建新会话复用原环境，而不必新建分支。多仓任务会整体复用，确保执行根完整。
- **会话显示优化**：修复了会话时间线中处理过程可能显示在用户消息之前的顺序问题；非当天消息现在会显示完整日期；冷加载时显示原位骨架，避免布局跳动；长历史通过内容可见性优化滚动性能。
- **Git 变更页面改进**：本地变更页面的提交区移至底部，并明确显示已暂存文件数；仓库列表只显示有变更的仓库。左右对比视图现在分别垂直滚动，并自动同步滚动位置，避免长 diff 错位。
- **其他修复**：修复点击代码审查报错的问题，并仅在存在可用任务的 worktree 时启用入口；修复合并冲突后重新打开原现场；修复会话引用标记在滚动时消失的问题；修正模型配置中 1M 上下文开关可能导致的保存报错。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从本页面下载 `Zeus-0.3.24-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹覆盖旧版本。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品仍为未公证的 ad-hoc 签名，升级后 macOS 可能再次询问“文稿”“下载”等权限，请选择允许。
- 继续已有任务分支时，若上一条会话仍在写入，或环境已部分关闭，则不可选择。
