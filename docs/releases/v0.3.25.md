# Zeus 0.3.25 更新内容

本次更新聚焦会话体验与代码交付的稳定性，包含以下改进：

## 会话输出更流畅

- 优化了会话过程中思考摘要、命令执行等状态的连续显示，减少闪烁和跳动，让输出过程更连贯。
- 改善了活动轮次的布局稳定性，状态更新时视觉过渡更自然。

## 排队消息引导更加可靠

- 修复了排队消息无法引导到当前回复的问题。现在，只有位于队首且当前回复正在执行时，才能使用“引导”功能；否则会提示先将消息上移或等待当前回复就绪。
- 引导失败时会明确提示原因，不再静默忽略。

## 代码交付状态更清晰

- 当来源分支存在未提交代码而无法合入时，界面会明确提示“来源分支存在未提交代码，请先处理后再合入”，而不是继续显示模糊的“待同步”状态。
- 批量合入时，如果因来源分支有未提交代码而失败，会集中显示原因，方便快速处理。

## 后台创建会话更迅速

- 任务推送后，会话工作面和首条消息会先显示出来，再在后台发起真实会话创建，避免界面被后台请求阻塞，让操作响应更快。

## 其他

- 为 ad-hoc 构建增加了稳定的代码签名要求，减少升级后因代码身份变化导致的权限重复询问。

## 如何升级

推荐通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载并安装版本化 DMG：`Zeus-0.3.25-arm64.dmg`。由于当前公开制品为 ad-hoc 签名且未经过公证，首次启动时可能需要在“系统设置 → 隐私与安全性”中允许来自未知开发者。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 当前公开包为 ad-hoc 签名且未公证，升级后可能再次询问“文稿”“下载”等隐私权限；用户主动选择项目、附件或导出位置时，macOS 仍可能按真实目录访问边界请求授权。
- 应用内自动更新尚未启用，请使用上述手动升级方式。

## 发布验证

公开 Release 只有在以下检查全部通过后才会创建：

- 构建、打包、签名和健康检查通过。
- 桌面应用能够正常启动，且核心功能（会话、任务、代码交付）运行正常。
- 安装介质（DMG）可正常挂载并安装。
