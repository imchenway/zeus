# Zeus 0.3.31 更新内容

## 会话同步与连接稳定性

在进入大型会话时，顶部持续出现“正在同步会话状态”“正在重新连接”并反复闪烁的问题已修复。现在后台重连会保持单一的重连状态，不再在“重新连接”和“正在同步”之间反复切换，也不会重复提交相同的快照，因此页面不会在断线重连时整页闪烁或重置滚动位置。

## 任务推送模型选择与操作确认

修复了任务推送时同名模型（例如同时存在原生 Codex 和外部 Pi 模型）可能被错误路由的问题。现在相同名称的模型只有在来源明确时才会被接受，否则会提示你重新选择模型，避免模型被推到错误的提供方。

同时修复了任务推送成功但被误判为失败的问题。此前操作已经返回“已接受”但客户端仍会显示“未返回耐久操作”，现在会正确核对操作身份，推送成功后不会再误报错误。

## 退出行为改进

退出 Zeus 时，如果存在尚未完成的 Provider 请求，应用会并行取消这些请求，而不是逐个等待。此前多个超时串行累积会导致退出超过 45 秒并弹出清理失败的提示，现在退出过程会更快，并且在极少数无法确认结果的情况下，也会如实记录而不会假装成功。

## 其他调整

- 只读的原生会话不再被错误归类为旧版只读会话，仍能加载完整历史，但禁止交互写入。
- 修复了本地服务在未完成监听时可能发送无效连接信息的问题，确保 WebSocket 连接身份正确。

## 如何升级

### 通过 Homebrew 升级

如果你使用 Homebrew 安装，执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级（DMG）

你也可以从发布页面下载新版本 DMG 并手动安装：

- `Zeus-0.3.31-arm64.dmg`

下载后打开 DMG，将 Zeus 拖入“应用程序”文件夹，覆盖旧版本即可。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0 或更高版本。
- 当前分发版本为手动升级方式，应用内自动更新尚不可用。
- 已知限制：在本版本中，某些任务推送场景在特定模型配置下可能仍会提示重新选择模型，这是为了确保模型来源明确，属于预期行为。
- 退出流程在极少数网络或外部 Provider 异常情况下，仍可能耗时较长，但不会像以前那样串行等待导致超时失败。

## 发布验证

公开 Release 只有在以下固定检查全部通过后才会创建：

1. 类型检查（typecheck）、代码规范（lint）、构建（build）和代码格式检查（prettier）必须全部通过，且不产生新的错误。
2. macOS 打包过程必须成功，生成的 DMG 必须通过签名校验。
3. 使用正式历史库的只读副本进行回归：目标会话必须能打开并显示完整对话，WebSocket 连接必须稳定保持，界面不得出现“正在同步会话状态”“正在重新连接”“连接失败”或“会话读取失败”等错误。
4. 只读会话必须使用 Snapshot V2 加载，不得回退到已退役的 V1 接口。
5. 退出进程必须在合理时间内完成，不得触发安全退出失败弹窗。

只有以上检查全部通过后，才会生成并发布公开版本，并且该版本才被视为正式可用。
