# Zeus 0.3.32 更新内容

## 更新摘要

本次更新主要围绕两个方向：优化 macOS 桌面端更新下载体验，以及修复会话记录显示与任务推送相关的问题。

### Homebrew 更新下载恢复能力

当通过 Homebrew 下载新版本时，若下载连接持续处于异常低速状态，Zeus 现在会自动检测并重新建立连接，且支持断点续传保留已下载内容，避免长时间无进展的等待。同时，更新界面会实时显示下载速度与进度，并新增“重新连接”按钮，允许你手动触发重新连接。

### 会话记录显示修复

修复了部分工具调用记录因内容过长被截断后，误显示为普通助手文字的问题。现在工具调用会基于结构信息稳定识别，长命令和长输出不再出现在自然语言会话正文中。

### 任务推送上下文窗口支持

为 `gpt-5.6-sol` 模型补充了上下文窗口与最大输出 tokens 的精确预算（基于 OpenAI 官方模型目录），修复了选择该模型时可能出现的“会话创建失败”问题。其他未核验的模型组合仍会安全地拒绝派发。

## 如何升级

### Homebrew 升级

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

从 Zeus 发布页下载 `Zeus-0.3.32-arm64.dmg`，打开后拖拽 Zeus 到 Applications 文件夹。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0
- 当前公开制品为 ad-hoc 签名且未公证，因此仅支持手动升级方式；应用内自动安装尚不可用。
- 上下文窗口回退仅对已核验的 `gpt-5.6-sol` 与 `gpt-5.4-mini` 生效，其他模型或 CLI 版本变化时，任务推送仍可能会按设计失败关闭。

## 发布验证

公开 Release 仅在满足以下检查后才会创建：

- 目标候选通过 `pnpm lint`、`pnpm typecheck`、`pnpm build` 和 `pnpm verify:zarch-gates`。
- 必要的打包检查 `pnpm package:mac` 通过，且构建产物满足签名与磁盘要求校验。
- 相关目标行为探针通过，已核验模型预算边界行为符合预期。

以上检查为发布门禁的固定条件，任何检查未通过时公开 Release 不会发布。
