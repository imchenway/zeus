# Zeus 0.3.35 更新内容

## 重要修复

本次更新重点修复了会话链路中的多个问题，提升稳定性和可靠性。

### 会话恢复与消息发送
- 修复了计划确认入口丢失导致后续消息阻塞的问题。现在待处理的计划确认会随会话一起恢复，不再出现“后续消息（1）”但无确认卡片可点的死锁。
- 修复了 Renderer 重载后消息可能滞留或重复发送的问题。发送确认状态现在能正确保留，即使 HTTP 响应前重载，也不会残留草稿或导致重复提交。
- 增强了消息发送的持久性，在外层命令信封（Command Envelope）中加入耐久缓存，确保页面重载后同一消息不会因身份不一致而阻塞。

### 界面显示与交互
- 修复了“查看处理过程”展开后状态丢失的问题，现在展开状态会稳定保留。
- 修复了冷启动时思考摘要被错误显示为正式回答的问题，现在思考摘要会正确归入处理过程区域。
- 修复了工具调用可能被重复显示或误入正文的问题，现在工具执行信息只出现在详情中。

### 队列与计划控制
- 修复了自动队列中第二条消息无法自动派发的问题，现在排队消息会按顺序自动发送，且不会产生重复执行。
- 修复了实施/修订计划动作后会话可能永久停留在“正在处理”的问题，现在完成后会正确回到“已就绪”。
- 改进了计划确认事件的发布顺序，避免实时窗口错过确认动作。

### 兼容性与稳定性
- 改进了与 Codex CLI 版本的兼容性，当初始化响应不包含版本时，会通过只读探测获取版本，确保模型上下文窗口匹配。
- 更新了模型上下文窗口配置，现在支持更多模型并修正了部分模型的窗口大小。

## 如何升级

### 通过 Homebrew（推荐）

如果您已通过 Homebrew 安装，请运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级（DMG）

1. 前往发布页面下载 `Zeus-0.3.35-arm64.dmg`。
2. 打开 DMG 文件，将 Zeus 应用拖入“应用程序”文件夹替换旧版本。
3. 如果 macOS 提示应用已打开，请先退出当前运行的 Zeus 再继续。

## 系统要求与已知限制

- 要求 macOS 13.0 或更高版本。
- 本版本尚未进行公证（notarized），首次启动时可能需要右键选择“打开”以绕过 Gatekeeper。
- 当前仅支持手动升级，应用内自动更新尚未启用。
- 如果您的 Codex CLI 版本较旧，模型上下文窗口可能无法正确匹配，此时可能影响部分模型的使用。

## 发布验证

此公开版本只有在以下门禁全部通过后才会创建：

- 静态检查：`pnpm lint`、`pnpm typecheck` 通过。
- 构建与打包：`pnpm build`、`pnpm package:mac` 成功生成应用和 DMG。
- 架构门禁：`pnpm verify:zarch-gates` 通过，且内部副作用审计无违规。
- 行为探针：验证事件流、恢复机制、消息去重等关键路径符合预期。
- 真机回归：在独立测试身份和真实 Provider 下完成冷启动、发送、工具、计划确认、队列、重载等场景验证，且数据库无未解决状态。

只有在上述验证全部完成后，才会发布公开版本并同步 Homebrew tap。
