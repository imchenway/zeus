# Zeus 0.3.38 更新内容

## 本次更新

- 修复升级交接被“等待代码交付”的冲突任务长期阻断的问题；交接受阻时不再短暂关闭 Git 读取和新会话派发，因此不会再随机出现“Git 状态读取失败”或“会话创建失败”。
- 修复旧 Provider thread 的目标状态读取失败时，已经取得的 Snapshot V2 历史仍被全屏错误遮住的问题；历史正文会立即显示，附属目标能力单独降级。
- 新版接管旧 Execution Host 时对可恢复阻断进行退避，并在请求撞上真实交接窗口时刷新连接后重试一次，降低升级重启期间的瞬时失败。
- 会话摘要新增可信的累计 Token、上下文占用、缓存命中率、最近请求输出速率和 API 等价费用估算；缺少真实请求边界或价格时明确显示不可用或不完整，不使用轮次耗时反推模型速率。
- 会话详情按使用与费用、性能与活动、环境重新分组，补充首段响应延迟、累计处理耗时和代码变更统计，同时精简重复或无法可靠解释的旧字段。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.38-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 若公开清单显示应用尚未完成 Developer ID 签名或 Apple 公证，首次启动可能需要按 macOS 提示手动确认。

## 发布验证

- 公开 Release 只在固定候选提交通过类型检查、正式打包、DMG 完整性和更新清单一致性校验后创建。
- 公开资产必须与 GitHub 服务端摘要、更新清单和 Homebrew Cask 保持一致。
