# Zeus 0.3.39 更新内容

## 本次更新

- 修复从 0.3.36/0.3.37 更新后仍连接旧 Core 时，已完成但等待代码交付的冲突任务被误判为后台写入，导致 Git 状态读取和任务推送持续报错的问题。
- 新版只在旧 Core 连续 30 秒确认没有活动轮次、等待请求、运行时和命令，并且数据库状态与误判计数一致时，才通过旧协议安全退出并接管；任一证据不完整都会继续阻断。
- 接管完成后统一会话派发自动恢复，历史会话、任务推送配置与代码交付 Git 状态无需靠发送消息或重启应用恢复。
- 兼容降级严格限制为 0.3.36/0.3.37，0.3.38 及以后报告的真实后台集成任务仍按正常安全交接规则等待完成。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.39-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 若公开清单显示应用尚未完成 Developer ID 签名或 Apple 公证，首次启动可能需要按 macOS 提示手动确认。

## 发布验证

- 公开 Release 只在固定候选提交通过类型检查、正式打包、DMG 完整性和更新清单一致性校验后创建。
- 公开资产必须与 GitHub 服务端摘要、更新清单和 Homebrew Cask 保持一致。
