# Zeus 0.3.4 更新内容

## 会话与任务界面改进

- **任务推送更快进入状态**：当任务处于默认状态时，你确认推送后，任务列表、任务详情、会话标题和侧边栏分组会立即更新为项目配置的“已推送”状态，不再等待会话创建成功，也不会因会话失败而回退。
- **推送状态更透明**：如果任务处于其他状态，推送时会明确询问你是改为“已推送”状态还是保留当前状态。状态同步失败时会显示“任务状态未同步”的提示，并提供重试，但不会影响会话的继续。
- **会话状态更精准**：区分了“排队中”“正在启动处理”“正在思考”等状态，避免出现“发送中”或“正在连接”的混淆。长轮次中即使暂时没有活动内容，也会保持“正在思考”的提示，不再空白。
- **已读会话更清晰**：冲突处理会话的创建请求现在包含唯一业务操作、会话、首发消息和冲突草稿，重试或重启后仍沿用同一身份，避免重复创建。同时，来源分支或任务分支有更新时，会在同一会话内自动追赶最新代码，无需新建会话。

## 更新机制增强

- **自动检测更新**：Zeus 现在会定期在后台检查新版本，当发现新版时会显示提示图标；下载过程中可看到进度，下载完成并校验后，你决定何时重启。
- **更可靠的更新流程**：处理了版本漂移问题，确保 Homebrew 管理的 Cask 与发布清单一致才升级。后台下载中断时会自动重试几次，失败后也会在界面上提醒。
- **新版本通知**：Zeus 不在前台时，下载完新版会发送系统通知，点击即可打开更新窗口。

## 模型与供应商改进

- **模型按供应商分组**：在所有模型选择界面，模型列表会按供应商（例如 DeepSeek、阿里云百炼）分组，并支持搜索供应商或模型名称。
- **支持 IP 接入**：你可以在模型连接设置中添加使用 `http://` 地址的明文端点，新建或改用时需要明确确认传输风险。
- **新增 DeepSeek-v4-pro 支持**：已为 DeepSeek 官方 V4 模型接入 AppServer 提供兼容支持。

## 其他修复与优化

- **会话可靠性与状态收口**：修复了会话状态残留导致界面误显示“运行中”的问题；无法确认送达的会话提交会明确显示“需要恢复”，不会静默删除或重发。
- **冲突处理弹窗确认更即时**：点击“AI 处理”后立即进入会话，不再等待后台准备完成。
- **消息附件展示优化**：回答记录的附件现在完整展示在选中框内，图片支持点击放大，其他资源通过安全通道打开。
- **修复若干界面问题**：修复了顶部状态卡片卡死、创建会话报错、菜单栏用量浮窗数据与主题问题、选项卡误触等问题。

## 如何升级

Zeus 0.3.4 建议通过 Homebrew 升级，或手动下载版本化的 DMG 文件。

- **Homebrew 升级**：如果你已安装官方 Homebrew Cask，在终端中运行：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- **手动升级**：从官方发布页面下载 `Zeus-0.3.4-arm64.dmg`，挂载后拖拽 Zeus 到 Applications 文件夹覆盖旧版本。

## 系统要求与已知限制

- **系统要求**：macOS 13.0 或更高版本。
- **已知限制**：
  - 应用内自动更新现仅支持 Homebrew 托管的应用，手动安装的版本可能无法使用自动更新。
  - 升级后首次启动可能需要重新授权某些系统权限。
