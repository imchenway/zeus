# Zeus 0.3.40 会话历史与 PLAN 持久化修复

## 本次更新

- 历史会话改为纯记录视图：打开时不再自动重连、不恢复旧发送队列，也不显示“后续消息”或连接失败卡；用户真正发送新消息时才在原会话继续。
- 修复侧边栏切换后正文仍停留在上一会话、冷加载长期卡住、PLAN 确认后的短暂空档，以及历史过程和命令状态串到其他会话的问题。
- 统一进行中与历史轮次的思考过程：PLAN 选择和自定义回答回到所属轮次，活动按类型分组，历史命令默认收起，展开后沿用进行中样式。
- 已批准 PLAN 作为原轮次的正式历史产物持久化，进入开发阶段、分页、冷启动或后续多轮对话后仍可查看。
- 修复原生 Codex 被错误路由到 DeepSeek 定价的问题；旧 `api:codex` 账本会按保留的模型与 Token 事实恢复为 OpenAI 官方估价来源。
- 运行指标只展示有真实来源的数据，不再用大量“不可用”占位输出速率、首段延迟或费用。
- Computer Use 真机控制链已恢复并用于独立 Test App 验收；Zeus 不再为旧外部桥接故障伪造替代实现。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.40-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 若公开清单显示应用尚未完成 Developer ID 签名或 Apple 公证，首次启动可能需要按 macOS 提示手动确认。

- 固定发布提交通过 lint、类型检查、完整构建、独立 Test App 打包和打包健康检查；Release Workflow 的 preflight、typecheck、package-mac、publish 均成功。
