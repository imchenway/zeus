# Zeus 0.3.49 更新内容

## 本次更新

- 同一 Provider 轮次的命令、文件、搜索、网页和工具调用现在只形成一个稳定活动组；运行中追加、超过 32 条操作、完成态和历史投影都不会再拆成多个顶层“使用了工具”或“运行了命令”。
- 每轮只保留最新一条灰色 reasoning 状态，并固定在处理过程底部；不同轮次仍各自分组。
- 会话、PLAN、排队、转向、资源、Git、设置、启动和错误边界统一只显示一行脱敏后的 `错误码: 原始消息`，移除了状态标题、友好解释、恢复建议和“技术详情”折叠层。
- 发送失败或结果未知时不再把原消息、附件、Browser 内容和上下文自动回填到输入框；失败气泡与审计记录仍保留，用户后来输入的草稿不会被迟到失败覆盖。
- 灰色 reasoning 扫光改为连续线性动画，移除了每轮末尾的周期性停顿；减少动态效果开启时仍保持静止。
- 长会话上滚改用首条可见稳定行做高度补偿，并移除虚拟窗口内的第二层 CSS 假高度，解决历史分页和延迟布局导致的闪烁、回跳与窗口反向重挂。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.49-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0，仅提供 Apple Silicon 版本。
- 当前正式包为 ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证；首次启动可能需要按 macOS 提示手动确认。
- 写出后结果未知的 Provider 提交仍禁止通过 retry API 重放，避免产生重复用户消息。
- 会话分组、错误、不回填、动效和 72 条混合高度上滚已在真实 Renderer 组件中回归；隔离 `Zeus Test.app` 使用空数据启动，没有把缺少真实 Provider 历史的启动冒充为 Provider 端到端验收。
