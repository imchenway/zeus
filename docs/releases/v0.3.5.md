# Zeus 0.3.5 更新内容

## 本次更新

- **会话不再被任务状态同步干扰**：删除任务推送专用状态接口、后台重试和“任务状态未同步”警告，新界面连接旧执行宿主时不再因附属接口不存在而持续报错。
- **任务推送流程更直接**：推送弹窗不再要求确认是否同时修改任务管理状态，确认后直接创建并进入会话。
- **任务状态改为手动维护**：创建或继续会话不再自动修改任务管理状态，需要调整时仍可在任务界面手动操作。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.5-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。
