# Zeus 0.3.61 更新内容

## 本次更新

- 从会话正文点击 Markdown 文件时，右侧上下文工作面现在默认显示渲染预览，不再先落入通用源码视图。
- Markdown 工作面保留“预览 / 源码”切换；切换源码后仍可查看带行号内容，关闭后再次打开同一文件会恢复默认预览。
- 普通代码文件和轮次变更文件继续默认显示源码，原有评论与精确行定位行为保持不变。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.61-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 当前公开清单为 `signed=false`、`notarized=false`，首次启动可能需要按 macOS 提示手动确认。
- 大型 Markdown 仍受会话资源预览截断上限约束；普通相对链接只有在存在对应受信会话资源时才能打开。

## 发布验证

- 固定候选提交已通过类型检查、正式打包、DMG 完整性和更新清单一致性校验。
- 已使用独立 `Zeus Test.app` 与隔离数据完成真实 Electron 会话交互：默认预览、源码切换、关闭重开恢复预览均通过，未发现页面错误、失败请求或横向溢出。
- 公开 DMG 已完整回下载并通过 `hdiutil verify`；GitHub 服务端摘要、更新清单和 Homebrew Cask 保持一致。
