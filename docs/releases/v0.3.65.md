# Zeus 0.3.65 更新内容

## 修复内置浏览器页面失败提示

内置浏览器打开无法连接的页面时，现在只保留 Chromium 自身的失败页，不再额外弹出 Zeus 全局错误对话框或用遮罩覆盖整个应用。URL 协议、安全校验、浏览器桥接和批注等 Zeus 功能错误仍按原有方式反馈。

## 收口会话执行期摘要

- 进行中的轮次只显示最新一条思考摘要，并固定在该轮所有命令和工具活动之后。
- 最终回答开始，或轮次进入完成、中断、失败和历史状态后，执行期思考摘要不再作为会话正文保留。
- 原始 Provider 事件仍保留在底层状态中，不影响审计与恢复。

## 清理命令与工具图标样式

移除了命令和工具图标不需要的蓝色圆底与光晕，保留图标本身、状态文字和点击区域。同时修复了内置浏览器地址栏聚焦后异步选择文本时可能出现的界面回调错误。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.65-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 若公开清单显示应用尚未完成 Developer ID 签名或 Apple 公证，首次启动可能需要按 macOS 提示手动确认。
