# Zeus 0.3.66 更新内容

## 导入 Codex 配置时同步工具运行时

从 Codex App 导入配置时，现在会额外复制 Computer Use 支撑应用以及 Browser、Chrome、Computer Use 三个精确插件缓存目录，确保这些工具的运行时路径真实存在且版本匹配。导入仍会排除账号、密钥、历史会话以及其它生成缓存，但不会把来源侧生成目录错改为不存在的路径。

## 中断状态不再伪装成完成

会话列表中的“本轮已中断”现在使用专门的警告圆形图标，不再与用户主动暂停混用。轮次耗时显示也区分了“处理中”“已处理”“处理已中断”和“处理失败”，中断或失败的轮次会以对应的警示色呈现，异常结束不再表现得像是正常完成。

## 如何升级

- 通过 Homebrew 升级：`brew upgrade --cask imchenway/tap/zeus`
- 手动升级：从 GitHub Release 下载 `Zeus-0.3.66-arm64.dmg`，打开后替换现有应用。由于当前公开制品为 ad-hoc 签名且未公证，请以手动方式升级。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品为 ad-hoc 签名，未完成 Developer ID 签名或 Apple 公证，因此不支持应用内自动安装更新。
- 导入 Codex 配置时会额外复制约百 MB 的工具运行时，导入过程耗时可能略有增加。

## 发布验证

公开 Release 只有在固定候选提交通过类型检查、正式打包、DMG 完整性校验和更新清单一致性校验后才会创建。GitHub 服务端资产元数据、manifest、Release notes 与 Homebrew Cask 在发布时保持一致。
