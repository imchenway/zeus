# Zeus 0.3.7 更新内容

## 本次更新

- 紧急修复：新界面继续连接升级前已在运行的执行宿主时，点击任意会话不再因旧能力响应缺少目标字段而进入全局界面错误。旧宿主上的目标模式会按真实能力降级为不可用，会话查看和继续操作不受阻断。
- 会话输入区：活动轮次中存在草稿或待提交资源时，主操作明确显示为“发送”；空输入时继续显示“停止”。
- 会话侧边栏：运行、待回复、待授权、暂停、失败和完成等状态收口为固定图标槽，状态变化不再改变会话行高度。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.7-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 若公开清单显示应用尚未完成 Developer ID 签名或 Apple 公证，首次启动可能需要按 macOS 提示手动确认。

## 发布验证

- 公开 Release 只在固定候选提交通过类型检查、正式打包、DMG 完整性和更新清单一致性校验后创建。
- 公开资产必须与 GitHub 服务端摘要、更新清单和 Homebrew Cask 保持一致。
- 当前产物未完成 Developer ID 签名和 Apple 公证，更新清单中如实标记为 `signed=false`、`notarized=false`。
