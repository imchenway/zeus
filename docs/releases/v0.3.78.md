# Zeus 0.3.78 更新内容

## 修复重启会话后的后台续接

本次更新修复了在重启会话后，回答已成功保存但界面仍错误提示“当前操作未完成，请稍后重试”的问题。现在，当你在会话中执行询问并触发后台续接时，界面会明确显示“回答已保存，正在恢复原会话…”，并在恢复完成后自动继续。如果原会话恢复超时或失败，界面会明确提示“回答已保存，但原会话恢复超时；续接尚未发送”或“回答已保存，但原会话恢复失败；续接尚未发送”，同时提供“重新恢复”和“取消续接”按钮，让你可以安全地手动处理，而不会丢失已保存的回答。

此外，后台恢复逻辑不再与回答保存同步阻塞，续接会由统一队列在后台单独执行，并确保一次恢复尝试只产生一次写入，避免重复续接。对于旧版本中已经暂停的续接记录，升级后也会显示明确的恢复或取消入口，不会自动重发。

## 如何升级

- **通过 Homebrew 升级**：运行以下命令即可自动升级到最新版本：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- **手动升级**：你也可以从 Zeus 官方网站或版本发布页面下载最新版本的 DMG 文件，并手动安装。请下载 `Zeus-0.3.78-arm64.dmg`，打开后拖拽 Zeus 应用到“应用程序”文件夹即可完成升级。

## 系统要求与已知限制

- Zeus 0.3.78 要求 macOS 13.0 或更高版本。
- 如果原会话线程较大，恢复过程可能需要较长时间。在恢复期间，你可以看到“回答已保存，正在恢复原会话…”的提示。
- 当前版本为手动升级安装，不提供应用内自动更新。

## 发布验证

公开 Release 只有在以下检查和验证全部通过后才会创建：

- 代码仓库必须通过 `git diff --check`、`pnpm lint`、`pnpm typecheck` 和 `pnpm build` 检查。
- 桌面应用必须成功完成 macOS 打包，生成 `Zeus.app` 和对应的 DMG 文件。
- 打包产物必须通过代码签名验证、公证（如适用）以及磁盘镜像完整性验证。
- 必须通过真实桌面环境的交互验收，包括长会话、重启、回答询问、后台单次续接以及再次重启的完整流程。
- 相关行为探针（如恢复超时、取消续接、旧记录兼容等）必须全部通过。

只有上述条件全部满足，才会创建公开的 GitHub Release 并同步更新 Homebrew Tap。
