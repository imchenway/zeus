# Zeus 0.3.80 更新内容

## 自动化与外部浏览器控制

- 新增自动化工作区，可在 Zeus 中创建和管理自动化任务，支持按计划触发。
- 新增外部浏览器控制能力（Zeus Browser 扩展），支持在 Chrome 或 Edge 中精确操作标签页、点击、输入、滚动、截图、下载等，并具备站点权限管理、敏感操作确认和审计跟踪。
- 计算机控制能力增强，可操控 macOS 应用，模拟鼠标键盘操作，但密码等安全字段仍禁止读写。

## IM 接入

- 新增 Telegram 机器人接入支持，可在 Zeus 中配置并接收消息、执行命令。

## 会话体验修复

- 修复断线后会话内容不完整的问题，恢复历史消息和附件。
- 修复菜单栏浮窗跨屏切换时不可见的问题，以及浮窗跟随点击屏幕。
- 修复会话页面内容显示不完整的问题。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`
- **手动升级**：从 Zeus 官网下载 `Zeus-0.3.80-arm64.dmg`，打开并拖拽 Zeus 到应用程序文件夹。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 外部浏览器控制需要安装 **Zeus Browser** 扩展（Chrome Web Store / Edge 加载项），并授予站点权限和可选高级权限（如历史记录、书签、下载等）。
- Computer Use 需要授予 Zeus 辅助功能权限和屏幕录制权限。
- 敏感操作（如登录、支付）仍需用户在 Zeus 中手动确认，密码等安全字段不会自动填写或读取。
