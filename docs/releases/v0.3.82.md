# Zeus 0.3.82 更新内容

## Telegram 配对体验修复

本次更新修复了 Telegram 配对过程中的两个问题：

- 修复配对成功回执投递失败导致误报“请求未能完成”的问题。此前，配对成功后如果欢迎消息发送失败，可能会显示错误提示，造成配对失败的误解。现在即使欢迎消息发送失败，配对状态也能正确保持，错误仅记录在日志中。
- 修复重复打开配对链接时提示“端点已绑定”的问题。现在，同一可信私聊中重复打开配对链接会返回当前绑定状态和帮助信息，不再报错。
- 配对页面提示更新为“使用手机相机扫码”，避免引导用户寻找 Telegram 内扫码入口，实际并不存在。

## 如何升级

### Homebrew

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动安装

从发布页面下载并安装 `Zeus-0.3.82-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹即可。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0（Ventura）或更高。
- 当前发布的 DMG 未经过 Apple 签名和公证，首次打开时可能需要右键选择“打开”以绕过 Gatekeeper。
