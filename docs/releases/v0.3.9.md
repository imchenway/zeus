# Zeus 0.3.9 更新内容

## 改进

### 更新体验
- 更新检查窗口已重新设计，现在支持最小化和缩放，并能根据内容自动调整高度，不再出现底部空白。
- 下载进度现在显示阶段文字和真实百分比，进度条与文字在同一行，信息更直观。
- 失败状态会展示简洁的说明，并可选查看和复制详细的技术日志，方便排查问题。
- 更新检查、Homebrew 信息刷新、缓存定位和下载时遇到临时问题会自动重试两次，减少中断；安装动作不会自动重试。
- 更新窗口被最小化后，再次检查更新会重新显示窗口，而不是留在最小化状态。

### 命令执行历史
- 项目命令页底部的公共执行历史已移除，每条命令现在有独立的“执行历史”按钮，点击可查看该命令在当前项目中的全部记录。
- 执行历史弹窗会展示记录列表、运行详情、实时日志、停止操作和产物预览。
- 运行命令并确认后，会自动打开该命令的历史弹窗并选中新记录，方便即时查看。

### 思考过程显示
- 调整了会话中思考过程的文字样式，已完成和进行中的说明使用相同字号和颜色，阅读更稳定。
- 思考摘要、工具调用汇总等顶层过程行统一使用 15px 正文尺寸，状态图标与文字垂直对齐，避免错位。

## 如何升级

### Homebrew 用户

打开终端执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

1. 从发布页面下载 `Zeus-0.3.9-arm64.dmg`。
2. 打开 DMG，将 Zeus 拖入“应用程序”文件夹，替换旧版本。
3. 如果遇到“已损坏”提示，请在“系统设置 → 隐私与安全性”中允许打开。

> 当前公开制品尚未公证，仅支持手动升级，应用内自动更新暂不可用。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 命令执行历史按“命令 + 当前项目”展示，全局设置页不提供跨项目汇总。
- 更新失败时，关闭窗口不会取消后台已开始的预取；安装失败需要手动重试。

## 发布验证

公开 Release 只有在固定候选版本通过以下检查后才会创建：

- 代码通过 `pnpm lint`、`pnpm typecheck`、`pnpm build` 和 `pnpm package:mac`。
- 打包产物通过签名验证。
- 内部发布流程确认无阻塞问题。

这些条件在候选生成后即生效，用于保证发布质量。
