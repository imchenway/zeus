# Zeus 0.3.90 更新内容

## 主要更新

### 任务处理失败后可继续会话

单轮任务处理失败不再将整个会话锁定为不可续接。现在，当一次对话轮次失败后，您仍然可以在原会话中继续输入、补充信息或发送下一条消息。同时，更新后的界面会直接显示模型返回的具体失败原因（如模型容量不足、配置错误等），帮助您判断如何处理。如果后续继续操作，系统会先确认底层状态安全无误，再开启新一轮，避免重复提交或产生错误影响。

### 数字员工支持 Plugin Skill

数字员工现在可以正确引用和运行 Plugin Skill（来自插件的能力），而不再局限于内置的普通 Skill。您可以在数字员工配置中选择 Plugin Skill，并在任务执行时由会话的插件运行时动态加载对应能力。如果所选 Plugin Skill 在运行前被更新，本次运行会明确提示版本变化，而不会静默使用新版本。

### Computer Use 操作更稳定

改善了电脑操作（Computer Use）在 macOS 上的可靠性和响应速度。当系统辅助功能检查耗时过长时，现在会按内部时间预算分阶段处理，并明确标记部分结果；操作（如点击、输入）若因超时中断，会告知“动作可能已生效”，且不会自动重试，避免重复点击或重复提交。同时，敏感操作（如支付、删除）在目标不确定时也会增加一道确认，提升安全性。

## 如何升级

推荐使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可手动下载版本化 DMG 并安装：

- 文件名：`Zeus-0.3.90-arm64.dmg`

安装后请重启 Zeus 应用以完成升级。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- Computer Use 功能需要系统授予“辅助功能”和“屏幕录制”权限，请在“系统设置”中确认。
- 本版本为手动升级提供 DMG 包；自动应用内更新暂不可用。

## 发布验证

本版本发布前，会通过以下门禁检查才创建公开 Release：

- 代码通过 lint、类型检查与构建。
- 相关模块的自动化验证通过。
- 在 macOS 目标版本上完成打包与基本功能验证。

只有上述检查全部通过，才会正式发布。
