# Zeus 0.3.91 更新内容

## 会话恢复与显示

- 修复了侧边栏会话图标持续转圈，但会话正文没有显示当前处理过程的问题。现在切走再切回会话时，已完成的过程（如思考摘要、命令执行、阶段说明）和当前运行状态都会正确显示，不再出现留白。
- 改进了活动轮次恢复逻辑，能够恢复最近已完成的思考、命令和会话消息，并保留其真实状态（进行中、已完成或失败），避免把已完成的操作误显示为仍在运行。

## 上下文管理

- 优化了上下文派发预算计算，现在会基于 Provider 真实历史请求基线、固定输入和估算安全余量来分配上下文编译预算，避免在接近上下文窗口上限时仍错误地认为有大量可用空间。
- 为 Codex 动态工具（如插件、浏览器、计算机操作）的文本结果启用了已有的 16K 字符投影和分页句柄能力，超长工具输出不会无界进入模型热历史，降低上下文压力。

## 如何升级

推荐使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载并安装版本化 DMG 文件：`Zeus-0.3.91-arm64.dmg`。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前提供的 DMG 为手动升级包，尚不支持应用内自动安装。
- 上下文估算为保守估算，不代替代理模型的精确 Token 计数，实际使用中可能略有偏差。

## 发布验证

此公开 Release 只有在以下检查通过后才会创建：

- 所有静态检查（lint、typecheck）通过。
- 构建（build）和独立测试包（package:mac）成功生成。
- 核心会话派发与恢复验证命令（verify:conversation-dispatch-command、verify:conversation-queue-dispatch、verify:conversation-queue-restart）全部通过。
- 交互验证确认活动轮次首屏可恢复已完成过程，且切换会话后再切回显示一致。

只有在上述门禁全部满足后，才允许创建公开 Release。
