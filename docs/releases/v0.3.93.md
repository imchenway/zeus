# Zeus 0.3.93 更新内容

本次更新修复了多个影响日常使用的问题，并优化了数字员工、会话展示和更新升级的体验。

## 数字员工配置与执行

- 数字员工不再限制并发数，可以创建多个独立工作项，新指派不会停止或替换已有运行。
- 员工配置中的模型、推理强度、权限等作为默认值，单次运行可自由调整，不再受预设上限约束。
- 任务详情中的“执行者”下拉始终作为新建指派入口，已显示运行数量，不会锁定当前员工。

## 会话展示与批注

- 修复了选中会话后批注入口消失的问题，现在历史会话中仍可对回答添加批注。
- 优化了 Markdown 表格预览，宽表格不再被截断，且支持横向滚动。
- 修复了会话中最终回答可能不显示的问题，恢复长会话的完整阅读体验。

## 更新升级改进

- 修复了低版本无法升级到最新版的问题，现支持跨协议升级，自动安全关闭旧宿主。
- 优化了检查更新弹窗，待重启状态下仍可发现并准备新版，不重复下载。
- 修复了升级过程中可能出现的版本校验异常。

## 其他优化

- 切换 Git 工作台不再重复显示全页加载，直接显示已缓存内容。
- 目标输入模式恢复附件入口，可正常添加和移除附件。
- 自动化表单下拉框统一为产品内样式，改善交互一致性。

## 如何升级

- 推荐使用 Homebrew 升级：`brew upgrade --cask imchenway/tap/zeus`
- 也可以从 GitHub Releases 下载 DMG 手动安装，文件名：`Zeus-0.3.93-arm64.dmg`。

## 系统要求与已知限制

- 最低 macOS 版本为 13.0。
- 跨协议升级时需确认停止活动工作，避免数据冲突。
- 数字员工并行运行受 Provider 限流和实际资源限制，并发过高可能导致错误。

## 发布验证

公开 Release 只在固定候选通过以下检查后创建：
- 类型检查、Lint 和构建通过。
- 打包产物通过签名验证。
- 核心行为验证（如升级、会话恢复）通过。
