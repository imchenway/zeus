# Zeus 0.3.94 更新内容

## 会话输入支持 @ 和斜杠命令

现在在新建会话或继续会话的输入框中，你可以使用 `/` 唤起命令菜单，选择 Skill、Plugin、Computer Use 或切换协作模式（计划模式、目标模式），也可以使用 `@` 直接点名项目中的数字员工参与本轮对话。被点名的数字员工会独立回复，并保留上下文；每轮最多点名 8 名数字员工。目标模式与专家点名互斥，同一草稿不能同时使用。

## 数字员工执行体验改进

数字员工单次执行弹窗中，“继续已有任务分支”现在支持选择已登记的远程任务环境，也可以选择未登记的本地 Git 任务分支。选择本地分支时，Zeus 会为原分支创建新的隔离 worktree，避免多个执行现场互相干扰。

## 上下文管理优化

会话上下文占用指示器现在会显示“下一请求安全余量（估算）”和最近一次上下文压缩状态。当估算显示可能超出安全预算时，界面会提示将在派发前执行原生压缩，帮助你更清楚地了解上下文使用情况。

## 其他修复

- 修复了截图粘贴偶发裂图的问题：粘贴 TIFF、HEIC 等非常用图片格式时，会自动转换为 PNG 以正常显示；同时修复了共享附件预览请求被反复取消导致的“裂图”或只显示文件图标的竞态问题。
- 修复了会话活动详情被自动收起的问题：活动完成后，你手动展开的处理过程详情现在会保持展开状态，直到你自己收起或整个轮次结束。
- 修复了会话内容显示错误，并优化了上下文管理策略，使上下文占用估算更准确。

## 如何升级

- **Homebrew 用户**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从 [Zeus 发布页](https://github.com/imchenway/homebrew-tap/releases) 下载 `Zeus-0.3.94-arm64.dmg`，挂载后将 `Zeus.app` 拖入“应用程序”文件夹即可完成升级。

## 系统要求与已知限制

- 适用于 macOS 13.0 或更高版本。
- 数字员工点名依赖项目中已启用且完成 Agent 入口迁移的数字员工；未满条件的员工不会出现在 `@` 菜单中。
- 多仓库任务中，只有所有仓库都存在且未被占用的同名分支才会出现在“继续已有任务分支”的本地分支列表中。
- 会话上下文余量是估算值，不是 Provider 实测；真实用量以发送后的模型请求结果为准。
- 当前发布版仍为手动安装，应用内自动升级可能不可用，请使用上述方式升级。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- `pnpm lint` 通过。
- `pnpm typecheck` 通过（含架构治理门禁）。
- `pnpm build` 通过。
- `pnpm verify:conversation-command`、`pnpm verify:conversation-dispatch-command`、`pnpm verify:conversation-queue-dispatch`、`pnpm verify:conversation-queue-restart` 全部通过。
- `pnpm package:mac` 通过，产物为 `dist/test/mac-arm64/Zeus Test.app` 与测试 DMG，严格签名和公证校验通过。

任何一项未通过，则该候选不会作为公开 Release 发布。
