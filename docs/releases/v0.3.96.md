# Zeus 0.3.96 更新内容

## 执行命令卡顿诊断与界面改进

- 修复了执行命令时 Zeus 偶尔失去响应的问题。现在命令执行详情页会持续同步最新日志和状态，即使本地连接短暂中断，也会在恢复后自动追平，并明确提示“连接中断，命令可能仍在执行”。
- 当检测到命令可能仍在后台运行时，界面会禁用“停止”按钮，避免误解停止操作已经生效，同时记录心跳故障与恢复的诊断信息，便于后续定位问题。

## 禅道任务导入增强

- 从禅道链接解析任务时，现在会一并带入附件（如截图、日志等），并保存到本机，方便随后预览和打开。导入结果会显示成功带入的附件数量，若有附件下载失败也会明确提示。
- 解析过程更加安全可靠：只下载同源的附件，对大小和数量有限制，并避免将认证信息暴露给页面。

## 开发计划预览修复

- 修复了点击开发计划无法在右侧预览正文的问题，现在活动会话和历史（只读）会话都能正常打开计划工作区，显示完整计划内容。

## 会话批注与界面优化

- 修复了会话批注编号在滚动时位置错乱的问题，现在编号会跟随正文滚动，不再出现“文字移动、图钉不动”的现象。
- 移除了输入框的灰色焦点边框，让界面更简洁。
- 优化了会话详情的排版，将运行详情按高频事实分组，显示更清晰。

## 自动化与数字员工改进

- 自动化配置中的“目标项目”现在支持批量选择，并统一为下拉框样式，便于管理多个项目。
- 自动化配置中的 Skill 和 Plugin 改为下拉列表选择，不再要求手动输入内部 ID，并会校验所选项目是否都支持已选能力。
- 指派给数字员工时，可以补充本次工作的额外说明（如优先级、已知线索等），仅用于本次工作项，不影响任务描述或员工提示词。

## 其他交互改进

- 历史会话重新发送消息时，界面会正确显示“正在恢复对话”的状态。
- 命令执行窗口在连接中断时会显示警告提示，并在恢复后自动同步日志。

## 如何升级

- 通过 Homebrew 升级：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- 手动升级：从发布页面下载 `Zeus-0.3.96-arm64.dmg`，打开后拖入“应用程序”文件夹覆盖旧版本。

## 系统要求与已知限制

- 最低支持 macOS 13.0。
- 当前公开制品为手动升级安装，不提供应用内自动更新。
- 禅道任务导入时，富文本正文中未作为附件列表出现的图片不会被自动转存；跨域重定向的附件下载可能会失败。
- 自动化配置中，当选择多个项目时，Skill/Plugin 的加载时间会受最慢项目影响。
