# Zeus 0.3.97 更新内容

## 本次更新

- 指派任务给数字员工时可以同时填写补充信息，补充内容会随指派进入任务执行链。
- 支持从禅道任务链接解析并自动填入任务信息，减少手工复制字段。
- 优化会话详情排版和滚动定位，修复标记位置随会话滚动偏移的问题。
- 思考过程收起后仍会展示文件变更，避免关键交付信息被一并隐藏。

## 工程收缩

- 删除未接入产品的恢复包双目的地复制/保留壳、未实例化存储子系统、不可达界面与无消费者导出。
- 将 Desktop QA 从大型手写状态夹具收缩为三个数据驱动真实组件场景。
- 移除 `diagram-engine`、`security-core`、`terminal-core` 三个没有独立运行边界的工作区包，将实现收回现有消费者。
- 七个离线 CLI 统一使用 Node `util.parseArgs`，命令身份与摘要复用现有实现。
- 本轮全仓收缩净删 8379 行，没有增加新框架或第三方依赖。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.97-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0，仅提供 Apple Silicon 版本。
- 当前公开包未配置 Developer ID 签名和 Apple 公证，首次启动可能需要按 macOS 提示手动确认。
