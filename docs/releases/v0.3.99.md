# Zeus 0.3.99 更新内容

## 会话展示更清晰

- 修复了使用中转 Opus 模型时，会话内容中思考过程、阶段说明与工具活动混排的问题。现在模型思考会作为可展开的“查看思考详情”默认收起，阶段说明与工具活动正确归属，避免完成会话显得像把思考当正文展开。

- 修复了推送子任务时用户消息重复显示的问题。同一条消息的两个投影（原始任务卡与 Provider 卡）现在会被正确识别为同一条消息，不会再出现重复卡片。

## 工作区稳定性提升

- 修复了执行命令时应用偶发卡死的问题。原因之一是隐藏的源码工作区在后台持续监听文件变化，发布等高频写入会造成事件风暴。现在源码工作区仅在需要时挂载，切换视图会释放监听；同时主进程会忽略生成目录（如 .git、node_modules、dist）的文件事件，渲染进程也会合并高频刷新，批量写入不再拖累界面响应。

- 普通源码文件的外部修改仍会及时同步到编辑器；未保存的草稿不会被覆盖，只会标记外部变更。切换视图后重新进入源码工作区，会从磁盘恢复已打开文件和目录。

## 如何升级

**通过 Homebrew 升级**：

```bash
brew upgrade --cask imchenway/tap/zeus
```

**手动升级（DMG）**：从发布页面下载 `Zeus-0.3.99-arm64.dmg`，挂载后将 Zeus 拖入“应用程序”文件夹（若已安装旧版，请先退出应用再覆盖）。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0（Ventura 或更高）。
- 当前发布制品未进行公证，首次打开时若提示“已损坏”或无法验证开发者，请使用右键“打开”或前往“系统设置 → 隐私与安全性”允许运行。
- 本版本仅提供手动升级，应用内自动更新暂不可用。

## 发布验证

公开 Release 仅在以下门禁全部通过后创建：候选提交通过 lint、类型检查、单元测试与构建；macOS 应用打包与签名校验通过；渲染进程事件流回归探针通过；在隔离测试应用（bundle ID `dev.hypha.zeus.test`）上完成真实 GUI 验收（含外接屏、命令执行、文件风暴、未保存保护与推送子任务场景）。任何门禁未通过将不会发布。
