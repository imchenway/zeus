# Zeus 0.1.5 更新内容

## 本次更新

本版本汇总 develop 中通过检查的改动。[查看完整变更](https://github.com/skylight-f/zeus/compare/skylight-v0.1.4...aaee371be85758a1106ede5e6c091c206ffbabe3)。

## 如何升级

从 [SkyLight 发布页](https://github.com/skylight-f/zeus/releases/tag/skylight-v0.1.5) 下载 Zeus-0.1.5-arm64.dmg，退出 Zeus 后安装。
从旧 0.3.x 版本切换到 0.1.x 时需要手动安装一次，之后按 SkyLight 的递增版本更新。

## 系统要求与已知限制

面向 Apple Silicon Mac，要求 macOS 13 或更高版本。签名、公证及自动安装能力以本次更新清单和应用检查结果为准。

## 发布验证

公开发布以源码检查、候选检查和安装包校验成功为前提；具体执行结果见同一提交对应的 GitHub Actions 记录。
