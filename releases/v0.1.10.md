# Zeus 0.1.10 更新内容

## 面向维护者的分阶段发布流程

- 新增发布内容草稿、候选准备、本地门禁和公开发布四个独立阶段，维护者可以逐步审阅结果，再决定是否继续。
- 发布内容草稿会依据稳定标签、候选提交和版本事实生成，并保留配套证据；生成过程不会修改源码、版本、Git 历史或远端状态。
- 候选准备默认只生成计划；显式确认后才会同步包版本和已审阅的 Release notes，且不会自动提交、推送或创建标签。
- 本版本没有新增桌面界面或运行时业务功能，桌面应用的日常使用方式与 0.1.9 相同。

## 更明确的发布安全边界

- 本地门禁集中检查候选版本、Release notes、构建与制品一致性，但不会创建提交、标签、GitHub Release 或 Homebrew Tap 变更。
- 公开发布默认只执行只读前置检查；只有候选提交、门禁摘要、远端状态和发布确认值均满足要求时，才会创建并推送标签、触发发布流程。
- 已存在的标签不会被改写；发布失败后保留现场，可在外部条件修复后继续回验。

## Zeus 项目命令配置

- 四个发布阶段可以声明为 Zeus 项目命令，包含参数、超时、启用状态和 Git／外部服务写入风险提示。
- 命令同步支持声明校验和只读差异预览；真实同步需要本机 API 凭据、匹配的项目目录和显式确认。
- 这些命令不会自动出现在现有 Zeus 项目中，仍需仓库维护者审阅并执行同步。

## 如何升级

本文是候选发布说明；GitHub Release 和 Homebrew Tap 是否就绪仍待发布流程确认。正式发布并完成 Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载 `Zeus-0.1.10-arm64.dmg`，退出正在运行的 Zeus 后手动安装并覆盖旧版本。

Homebrew 和 DMG 均属于用户主动执行的手动升级方式，本候选不声明应用内自动安装可用。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 截至本草稿，当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证；0.1.10 正式制品的签名与公证状态待发布门禁确认。
- 在 Developer ID 签名和 Apple 公证得到确认前，不启用应用内自动安装；首次打开手动安装的应用时，可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 发布内容草稿生成需要本机 Codex CLI 已登录，并会把候选变更交给外部 AI 服务分析。
- 项目命令同步需要维护者提供 Zeus 本机 API 地址、令牌和项目 ID，不会自动修改现有项目配置。
