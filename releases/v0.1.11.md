# Zeus 0.1.11 更新内容

## 改用本机 Codex CLI

- Zeus 不再内置 Codex。升级后需要在本机安装并登录 Codex CLI，Zeus 不会下载、安装或自动升级它。
- 可以在设置中指定 Codex 可执行文件的绝对路径；留空时，Zeus 会依次检查当前 `PATH`、macOS 常见安装目录和登录 Shell。
- 检测结果会显示实际路径、版本、检测时间和 `app-server` 兼容状态。未找到 Codex 或能力不兼容时，Zeus 会阻止相关 AI 执行并提供安装或升级指引，不会回退到内置版本。

## 会话目录、分支与 Token 用量

- 会话运行信息新增当前执行目录和 Git 分支，方便在开始工作前确认会话是否位于正确的项目或任务工作区。非 Git 目录和无法取得执行目录的会话会显示对应状态，不会用项目主目录猜测。
- 较长的目录和分支会按可用空间省略，悬停仍可查看完整内容。
- Token 用量会按 1000 进位自动使用 `K`、`M`、`B`，最多保留三位有效数字；摘要和展开详情中的总量、输入量、输出量使用同一规则。
- 紧凑显示不会改变原始计数精度；悬停文本和辅助技术标签仍提供带千分位的精确数值。

## 任务列表时间列

- “创建时间”和“更新时间”列标题恢复为列内居中，排序箭头出现时标题位置也保持不变。
- 时间值继续右对齐并使用等宽数字，便于纵向比较。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.11-arm64.dmg`，退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不再附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需的 `app-server` 能力时，相关 AI 执行不可用。
- 修改 Codex 路径后，新路径只影响之后新建的执行进程；已经开始的执行轮次不会迁移或重放。
- 会话分支显示来自读取会话快照时的 Git 状态；如果在外部切换分支，需要等待下一次会话快照刷新。
- 当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在 Finder 中右键 Zeus 并选择“打开”。

## 发布验证

- 当前处于 Release notes 生成阶段；候选提交中的根包和桌面包版本仍为 `0.1.10`，没有执行版本写入、发布提交、推送、标签创建或公开发布。
- 草稿通过后，编排器将写入 `0.1.11` 的双包版本和发布正文，并为同一候选提交创建发布提交。
- 随后将执行本地发布门禁，包括格式检查、lint、类型检查、构建、发布契约检查、验收矩阵、正式打包、应用健康检查以及 DMG 完整性、摘要、签名和公证状态核对。
- 本地门禁通过后，编排器将推送 `main`，等待同一提交的 CI 结果，再创建并推送不可变的 `v0.1.11` 标签并触发 Release Workflow。
- 最后将回验 GitHub Release、版本化 DMG、发布清单和 Homebrew Tap 的版本与摘要一致性；本草稿不将这些后续动作描述为已经完成。
