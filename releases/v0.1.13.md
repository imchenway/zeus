# Zeus 0.1.13 更新内容

## 任务详情可独立提交和推送代码

- 任务详情的“代码交付”区域新增“提交代码”和“推送代码”两个独立入口，原有完整代码交付流程保持不变。
- “提交代码”支持选择任务开发线、审查差异、选择文件并填写提交说明；完成后只创建本地提交，不会自动推送或改变任务状态。
- “推送代码”只推送当前开发线已有的本地提交。未提交和已暂存的改动会保持原样，不会被自动带入远端。
- 推送不会使用强制推送，也不会自动合并目标分支或回收开发线；完成后还会核对远端分支是否与本地当前提交一致。

## 任务首次成功推送后自动进入开发中

- “待开始”任务推送到新会话，并且首轮执行成功启动后，任务状态会自动改为“开发中”。
- 只有“待开始”会自动迁移；测试中、待验收、已阻塞、已完成和已取消等其他状态不会被回退或重新打开。
- 仅创建会话、首轮发送失败或等待重试时，任务状态不会改变。若用户在推送过程中手动修改了状态，Zeus 也不会覆盖该修改。

## 后台会话状态自动刷新

- 未选中的后台会话发生状态变化时，会话列表现在会自动更新，无需先点击该会话。
- 自动刷新覆盖响应中、等待批准、需要用户输入、完成、失败、暂停和排队等运行状态。
- 阻塞请求解决后，仍在执行的会话会恢复显示为响应中；会话列表会继续跟随实际运行状态变化。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.13-arm64.dmg`，退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 提交和推送入口需要任务存在可用的开发线；开发线上仍有活动会话或存在未解决冲突时，这些操作会被阻止。
- “推送代码”不会自动提交未提交或已暂存的改动，也不会在远端分支无法快进时强制覆盖远端。
- 当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在 Finder 中右键 Zeus 并选择“打开”。
