# Zeus 0.1.14 更新内容

## 代码交付改为同窗四步流程

- “代码交付”窗口现在依次提供查看代码、提交、可选推送和合入四个步骤，每一步独立执行，不会自动触发后续 Git 写操作。
- 任务分支推送不再是合入前置条件；代码已经提交且任务工作区干净时，可以直接合入目标分支。
- 合入时可以选择目标分支以及普通合并或压缩合并，并持续显示每一步的成功、失败或冲突状态。
- 任务详情中原有的独立“提交代码”和“推送代码”入口继续保留，并与代码交付窗口使用一致的状态反馈。

## 已提交成果与本机变化分开查看

- 默认展示任务分支相对来源分支的全部已提交成果。即使任务工作区已经干净或开发目录已回收，仍可查看文件列表和文本差异。
- “已提交成果”和“本机未提交”使用独立页签，不再把提交后的干净状态误解为没有代码变化。
- 本机仍有变化时，可以选择需要纳入提交的文件并填写提交说明；提交完成后，文件数量和差异内容会立即刷新。
- 切换不同任务分支时，选中状态、文件列表和差异会同步更新；重复选择当前分支也会给出明确反馈。

## 脏工作区下也能安全完成交付

- 目标分支所在的本地工作区存在未提交代码时，Zeus 会在隔离环境中完成合入并推送远端，不暂存、覆盖或改写本机现有文件。
- 远端目标分支校验成功后即记录为已交付；如果本地目标分支暂时无法安全同步，界面会明确显示“远端已交付，本地待同步”。
- 如果目标分支在合入过程中发生变化，Zeus 会安全停止，不会强制推送或覆盖新提交。
- 任务分支推送仍只同步当前提交，不会把尚未提交的本机变化带到远端。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.14-arm64.dmg`，退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 创建提交或执行合入前，需要先停止仍可能写入任务分支的活动会话，并解决任务工作区中的冲突。
- 合入要求任务分支的本机变化已经提交；任务分支是否已推送不影响合入。
- 目标分支的本地工作区有未提交代码时，远端交付后本地会保持原样并进入待同步状态；处理完本机变化后仍需自行同步目标分支。
- 二进制文件或仅文件属性发生变化时，可以看到文件级变化，但可能没有可显示的文本差异。
- 当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在 Finder 中右键 Zeus 并选择“打开”。

- 当前处于 Release notes 草稿生成阶段；候选提交中的根包和桌面包版本仍为 `0.1.13`，尚未执行 `0.1.14` 版本写入、发布提交、正式打包或公开发布。
