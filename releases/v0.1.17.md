# Zeus 0.1.17 更新内容

## 任务推送错误不再持续占据顶部

- 打开任务推送窗口时，如果能力加载失败，错误只会显示在当前推送窗口中，不再重复出现在工作区顶部。
- 任务发送失败时，错误原因和“重试发送”入口会保留在对应的失败会话中，不再被误报为 Zeus 的全局故障。
- 开始重试时会清除旧的局部错误；发送成功后将进入真实会话。
- 离开失败会话或切换页面后，任务推送错误不会继续停留在窗口顶部。其他本地操作的全局错误提示行为不受本次修改影响。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.17-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 任务发送失败后，错误和重试入口保留在对应会话中；离开该会话后不会继续收到跨页面提醒，需要返回失败会话查看或重试。
- 项目级 Git 状态、差异、快照和补丁页面暂不支持多仓或嵌套仓库；这些项目需要在任务的代码交付窗口中逐仓操作。
- 新建多仓任务环境会为所有已登记仓库创建 worktree，所需时间和磁盘空间可能随仓库数量增加。
- 共享可写目录会直接修改真实文件，不具备 Git worktree 的隔离与回滚能力。
- 提交或合入某个仓库前，需要先停止仍在写入该仓库工作区的活动会话，并处理已有冲突。
- 截至本草稿生成时，当前公开制品仍采用 ad-hoc 签名且未完成 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在 Finder 中右键 Zeus 并选择“打开”。
