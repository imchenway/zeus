# Zeus 0.1.19 更新内容

## 任务状态与优先级更易扫读

- 任务列表中的管理状态、运行状态和优先级改为低饱和轻底标签，并保留完整文字；颜色只用于辅助识别。
- 管理状态使用独立语义色：开发中为蓝色、测试中为紫色、待验收为琥珀色、已阻塞为红色、已完成为绿色，待开始和已取消保持中性色。
- 运行状态继续与管理状态分开显示：连接、重连和运行中为蓝色，等待用户、等待授权和暂停为琥珀色，失败为红色，空闲为绿色，未启动和旧会话只读保持中性色。
- 优先级按 P0 至 P4 依次使用红色、橙色、琥珀色、蓝色和中性色，便于快速识别处理顺序。
- 浅色与深色主题分别调整了标签颜色，避免状态提示在不同主题下过亮或过暗。

## 运行状态增加动态提示

- 连接、重连、运行中、等待用户和等待授权状态会显示与会话列表一致的旋转标记，帮助区分正在活动或等待处理的任务。
- 暂停、失败、空闲等状态保持静态，避免不必要的视觉干扰。
- 系统启用“减少动态效果”后，旋转标记会停止动画，状态文字和颜色仍然保留。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.19-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已经安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 新的语义色目前应用于任务列表中的管理状态、运行状态和优先级；任务详情和创建任务窗口暂未采用这套显示方式。
- 颜色不是唯一的状态提示。所有状态和优先级仍显示完整文字，启用“减少动态效果”也不会影响文字识别。
- 截至本草稿生成时，当前公开版本尚未经过 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在“系统设置 > 隐私与安全性”中选择“仍要打开”。
