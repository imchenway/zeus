## Zeus 0.1.2 更新内容

### 过程反馈与对话体验

- 新增动态“正在思考”状态；初始请求以及 Plan 模式回答问题后都会立即恢复可见反馈。
- Codex 可读推理摘要改为按完整句和摘要分段展示，并使用轻量淡入动效，不再模拟逐字打字。
- 工作活动运行中实时显示最新的读取、搜索、命令、文件和 MCP 进度；阶段结束后自动收为摘要，仍可展开查看完整历史。
- 补齐 reasoning summary、命令输出和 MCP progress 等 Codex app-server 事件，避免完成事件清空已收到的流式内容。
- 支持“减少动态效果”，关闭空间位移动效但保留明确运行状态。

### 统一底部交互坞

- Plan 提问、计划确认、命令、文件、权限和 MCP 等阻塞请求统一占用输入框位置，不再与 composer 同时出现。
- 一次只展示队首请求；提交后显示处理中，解决后恢复输入框或切换到下一项请求。
- 保留输入草稿、附件、模型和运行设置。
- 长审批内容只在交互坞内部滚动，修复卡片滑到对话顶部和底部大块留白问题。

### 检查更新

- macOS 应用菜单的 `Check for Updates...` 和快捷键 `Command+U` 现在会直接执行真实更新检查并打开结果弹窗。
- 弹窗覆盖检查中、已是最新、发现更新和检查失败状态。
- 只有同时完成 Developer ID 签名和 Apple 公证的版本才允许进入“下载并安装”路径。
- 当前未签名或未公证的版本只提供“打开下载页”，不会静默替换本机应用。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.1.2-arm64.dmg` 手动升级。

从 0.1.1 升级时，需要先通过 Homebrew 或 DMG 完成这次升级；新的应用内检查更新弹窗从 0.1.2 开始提供。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 当前发布包采用 ad-hoc 签名且未完成 Apple 公证。首次启动可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 当前发布包不启用静默自动安装。
