# Zeus 0.1.21 更新内容

## 任务类型与结构化内容

- 新建任务时必须选择“需求”“缺陷”或“优化”，不再使用同一段说明承载所有任务内容。
- 需求提供“需求描述”；缺陷提供“现状、预期、复现步骤”；优化提供“现状、预期”。标题和类型必填，其余内容可按需填写。
- 创建后可以修改任务类型。切换类型不会清除其他类型已经填写的内容，切回原类型时可以继续编辑。
- 任务列表新增默认可见且可排序的“类型”列；历史无类型任务会自动归为“需求”，原任务说明保持不变。
- 将任务推送到新会话时，只发送当前任务类型及其当前可见字段，不会发送其他类型下保存的隐藏内容。

## 会话归档与恢复

- 任务会话的“更多会话操作”中新增“归档会话”。归档后，会话会从普通列表移除，但消息、任务关联和工作目录信息仍会保留。
- 可以在“设置 → 缓存与数据 → 已归档会话”中查看归档内容，并将会话恢复到原项目和原任务。
- 归档与恢复会同步 Zeus 和对应的 Codex 会话状态；底层操作失败时不会只在 Zeus 中隐藏会话并显示虚假成功。
- 正在响应、排队、等待批准或等待用户输入的会话不能归档。归档不会改变任务状态、删除任务工作区或执行 Git 操作。

## 后台创建会话

- 从任务推送新会话后，弹窗会立即关闭，会话在后台创建；当前页面保持可操作，也不会提前插入尚未真实创建的临时会话。
- 同一任务创建期间会阻止重复提交，不同任务仍可分别创建会话。
- 如果用户一直停留在提交时的位置，创建成功后会自动打开真实会话一次；如果用户已经切换页面或会话，只更新列表和成功反馈，不再强行抢回页面。
- 创建失败不会留下无效会话，可从原任务入口查看错误并重试。

## 升级交接与启动

- 手动升级后，即使上一版本的执行宿主仍在处理任务，新版本主窗口和工作台也能正常打开，不再因跨版本数据字段差异进入整体错误页。
- 交接期间，已有执行、批准、回答和停止操作可以继续；为避免启动第二个数据写入者，新的执行入口会暂时不可用并显示说明。
- 上一版本宿主空闲并稳定释放后，Zeus 会切换到当前版本宿主，避免中断已有轮次或自动重跑任务。

## 如何升级

本候选尚未公开发布。正式发布并完成 Homebrew Tap 同步后，可手动运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.1.21-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。升级前请确认本机已安装并登录兼容的 Codex CLI。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；本机 Codex CLI 缺失、未登录或不支持所需能力时，相关 AI 执行不可用。
- 正在响应、排队或等待交互的会话必须先结束当前活动，才能归档。
- 旧版只读会话无法证明其底层线程能够同步归档，因此不提供归档操作。
- 会话归档依赖 Codex 服务可用；底层归档或恢复失败时，Zeus 不会退化为只修改本地显示状态。
- 升级交接期间可以继续处理已有工作，但在上一版本宿主安全退出前不能开始新的执行。
- 截至本草稿生成时，当前公开制品仍为 ad-hoc 签名且未经过 Apple 公证，只能通过 Homebrew 或 DMG 手动升级。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。
