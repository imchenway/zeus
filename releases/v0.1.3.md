# Zeus 0.1.3 更新内容

## 更聚焦的任务筛选

- 在任务页“全部”右侧新增“未完成”快捷按钮，并把它设为新项目或没有历史偏好项目的默认筛选。
- “未完成”会显示待开始、开发中、测试中、待验收和已阻塞任务，自动排除已完成与已取消任务。
- “全部、未完成、待开始、开发中、测试中”保持在同一组快捷按钮中，便于快速切换。

## 按项目记忆选择

- 用户显式切换筛选后，Zeus 会按项目保存最后一次选择。
- 切换项目或退出并重新启动 Zeus 后，每个项目都会恢复自己的筛选。
- 点击“清除筛选”或“查看全部状态”会选择并记住“全部”。
- 创建任务、从图谱创建任务或打开新对话不会再覆盖已经保存的项目筛选。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.1.3-arm64.dmg` 手动升级。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 当前发布包采用 ad-hoc 签名且未完成 Apple 公证。首次启动可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 当前发布包不启用静默自动安装；应用内检查更新会引导到 GitHub Release 下载页。
