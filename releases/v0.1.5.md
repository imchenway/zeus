# Zeus 0.1.5 更新内容

## 会话连接恢复

- 修复 Zeus 界面仍在运行、执行宿主却因界面租约过期而退出后，会话持续显示“正在重新连接”的问题。
- 界面租约失效后，Zeus 会先重新附着当前执行宿主；原宿主已经退出时，会发现或启动唯一新宿主并刷新 Local Server 连接地址。
- 租约心跳不再依赖业务服务健康状态，短暂的 Local Server 异常不会把仍然有效的界面租约错误判定为失联。
- 恢复过程不会自动重放状态未知的旧提交，也不会创建第二个数据库写入者。

## 历史消息显示

- 修复连接尚未恢复时，已有会话被错误显示为“发送第一条消息”的问题。
- 只有权威历史 snapshot 已成功加载且确实没有消息时，才展示空会话提示。
- 历史暂时无法读取时会明确提示“历史消息暂不可用；连接恢复后会自动显示”，恢复后继续展示原有消息。
- 本次升级不会迁移或改写既有会话、消息、执行轮次和 provider thread 身份。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.1.5-arm64.dmg` 手动升级。

从 `0.1.4` 升级仍属于用户确认后的手动安装。建议先确认重要操作已经保存；状态未知的旧提交不会在新版启动后被自动重放。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 当前发布包采用 ad-hoc 签名且未完成 Apple 公证，首次启动可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 因缺少 Developer ID 签名和 Apple 公证，本版本不启用应用内自动安装；应用内检查更新仍会引导到 GitHub Release 下载页。
- 已处于“需要恢复”的旧 submission 仍需要用户确认后处理，本版本不会根据重连结果擅自判断其是否应该再次执行。
- 本次修复保证历史读取失败不会被显示成空会话，不把数据库外的 provider 运行状态推断为已经成功或失败。
