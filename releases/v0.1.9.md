# Zeus 0.1.9 更新内容

## 代码交付不再受任务状态限制

- 只要任务存在开发分支，无论任务处于待开始、开发中、测试中、已完成还是其他管理状态，都可以打开代码交付。
- 任务管理状态继续只表示工作推进阶段，不再作为提交、推送、远端校验、worktree 回收或目标分支合入的权限门禁。
- 准备交付、合入目标分支和任务状态修改仍是彼此独立的显式操作，代码交付不会静默把任务标记为已完成。

## 完整的分支交付路径

- 待准备或上次操作失败的分支会显示“审查并准备交付”，进入完整变更审查后再提交、推送、校验远端并回收 worktree。
- 交付准备完成后会回到同一个代码交付窗口，继续选择目标分支和 Merge／Squash 方式。
- 已回收、已交付和已放弃的分支会展示真实生命周期状态；准备未完成时目标和合入方式保持禁用，避免点击一个必然失败的合入动作。
- 取消交付准备只返回代码交付窗口，不修改任务状态，也不会执行提交、推送、回收或合入。

## 分支名称与错误提示

- 任务分支选择器始终显示真实 Git 分支名和当前状态，不再把 `task_workspace_*` 内部关联标识暴露给用户。
- 主工作区变脏、目标分支变化、活动会话未停止或远端校验失败时，中文界面会给出对应的可操作说明。
- 服务端继续以真实 Git 状态执行最终安全门禁；界面流程变化不会绕过冲突、远端一致性或工作区清洁检查。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.1.9-arm64.dmg` 手动升级。

从 `0.1.8` 升级仍属于用户确认后的手动安装。建议先停止或保存重要操作；当前公开包没有启用 Apple 公证和应用内自动安装。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 当前发布包采用 ad-hoc 签名且未完成 Apple 公证，首次启动可能需要在 Finder 中右键 Zeus 并选择“打开”。
- 因缺少 Developer ID 签名和 Apple 公证，本版本不启用应用内自动安装；应用内检查更新仍会引导到 GitHub Release 下载页。
- 代码交付仍保留“准备交付”和“合入目标分支”两个显式步骤，不会在没有审查变更时自动提交或删除可写 worktree。
- 本次没有改变服务端的 Git 安全门禁；存在活动会话、未提交变更、冲突或远端不一致时仍会阻止相应写操作。
