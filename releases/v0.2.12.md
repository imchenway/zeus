# Zeus 0.2.12 更新内容

## 会话列表与阅读体验

- 会话列表改为按照排队、运行、待回复、完成等阶段的实际变化时间排序。打开或阅读会话，以及同步消息、Token 和配置，不再让会话意外置顶。
- 历史会话会根据已有阶段记录恢复排序时间；升级后列表可能发生一次符合新规则的重排。任务详情中的关联会话仍按创建时间顺序展示。
- 回答和过程说明改为按自然语言片段自适应显示；完整答案与历史答案直接呈现，文件路径、链接和行内代码不再逐字符缓慢增长。
- 修复部分历史 Pi／DeepSeek 会话发送消息后短暂消失并回填输入框的问题。Zeus 只会在本地记录提供充分证据时修正会话归属，正常 Codex 会话不会因模型名称被误判。

## 任务流程与 Git 操作

- 可分别为每个项目新增、改名、改色、排序和删除任务管理状态；全局设置中可维护新项目的默认状态模板，模板修改不会自动改变已有项目。
- 删除仍被任务或默认流程使用的状态时，需要选择替代状态；保存后，已有任务及原状态承接的流程行为会一并迁移，避免任务失去状态。
- 任务状态颜色会用于列表、详情和状态选择入口，同时保留文字标签，并适配浅色与深色主题。
- 任务代码提交说明会根据任务类型默认使用 `feat`、`fix` 或 `perf` 前缀，且仍可在提交前手工修改；代码交付产生的合入说明不受影响。
- 多仓任务中，单个仓库远端认证或网络失败不再清空全部工作区。远端不可用时仍可查看本地变更并创建本地提交，仅禁用依赖远端的拉取、推送和合入操作。
- 没有配置远端的纯本地仓库会使用本地命名分支，不再因缺少 remote 而阻止本地查看和提交。

## 命令运行耗时

- 命令执行历史和详情现在都会显示实际耗时，并将原有“超时”明确标注为“超时上限”。
- 实际耗时从命令真正启动时开始计算，不包含等待用户确认的时间；运行中逐秒更新，结束后固定，从未启动的记录显示“未启动”。

## Zeus 会话远程接管

- 设置页进一步明确手机端操作的是 Zeus 当前会话，底层连接仍由 Codex Remote Control 提供。
- 启用失败时会保留经脱敏处理的实际原因，并在同一设置区域提供安装、登录说明和“重新检测并重试”入口，不再只显示笼统的退出码。
- 远程接管启动失败后会恢复为未启用状态，避免后续普通 Codex 操作被导向失败的远程链路。

## 如何升级

0.2.12 正式公开并完成制品回验后，可通过 Homebrew 手动升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以在正式公开后下载版本化安装包 `Zeus-0.2.12-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 均为手动升级方式，本版本不声明应用内自动安装可用。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；使用 Codex 模型及会话远程接管仍依赖本机安装、完成登录且兼容的 Codex CLI。
- Zeus 不会自动安装、替换或切换外部 Codex CLI。显式配置的 CLI 路径仍具有优先级，修复外部安装或登录问题后需要手动重新检测并重试。
- 历史 Pi 会话修复采用严格证据条件。证据不足的异常记录会保持不变，以避免误改真实 Codex 会话。
- 远端不可用时只能继续本地查看与提交；恢复拉取、推送及依赖最新远端的合入仍需先解决网络或仓库凭据问题。

## 发布验证

- 草稿通过后，将把根包和桌面包版本从 0.2.11 写入 0.2.12，并将已审阅的 Release notes 写入候选提交。
- 同一干净候选提交将执行冲突残留、空白与格式、ESLint、TypeScript、生产构建、验收矩阵和 AI CLI 适配检查，并生成正式 macOS 应用、`Zeus-0.2.12-arm64.dmg`、发布清单及 Homebrew Cask。
- 公开前将使用隔离数据和桌面交互回验会话阶段排序、历史会话迁移、流式内容分块、结构化片段显示、减少动态效果，以及历史 Pi 会话与正常 Codex 会话的身份隔离。
- 还将回验任务状态的新增、改名、改色、排序和删除迁移，默认提交说明生成，多仓远端失败时的本地提交能力，以及运行中、已结束和未启动命令的耗时展示。
- 会话远程接管将核对失败原因展示、失败状态回滚和重新检测入口；正式制品不会仅凭设置页可见或刷新成功宣称手机配对与远端回答回流可用。
- 正式候选制品将核对应用身份、包体健康、DMG 完整性，以及发布清单中的版本、架构、文件大小、SHA-256、签名和公证状态。
- 只有本地发布门禁和候选提交的主分支 CI 通过后，才会创建不可变标签 `v0.2.12`、触发 Release Workflow、生成 GitHub Release 并同步 Homebrew Tap。
- 公开流程完成后，还将重新下载 `Zeus-0.2.12-arm64.dmg` 和发布清单，复验 DMG，并对账 GitHub Release 正文与资产、发布清单以及 Homebrew Cask 的版本、架构和摘要。
