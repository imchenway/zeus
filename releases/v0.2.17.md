# Zeus 0.2.17 更新内容

## 修复提交前代码格式检查

在提交代码前，Zeus 会自动调用 Prettier 对选中的文件进行格式化和检查。此前，当 Zeus 从 Finder 启动时，可能因为系统 PATH 中没有包含 Node 命令而无法正常调用 Prettier，导致提交报错。本次更新修复了这一问题：现在 Zeus 会使用自身内置的 Node 运行时直接启动项目本地的 Prettier，不再依赖外部 `node` 命令。这样，无论您是否从终端启动 Zeus，代码提交前的格式检查和自动修复都能正常工作。

## 如何升级

- **Homebrew**：执行以下命令升级：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- **手动升级**：从 GitHub Releases 下载 `Zeus-0.2.17-arm64.dmg`，打开并拖拽 Zeus 到 Applications 文件夹完成替换。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本（Apple Silicon）。
- 当前版本仍为 ad-hoc 签名，未进行 Apple 公证，因此首次打开时可能需要右键“打开”以绕过 Gatekeeper。
- 本版本为手动升级，应用内自动安装更新功能尚不可用。

## 发布验证

在正式发布之前，需要完成以下门禁和回验：

- 候选提交的 lint、TypeScript 类型检查、单元测试和构建必须全部通过。
- 需要生成并验证正式 DMG 包（`Zeus-0.2.17-arm64.dmg`）和更新清单（manifest），并核对它们的 SHA-256 校验和。
- 需要将新的不可变标签 `v0.2.17` 指向正式发布提交，并将 GitHub Release 设置为公开状态，确保 Homebrew Tap 的 Cask 与 release 资产一致。

这些步骤将在草稿通过后由发布流程自动执行。
