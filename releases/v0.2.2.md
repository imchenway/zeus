# Zeus 0.2.2 更新内容

## 配置 OpenAI 兼容模型

- 系统设置新增“模型供应商”，可创建多个连接并配置连接名称、服务地址、模型目录路径、API Key 和模型列表。
- 提供 DeepSeek、阿里云百炼快捷模板，也支持自行填写其他 OpenAI Chat Completions 兼容服务。
- API Key 只保存在本机 macOS 钥匙串中，不会在普通设置或接口响应中返回明文。
- 可以从供应商目录获取模型，也可以手工添加模型 ID，并为各模型维护显示名称、速度标签、推理等级、工具调用和图片输入能力状态。
- 新增连接诊断，可区分配置、凭据和模型目录访问问题。

## 按项目管理可用模型

- 每个项目可以从全局连接中选择多个 Pi 模型，并设置默认预选模型。
- 默认模型只决定任务推送和后续轮次的初始选择，不会限制改选项目已授权的其他模型。
- 项目设置会显示模型所属连接、速度标签、可运行状态及不可用原因。
- 未配置 API Key、连接或模型已停用、或者明确不支持工具调用的模型不会被正式派发。

## 在任务与会话中选择模型

- “推送到新会话”现在可以选择 Codex 模型或当前项目已授权的 Pi 模型，并显示模型来源和速度标签。
- 同一 Pi 会话可为后续轮次改选项目允许的模型；切换后会重新应用该模型对应的推理等级和能力设置。
- Pi 的文件读取、搜索、编辑和命令请求继续通过 Zeus 的权限模式与审批链路，不会绕过现有安全控制。
- Pi 运行能力已包含在 Zeus 中，不要求另外安装 Pi CLI。

## 如何升级

0.2.2 完成公开发布与制品核对后，可通过 Homebrew 手动升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从对应的 GitHub Release 下载版本化安装包 `Zeus-0.2.2-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 都是手动升级方式，本版本不声明应用内自动安装可用。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Codex 执行仍要求本机安装、登录并保持兼容的 Codex CLI；Zeus 不会随应用安装 Codex CLI。
- Pi 首版仅接入 OpenAI Chat Completions 兼容协议，不包含各供应商的 Responses、Anthropic 兼容接口、托管工具或其他专有能力。
- 本次候选未使用 DeepSeek、阿里云百炼等供应商的真实 API Key 完成外部端到端验收。连接诊断成功只表示模型目录可以访问，不代表流式输出、工具调用、思考内容、图片输入或用量统计均已兼容。
- 用户手工填写的模型能力在真实运行探针前仍属于声明信息；不同供应商和模型的实际兼容程度可能不同。
- Codex 与 Pi 是不同的 Agent，会话中不能直接互相切换；需要选择另一 Agent 时应新建会话。
- Pi 模型名称中的 Fast、Flash、Turbo 或 High-Speed 只作为模型速度标签，不等同于 Codex Fast 服务档位；Pi 首版不提供 Fast 服务档位开关。
- 当前公开稳定制品为 ad-hoc 签名且未经过 Apple 公证；0.2.2 的实际签名和公证状态将由正式发布清单记录。若正式制品仍未公证，首次打开时可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 发布验证

- 本草稿通过后，发布编排器将把根包和桌面包版本写为 `0.2.2`，写入已审阅的 Release notes，并形成固定且干净的发布候选提交。
- 公开前将执行版本与正文一致性检查、冲突和空白检查、格式检查、lint、类型检查、生产构建、验收矩阵、AI CLI 适配探针及正式 macOS 打包。
- 发布门禁还将检查应用包结构与可执行文件、严格 codesign、DMG 完整性，以及发布清单、DMG 摘要和 Homebrew Cask 的版本与架构一致性；签名和公证状态以生成的正式清单为准。
- 本地门禁通过后，编排器才会推送 `main` 并等待对应 CI 成功，然后创建不可变的 `v0.2.2` 标签、GitHub Release，并同步 Homebrew Tap。
- 公开后还将重新下载 DMG 和发布清单，复核文件大小、SHA-256、`hdiutil verify`、Release 资产元数据、Release notes 与 Homebrew Cask；这些步骤完成前不视为发布结束。
