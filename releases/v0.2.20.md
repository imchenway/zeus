# Zeus 0.2.20 更新内容

- **修复：发送消息后任务标题等信息丢失的问题**。在 Codex 原生会话中，发送任务后，任务标题、任务类型和优化目标等关键信息有时会意外消失。此版本已修复该问题，确保这些信息在消息发送后可靠保留。
- **优化：会话消息正文的稳定性**。改进了用户消息的正文选择逻辑，优先保留本地已提交的完整内容，避免因异步事件回放导致内容被覆盖或显示为空。
- **改善：会话快照恢复的准确性**。当重新打开或切换会话时，历史消息能够更准确地恢复，尤其是包含任务结构化信息的消息。

## 如何升级

**Homebrew 用户**：

```bash
brew upgrade --cask imchenway/tap/zeus
```

**手动升级**：

从 Zeus 发布页面下载最新版本的文件 `Zeus-0.2.20-arm64.dmg`，打开并拖拽 Zeus 到“应用程序”文件夹，覆盖旧版本。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- 当前公开发布的 DMG 未签名，需要手动升级；应用内自动更新暂不可用。
- 已知限制：本版本尚未经过真实 app-server 交互验证，某些与 Codex 提供方深度相关的场景可能需要进一步观察。
