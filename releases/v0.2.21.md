# Zeus 0.2.21 更新内容

## 主要变化

### 恢复用户消息正文显示

修复了 Codex 原生会话中用户消息正文不可见的问题。此前，发送后的用户消息（例如任务标题、任务类型、现状和预期）在会话气泡中只显示附件和时间，文字内容完全消失。现在，用户消息正文会重新以静态 Markdown 形式渲染，长消息的折叠、展开、复制和编辑功能保持不变，助手消息和思考过程仍沿用原有的流式渲染。

### 稳定性与细节优化

本次更新还包含了相关的稳定性修复，确保会话消息在切换或重新打开会话后仍能正确显示完整正文，不改变任务提示词的发送内容和结构化附件。

## 如何升级

### 通过 Homebrew 升级

如果你是通过 Homebrew 安装的 Zeus，可以运行以下命令升级到 0.2.21：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

你也可以从版本化 DMG 进行手动升级：

1. 下载 `Zeus-0.2.21-arm64.dmg`。
2. 打开 DMG 文件，将 Zeus 拖入“应用程序”文件夹。
3. 如果旧版本正在运行，请先退出，然后启动新版本。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前发布制品为手动升级包，暂不支持应用内自动安装。
- 已知限制：如果用户消息中仅包含附件而没有文字，则不会显示正文；这是预期行为，并非回归。

## 发布验证

本次发布前需要完成以下门禁与回验：

- 执行 lint、typecheck 和构建，确保代码质量与可编译性。
- 进行打包和签名校验，确保 DMG 制品完整可用。
- 由编排器执行版本写入（更新 package.json 中的版本号），生成正式制品并公开发布。
- 发布后需验证 Homebrew Tap 同步成功，并抽检升级流程。

这些步骤将在草稿通过后自动执行，当前尚未完成，请勿提前发布或声称已发布。
