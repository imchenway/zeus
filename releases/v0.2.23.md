# Zeus 0.2.23 更新内容

## 对话中断后可继续对话

修复了停止当前会话后再次发送消息，消息短暂显示后回到输入框，会话无法继续的问题。现在，中断后若没有未发送的消息，会话会恢复为可继续对话状态，您可以在同一会话中直接发送新消息。若中断前已有未发送的排队消息，这些消息会保留为暂停状态，您仍然可以显式恢复发送。

## 合并冲突时 AI 处理更稳定

修复了代码合并冲突后点击“AI 处理”立即提示“任务模型当前没有可用执行位”并生成空白会话的问题。现在，“AI 处理”会直接创建模型会话并立即发送消息，不再受普通会话并发队列限制。若消息确实未能发出，界面会明确提示“会话已创建但消息未发送”，并提醒您不要重复点击。

## 如何升级

### 通过 Homebrew 升级

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

从发布页面下载 `Zeus-0.2.23-arm64.dmg`，打开后将 Zeus 图标拖入“应用程序”文件夹，然后启动新版本。

## 系统要求与已知限制

- 本版本要求 macOS 13.0 或更高版本。
- 当前公开制品为手动升级方式，应用内自动安装尚不可用。
- 若您曾因“AI 处理”报错创建了空白会话，这些历史会话不会被自动清理，您可手动删除。
