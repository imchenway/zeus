# Zeus 0.2.26 更新内容

## 远程接管状态更清晰

- 现在，设置页面会单独显示“Remote Control 独立版”的状态，不再因为系统里存在普通 Codex CLI 就误以为远程接管可以立即启用。
- 如果 Zeus 独立 Codex 目录中缺少官方独立安装版，启用和配对按钮会禁用，并展示对应的安装命令，你可以复制后在终端执行。

## 更准确的恢复指引

- 当远程接管启动失败时，错误提示会针对 Zeus 的独立目录给出对应的官方安装命令，而不是笼统地给出默认安装命令。
- 失败恢复的提示文案更具体，涉及登录、网络或授权问题时会明确说明，Zeus 不会自动安装或使用内置回退。

## 如何升级

- 如果你通过 Homebrew 安装，可在终端运行：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载版本化 DMG 文件 `Zeus-0.2.26-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹，替换旧版本。

## 系统要求与已知限制

- 要求 macOS 13.0 或更高版本。
- Remote Control 独立版安装后，需要在 Zeus 内完成 Codex 登录，并点击刷新才能使用远程接管。
- 若已安装普通 Codex CLI，仍需为 Zeus 单独安装独立版，占用额外空间。
- 当前公开制品为手动签名，未公证，请使用上述方式手动升级。
