# Zeus 0.2.32 更新内容

## 修复会话请求显示逻辑

- 统一了服务端与桌面客户端对用户询问请求的解析规则，避免同一份请求被服务端正常接收、却因客户端校验过于严格而被隐藏。
- 修复了部分情况下，模型发出的提问（如产品决策询问）卡在“准备问题”状态、无法在会话中显示的问题。
- 升级后，已落库但未显示的问题无需重发即可正常呈现。

## 改进问题展示与交互

- 问题卡片现在支持完整展示问题描述与选项，并保留“其他回答”的自定义输入入口。
- 修正在特定元数据（如 `isBlocking` 标记）存在时，问题可能被错误过滤的缺陷。

## 如何升级

### Homebrew

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动下载

从发布页面下载 `Zeus-0.2.32-arm64.dmg`，打开后按提示拖入“应用程序”文件夹完成升级。

## 系统要求与已知限制

- 支持 macOS 13.0 或更高版本（Apple 芯片）。
- 本次更新包含未签名的测试制品，正式升级请使用上述官方渠道；自动更新安装暂不可用，请手动升级。

## 发布验证

- 已完成代码格式、静态检查、类型检查及生产构建。
- 已在浏览器 QA 页面验证带真实元数据的请求能正确显示并响应“其他回答”。
- 后续将进行桌面应用打包、签名、公证及正式发布，并在测试账号中补验完整问题事件。
