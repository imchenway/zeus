# Zeus 0.2.34 更新内容

## 会话与任务体验优化

- **任务首发即时进入会话**：提交任务后，立即进入可操作的会话工作面，无需等待后台创建完成。真实会话建立后原位接管，不再跳转或重置页面；创建期间仍可输入、添加附件或排队消息。
- **会话状态实时同步**：会话列表、任务表、会话抽屉和标题区的运行状态现在自动保持同步，后台会话进入响应、等待、完成、失败等状态时会即时更新。网络中断或本机服务重启后会自动重连并校准状态，期间保留最后已知状态并显示“正在同步会话状态”提示。
- **消息时间线更稳定**：已回答的询问记录按答案提交时间正确进入会话时间线，历史消息不再因内容更新而错位；正在执行的轮次中，过程说明和用户中途引导会完整展示，最终回答到达后自动收口。
- **发送中的图片立即显示**：发送图片后立即在会话中显示本地预览，不再依赖服务端回放；支持任务推送消息中的占位图片。
- **历史消息操作栏**：鼠标移入或键盘聚焦消息时显示操作按钮，不再常驻，界面更简洁。

## 任务管理与代码交付

- **任务列拖动更稳定**：拖动任务列时不再实时重排整列，而是显示目标插入线，松手后整列一次到位；避免拖动过程中的视觉抖动。
- **下拉框宽度自适应**：下拉浮层打开时立即达到最终宽度，不再先窄后宽，且不会撑开父级布局。
- **代码交付流程简化**：提交和推送不再要求停止活动会话；活动会话仅作为信息提示，只在可能回收 worktree 的合入操作时提醒风险。代码审查会话作为独立入口，只审查当前仓库的完整变化，不自动跨仓库。
- **环境信息卡片新增命令入口**：可直接从环境卡片进入当前项目的完整命令中心。

## 更新与升级体验

- **更新进度显示百分比**：通过 Homebrew 更新时，系统通知直接显示下载百分比，不再显示“已下载 MB / 总 MB”，更直观。

## 其他改进

- 会话中的过程说明、命令摘要等字号略有增大，阅读更舒适。
- 修复了部分场景下图片显示延迟的问题。

## 如何升级

- **通过 Homebrew 升级**：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- **手动升级**：从发布页面下载 `Zeus-0.2.34-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹，并替换旧版本。

## 系统要求与已知限制

- **系统要求**：macOS 13.0 或更高版本。
- **当前限制**：
  - 当前公开制品为 ad-hoc 签名，未公证，因此**不支持应用内自动更新**，请使用上述手动方式升级。
  - 代码审查仅覆盖当前会话对应的仓库，不会自动扩展到同一环境的其他仓库；审查时权限模式继承当前会话，但固定为只读、不修改文件。

## 发布验证

在正式公开发布前，需完成以下验证与门禁：

1. **代码质量门禁**：运行 lint、typecheck、单元测试与构建，确保无回归。
2. **桌面应用验证**：在 macOS 13.0 及以上系统验证安装、启动、会话创建、任务推送、代码审查、更新进度显示等关键流程。
3. **产物签名与公证**：对 DMG 进行签名与公证，并验证 Gatekeeper 通过。
4. **版本写入**：将版本号写入 package.json 和 electron-builder 配置，更新 Homebrew cask。
5. **公开发布**：发布 GitHub Release，同步 Homebrew tap，验证 `brew upgrade --cask imchenway/tap/zeus` 可正常升级。

以上流程将在本草稿通过后由编排器执行，当前尚未完成。
