# Zeus 0.2.37 更新内容

## 主要更新

- **更流畅的跨设备会话体验**：修复通过 ChatGPT iOS 远程回复的消息在 Zeus 中不可见的问题，现在远程输入和回复能正确同步到会话中，切换设备时无需手动刷新即可继续对话。
- **交互改进**：
  - 答案选项框支持粘贴和拖放附件，自由输入回答时也可附加文件。
  - 未登录状态优化，登录完成后自动回到原窗口并继续之前的操作。
  - 退出时提供“停止活动工作并退出”选项，更明确地处理正在运行的任务。
  - 状态栏样式优化，更新进度显示更清晰。
- **代码交付优化**：代码审查生成的会话点击不再卡死；代码交付页面优化，分支名称完整显示并可复制。
- **推送任务优化**：任务首次推送更快进入会话，推送时可粘贴附件到补充信息，推送提示词优化，减少无用信息。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc 签名，未公证，因此只能手动升级，不支持应用内自动安装。
- 远程消息同步依赖已授权设备，具体设备信息可能无法精确显示。

## 如何升级

### Homebrew

执行以下命令升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动下载

访问版本发布页下载 `Zeus-0.2.37-arm64.dmg`，双击打开并拖拽 Zeus 到“应用程序”文件夹完成升级。

## 发布验证

本版本尚处于发布流程中，以下步骤将在草稿通过后执行：

1. 运行 `pnpm lint`、`pnpm typecheck` 和 `pnpm build` 确认代码质量与构建通过。
2. 构建并签名 macOS 应用，生成公证后的 DMG 文件。
3. 在干净环境安装 DMG，手动验证关键功能。
4. 更新 Homebrew Cask 并推送发布说明到 GitHub Releases。
5. 确认用户可通过 Homebrew 或 DMG 正常升级。
