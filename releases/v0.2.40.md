# Zeus 0.2.40 更新内容

## 任务首发内容预览与创建流程改进

- 任务首发内容预览不再使用独立滚动条，长任务内容会完整展开，并随弹窗正文统一滚动，避免两层滚动造成的阅读中断。
- 预览中任务标题与字段名称的层级更加清晰：任务标题作为主标题，字段名称以次级标签样式缩进显示，并在名称末尾补充全角冒号，使字段归属更易扫读；该格式同时应用于推送预览和已发送消息。
- 超长任务标题、正文和会话路径支持软换行，不再通过省略隐藏首发内容。
- 创建新会话的流程更加稳健：仅当首发内容预览和准备工作面全部构造成功后，才进入“正在创建”状态；若准备阶段发生异常，会保留表单配置、显示具体错误，并恢复关闭、取消等操作，避免弹窗永久卡死。

## 思考过程轮次耗时入口位置调整

- 模型思考和执行过程中，“已处理……”轮次耗时入口移至过程内容底部，使思考摘要、命令和工具活动自然位于上方。
- 模型回复完成后，入口仍位于最终回复正文上方；展开历史过程时，过程内容从入口下方展开，阅读顺序与操作预期一致。
- 该规则同时应用于普通会话页和任务会话抽屉。

## 用户中途引导消息对齐修复

- 修复了模型回复期间发送的引导消息在过程区显示在左侧的问题。现在这些“用户中途引导”无论出现在会话外层还是当前轮次过程区，都始终保持用户消息的右对齐视觉语义，同时保留其真实时间顺序和折叠行为。

## 如何升级

- 使用 Homebrew 升级：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载并安装版本化 DMG 文件 `Zeus-0.2.40-arm64.dmg`。

当前公开制品仍为手动升级方式；应用内自动安装暂不可用。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 任务首发内容预览和思考过程布局的视觉调整仅在桌面应用中生效；内置浏览器不具备完整桌面会话状态，可能无法用于验收这些界面。
- 创建新会话的异常恢复逻辑已实现，但真实运行中的失败场景仍需在桌面环境验证。
