# Zeus 0.2.41 更新内容

## 会话输入区焕然一新

- 输入框重新设计：整体更紧凑，减少固定空白和过重的阴影，让输入本身成为焦点。
- 常用操作分组更清晰：左侧集中放置附件、权限模式和计划模式；右侧集中放置上下文占用、服务档位、模型选择和推理强度，方便快速定位和调整。
- 模型名称现在完整显示，不再截断，窄窗口下会自动换行保证信息完整可读。
- 权限模式、计划模式、服务档位等改用了更直观的状态图标，悬停或聚焦时显示完整说明，减少界面杂乱。

## 新增上下文占用指示器

- 在输入区新增了上下文占用圆环，直观显示当前会话已使用的上下文比例。
- 当占用达到 75% 时圆环变为警示色，达到 90% 时变为红色，帮助您及时了解上下文余量。
- 悬停或聚焦圆环会显示占用百分比、已用/容量和剩余 Token 数。

## 改进的会话与通知行为

- 修复了后台会话消息被误判为已读的问题，现在只有 Zeus 处于前台且窗口聚焦时才会标记已读。
- 系统通知的触发条件更加准确，当 Zeus 处于前台时不再弹出重复通知。

## 如何升级

- 如果通过 Homebrew 安装，请运行：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 也可以从发布页面下载版本化 DMG 手动升级：

  - 文件名：`Zeus-0.2.41-arm64.dmg`
  - 下载后打开 DMG，将 Zeus 拖入 Applications 文件夹即可完成升级。

## 系统要求与已知限制

- 本版本要求 macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc 签名，未公证，因此只能通过上述手动方式升级，应用内自动安装可能不可用。
- 部分新功能（如上下文占用指示器）需要运行一轮对话后才能显示实际占用数值，新建会话中显示为空环。
