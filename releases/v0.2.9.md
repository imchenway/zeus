# Zeus 0.2.9 更新内容

## 任务详情支持直接粘贴附件

- 在任务标题、需求描述、缺陷现状与预期、复现步骤、优化现状与预期以及标签编辑框中，可以直接粘贴图片、文件和文件夹。
- 普通短文本仍会插入当前光标位置；达到 5000 个字符的长文本会自动转为文本附件。
- 支持从 Finder 和 Paste.app 粘贴资源。附件关联期间会保留当前文字草稿、焦点和选区，随后保存文字时不会因附件更新产生冲突。
- 资源读取或保存失败时，文字草稿不会丢失，并会显示错误和重试入口。

## 下拉菜单自动避开窗口底边

- 任务列表底部的状态菜单不再固定向下展开：下方空间不足时会改为向上完整展开。
- 这一行为同时适用于任务详情、设置和弹窗中的同类下拉菜单；下方空间充足时仍保持向下展开。

## Codex 询问可以在后台切换后继续回答

- Codex 等待用户回答期间，即使后台会话服务已经切换，仍可在原会话中提交选项或自定义文字，无需放弃会话或重新描述上下文。
- 符合该情形、此前因后台切换而失败的最近一次询问也可以恢复显示并继续回答。
- 续接会在同一 Codex 会话中开启新的轮次；涉及操作审批时，不会沿用切换前的旧批准，Codex 需要重新发起明确审批。

## Pi 会话显示完整最终回答

- 通过 Pi 使用 DeepSeek 等模型时，工具调用前的阶段说明会在执行期间保留；最终回答到达后，会替换阶段说明，不再让会话停留在第一句话。
- 对本地已经保存完整最终正文的受影响 Pi 历史会话，Zeus 会恢复完整的最终回答显示。

## 如何升级

0.2.9 正式公开并完成制品回验后，可通过 Homebrew 手动升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以在正式公开后下载版本化安装包 `Zeus-0.2.9-arm64.dmg`。退出正在运行的 Zeus 后打开 DMG，并用新版本覆盖旧版本。

Homebrew 和版本化 DMG 均为手动升级方式，本版本不声明应用内自动安装可用。

## 系统要求与已知限制

- 支持 Apple Silicon Mac，要求 macOS 13 或更高版本。
- Zeus 不附带 Codex；使用 Codex 模型仍依赖本机安装且兼容的 Codex CLI。
- 在极矮的窗口中，下拉菜单即使改为向上展开，顶部仍可能被窗口边缘裁切。
- Pi 的阶段说明不会作为独立消息永久保留；最终回答到达后会覆盖它。历史会话只有在本地已经保存完整最终正文时才能恢复完整显示。
- 从旧数据目录升级且首次迁移未成功的用户，仍可能看到空白项目列表。若历史数据位于 `~/Library/Application Support/@zeus/desktop`、当前 `~/.zeus` 为空，请先退出 Zeus并备份两个目录；完整恢复需要同时保留附件、会话文件和命令脚本，不能只替换数据库文件。
- 截至本候选草稿生成阶段，当前公开稳定制品 0.2.8 仍为 ad-hoc 签名且未经过 Apple 公证，因此只采用手动升级口径。0.2.9 的签名与公证状态将在正式制品生成后按实际清单核对，完成前不作 Apple 认证分发声明。

## 发布验证

- 草稿通过后，将把根包和桌面包版本从 0.2.8 写入 0.2.9，并以同一干净候选提交执行完整发布门禁。
- 门禁将检查冲突残留、空白与格式、ESLint、TypeScript、生产构建、验收矩阵和 AI CLI 适配，并生成正式 macOS 应用、版本化 DMG、发布清单及 Homebrew Cask。
- 公开前将使用隔离测试应用回验任务详情资源粘贴、下拉菜单上下展开、Codex 询问恢复和 Pi 最终回答覆盖；同时核对应用身份、包体健康、DMG 完整性，以及清单中的版本、架构、文件大小、SHA-256、签名和公证状态。
- 只有候选门禁和主分支 CI 通过后，才会创建不可变标签 `v0.2.9`、触发 Release Workflow、生成 GitHub Release 并同步 Homebrew Tap。
- 公开流程完成后，还将重新下载 `Zeus-0.2.9-arm64.dmg` 和发布清单，复验 DMG，并对账 GitHub Release 正文与资产、清单以及 Homebrew Cask 的版本、架构和摘要。
