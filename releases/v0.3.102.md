# Zeus 0.3.102 更新内容

## Computer Use 体验改进

- 修复在 worktree 模式下，新用户推送任务后无法查看分支的问题。
- 改进 Computer Use 的目标窗口管理与输入控制，现在可以更可靠地操作特定应用窗口，并在用户介入时自动暂停，避免冲突。
- 在会话中新增屏幕控制预览，便于观察 AI 操作目标应用的过程。
- 优化通知：系统通知将区分思考过程与最终结果，减少无关通知干扰。

## 浏览器与扩展更新

- 浏览器扩展弹窗与权限提示改为跟随 Zeus 应用的语言设置。
- 明确区分"允许当前站点"与"允许高级访问"，并说明高级访问包含的权限范围，增强透明度。
- 修复浏览器自动化桥断开后可能造成操作结果不明的情况，避免自动重放动作。

## 新用户引导与稳定性

- 修复新用户未登录 Codex 订阅时的入口问题，优化模型接入引导。
- 修复从对话框选择 Skill 时可能出现的错误。
- 改进插件安装失败的错误提示，并提供安全重试机制。
- 重构了全项目的用户提示语，使错误信息更易懂且不泄露敏感细节。

## 界面与本地化改进

- 应用菜单、文件选择对话框、安全登录窗口等系统界面现可跟随应用语言（简体中文或英文）。
- 应用重启前的确认提示会更清晰地说明正在运行的工作，避免误操作。

## 如何升级

- **通过 Homebrew 升级（推荐）**：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- **手动下载升级**：访问 Zeus 发布页面，下载 `Zeus-0.3.102-arm64.dmg`，挂载后拖拽 Zeus 到“应用程序”文件夹覆盖旧版本。

> 注意：当前版本为手动升级模式，应用内自动更新尚不可用。升级前请确保退出 Zeus 并保存正在进行的工作。

## 系统要求与已知限制

- macOS 13.0 或更高版本（Apple Silicon）。
- 使用 Computer Use 需要授予“辅助功能”和“屏幕录制”权限。
- 外部浏览器控制需要安装并授权对应浏览器扩展。
- 若使用远程控制（Codex）需登录 Codex 订阅。

## 发布验证

公开 Release 只有在以下检查全部通过后才会创建：
- 代码通过架构治理校验（`verify-architecture-governance`）。
- TypeScript 类型检查与 lint 通过。
- 前端与原生辅助程序构建成功。
- 桌面应用打包成功，且通过基础启动与核心流程冒烟测试。
- 更新包（DMG）的完整性校验通过。

任何检查失败都会阻止创建公开 Release，以保证交付质量。
