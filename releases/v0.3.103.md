# Zeus 0.3.103 更新内容

## 新用户引导与任务创建优化

- 首次进入工作区时，会看到一个清晰的三步引导：选择文件夹、创建任务、确认并推送。引导会提示模型可以在稍后接入，项目与任务都保存在本机，让新用户能更快上手。
- 创建任务弹窗经过精简，移除了不必要的字段和层级，并把禅道链接、优先级、父任务、标签等移到“更多选项”区域，界面更清爽，减少初次使用的干扰。
- 创建项目后会自动打开任务创建对话框，方便立即开始描述任务。

## 任务推送与模型接入更流畅

- 从任务发起推送时，会先检查模型接入状态。如果还没有可用模型，会直接引导你完成接入，而不必先去设置页。
- 在推送确认页也可以直接打开模型接入，完成后会返回当前确认页，不会丢失已经填写的内容，也不会在接入完成前自动创建会话或开始执行。
- 接入模型后可以只针对当前项目启用，不会影响其他项目或全局设置。
- 修复了推送任务时可能误判文档目录、图片预览不显示或显示错误的问题，现在推送预览中的图片能稳定显示，且不会重复加载。
- 改进确认页的布局，加入更明确的提示，让用户清楚知道下一步会发生什么。

## 会话稳定性与状态展示修复

- 修复了会话恢复时出现的误报错误，现在会话结构和最新消息会在服务端一次性同步读取，避免在恢复过程中出现短暂的不一致或报错。
- 修复了进行中的会话突然报错的问题，尤其是消息发送后在应用重启或断线情况下，系统会明确提示消息状态需要确认，不再自动重发，避免重复或丢失。
- 修复了会话发送卡死的情况，优化了发送队列的恢复逻辑，现在重试时会更准确地检查状态。
- 修复了图片在会话中不可见的问题，现在图片预览的链接和加载更可靠。
- 改进了会话活动区域的展示，减少重复和冗余的状态信息，比如“正在整理上下文”的表述更清楚，避免上下文中相似内容重复展示。
- 调整了思考摘要的显示：当模型思考没有实际可读内容时，不会再显示通用标题或多余的省略号，让界面更干净。

## Computer Use 与内置浏览器设置改进

- 在发送消息前，现在需要输入 / 并选择 Computer Use，才能允许 AI 在那一轮操作其他应用，授权更明确，降低误操作风险。
- 修复了 Computer Use 桥接可能重复触发动作的问题，现在即使出现连接中断，也不会自动重放之前的点击或输入，而是提示用户手动确认。
- 内置浏览器设置中的开关（如启用浏览器、下载前询问等）现在修改后立即生效，其他输入仍通过“保存浏览器设置”统一保存，并会有清晰的保存反馈。

## 如何升级

### Homebrew

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

从发布页面下载并安装 Zeus-0.3.103-arm64.dmg，然后将其拖入“应用程序”文件夹。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品为手动升级包，应用内自动更新尚不可用。
- 使用内置浏览器控制其他应用前，需在系统设置中授予 Zeus 辅助功能与录屏权限，并在每条消息前明确选择 Computer Use。
- 归档会话时，如果正在运行或排队，可能无法立即归档，具体状态以服务端判断为准。
- 使用 DeepSeek 模型时，思考摘要的展示可能因模型返回内容不同而有所变化。
