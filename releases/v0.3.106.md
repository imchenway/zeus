# Zeus 0.3.106 更新内容

## Computer Use 控制范围调整

本次更新调整了 Computer Use 功能的可控制应用范围：

- 开启 Computer Use 后，现在可以控制另一个独立的 Zeus Test 实例进行验收测试，无需再启用额外的 QA 模式。
- 正式 Zeus 实例、当前宿主以及控制服务本身仍禁止被控制，以保护自身审批流程。
- 如果同时运行多个 Test 实例，可以使用应用的绝对路径来指定要控制的目标。

这一调整简化了测试场景下的操作，同时保持了对正式实例的严格控制。

## 如何升级

- **Homebrew**：运行以下命令升级：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- **DMG 手动升级**：下载最新版本 DMG（例如 `Zeus-0.3.106-arm64.dmg`），打开后将 Zeus 拖入“应用程序”文件夹替换旧版本。

## 系统要求与已知限制

- 本版本要求 macOS 13.0 或更高版本。
- 当前发布的制品为手动升级渠道，应用内自动安装可能不可用。
- Computer Use 在控制独立测试实例时，敏感操作仍需用户确认。

## 发布验证

公开 Release 仅在候选版本通过以下检查后才会创建：

- 代码通过 lint 与类型检查。
- 桌面端构建成功。

- 关键交互功能验证通过。

上述门禁为公开发布的必要条件，验证通过后才会生成对应的 GitHub Release 并同步 Homebrew Tap。
