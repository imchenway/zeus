# Zeus 0.3.107 更新内容

## 从第三方创建任务

在新建任务时，可以直接粘贴 GitHub Issue、Jira 工作项或禅道详情链接。Zeus 会读取标题和正文，确认后即可创建任务。若页面需要登录，可点击“在 Zeus 中打开并登录”，在应用内完成登录后重新解析。

## Telegram 机器人设置界面焕新

重新设计了 Telegram 机器人设置界面，操作步骤更清晰，并优化了窄窗口下的显示效果。连接状态、绑定项目与已配对用户等信息一目了然，远程审批与智能体配置的说明也更明确。

## 修复常见问题

- 修复了文件审阅时正文未加载导致无法审核的问题，现在摘要视图也可随时加载差异内容。
- 修复了会话中频繁出现的错误提示，归档失败时会明确提示并保留处理入口。
- 优化了从第三方创建任务时的输入框交互，只有粘贴完整链接时才自动解析，避免误触发。

## 如何升级

- **Homebrew 用户**：执行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：下载版本化 DMG 文件 `Zeus-0.3.107-arm64.dmg` 并替换现有应用。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 从第三方创建任务时，GitHub 与 Jira 的附件会保留为来源链接，不下载为本地附件。
- 第三方登录需在“设置”中启用内置浏览器功能；禅道仍需在设置中配置账号密码。

## 发布验证

公开 Release 在通过 lint、类型检查、构建、打包与桌面交互验证后创建；签名与公证完成后，安装包才会对外提供。
