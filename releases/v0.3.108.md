# Zeus 0.3.108 更新内容

## 窗口位置与大小记忆

- 主窗口、任务代码交付窗口、项目差异窗口和第三方任务登录窗口现在会记住上次的位置与大小，下次打开时恢复到调整后的状态。
- 如果外接显示器被移除，窗口会自动回到当前可用屏幕内，不会跑到屏幕外面。
- 长按拖动调整窗口大小时，不再频繁写入记录，关闭窗口时会立即保存当前状态。

## 问答表单与任务推送窗口改进

- 之前任务详情里“提交回答”的弹层在窗口较小时会显示不全，现在表单更紧凑，并支持在窄窗口内同时滚动查看全部内容。
- 当回答已经送达时，原问题会收起，避免重复弹出；如果原轮次已结束，回答会保留为草稿，并可选择作为新消息发送。
- 推送任务的窗口现在分为左右两栏：左边配置任务内容与模型，右边配置工作区。两栏可分别滚动，也各自保存阅读位置。窗口宽度不足时会自动改为单栏顺序排列。
- 任务推送窗口的宽度上限从 720px 增加到 1280px，宽屏下能同时看到更多内容。

## 表格预览与选项卡弹窗修复

- 修复了 Markdown 表格在某些情况下预览错位的问题。
- 修复了选项卡弹窗在切换时可能出现的布局异常。

## 如何升级

- 使用 Homebrew 升级：
  ```
  brew upgrade --cask imchenway/tap/zeus
  ```
- 手动升级：从发布页面下载 Zeus-0.3.108-arm64.dmg，打开后拖拽 Zeus 到 Applications 文件夹覆盖旧版本。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前发布制品为手动升级，不支持在应用内自动安装。
- 如果问题表单在回答送达后收起，但你仍想查看已提交的回答，可以重新打开该任务的信息；某些情况下可能需要刷新以显示最新状态。

## 发布验证

公开 Release 只会在以下检查全部通过后创建：候选版本通过自动化测试、桌面应用可正常构建并打包，应用在 macOS 13 上通过基本交互验证。验证通过前不会发布 0.3.108 版本。
