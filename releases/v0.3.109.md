# Zeus 0.3.109 更新内容

## 变更亮点

- **Computer Use 操作更安全、更可靠**：每次执行点击、输入、拖拽等操作前，Zeus 会先检查并请求你确认目标应用、窗口和控件，只有你允许后才会继续；等待期间若窗口或内容发生变化，会中止操作并提示重新确认，避免误操作。普通文本编辑不再反复弹窗打扰。
- **支持等待界面状态**：新增 `wait_for` 能力，可让 AI 在点击或输入后，等待某个控件出现、消失或文本变化后再汇报结果，减少来回截图确认。
- **Git 操作完善**：修复“代码已经合入，但界面仍显示待提交”的问题；重命名分支、创建/推送/删除标签等操作更稳定；弃用（discard）修改现在也有明确入口。工作区提交面板可收起为摘要，展开后可拖动调整区域；右键菜单提供标签、分支等快捷操作。
- **编辑器与文档**：固定 Markdown 等纯文本文件的差异预览不能直接查看的问题，现在可预览；修复源码编辑器在删除文件后可能打开错误标签页、新建文件提示不清晰的问题；编辑中的切换或自动恢复不再丢失未保存的草稿。
- **数字员工与自动化**：自定义模板与项目员工编辑支持未保存草稿缓存，刷新或切换后不丢失；创建自动化前增加时间、间隔和依赖项校验；修复启用/停用状态显示与修订冲突问题。
- **任务与项目**：支持把任务修改或复制到其他项目；设置页增加搜索功能，可快速定位设置项；记忆、设置、源码与 Git 页面文字与布局更清晰一致。

## 如何升级

- **Homebrew**：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
  如果 Tap 未同步，请先运行 `brew update`。
- **手动升级（DMG）**：下载并替换旧版本。文件名：`Zeus-0.3.109-arm64.dmg`。

> 当前公开发布仍为手动升级方式，尚未启用应用内自动安装。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- Computer Use 的敏感操作（如发送、删除、付款等）必须在弹出确认框后点击“允许一次”才会执行；若你未确认或拒绝，操作不会发生。
- `wait_for` 只能确认可访问的界面状态；复杂界面可能需要补充完整观察。性能因应用与界面复杂度而异。
- Git 推送标签、修改任务归属等功能需要服务端或远端支持。
