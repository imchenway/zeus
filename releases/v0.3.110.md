# Zeus 0.3.110 更新内容

## 改进与修复

本次更新优化了桌面端自动化操作的稳定性与行为一致性，主要改进如下：

- **精简自动化操作描述，提升响应效率**：重构了“电脑操作”工具组的说明文本，使其更简洁清晰。这有助于模型更快理解操作规则，减少冗余描述，同时完整保留关键行为约束，如“操作前先观察界面”“同一时间仅一个回合控制”等，避免因描述过长导致的任务执行偏差。
- **修复已知问题**：修复了自动化操作过程中的一处问题，提升了执行可靠性和结果准确性。

## 如何升级

- **Homebrew 用户**：执行 `brew upgrade --cask imchenway/tap/zeus` 即可升级。
- **手动升级**：从发布页面下载并打开 `Zeus-0.3.110-arm64.dmg`，将应用拖入“应用程序”文件夹完成替换。

## 系统要求与已知限制

- 本版本要求 macOS 13.0 或更高版本。
- 当前候选制品为手动签名且未公证，首次启动可能触发系统安全提示，请按系统指引允许运行；此限制不影响家庭自动化功能，但应用内自动更新暂不可用。
