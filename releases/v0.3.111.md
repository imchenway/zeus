# Zeus 0.3.111 更新内容

本次更新优化了异步回答的展示方式，并让订阅登录与自动更新更可靠。

## 异步回答样式优化

回答异步问题时，你提交的答案现在会以更清晰的结构化卡片显示在对话中，不再与普通消息混排。长问题和多项选择会保持整齐的换行，相关操作按钮也更易识别。

## 登录稳定性改进

使用 ChatGPT 账号登录 Codex 订阅后，现在会等待并确认本次浏览器登录的官方完成通知，不再误用之前的账号缓存判断登录状态。若登录未完成或已经失效，会给出明确提示，你可以重新发起登录。

## 更新体验改进

应用内更新会识别当前安装方式，并提供更贴合的方式：

- Homebrew 安装的版本继续沿用 Homebrew 更新。
- 手动从 DMG 安装的版本，在满足正式签名、公证和安装位置条件时会自动下载并确认安装；不满足时则显示“下载新版”并引导你手动替换应用，而不是反复尝试失败的操作。
- 临时签名版本需先手动安装一次正式签名版本，才能使用后续的直接自动安装。

更新窗口也会根据你的语言显示准确的错误和可用操作，重新打开应用后仍能看到原因。

## 如何升级

- **Homebrew 方式**：在终端执行以下命令：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- **手动方式**：从 GitHub Releases 下载版本化 DMG 安装包，例如 `Zeus-0.3.111-arm64.dmg`，将其中的 Zeus 拖入“应用程序”完成安装。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 本次正式发布制品仍为手动升级方式，应用内自动安装仅对满足条件的已签名版本可用。

## 发布验证

公开 Release 仅在以下检查全部通过后创建：
- 候选版本通过 lint、类型检查、构建与打包。
- 桌面安装包通过正式代码签名与公证。
- 自动化更新与安装流程在预发布验证中通过版本校验、安装条件检查及回滚保护。

这些是发布前必须满足的门禁条件；满足前不会创建公开 Release。
