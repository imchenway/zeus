# Zeus 0.3.114 更新内容

## 更放心的浏览器自动化

以往 AI 在浏览器里点击、输入或按下回车前，经常需要你一次一次确认，Zeus 0.3.114 简化了这套流程。现在 AI 访问网站和执行常规网页操作时，不再需要逐次授权，可以更连贯地完成像“自己看图”这样的任务。不过，网页本身的设备权限、登录输入，以及从电脑上选择文件上传等操作，仍会按各自的安全流程处理。

如果你担心 AI 在网页上进行了意外的敏感操作，可以随时在浏览器会话中暂停或停止任务。

## 更顺手的项目与文件操作

### 调整代码目录宽度更简单

现在，你可以直接拖动代码目录的分隔条来调整宽度，双击分隔条还能快速恢复默认大小。用键盘操作也行：选中分隔条后，按左右方向键可以精细调整，按住 Shift 再按方向键可以大步调整，按 Home 键则回到默认宽度。

### 右键菜单更可靠

在代码文件上右键打开菜单后，菜单的关闭逻辑更稳定，不会再因为误点页面其他地方而意外消失。菜单里的“在 Finder 中显示”操作也修正了，点击后会正确执行并关闭菜单。

## 任务收尾与工作区整理

当任务关联的会话还没有归档时，代码合入后会保留工作目录，方便你继续对话。如果不再需要这些文件，可以手动回收，或随任务完成、取消时一并清理。

恢复一个已经交付的任务时，如果发现残留的目录没有 Git 登记（例如是之前手动创建的），Zeus 会先整体保留它，再按任务分支重建干净的工作区。残留目录的位置会记录在任务动态里，不会自动混入重建的代码，避免把旧文件意外带进新任务。

## 更清爽的界面与设置

这次更新还对几个界面和设置入口做了优化，让日常操作更顺手：

- **会话消息布局**：优化了消息的间距、耗时显示和状态展示，执行状态更清晰地跟在处理摘要旁边，看起来更整齐。
- **创建任务页简化**：去掉了不必要的输入项，填写任务信息更快了。
- **任务侧边栏**：布局更紧凑，折叠箭头在悬停时显现，触摸设备上则一直可见。
- **设置页**：系统设置、浏览器设置、模型连接等页面都做了布局调整，视觉上更统一，减少误操作的可能。
- **模型选择框**：当你把某个模型“置顶”后，它的来源会以小字显示在名称下方，避免不同提供商的同名模型混淆。
- **答题选项卡**：交互样式微调，选项的选中反馈更明显。

另外，修复了新用户登录 Codex 订阅后看不到订阅内模型、而看到的是旧模型的问题。现在登录后可以正确同步订阅模型。

## 如何升级

推荐使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

如果你习惯手动升级，可以下载 `Zeus-0.3.114-arm64.dmg`，打开后把 Zeus 拖入“应用程序”文件夹即可。

> 注意：当前公开制品仍是手动升级方式，应用内自动更新暂不可用。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0 或更高。
- 浏览器自动化简化后，AI 在网页上的操作不再逐次询问；网页自身向系统申请摄像头、麦克风等权限时，仍会弹出系统授权请求。
- 任务收尾保留工作目录的新行为仅适用于新完成的任务；已存在的旧任务可能需要手动清理。

## 发布验证

在公开 Release 创建前，固定候选版本需通过以下检查：

- 所有单元测试和集成测试通过。
- 桌面应用在 macOS 13 及最新系统上完成构建，并能正常启动、进行基础交互。
- 对浏览器自动化、任务收尾等关键路径执行 QA 场景验证。
- 签名与公证（如适用）通过。
- 用户升级路径（Homebrew 或 DMG）已验证可用。

只有上述检查全部通过，才会发布公开版本。
