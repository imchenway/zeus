# Zeus 0.3.116 更新内容

## 界面优化

- 简化了项目导航和任务筛选区域的视觉样式：移除了多余的玻璃拟态效果，选中状态改为背景色区分，使当前所处页面/状态更加一目了然。
- 统一了顶部导航和任务表格内筛选按钮的圆角与间距，整体界面更加协调。
- 修正了任务页顶部工具栏的固定行高设置，现在工具栏高度会随内容自动调整，在窗口高度有限时能更好地利用首屏空间。
- 修复了图标颜色异常的问题，主导航选中状态下图标与文字现在会一同显示为正确的颜色。

## 如何升级

**通过 Homebrew 升级（推荐）**

如果你已通过 Homebrew 安装 Zeus，可直接运行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

**通过 DMG 手动升级**

前往发布页面下载最新版本：

- 文件名：`Zeus-0.3.116-arm64.dmg`

下载后打开 DMG，将 Zeus 图标拖入“应用程序”文件夹覆盖旧版本即可。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 当前公开制品仍为手动升级方式，应用内自动安装更新暂不可用；后续版本可能改善安装体验。
- 本次调整仅涉及界面展示，不改变任务数据的存储或计算逻辑；若你自定义了主题样式，更新后部分自定义样式可能与新版内置样式冲突，可能需要手动调整。
