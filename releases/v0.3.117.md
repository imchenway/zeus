# Zeus 0.3.117 更新内容

## 侧边栏筛选现在会正确保留

侧边栏会话漏斗的状态过滤、是否隐藏无匹配会话的项目、是否只显示最新会话，这些选择现在与其他本机设置一起保存。重启 Zeus 后，之前选好的筛选不会再被重置回默认值。

从旧版本升级时，你此前保存在本机界面缓存里的侧边栏筛选会被接收并继续使用；如果本机设置数据库中已经有对应记录，则以数据库记录为准。

## Git 项目切换与差异查看更稳定

修复了在多个 Git 项目之间切换时可能出现的显示或状态错误。

查看文件差异时，如果该文件是二进制文件或只有文件元数据变化、没有可展示的文本差异，界面会给出明确说明，而不是显示空白内容。

## 项目页与技术界面外观调整

项目页的 Git 区域不再重复绘制卡片外框，改为沿用项目页统一的外层结构，视觉上更简洁。

应用图标已更新。

## 如何升级

推荐使用 Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从发布页下载对应安装包手动升级：

- Apple 芯片：`Zeus-0.3.117-arm64.dmg`

当前公开制品未经过公证，升级需要手动完成，应用内自动安装升级不可用。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 当前公开制品未经过公证，首次打开可能需要在系统设置中允许；升级请按上面的手动方式操作。
- 侧边栏筛选需要从数据库或旧的本机缓存读取，若本机存储被清理，筛选会回到默认显示。

## 发布验证

公开 Release 只会在固定候选版本完成以下检查后才创建：

- 代码检查、类型检查和构建通过。
- 桌面端打包成功并生成版本化制品（含 `Zeus-0.3.117-arm64.dmg`）。
- 安装包可安装并启动，应用基本交互可用。

只有上述门禁全部满足，才会创建对应的公开 Release 与门禁通过的制品。
