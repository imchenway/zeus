# Zeus 0.3.118 更新内容

## 会话体验

- 新增完整的用户发言导航刻度：打开长会话时即可看到全部历史发言位置，鼠标悬停可预览该轮提问与答复摘要，点击即可跳转。正文仍按需读取，靠近视口时才加载，因此打开长会话不需要一次读取全部内容。
- 会话消息展示更清晰：完成态只在正文上方显示一次处理耗时，处理过程入口与轮次状态保持一致；鼠标悬停到消息上时会显示复制、反馈与时间戳操作。
- 主智能体下发给子智能体的指令内容不再单独占据一栏，而是与消息时间线合并展示，避免同一内容重复出现。
- 会话输入框与工具栏优化：模型、思考强度、权限模式和协作模式可在输入框内直接切换；切换模型后选中状态会正确保持。响应进行中且草稿为空时，发送按钮会变为停止操作。
- 排队消息的样式与操作统一：按真实送达状态显示删除、引导与检查入口；已接纳的消息会退出队列操作并恢复为普通历史，不会重复显示正文或遗留占位。提交按钮进入处理中状态，失败时保留原消息。

## 侧边栏与项目入口

- 进行中的会话不再受普通会话数量限制：侧边栏优先保留正在运行、排队、连接或重连的会话，普通会话仍按首屏额度展示，并可继续展开更多。
- 新增按会话运行状态筛选，与任务状态筛选按维度共存；搜索结果不受数量额度影响，全部匹配项都会展示。
- 项目入口与折叠操作的点击区域更合理：项目行空白处也可进入项目，独立的折叠与操作按钮仍保持各自的响应规则。
- 欢迎页与创建项目表单重做：先选择工作文件夹，目录确定后再确认或修改自动填入的项目名称；取消选择会返回原入口并恢复焦点，选择失败时会在表单内显示原因和重选入口。
- 统一了界面中的绿色为品牌色，涵盖 Git 文件状态、代码差异、冲突解决、数字员工状态、即时通讯连接状态等位置，浅色与深色主题保持一致。

## Git 工作台

- 控制台现在展示桌面工作台已落盘的 Git 操作历史：操作记录会在重启应用后保留，并可滚动加载更早的记录、在读取失败时重试。
- 每条操作记录会显示动作名称、仓库、时间、耗时与结果状态，并包含实际执行的 Git 命令与被截断标记；旧记录缺少的信息会明确说明，不会用空白掩盖。
- 处理冲突后再提交不再因操作历史写入报错；执行失败时错误信息会与动作名称一并显示，便于定位。
- 操作历史的读取与正文分页均只读取账本，不重放任何 Git 操作。

## 系统要求与已知限制

- 系统要求：macOS 13.0 及以上。
- 提示词加密：主智能体下发给子智能体的部分指令内容可能因加密或不可用而无法显示，界面会标注该状态而不是显示空白。
- Git 操作历史：单条记录的命令输出最多展示前 64 Ki 字符，超出部分会标注截断；较早版本产生的记录可能没有保存动作名称或输出内容。
- 会话导航：预览摘录来自目录快照，未加载正文的轮次会显示真实轮次状态，而不是伪造答复文本。

## 发布验证

公开 Release 只在固定候选版本通过以下检查后才会创建：

- 类型检查与构建：候选提交完成类型检查与打包构建，未出现错误。
- 桌面交互检查：通过会话、侧边栏、Git 工作台相关自动化与人工检查脚本，确认本次变更的主要交互路径可用。
- 制品校验：生成的 `Zeus-0.3.118-arm64.dmg` 与预期版本一致，并记录校验信息。

## 如何升级

- Homebrew：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动安装：下载版本化 DMG `Zeus-0.3.118-arm64.dmg`，打开后将 Zeus 拖入「应用程序」覆盖旧版本。

- 当前公开制品为 ad-hoc 签名、未经过公证，应用内自动安装可能不可用，请使用上述手动方式升级。
