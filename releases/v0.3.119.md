# Zeus 0.3.119 更新内容

## 回答批注更贴合正文

- 选中回答正文即可添加评论，批注标记由序号改为气泡图标，更直观地表达“这是评论”。
- 批注编辑框现在紧贴所选文字显示，并根据可用空间调整宽度与高度；空间不足时编辑框内部滚动，操作按钮不会被裁掉。
- 编辑框进入浏览器顶层定位，输入时不会再滚动正文；窄分栏、调整窗口或正文换行后，标记与编辑框位置会同步更新。
- 编辑框不再单独展示引用原文块，直接以输入框承载评论内容，占位提示改为“添加可选评论…”。

## 上下文与长结果更省、更完整

- 上下文预算改为按 UTF-8 字节计算，中文与表情等非 ASCII 内容不再因为按字符数估算而被低估。
- 工具结果预览统一限制在约 16 KiB 字节，分页读取始终按完整字符切分，不会再出现半个汉字或被截断的表情。
- 命令类结果保留开头与结尾并标注分页位置，读取与搜索类结果先限字节再限行数。
- 交接给模型的历史会去掉工具调用中重复的大段输出，只保留调用参数、完成状态、退出码和简短错误摘要；完整内容仍可通过句柄读取，既有历史证据不受影响。
- 缺少当前轮次归档身份时，工具调用会在执行前被拒绝，不会先执行再无限回传原文或原图。

## 工作区搜索更可控

- 搜索默认只返回匹配的文件名，需要正文时使用内容模式，并可按 glob 筛选文件。
- 内容模式按每个文件限制命中数（默认 50，最多 200），长行只展示预览；搜索表达式与路径作为参数传递，不会被误当成命令选项。
- 搜索收集结果上限为 64 KiB，达到上限时会在结果开头明确标注“结果不完整”，分页只能读取已收集部分，并提示缩小搜索范围。
- 只有正常的零匹配才返回“没有匹配结果”，语法错误、超时、路径不存在和取消操作会如实上报。

## 会话界面细节

- 历史导航的跳转标签改为按发言内容说明，不再附带顺序编号；鼠标移出后回到原阅读位置。
- 变更文件列表按新增、删除两列对齐，数字位数变化不会挤偏相邻列；无法撤销导致的不可用提示改为中性信息样式，只有真实操作冲突才使用红色告警。
- 内联文件链接与正文文字基线对齐，前置图标不再把整段链接抬高。
- 内置浏览器关闭标签后，迟到的布局请求会直接失效，不会误移除刚切换的新标签。
- 已有等待圆环的按钮不再叠加第二个加载圆点，避免双重动画。

## 如何升级

- Homebrew：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动安装：下载版本化 DMG 文件 `Zeus-0.3.119-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成覆盖安装。

当前公开制品若为临时构建且未完成公证，请使用上述手动方式升级，应用内自动安装可能不可用。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 批注编辑框在可用空间不足时改为内部滚动，操作按钮仍可见。
- 搜索结果达到 64 KiB 收集上限时结果不完整，分页只能读取已收集部分。
- 工具结果分页每次最多约 16 KiB 字节，需按返回的 nextOffset 继续读取。
- 工具调用缺少当前轮次归档身份时会被拒绝执行，完整结果需通过句柄读取。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 类型检查与代码检查无错误。
- 桌面端构建与打包成功，产物名称包含版本号。
- 校验工具结果归档、分页、UTF-8 字符完整性与工作区搜索行为的检查通过。
- macOS 代码签名与公证校验通过；未公证时不得声明应用内自动安装可用。
