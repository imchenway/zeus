# Zeus 0.3.12 更新内容

## 会话体验优化

- 消息发送后立即进入时间线，回复区在首次绘制前一同定位；流式内容按小批次连续呈现，减少跳动与重排。
- 思考摘要样式统一，并优化了读屏播报，减少重复朗读。
- 修复了会话升级后消息重复且无法继续的问题，以及补充消息带附件时可能报错的问题。
- 优化了会话切换：选择另一会话时立即显示目标内容，冷加载时显示目标骨架而非保留旧正文。
- 改进了侧边栏会话标题字重，使层级更清晰；冲突页样式同步调整。
- 会话输入框下拉菜单（项目、分支、模型等）统一到全局选择组件，位置与搜索行为更稳定。

## 目标模式重做

- 目标输入框支持直接输入目标，并增加字数限制提示；可创建、暂停、恢复或清除目标。
- 目标模式下的按钮与交互对齐 Codex，发送按钮在目标输入时变为创建目标。
- 目标输入期间保留普通消息草稿，退出后即可继续。

## 任务管理改进

- 任务推送后即时进入“开发中”状态，会话首条消息出现时任务已处于正确分组，不再需要手动调整。
- 清理任务并标记终态时，改为原生确认弹窗，明确列出将停止并归档会话、删除未提交文件，以及保留已提交代码。
- 优化了无任务时的列表提示，以及筛选无结果时的文案。
- 修复点击归档任务时的报错，归档操作更可靠。

## 错误处理与稳定性

- 全应用错误统一为弹窗显示，支持查看详情，并自动屏蔽凭据信息；不再在页面内直接展示原始错误文本。
- 模型请求失败时显示为警告而非会话失败，会话可继续使用；对应系统通知文案已调整。
- 修复了外部供应商模型连接时的报错，单次请求失败不会中断整个会话。
- 修复了首次安装或打开时可能出现的 Gatekeeper 恶意软件提示问题。
- 修复了会话输入框中文输入法偶发无法输入的问题。
- 修复了菜单栏今日 Token 与近 7 日用量数值不一致的问题。
- 点击开发计划现在会在右侧正确预览。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从发布页面下载 `Zeus-0.3.12-arm64.dmg`，挂载后拖入 Applications 目录替换旧版本。

> 当前为手动升级方式；请关闭正在运行的 Zeus 后再替换应用。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 本版本为未公证的 ad-hoc 构建，首次打开时可能需要在“系统设置 → 隐私与安全性”中允许运行。
- 若从旧版本升级，历史会话可能需要重新登录或重新配置模型供应商；已归档会话仍可查看。

## 发布验证

在创建公开 Release 前，候选提交必须通过以下检查：

- 所有 lint、类型检查与单元测试通过。
- Electron 应用在干净环境构建成功，应用能正常启动并完成首次引导。
- 桌面端核心流程（新建/继续会话、发送消息、任务推送与状态变更、归档/恢复）手工验证通过。
- 安全项验证：错误弹窗正确脱敏，不显示明文凭据；任务清理确认弹窗正确提示文件删除范围。
- 打包产物（arm64 DMG）制作成功，且安装后能正常打开。

以上门禁全部通过后，才会创建公开 Release。
