# Zeus 0.3.120 更新内容

## Git 工作台更完整，减少来回切换

项目页的 Git 工作台在这一版做了较大幅度调整，重点是把查看、比较和操作集中到同一处：

- 新增分支领先/落后状态展示，能直接看出当前分支与上游的差距。
- 新增贮藏（stash）详情查看与差异预览，暂存的改动不再只显示一行摘要。
- 差异查看器支持按 hunk 逐个操作，并改进了相关界面布局，处理局部改动时不必整段应用。
- 强化同步操作与项目工作区导航，提交说明生成流程也一并优化。
- Git 错误提示更具体：认证失败、主机验证失败、超时等原因会给出可处理的说明，而不是统一报“操作失败”。

## 源码页增加更改面板与图片预览

源码工作区现在同时承载代码浏览和本地改动：

- 左侧新增“更改”区域，可查看各仓库的暂存、未暂存和合并更改，并直接从列表打开差异对比。
- 发生冲突的文件会跳到对应编辑界面，冲突处理提供“当前更改/传入更改”的两栏比较视图。
- 打开图片文件时直接显示预览，不再只提示无法读取二进制内容。
- 源码与更改两个模块的高度可以拖动调整，双击恢复默认比例。
- 文本编辑器标签的外部修改提醒更收敛，只保留需要你处理的提示，不再为每次保存、创建、重命名弹出成功通知。

## 会话、权限与应用外观

- 会话权限菜单提供“只读”“自动”“替我批准”和“完全访问”，每项下方说明权限范围。“自动”允许工作区内修改，需审批的操作交给用户；“替我批准”保留工作区限制，由 Codex 自动审核审批请求，有风险时仍可能询问或拒绝，不等于完全访问。此选项仅支持具备自动审核能力的 Codex，其他引擎不可选择。
- 修复了关联会话点击后会话页空白但实际有消息的问题，并修正了“本次没有答复”的错误展示。
- 调整了会话消息的起始位置对齐、推送任务的提示词布局以及子智能体会话的展示。
- 更新应用图标、启动页图案与菜单栏托盘图标，启动页不再出现图案割裂感。
- 菜单栏用量卡片与用量设置界面调整了展示细节。
- 引导流程不再自动创建任务。

## 内置全局命令与开发模式

- 新增四条内置全局命令，覆盖微信开发版上传、二维码预览、手机自动预览和真机调试，可直接在项目命令中运行，无需复制脚本或额外安装 Node.js。
- 微信命令需要安装并登录微信开发者工具、开启服务端口，并具有对应小程序的开发权限。默认使用当前项目；框架项目请填写构建后包含 `project.config.json` 的小程序目录，Zeus 不替项目猜测或执行构建。上传时填写版本号；预览二维码和返回信息保留在执行产物中。新安装自动提供这四条命令，升级会保留已有的同名或同别名命令；你修改、停用或删除后不会在下次启动被重置。
- `pnpm dev` 改为 Electron + Vite 开发模式：首次构建运行依赖后启动，React/CSS 修改热更新；主进程、preload 和共享后端包修改后需重启命令。退出开发窗口或按 Ctrl+C 会关闭本次开发服务，不影响已安装应用。
- 开发配置读取根目录 `.env`、`.env.development`，系统环境变量优先；`ZEUS_DEV_MODE=test pnpm dev` 读取 `.env`、`.env.test`。数据默认隔离到 `.tmp/electron-development-data` 或 `.tmp/electron-test-data`，可通过 `ZEUS_USER_DATA_DIR` 指定兼容的开发数据目录。不要指向正式数据目录。修改环境文件后重启开发命令；只有 `VITE_` 前缀变量可供前端读取，勿放入密钥。
- 开发模式使用独立的 `Zeus Dev` 名称与图标，避免与正式 Zeus 混淆。`pnpm build`、`pnpm verify:publish` 和所有打包、签名、发布入口保持原有行为。

## 如何升级

- 使用 Homebrew：

  ```
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动下载安装：从发布页获取 `Zeus-0.3.120-arm64.dmg`，打开后将 Zeus 拖入“应用程序”，覆盖旧版本即可。当前公开制品为 ad-hoc 签名且未经过公证，请使用上述手动方式升级，应用内不会自动下载安装。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品未做公证，首次打开可能需要在“系统设置 → 隐私与安全性”中手动允许。
- 微信命令依赖微信开发者工具已安装并登录、已开启服务端口，且账号具有对应小程序的开发权限。
- “替我批准”权限仅适用于具备自动审核能力的 Codex，其他引擎无法选择该项。
