# Zeus 0.3.121 更新内容

## 启动图标替换为 PNG 资源

启动占位页与启动失败页使用的品牌图标已从 SVG 替换为 PNG（`startup-mark.png`），原有圆角品牌底板保留不变。两处引用（启动加载画面与启动失败提示）同步更新为同一 PNG 资源，视觉表现一致。

## 如何升级

- Homebrew：

  ```
  brew upgrade --cask imchenway/tap/zeus
  ```

- 版本化 DMG 手动升级：下载 `Zeus-0.3.121-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。

当前公开制品为 ad-hoc、未公证，应用内自动安装不可用，请按上述方式手动升级。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 分发架构：arm64。
- 当前公开制品为 ad-hoc、未公证，首次打开可能需要手动放行，且不支持应用内自动更新。

公开 Release 只有在固定候选提交通过仓库的发布门禁（构建、打包及既有校验）后才会创建；未通过门禁的候选不会生成公开 Release。
