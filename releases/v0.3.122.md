# Zeus 0.3.122 更新内容

## 状态栏图标修复

本次更新替换了桌面端状态栏（菜单栏）使用的模板图标资源，修复了状态栏图标显示异常的问题。更新后，状态栏图标可以正常展示。

## 如何升级

- 通过 Homebrew 升级：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：从发布渠道下载版本化 DMG 文件 `Zeus-0.3.122-arm64.dmg`，打开后将 Zeus 拖入“应用程序”文件夹完成替换。

当前公开分发的制品为 ad-hoc 签名、未经过公证，应用内自动更新安装可能不可用，请优先使用上述手动方式升级。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 公开制品为 ad-hoc 签名、未经过公证，首次打开时 macOS 可能提示安全警告，需要在“系统设置 - 隐私与安全性”中允许打开。
- 由于制品未公证，应用内自动更新安装可能不可用，升级请通过 Homebrew 或手动下载 DMG。

## 发布验证

公开 Release 只有在固定候选提交通过以下检查后才会创建：

- 代码质量门禁：lint 与类型检查通过。
- 构建门禁：桌面端构建与打包成功，并产出与目标版本一致的制品。
- 制品校验：生成的 DMG 文件名与目标版本、架构匹配（`Zeus-0.3.122-arm64.dmg`）。
- 版本一致性：根包与桌面包版本号、标签版本一致。

以上任一检查未通过时，不会创建对应版本的公开 Release。
