# Zeus 0.3.123 更新内容

## 目标面板操作更清晰

- 目标详情弹窗改用统一的按钮与配色，操作区在窄窗口下会自动换行，不再挤压出错位。
- 执行中的目标显示“暂停执行”，暂停或受阻的目标显示“继续执行”；若目标内容有未保存的修改，会提示先保存再继续，避免误在旧目标上恢复自动执行。
- 保存按钮改为“保存修改”，与“创建目标”区分，未改动内容时不再显示无效保存入口。
- 目标摘要栏与输入框等宽并居中对齐，长目标文本可悬停查看完整内容；用量单位在中文界面显示为“令牌”。
- 运行时长与令牌用量的摘要和详情保持一致，时间线在内容较多时可滚动查看。

## 计算机操作更可控、更安全

- 辅助功能动作只能执行当前控件实际公开的操作；不再根据控件名称猜测动作，未知动作不会被视为导航而被直接放行。
- 滚动、翻页、打开菜单等导航类动作沿用既有授权；删除、确认、提交等有实际影响的操作仍会请求批准。
- 密码、验证码等安全输入框在文本输入和快捷键路径下受到一致保护，不会因为按钮文案而误判为可输入字段。
- 文本编辑快捷键（如选择、查找、复制、粘贴、剪切、撤销、重做）与导航快捷键（如 Command+A/F/G、Command+Shift+G）不再弹出多余确认，编辑区内的光标移动也不受影响。

## 会话与界面细节修复

- 只有存在至少两轮用户发言时才会显示历史刻度导航，单轮会话保留原生滚动条，避免出现无意义的刻度。
- 菜单栏图标固定为 18×18 逻辑像素，替换图标资源时不会再撑大菜单栏。
- 工具栏、协作模式、服务等级、附件和目标等按钮的悬停配色改用品牌前景色，深色与浅色模式下不再出现黑色高亮盖住状态的问题。

## 如何升级

- Homebrew：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：从发布页下载 `Zeus-0.3.123-arm64.dmg`，打开后把 Zeus 拖入“应用程序”完成替换。当前公开制品为 ad-hoc、未经公证，应用内自动安装不可用，请使用上述手动方式升级。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 当前桌面制品为 ad-hoc 签名且未公证，可能需要手动移除隔离属性才能启动；应用内自动更新不可用。
- 依赖辅助功能权限的计算机操作功能，需要先在系统设置中授予 Zeus 相应权限；权限未就绪时相关动作可能被拒绝或需要重新观察目标。
