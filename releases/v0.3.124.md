# Zeus 0.3.124 更新内容

## 项目内交互终端

Zeus 现在可以在项目“命令”页直接打开交互终端，无需切换窗口或另开应用。

- 在项目命令页点击“终端”，终端面板从底部打开，并默认进入当前项目目录。
- 支持标签页：可同时开启多个终端会话并随时切换。
- 沿用本机 shell 的提示符、补全和主题，支持键盘输入与 Ctrl+C。
- 收起终端面板后，终端会话继续在后台运行，重新展开即可继续操作。
- 可在“设置 → 终端”中保存启动命令，之后每个新终端会在项目目录自动执行一次该命令。
- 通过 `exit` 或面板上的“结束会话”关闭终端。

## 文件预览

代码交付、会话资源与 Git 工作台中的文件预览现在统一由应用内阅读器处理，无需为查看内容反复切换应用。

- 代码交付页和会话资源中的图片、PDF、音频、视频可直接在页内预览；较大的图片或不适用的格式会提示改用系统预览。
- Git 历史文件的预览会读取该提交对应的内容版本，而不是工作区当前文件。
- 预览支持导出、在访达中显示、用系统默认应用打开，以及 macOS 快速预览。
- 文件在预览期间发生变化、被移动或权限不足时，预览会明确提示刷新或使用系统预览，而不是静默显示旧内容。

## Computer Use 授权与操作确认

Computer Use 的使用流程更贴近实际授权状态，减少使用过程中的反复打断。

- 在系统设置的 Computer Use 中启用并完成 macOS 辅助功能与录屏授权后，使用期间不再重复弹出授权申请。
- 权限缺失或被撤销时，操作停止并提示回到设置补齐，不会自动申请或重试。
- 敏感动作沿用设置中的授权，不再为普通操作额外弹出应用内确认框。
- 仍不读取或填写密码、验证码等安全文本字段。
- 扩展了对原生菜单、文件选择面板等系统浮层的识别，并在缺少辅助功能信息时提示重新观察目标。

## 任务与数字员工

任务详情与数字员工面板的信息组织更完整，也更容易定位当前工作状态。

- 任务列表使用数据表格呈现，便于浏览和检索任务。
- 任务详情页整合了工作方案、工作复盘、交付物阅读和对话视图，便于在同一页面跟进任务进展。
- 数字员工可提出记忆更新建议，供你查看与处理。
- 会话目标（Goal）面板在历史会话中也能正确显示当前状态与可执行操作。

## 其他改进

- 会话中已回答的答题卡现在会进入会话刻度导航，便于在长会话中快速定位。
- 使用自定义供应商模型时，技能（skill）可以正常触发。
- 修复消息排队时报错的问题。
- 修复批注按钮一闪即消失的问题，布局变化或窗口缩放不再误关闭入口。
- 修复打开内置浏览器卡住的问题，空白标签页也能正常初始化。
- 使用 DeepSeek 模型时，思考过程展开不再全部显示为工具调用。
- 修复文件无法点击、代码交付页看不到图片、点击代码交付出现乱码、会话切换等若干交互问题。
- 菜单栏图标针对 Retina 屏幕提供更清晰的绘制，并移除图标内部的白色闪电，保留纯黑色模板样式。
- 调整了多处界面样式，包括异步问题框文字与按钮高度对齐、目标执行中状态显示、会话状态筛选分组等。

## 如何升级

Homebrew 用户执行：

```
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载 `Zeus-0.3.124-arm64.dmg`，打开后将其中的 Zeus 拖入“应用程序”完成升级。当前公开制品为 ad-hoc 签名且未公证，因此升级需要手动完成，应用内暂不提供自动安装与自动替换正在运行的应用。

## 系统要求与已知限制

- macOS 13 或更高版本，当前公开制品为 arm64。
- 未公证的 ad-hoc 制品在首次打开时可能需要在“系统设置 → 隐私与安全性”中允许运行。
- Computer Use 需要 macOS 辅助功能与录屏权限；权限被撤销时操作会停止并提示回到设置，不会自动恢复。
- Computer Use 不读取或填写密码、验证码等安全文本字段。
- 菜单或系统浮层未公开辅助功能子项时，可能无法通过辅助功能直接定位其中某项，需要重新观察目标后再操作。
- 使用自定义供应商模型时，技能触发需模型返回符合预期的结构，仍可能受模型行为影响。

- 打包产物在 macOS 13 及以上系统可启动，且启动后能连接到本地服务。
- Computer Use 的权限检查、敏感字段保护与目标校验行为在打包产物中通过验证。
- 文件预览在图片、PDF、文本及历史版本文件上的读取与释放行为通过验证。
