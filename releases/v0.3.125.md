# Zeus 0.3.125 更新内容

## 会话正文与图表

- 会话中的 Mermaid 图表现在可以直接在正文里预览，包括时序图、流程图等常见图表；如果图表语法有误，会保留源码而不是让整段内容显示失败。
- 图表预览关闭了脚本执行、链接跳转和导出入口，只在会话内安全呈现。
- Markdown 正文作为气泡内容时不再被宽表撑开，超长表格在气泡内部横向滚动。
- 粘贴 Markdown 格式文本后，表格可以在原位直接编辑单元格，支持长编号、前导零、列内空格、竖线转义，以及只包含部分列的表格行；编辑时撤销、重做、回车完成编辑等行为已统一。

## 会话资源与文件审阅

- 会话里的图片以弹窗形式预览，关闭后不会打断右侧正在阅读的内容。
- Markdown、代码、PDF 等其他文件统一进入右侧“文件审阅”，不再各自弹窗；网页链接进入内置浏览器，邮件链接交给系统邮件应用。
- 缩略图、附件卡片、正文内联链接共用同一套打开逻辑，同一资源的去向保持一致。

## 浏览器标签与会话状态

- 浏览器标签、活动页和分组只在本次应用运行期间保留，重新启动后不会恢复上次遗留的标签；登录状态和书签等长期内容仍会保存。
- 明确关闭会话内的浏览器时，会同时释放该会话的所有标签，避免下次打开仍看到旧页面。

## 权限与审批

- 权限选择菜单为只读、自动、自动审阅、完全访问分别提供图标，菜单与入口图标保持一致。
- 审批菜单新增“允许所有（完全访问）”：选择后需要先确认风险，确认完成才会批准当前请求，并把完全访问应用到后续轮次；正在执行的轮次仍沿用原有权限。
- 命令审批区域保留命令的原始换行与参数边界，支持横向查看长命令，窄侧栏下按钮换行显示，不再挤压命令列。

## 任务状态与界面一致性

- 修改任务状态时不再出现旋转加载标记，保留下拉箭头，其余保存反馈保持原有行为。
- 合入代码时不再因关联会话活动而弹出额外确认；只合入已提交内容，关联会话未归档时工作目录会保留。
- 会话卡片、文件审阅卡片、环境信息卡片统一使用圆角与底色表达层次，标题下不再叠加描边和阴影。
- 消息图标（复制、点赞/点踩、展开/收起）轮廓更清晰，配合实际尺寸使用可见的圆角与描边。
- 启动首屏会沿用已保存的主题设置，深色模式下代码交付窗口不再出现首屏闪白；独立仓库差异窗口会跟随应用主题实时更新。
- 透明图片网格、同步差异窗口也随深浅主题切换，深色模式下仍能辨认透明区域。

## 如何升级

- Homebrew：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动安装：从公开 Release 下载 `Zeus-0.3.125-arm64.dmg`，打开后将 Zeus 拖入“应用程序”。当前制品为手动升级方式，应用内自动安装不可用。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- 当前公开制品未公证，首次打开可能需要在“系统设置 → 隐私与安全性”中允许运行，或右键选择“打开”。
- 应用内自动更新不可用，需要通过 Homebrew 或下载版本化 DMG 手动升级。
- 浏览器标签、活动页和分组不会跨应用重启保留；登录状态与书签仍会保留。
- 完全访问只在确认后从下一轮生效，正在执行的轮次仍使用当前权限。

## 发布验证

公开 Release 只有在固定候选通过仓库预设的门禁后才创建，包括：类型检查、构建、打包，以及会话核心与事件流相关的验收检查。任一检查失败都不会创建公开 Release。
