# Zeus 0.3.126 更新内容

## 会话终端

会话底部新增内置终端面板，直接在项目目录中执行命令。

- 按 Control（⌃）+ 反引号键显示或隐藏终端，隐藏面板不会终止正在运行的进程。
- 支持多个终端标签，标签会显示工作目录名与运行状态，最多同时保留 8 个标签。
- 面板高度可拖动调整，并会记住上次高度；双击分隔条可恢复默认高度。
- 首次使用前需要在项目中允许 Shell，面板会就地提示并可一键开启。

## 会话列表右键菜单

在会话列表条目上点击右键可以打开上下文菜单。

- 重命名会话，在对话框中输入新标题后保存。
- 标记为未读或已读。
- 归档或取消归档会话。归档当前正在查看的会话后，会自动选中同一项目下的另一个活跃会话；没有可用会话时回到会话列表。

## 任务与禅道同步

- 任务列表新增操作列，可直接从行内发起代码交付、推送到新会话和删除任务。
- 新增禅道导入：读取当前禅道账号负责的任务和缺陷，确认后导入 Zeus。
- 任务标题为空时，界面回退显示会话标题，不再出现空白项。

## 用量与 Git

- 用量设置改为按供应商分别展示本地采集的逐轮数据，不同供应商的 Token、缓存与费用口径相互独立，不跨供应商相加；未提供官方配额的供应商只展示本地明细。
- 项目 Git 面板支持检出远程分支，可选择检出现有本地分支，或基于远程分支新建本地分支并决定是否跟踪远程引用。

## 如何升级

- Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- 手动升级：下载 `Zeus-0.3.126-arm64.dmg`，打开后按提示替换现有应用。

## 系统要求与已知限制

- 仅提供 macOS 13.0 及以上版本的 arm64 构建。
- 当前公开制品为 ad-hoc 分发、未公证，应用内自动安装不可用，请按上面的 Homebrew 或 DMG 方式手动升级。
- 会话终端要求项目已允许 Shell，未开启时终端面板会提示先开启。
- 会话列表右键菜单中的置顶、移动到项目、移动到分区、复制、分叉、分享、在新窗口中打开等入口当前为禁用状态。

## 发布验证

公开 Release 只有在固定候选版本通过以下检查后才会创建：候选提交在代码仓库中通过 lint、类型检查与构建；桌面应用完成打包并能正常启动主窗口；升级说明中列出的功能在候选构建上完成交互核对；发布门禁全部通过后生成对应版本的公开 Release，并同步分发渠道。
