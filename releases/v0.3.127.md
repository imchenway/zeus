# Zeus 0.3.127 更新内容

## 临时会话与不再必须选项目

- 首次进入时可以点击“开始临时会话”直接开始，无需先选择项目文件夹。
- 临时会话使用默认目录 `workspaces/temporary`（位于当前 Zeus 数据目录下），文件和会话历史都保存在本机。
- 原来的“选择工作文件夹”入口保留，用于创建常规项目。

## 主界面布局切换

- 在“设置 → 通用”中可以在经典布局和紧凑布局之间切换，选择会自动保存。
- 未选择过布局时沿用经典布局；已有布局选择和会话状态保持不变。
- 经典布局沿用原有的项目工具栏与侧栏结构；紧凑布局把项目切换固定在左上角，工作区入口改为最左侧的图标活动栏。

## 项目内搜索与源码工作区

- 标题栏新增全局搜索，可同时检索任务、会话和代码内容，并可按“全部 / 任务 / 会话 / 代码内容”筛选范围，用键盘上下键和回车直接打开结果。
- 代码内容搜索针对项目内的路径和 UTF-8 文本进行，会跳过依赖、构建产物、二进制和超大文件；结果数量有上限，超出时提示缩小范围。
- 项目左上角可并列打开多个项目槽位，每个槽位保留下拉切换；关闭当前项目槽位时会切换到相邻的已打开项目。
- 源码工作区把新建文件、新建目录等操作移到目录标题旁，标签样式调整为编辑器风格的选中态，文件保存、创建、重命名、移动和移入废纸篓后会显示结果提示。
- 项目工作区入口（会话、任务、Git、源码、命令，以及自动化、扩展管理、设置）整合为独立活动栏，未选择会话时会说明当前会话入口不可用的原因。

## 会话与提交可靠性

- 提交消息时会校验提交回执，并改进发送失败时的提示。
- 持久思考条目保留独立身份，避免在同一会话中相互覆盖。

## 如何升级

本发行版使用 Homebrew Tap 升级。

```bash
brew upgrade --cask imchenway/tap/zeus
```

未使用 Homebrew 的用户可以从 https://github.com/imchenway/zeus/releases 下载版本化 DMG：`Zeus-0.3.127-arm64.dmg`。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品若未经过 Apple 公证，首次打开时 macOS 可能提示无法验证 Zeus，需要手动确认打开；此时请按手动方式安装 DMG，不能依赖应用内自动安装。
- 全局搜索中的代码内容结果有数量和读取体积上限，超大仓库或超大文件可能只返回部分结果或跳过该文件。

## 发布验证

只有在固定候选提交同时通过以下检查后，才会创建公开 Release 并同步对应 Tap：

- 触发的源码通过 `pnpm verify:publish` 校验。
- 候选提交精确等于发布分支的远端提交，且发行归属与应用版本一致，目标标签等于 `v0.3.127`。
- macOS 构建与打包完成，产物中的发行清单与候选提交、版本一致。
- 公开发布所需的凭据齐备；启用 Homebrew 发布时 Tap 令牌可用。
- 已启用 Homebrew 的发行版在发布时同步生成并推送对应 Cask。

任何一项不满足都不会创建公开 Release。
