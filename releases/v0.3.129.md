# Zeus 0.3.129 更新内容

## 登录信息直接填写

- 浏览器与电脑操作支持填写用户已经提供并授权使用的账号、密码和验证码，无需被强制转入另一套登录流程。仍可选择私密登录交接。
- 改进浏览器表单填写，使用受页面框架管理的登录表单时，字段变化能正确传递到页面。
- 页面快照和字段读取继续遮蔽已有密码。直接交给任务使用的登录信息仍可能出现在任务记录中。

## 多任务电脑操作

- 不同任务可以分别观察和控制不同应用，分别维护画面预览和控制状态。
- 结束或停止一个任务时，只释放该任务的控制；停止可以及时打断耗时的界面读取。
- 同一应用仍只允许一个任务控制，避免多个任务争用应用内焦点；电脑输入动作仍按顺序执行。

## 如何升级

- Homebrew 用户执行 `brew upgrade --cask imchenway/tap/zeus`。
- 手动安装可从 [GitHub Releases](https://github.com/imchenway/zeus/releases) 下载 `Zeus-0.3.129-arm64.dmg`，结束当前工作并退出 Zeus 后覆盖安装。

## 系统要求与已知限制

- 安装包面向 Apple Silicon Mac，要求 macOS 13 或更高版本。
- 多个任务同时观察应用会增加采集资源开销；同一应用的多个窗口仍共享控制归属。
- 签名与公证状态以公开更新清单为准；尚未完成 Developer ID 签名或 Apple 公证的安装包使用手动升级入口。

## 发布验证

- 公开 Release 只在固定候选提交通过源码检查、正式打包、包内容和更新清单校验后创建。
- 发布后核对 GitHub 资产摘要、下载的安装包与更新清单，并检查 Homebrew Cask 的版本和校验值。
