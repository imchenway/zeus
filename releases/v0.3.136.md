# Zeus 0.3.136 更新内容

## 本次更新

- 修复旧会话显示位置初始化时可能报错、无法继续读取的问题。初始化按批次保存进度，意外退出后可以从已提交的位置继续。
- 改善长历史会话的排序初始化，减少重复重编号；工具调用与结果按明确调用身份关联，保留原输入和阶段归属。
- 会话正在初始化时保留已有内容并自动重读；正常等待、等待超时和真实失败分别提示，重新连接或离开会话会取消旧请求。
- 补齐开发应用的真实宿主健康检查，支持核对隔离数据、进程身份及持续推进的界面心跳。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.136-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 独立开发环境缺少 Codex 登录和 Pi 供应商配置，本次未完成这两种运行方式的真实消息流程及滚动稳定性验收。
- 历史初始化仍可能短暂等待；本次没有修改既有事件串行处理规则或扩大缓存预算。
- 签名与 Apple 公证状态以公开更新清单为准；未完成时，首次启动可能需要按 macOS 提示手动确认。

## 发布验证

- 存储断点恢复、工具身份关联、查询计划和完整 Renderer 事件探针通过；618 个会话、721032 条来源的隔离元数据重放完成，正式数据仅作只读读取。
- 三个大历史样本的真实磁盘恢复及提交前后突然退出核验通过；开发应用副屏启动及真实宿主心跳核验通过。这些结果不等同于双 Provider 消息交互或界面性能验收。
- 公开 Release 以固定候选提交的发布检查、正式打包、DMG 完整性和更新清单一致性校验为准，公开资产与 Homebrew Cask 分别核对。
