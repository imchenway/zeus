# Zeus 0.3.137 更新内容

## 会话消息渲染更稳定

- 修复了长会话中较早的用户输入在刷新或重新分页后可能丢失的问题：已确认并显示过的输入会保留原有位置，不再被排到回复之后或消失。
- 已完成的操作记录在会话刷新后仍会保留其所属轮次与耗时，后续继续翻阅时不会丢失上下文。
- 实时消息若缺少正式显示位置，会触发一次会话重新同步，而不是把顺序不确定的内容混入消息列表。
- 内容与操作共用的标题、运行摘要和展开详情现在对齐到同一起点，窄窗口下缩进一致，阅读更整齐。

## 界面细节调整

- 项目侧边栏在空闲时隐藏滚动条滑块，滚动区域宽度保持不变；按住拖动或滚轮滚动时滑块仍会短暂显示，避免误以为列表被裁切。
- 任务、Git、源码、命令与会话页面共用连续底色，外层卡片边缘不再重复绘制，界面层次更干净。
- 菜单栏用量窗口整体收紧字号与留白：当日与近 7 日指标统一称为“今日 Token”和“近 7 日 Token”，图表按日期补齐近七天并以实际柱形汇总，缺失日期显示破折号而不按零推算。
- Codex 用量图会明确标注数据来源：历史日期使用 Codex 账户统计，当天使用 Zeus 本地消耗，近 7 日为图中用量合计，并提供说明入口；Codex 主额度组会固定显示在首位。

## 更新与安装来源更明确

- 安装检查、更新清单与说明文案统一指向 Zeus 官方仓库和 `imchenway/tap` Homebrew 来源，不再展示其他安装渠道或发行配置项。
- 更新提示中的操作名称改为“使用 Homebrew 更新”，引导用户通过官方 Tap 完成升级。

## 如何升级

- Homebrew 用户可执行：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 也可以下载 `Zeus-0.3.137-arm64.dmg`，退出正在运行的 Zeus 后手动覆盖安装。当前公开制品需手动完成升级。

## 系统要求与已知限制

- 面向 Apple Silicon（arm64）Mac。
- 要求 macOS 13 或更高版本。
- 当前公开的 DMG 未完成 Apple Developer ID 签名和公证，系统可能提示来源未验证，请确认文件来自 Zeus 官方发布渠道后手动安装。
- 由于制品尚未签署和公证，应用内自动下载与安装可能不可用，请按上面的 Homebrew 或 DMG 方式手动升级。

公开 Release 只有在固定候选提交 `25ad137fe9f50e8e4552789644005268905a2671` 通过源码检查、候选构建与发布清单校验后才会创建。门禁要求：

- 候选提交等于 `origin/main`，且目标标签 `v0.3.137` 与根包及桌面包版本一致。
- CI 检查在该提交上完成且通过。
- 发布清单来源为 `imchenway/zeus`、渠道为 `stable`，且其中每个制品的下载地址均指向该仓库对应标签的发布资产。
