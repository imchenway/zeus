# Zeus 0.3.138 更新内容

## Git 工作台与源码更改面板重构

Git 相关工作区进行了整体调整，导航与右侧工作面拆分为独立区域，仓库、分支和文件状态的呈现更清晰：

- 分支选择器集中展示最近、本地、远程分支和标签，支持按分支、操作和仓库搜索。
- 源码更改面板支持树状与平铺两种文件视图，并可对更改文件进行筛选。
- 更改文件按冲突、更改、未版本控制的文件分组展示，仓库以颜色标识区分。
- 更改与提交操作可以直接在源码更改面板中完成，无需切换到独立的 Git 标签页。

## 提交与推送体验改进

提交选择和提交说明的交互进行了重做：

- 可以在更改列表中勾选要提交的文件或整个目录，选择独立于 Git 暂存区，仅在提交时暂存所选文件。
- 支持在多个仓库之间选择并批量提交所选文件，提交时会校验分支和 HEAD 是否与选择时一致。
- 提交说明支持由 AI 根据勾选的文件生成，过程中可随时停止。
- 支持提交后直接推送，推送对话框可按仓库选择本地分支和远程目标、设置上游跟踪、推送标签，以及仅当远端未被他人更新时强制推送。

## Git 操作与冲突处理

常用 Git 操作补齐了确认与反馈：

- 更新项目支持合并、变基、重置三种方式，重置到远端前会提示将丢弃的本地提交数量并要求确认。
- 新建并签出分支、签出远程分支、切换到标签或提交都可以在对话框中指定起点和名称。
- 签出、合并、变基、拉取等操作产生冲突时会给出提示，并引导打开冲突文件处理。
- 贮藏面板可以查看、应用仓库中的贮藏，并在提交标签页中对当前仓库执行贮藏。

## 会话与通知修复

- 修复继续对话时的报错问题。
- 修复创建会话时可能出现的卡顿。
- 批注消息发出后样式保持一致，不再发生变化。
- 错误消息现在允许选择并复制文本。
- Git 工具栏的仓库与分支展示做了简化处理。
- Pi 对话为工具进程启动的受管命令进程结束运行后，不再发送“运行已结束”系统通知。

## 如何升级

本次发布提供 Homebrew 与版本化 DMG 两种升级方式。当前公开制品未经过公证，仅支持手动升级，应用内自动更新暂不可用。

使用 Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

使用版本化 DMG 手动升级：下载 `Zeus-0.3.138-arm64.dmg`，打开后将 Zeus 拖入“应用程序”覆盖旧版本。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品为手动升级方式，未经过公证，应用内自动安装不可用。
- 多仓库提交会逐个执行；若某个仓库提交失败，剩余仓库的选择和提交说明会保留，便于稍后继续。

公开 Release 只有在固定的候选构建通过以下门禁检查后才会创建：
