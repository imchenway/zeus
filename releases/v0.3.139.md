# Zeus 0.3.139 更新内容

## 模型启用改为在供应商中统一勾选

模型供应商设置里的模型列表现在区分“候选模型”与“已启用”。从服务获取模型只会刷新候选池：新发现的模型默认处于停用状态，需要你在“启用模型”下拉中显式勾选才会启用，取消勾选即停用。每个模型卡片会用“已启用 / 候选”标记当前状态，取消勾选不会改动该模型已配置的请求格式、认证方式等信息。

同步候选池时，界面会给出发现、新增和移除的模型数量，分类说明新模型默认未启用。候选池按服务返回的模型列表同步，服务不再返回的模型会从候选池移除；已存在的模型继续保留原有启用状态和手动配置。

## 项目级模型选择已移除

不再有“项目可用模型”这一层配置：模型白名单、项目默认模型以及新项目的默认模型引用都已取消。供应商中启用的模型在该账号下全局可用，不再按项目限制范围。项目设置中的原“可用模型”入口已替换为“上下文容量”，用于设置该项目后续新会话默认使用的上下文容量。

提交信息生成、会话能力查询、任务运行等入口不再读取项目级默认模型，改为沿用全局默认模型或最近一次记住的选择：提交信息生成未记住模型时会退回第一个可用模型。已有项目配置中的项目默认模型字段会被忽略，按全局默认处理。

## 会话消息顺序更稳定

会话消息排序在缺少服务端持久位置时不再把条目排到有位置的回复之前。缺失位置的条目会按候选顺序保留原位，开场输入不会沉底；冷加载场景也会核对本次快照中的条目是否缺少整数位置并触发位置补齐，减少会话打开时的顺序跳变。

## 如何升级

Homebrew 用户可执行：

```sh
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载版本化安装包 `Zeus-0.3.139-arm64.dmg`，打开后按提示完成升级。当前公开制品为未公证版本时，应用内自动安装不可用，请使用上述手动方式。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 升级不会自动删除已有项目配置；其中原有的项目默认模型设置不再生效，模型以供应商中启用状态为准。
- 从服务获取模型会同步候选池并移除服务不再返回的模型，启用状态以你在下拉中的勾选为准。
- 当前制品未公证，首次打开可能需要在系统设置中允许运行；应用内自动安装不可用，请手动升级。

## 发布验证

公开 Release 只有在固定候选版本通过以下门禁后才会创建：

- 依赖安装、类型检查、构建与桌面包打包完成；
- 打包产物按目标版本命名，并与候选提交一致；
- 发布前完成签名与公证检查（在具备相应凭据的环境中）。
