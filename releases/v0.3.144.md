# Zeus 0.3.144 更新内容

## 会话费用显示更完整

- Codex 用量中此前缺少价格的记录会自动补齐估算：后台会获取官方公开价格，并对缺价的历史记录按补价时的价格估算。已记账的价格不会被覆盖。
- 当汇总中包含这类补算记录时，用量浮窗会明确提示“含历史补算：按补价时价格估算”，避免与原始记账价格混淆。
- 只对能精确匹配到官方定价表的模型补算，未收录的模型及第三方供应源不会套用官方费率，仍保持费用未知。

## 会话终端的工作目录更贴合当前会话

- 在会话中新建终端时，工作目录改为由后台根据当前会话解析，会正确落在该会话的任务工作区或隔离工作树上，而不是回退到项目主目录。
- 终端启动与确认绑定同一会话，跨会话复用的确认不会被接受；若会话工作目录不可用，会提示检查任务工作区后重试。

## 终端分隔条与宽度调整更顺手

- 右侧终端的最大宽度上限与拖动逻辑对齐，不再被样式限制在一半宽度。
- 分隔条的拖动命中区域完整位于面板内，不再被裁掉；悬停或键盘聚焦时整条边界都会清晰显示可拖动位置。

## 如何升级

推荐使用 Homebrew：

```
brew upgrade --cask imchenway/tap/zeus
```

也可手动下载版本化 DMG 安装包升级：

- `Zeus-0.3.144-arm64.dmg`

当前公开制品为手动升级方式，暂不提供应用内自动安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 自动补价仅使用官方公开定价页面，不会读取会话内容或账号凭据；官方价格暂不可读或格式变化时会保留费用未知并稍后重试。
- 历史补算是按补价时公开价格做的估算，不代表当时实际账单价格。
- 会话工作目录不可用（例如工作区被移动或删除）时，终端会停止启动并提示检查。
