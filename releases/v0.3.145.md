# Zeus 0.3.145 更新内容

## 会话过程中的显示更清晰

- 正在进行的轮次现在会在过程入口上方固定展示最新进展和当前动作，历史操作默认收起，需要时再展开查看。
- 过程入口会显示已加载的操作数量（例如“5 项操作”），折叠状态下也能了解信息规模。
- 无副作用的失败命令会以异常项直接指出，不再被普通成功样式淹没；混合操作组会同时保留总量和失败对象。
- 操作摘要按真实结构化动作计数，例如“读取 2 个文件 · 运行 3 条命令”，不再把不同规模都写成同一句话。
- 终端输出改用实际字符网格计算可见行列数，输入命令后光标位置更稳定。

## 用量与费用信息

- 费用改为按供应商原币展示最近一次读取的价格估算，覆盖部分模型时会标注“（部分）”；无法估算时回退到原有美元口径。
- Codex 用量图表新增“统计来源”下拉，可在“Zeus 本地统计”和“Codex 账户统计”之间切换。账户统计显示官方在所有客户端的每日 Token，官方未提供每日费用。
- 菜单栏用量浮窗中的费用指标旁边新增可点击的“!”明细入口，展示每个模型的单价与消耗 Token；浮层支持悬停、点击固定和键盘焦点，空间不足时会自动翻转位置。

## 模型连接支持整页价格清单

- 模型连接配置新增“价格清单页面”字段，只需提供一个页面地址，即可自动匹配该页面中的全部模型价格。
- 页面读取使用无登录凭据的临时沙箱，不占用你的浏览器会话标签页，也不会把连接密钥发往价格页面；公开价估算不包含私人折扣。
- 读取结果会显示已匹配的模型数量、上次读取时间和价格明细，失败时保留最近一次有效价格。
- 内置供应商（如 DeepSeek、Kimi、Z.ai、阿里百炼）的价格页面由 Zeus 维护来源，自动解析公开标准价格；无法确认的档位（如节假日例外、缓存写入 TTL）保持未知，不以猜测填充。

## 桌面控制（Computer Use）更贴合后台应用

- 文字输入与粘贴现在必须绑定最新一次观察到的可编辑控件，不再依赖前台焦点猜测，后台应用也能稳定输入。
- 用户操作受控应用时临时让出控制，操作其他应用不受影响；让出后需要重新观察，旧动作不会自动重放。
- 锁屏不再直接结束本轮控制；像素采集不可用时仍保留辅助功能观察和定向输入。
- 采集停止原因尚不明确时会阻止旧动作继续，避免误发输入。

## 其他改进

- Pi 会话在 Zeus 中交付本地文件或图片时会遵循一致的交付约定：文件使用 Markdown 链接，图片使用 Markdown 图片语法，网页优先使用 Zeus 内置浏览器。
- 文件与图片资源在实时事件和重新打开会话时读取同一份落盘结果，资源展示保持一致。

## 如何升级

Homebrew 用户：

```
brew upgrade --cask imchenway/tap/zeus
```

也可以从下载页获取 `Zeus-0.3.145-arm64.dmg`，打开后手动将 Zeus 拖入“应用程序”完成升级。当前公开制品为 ad-hoc 签名且未公证，因此请使用上述手动方式升级，暂不支持应用内自动安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 首次使用桌面控制需要授予“屏幕录制”和“辅助功能”权限。
- 价格清单页面只接受无凭据的 HTTP 或 HTTPS 地址；公开价估算可能不包含私人折扣或促销档位。
- Codex 账户统计只提供 Token，不提供每日费用；费用仍以 Zeus 本地账本按模型单价估算。
- 内置价格页面依赖供应商官网结构，官网改版后部分模型价格可能暂时标记为未知。

## 发布验证

公开 Release 只有在固定候选提交通过以下门禁后才会创建：lint、typecheck、build、`git diff --check`，以及针对用量计价、性能跟踪与制品存储行为的验证脚本。桌面交互与签名、公证结果以对应门禁输出为准；任一环节未通过时不会生成公开发布。
