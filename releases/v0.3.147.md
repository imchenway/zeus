# Zeus 0.3.147 更新内容

## Codex 更新过程更透明

- 在模型设置中更新 Codex 时，界面会显示当前所处的阶段，例如正在检查最新版本、正在准备更新、正在下载 Codex、正在安装 Codex、正在校验安装结果、正在切换运行实例、更新完成。
- 下载阶段会显示来自真实下载字节数的百分比进度；只有在下载器返回真实总量时才显示具体百分比，其余阶段以不确定进度条表示，不按时间伪造推进。
- 进度信息来自本机 Core 上报的真实更新阶段，界面不会自行估算或推演进度。

## 更新请求改为串行处理

- 手动更新与自动更新共用同一条串行处理链，后到的更新请求会等待前一轮完成后重新检测是否仍需更新，避免并发更新互相干扰。
- 当检测结果显示已是最新版本时，仍会直接返回结果，不会因周期检测而重建正在运行的 Codex 实例。
- 只有实际完成更新或回放已完成的更新后，才会切换到新的运行实例。

## 已知体验说明

- 更新进度仅在下载阶段可能给出具体百分比；其他阶段显示为不确定进度，这是有意设计，用于避免展示不真实的数字。

## 如何升级

- 通过 Homebrew 升级：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 也可以手动下载版本化安装包 `Zeus-0.3.147-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成升级。
- 当前公开制品为 ad-hoc 签名且未公证，应用内自动安装不可用，请使用上述手动方式升级。

## 系统要求与已知限制

- 系统要求：macOS 13.0 及以上。
- 本版本提供 arm64 安装包 `Zeus-0.3.147-arm64.dmg`。
- 当前公开制品为 ad-hoc 签名且未公证，首次打开可能需要按系统提示确认；应用内自动安装不可用，升级需手动完成。
- 更新进度中的百分比只在下载器返回真实总量时出现，其他阶段可能仅显示阶段文案与不确定进度条。

## 发布验证

公开 Release 只有在固定候选提交通过以下门禁检查后才会创建：

- 类型检查通过。
- 代码检查（lint）通过。
- 构建与打包成功，并产出与版本号一致的制品。
- 桌面端启动与关键交互冒烟检查通过。
- 制品签名与公证状态按发布配置确认，未公证时按手动升级方式对外说明。

只有在上述检查全部通过后，才会创建对应的公开 Release；任一检查未通过都不会生成公开发布。
