# Zeus 0.3.148 更新内容

## Codex 在线升级更可靠

- 更新 Codex 时，Zeus 会在同一个更新窗口内完成旧运行进程的退出与新版本接管，避免出现“磁盘已更新、实际仍在跑旧程序”的情况。
- 更新完成后会校验当前运行进程的版本是否与磁盘上的版本一致；不一致时不会把本次更新标记为完成。
- 升级后会自动重新读取模型目录，模型选择器会同步到新版本的模型列表。
- 如果检测到远程接管守护进程仍在运行旧程序，即使磁盘已是最新版本，也会自动完成一次接管刷新。

## 更新期间的任务保护

- 更新过程中会先等待正在进行的 Codex 任务、写入和授权请求收口；仍有任务在处理时会提示完成后再更新，不会强行中断。
- 更新进行期间新的 Codex 写入请求会被拒绝，已有查询仍可正常返回。
- 远程接管模式下会先有序关闭旧守护进程再启动新进程，避免旧连接在断开后自动重连并再次拉起旧程序。

## 如何升级

方式一：使用 Homebrew 升级

```bash
brew upgrade --cask imchenway/tap/zeus
```

方式二：手动安装版本化 DMG

下载 `Zeus-0.3.148-arm64.dmg`，打开后按提示将 Zeus 拖入“应用程序”完成覆盖安装。

> 当前公开制品为 ad-hoc 签名、未公证构建，应用内自动安装不可用，请使用上述手动方式升级。

## 系统要求与已知限制

- 支持 macOS 13.0 及以上版本。
- 当前制品为 ad-hoc 签名且未公证，首次打开可能需要在“系统设置 → 隐私与安全性”中手动允许。
- 应用内自动安装升级不可用，请通过 Homebrew 或版本化 DMG 手动升级。
- Codex 在线更新在存在进行中的任务、写入或授权请求时会被推迟或拒绝，需要任务结束后重试。

## 发布验证

公开 Release 只在固定候选提交通过以下检查后才会被创建：

- 代码检查（lint）与类型检查（typecheck）通过。
- 构建与桌面打包成功，并产出对应版本的安装包。
- 桌面端可正常启动并完成基本交互检查。
- 签名与公证检查按项目发布要求通过。
- 发布制品与候选提交一致，版本号与目标版本匹配。

以上检查全部通过后，才会创建公开 Release 并同步分发渠道。
