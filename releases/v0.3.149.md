# Zeus 0.3.149 更新内容

## 任务状态与优先级下拉不再受其他任务操作牵连

在任务列表中，当某个任务正在进行保存、批量操作等会占用共享忙碌状态的操作时，其他任务的状态下拉和优先级下拉可能也会被置灰、无法点击。本次调整后，任务状态和优先级下拉只会在该单元格自身不可编辑或正在保存时禁用，不再因为其他任务或批量操作正在进行而整体变灰，日常连续修改多个任务时更顺手。

## 如何升级

- 使用 Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- 或者从公开 Release 下载版本化 DMG（`Zeus-0.3.149-arm64.dmg`），退出当前应用后手动拖入「应用程序」完成替换。

## 系统要求与已知限制

- 支持 macOS 13.0 及以上版本。
- 当前公开制品为 ad-hoc 签名且未公证，首次打开可能需要在「系统设置 → 隐私与安全性」中允许，或右键选择「打开」；此情况下不支持应用内自动安装升级。

## 发布验证

公开 Release 只有在锁定的候选版本通过以下检查后才会创建：lint、typecheck、单元/集成测试、桌面端构建与打包均通过，并完成版本化 DMG 的产物校验。发布门禁全部通过前不会创建公开 Release，本版本按上述条件执行。
