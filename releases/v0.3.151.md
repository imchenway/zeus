# Zeus 0.3.151 更新内容

## 数字团队工作流入口更准确

任务详情里的“数字团队”入口现在会直接列出当前项目中已保存的工作流，以及该任务已有的运行记录，不再只是一个通用按钮。

- 选择某个工作流后，会进入数字团队页面并直接定位到对应流程；如果任务尚未结束且没有未完成的运行，还会直接弹出启动该流程的入口。
- 选择某条运行记录后，会直接打开该运行的详情。
- 运行记录会显示简短状态，例如 CTO 规划中、等待规划批准、员工执行中、正在集成候选、正在验证候选、CTO 汇总中、等待最终验收、已完成、失败、结果待核对、已取消。
- 任务已经结束、存在未结束的运行、或工作流配置尚不完整时，相关选项会被禁用并给出原因。
- 如果工作流和运行读取失败，入口右侧会提供“重新读取”，无需离开任务详情。

## 会话过程展示更稳定

- 处理过程与助手正文的归类更稳定：助手消息从创建起就固定在正文位置，不会因为首个文字分片到达而在处理过程与正文之间跳动。
- 用户消息与会话过程的位置关系更可靠，尽量沿用开场输入身份固定位置，减少实时消费、补页或重连后条目顺序的视觉跳位。
- 处理过程展开后，内部操作明细不再形成“列表套列表”的额外缩进，层级更扁平。
- 只有本轮真实新增的操作条目会播放一次入场动画；折叠时不提前构造长输出内容，历史回放和普通重渲染不会重复播放。
- 在系统设置中启用“减少动态效果”时，新增条目的入场动画会被关闭。

## 如何升级

- 通过 Homebrew 顶 Tap：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载 `Zeus-0.3.151-arm64.dmg`，打开后把 Zeus 拖入“应用程序”完成替换。

## 系统要求与已知限制

- 支持 macOS 13.0 及以上版本。
- 当前公开制品仍为未公证材料，升级需要按上面的方式手动完成，应用内自动安装可能不可用。
- 数字团队入口依赖工作流与运行数据的读取；读取失败时会提示并可重试，但如果项目尚未配置任何工作流，入口中不会出现可启动的流程。
- 任务已有未结束的运行、或任务已结束时，只能查看已有运行，不能从该入口启动新的工作流。

## 发布验证

公开 Release 只会基于固定候选通过以下检查后创建：

- lint 与 typecheck 通过。
- 桌面端构建与打包成功，产出 `Zeus-0.3.151-arm64.dmg`。
- 版本号与发布目标 0.3.151 一致。
- 签名与公证检查按当前发布流程执行，未公证制品只能走手动升级路径。
