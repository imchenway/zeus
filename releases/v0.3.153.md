# Zeus 0.3.153 更新内容

## 计划模式更清晰

计划模式现在只做只读分析，不会改动你的项目，也不会改写你保存的权限偏好。

- 进入计划模式后，权限入口会明确显示这是本轮的临时只读覆盖，实施后恢复你原本的权限设置。
- 计划模式下会持续说明当前状态：是在继续规划，还是已经形成待确认的正式计划。
- 只有对某一份正式计划做出明确确认后才会进入实施；普通对话里的“开始”不会被当作实施授权。

## 排队消息集中到输入框上方

仍在等待发送的消息现在统一显示在输入框上方，不再散落在会话正文底部。

- 每条排队消息支持编辑正文、删除、引导到当前回复、上移和下移。
- 编辑排队消息时会保留原附件不变，纯附件消息不再显示为空白。
- 引导只在队首且当前回复可接受引导时可用，不可用时仍可见并说明原因。
- 已进入模型处理的或状态未知的消息仍由原有状态入口承载，不会混进可排序的排队卡片。

## 网络设置与连接检查

新增独立的网络设置分区，可集中配置代理并检查连接。

- 连接检查会分别给出浏览器通道和直连通道的结果，并显示相应延迟。
- 设置页不再因底层操作长时间无响应而永久等待：代理切换、连接检查和连接清理都有明确的超时上限。
- 每次检查使用独立会话，多次检查互不干扰；不会沿用浏览器登录信息。

## 其他改进

- 文件预览工具栏改为图标入口，悬浮时显示功能名称，操作更紧凑。
- 回复流中断但已收到回答时，会提示“回答已保留”，而不是误报为没有收到完整回复。
- 恢复连接时会显示明确的尝试计数。
- 定时任务与任务推送相关行为更稳定，提示词不再混入会话消息底部。
- 数字团队工作流可直接拖入现有数字员工分工，并填写完成标准与预期交付物；分支前缀可在设置中自定义。
- 合并来源分支时，来源分支存在未提交代码不再直接阻止合并。
- Computer Use 通过后台打开应用时，不会每次都把新窗口切到最前并抢占焦点。

## 如何升级

使用 Homebrew 安装的用户：

```sh
brew upgrade --cask imchenway/tap/zeus
```

手动升级：

1. 下载版本化安装包 `Zeus-0.3.153-arm64.dmg`。
2. 打开 DMG，将 Zeus 拖入“应用程序”覆盖旧版本。
3. 从“应用程序”启动新版本。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 当前公开制品采用 ad-hoc 签名、尚未公证，因此需要按上述方式手动升级；应用内自动安装可能不可用。
- 网络连接检查会向所选地址发起请求，请确保该地址可从你的网络访问。
- 计划模式对当前轮次只施加临时只读上限，不会永久更改你保存的权限偏好。
