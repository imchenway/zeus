# Zeus 0.3.154 更新内容

本次更新聚焦 Computer Use 后台启动体验、会话过程展开的阅读稳定性、费用文案与菜单栏用量浮窗，以及任务详情页布局。

## Computer Use 打开应用时不再抢占桌面

- 当 Computer Use 需要打开一个尚未运行的应用时，应用会先在隐藏状态下完成冷启动，随后再恢复到后台，不覆盖你当前正在使用的桌面。
- 如果你在启动期间切换了前台应用，Zeus 会跟随你最新的前台应用进行恢复，而不是回到最初的应用。
- 如果目标应用无法创建可控制窗口，或拒绝保持在后台显示，Zeus 会重新隐藏它并返回明确失败，而不把窗口留在最上层；此类应用可能需要你手动打开后再继续控制。
- 同一路径已有实例时会复用，避免重复打开同一个应用。

## 会话处理过程展开时保持阅读位置

- 在对话记录中展开或收起某轮的处理过程时，你点击的那一行会尽量保持原位，内容在其下方展开，不再把入口推动到别处。
- 展开过程会进入静态阅读状态；即使新内容继续到来，也不会突然把你拉回底部，需要时可回到最新内容。
- 已完成过程在入口处显示操作数量，运行中的过程继续展示实时进展；最终回答区保留复制等操作入口。

## 费用文案与菜单栏用量浮窗调整

- 会话运行详情与菜单栏用量中的“估算费用”“估算不完整”等文案统一改为“费用”“费用不完整”；美元沿用 `$` 形式，其他币种保留货币代码并使用波浪号表示估算属性。
- 菜单栏用量浮窗在展开费用明细时会临时加宽透明宿主，明细可以越过菜单栏主体边缘显示；关闭后恢复菜单栏宽度。
- 费用明细按 Token 消耗从大到小排序，消耗相同的分组按模型名稳定排列；模型名与结果列按内容自适应，减少空白和换行。
- 浮窗打开位置改为跟随鼠标左下方，并保留与热点之间的间距，避免遮住你刚点击的位置。

## 任务详情页布局

- 任务详情页中，要求面板获得更稳定的阅读宽度，沟通与成果区域保留主要工作空间。
- 状态、执行人与数字团队合并到同一行展示，宽度不足时自然换行，不再让数字团队单独占用整行。
- 首次讨论引导保持在可用空间中央，输入框固定在内容区底部。

## 如何升级

Homebrew：

```sh
brew upgrade --cask imchenway/tap/zeus
```

手动升级：下载 `Zeus-0.3.154-arm64.dmg` 并拖入 Applications 覆盖旧版本。当前公开制品为 ad-hoc、未公证，应用内自动安装不可用，请使用上述手动方式升级。

## 系统要求与已知限制

- 最低系统版本要求：macOS 13.0。
- 公开制品为 arm64 的 ad-hoc、未公证构建；应用内自动安装不可用，需要手动升级。
- Computer Use 需要相应权限，权限在设置中配置；权限缺失时可前往设置处理。
- Computer Use 无法控制没有可见可捕获窗口的目标应用；后台启动失败时目标保持隐藏，需要手动打开后再继续控制。
- 完全拒绝后台显示的应用可能无法通过 Computer Use 自动打开，可能需要在失败后手动打开。
