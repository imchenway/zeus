# Zeus 0.3.155 更新内容

## 计算机操作更稳定

- 冷启动外部应用时不再需要把应用隐藏起来等待窗口就绪，应用窗口会在后台完成创建，避免遮挡你当前的桌面。
- 当目标应用在操作后弹出新的独立窗口或对话框时，Zeus 会先提示你重新选择要控制的目标窗口，而不是继续在旧窗口上盲目操作。
- 屏幕上的内部浮层、工具提示、截图角标等不会被误认为可独立控制的新窗口，减少误判。
- 滚动操作在到达页面边界时会正确停止，不再重复投递多余的滚动次数。
- 元素变化检测不再因为同级元素位置移动而把整段内容都算作“已变化”，查看处理过程时看到的差异更贴近真实改动。

## 数字团队配置更统一

- 团队工作流中的员工节点现在直接读取项目数字员工配置，不再维护一份可能过期的节点级副本。
- 在团队画布中也可以直接编辑数字员工，保存后其他入口立即使用同一份配置。
- 已停用的数字员工不能作为新节点绑定，但仍保留在既有节点中以便你重新配置。
- 员工节点在画布和上游连线选择中统一显示员工名称，不再显示历史节点标题。

## 会话与界面细节优化

- 图片预览改为以文件名为主标题、类型作为辅助说明，并优化了透明区域的棋盘格展示与弹窗阴影。
- 计划模式与权限模式分离：计划模式只表达“正在规划”，权限入口始终显示你实际选择的权限，不再叠加只读覆盖提示。
- 会话排队消息在服务端身份确认前不会提供编辑、引导、删除和排序操作，避免对尚未落地的本地投影做修改。
- 归档会话的加载、恢复和归档失败会在归档列表处就地显示并支持重试，不再打断整个工作面。
- 空的本地 Git 仓库在创建新会话工作树时会展示当前分支作为来源，并说明当前项目文件会被带入工作树。
- 费用悬浮窗的费用明细改为独立窗口，支持悬停跨越两个窗口、点击外部或按 Escape 关闭；菜单栏主体宽度保持固定，仅高度随内容收缩。

## 浏览器工具等待更准确

- 等待元素时可以指定等待状态（attached、visible、hidden、detached、enabled）和期望文本，避免仅存在于 DOM 中就被判定为完成。
- 等待超时时会返回最后一次观察到的状态，便于排查页面实际进度。

## 如何升级

- Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- 手动升级：下载 `Zeus-0.3.155-arm64.dmg`，打开后将 Zeus 拖入“应用程序”替换旧版本。
- 当前公开制品为 ad-hoc、未公证，应用内自动安装可能不可用，请使用以上方式手动升级。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- 当前公开制品未经过公证，首次打开可能需要在“系统设置 → 隐私与安全性”中允许，或右键选择“打开”。
- 应用内自动更新与自动安装可能不可用，请使用 Homebrew 或 DMG 手动升级。
- 计算机操作中的屏幕录制与辅助功能权限仍需在系统设置中授权。

## 发布验证

公开 Release 只在固定候选提交满足以下门禁后才创建：

- 渲染进程事件流校验通过。
- 桌面端类型检查与构建通过。
- 打包后的应用在签名与公证流程中满足对应要求。
- 公证后的 DMG 与 Homebrew cask 产物与候选提交一致。

以上条件全部满足后，才会创建公开 Release 并同步 Homebrew Tap。
