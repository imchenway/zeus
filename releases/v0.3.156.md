# Zeus 0.3.156 更新内容

## 屏幕控制不再抢占前台

- 当 Zeus 需要打开某个应用进行屏幕控制时，应用会在后台显示窗口，不再把目标窗口直接压到当前桌面之上。
- 在你正使用目标应用的其他窗口时，Zeus 会让出输入，等窗口空闲后再继续，不会和你抢键盘鼠标。
- 解锁屏幕或从休眠唤醒后，需要重新观察窗口才能继续控制，避免在不可见状态下继续操作。
- 目标应用创建窗口超时或拒绝后台显示时，会被安全隐藏并给出说明，不会把窗口留在最上层。

## 会话与处理过程展示更清晰

- 修复会话消息错位的问题，消息顺序和归属更可靠。
- 处理过程的展开内容重新分层折叠，查看中间步骤时更容易聚焦当前环节。
- 会话状态更明确地区分“进行中”和“已结束”，减少对会话是否还在运行的困惑。
- 你给出的回答在对话中保持直接可见，不会再被后续内容盖住。

## Codex 与计划模式

- 改善 Codex 发生全链路故障时的处理，减少卡死或状态不一致。
- Codex 的线程计划模式在同步后保持一致。
- 点击“推送到模型”后不再长时间停在等待界面。

## 其他修复

- 修复 Zeus 自身的应用图标丢失问题。
- 修复纵向打开的终端显示异常。
- 修复计划书边缘不可见的问题。
- 费用悬浮窗内部做了优化。
- 避免把普通 Skill 目录内容错误追加到用户正文。

## 如何升级

方式一，使用 Homebrew：

```
brew upgrade --cask imchenway/tap/zeus
```

方式二，手动下载安装包 `Zeus-0.3.156-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成升级。当前公开制品为手工分发的未公证版本，升级需要按上述方式手动完成，应用内自动安装尚不可用。

## 系统要求与已知限制

- 系统要求：macOS 13.0 及以上。
- 屏幕控制需要授予辅助功能与屏幕录制权限；缺少权限时相关动作无法执行。
- 解锁、休眠唤醒或窗口变化后需要重新观察目标窗口才能继续控制。
- 密码等安全文本字段的已有内容不会被读取。
- 当前制品未公证，系统可能提示来源不明，需要手动确认。
