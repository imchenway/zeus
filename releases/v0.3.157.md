# Zeus 0.3.157 更新内容

## 数字员工新增流程调整

- 数字员工页面的“新增”入口现在先让你选择创建方式：从内置模板开始，或从空白配置自己新建。
- 从模板创建后，生成的是一名独立的数字员工，与模板不再保持关联；后续可以自由编辑名称、岗位、业务领域、说明、模型、Skill 和提示词等配置。
- 内置模板不再出现在数字员工列表中，列表只展示你自己创建的数字员工；删除数字员工时，已经添加到项目的员工配置不会被删除。

## 终端会话显示与回放改进

- 纵向打开终端时，Shell 首屏会按终端的实际字符尺寸启动，减少提示符先按默认尺寸绘制再被重排的情况。
- 终端冷回放会按输出产生时的尺寸还原文本与换行位置，重新打开终端或切换标签时更接近原始输出效果。
- 标签切换会记住每个会话最近一次的实际终端尺寸，不会回退到默认尺寸。
- 排队消息编辑去掉了冗余的编辑标题栏，输入区域更完整，操作按钮位于输入框内右下角。

## 菜单栏用量窗口稳定性

- 菜单栏用量窗口在读取本地缓存时，会校验当前渲染所需的字段结构；旧版本缓存缺少必要字段时会等待实时数据，避免整个菜单栏用量页面崩溃。

## 如何升级

- Homebrew：

  ```
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载 `Zeus-0.3.157-arm64.dmg`，打开后将 Zeus 拖入应用程序文件夹完成替换。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本；当前公开制品为 arm64。
- 终端尺寸、冷回放和会话标签的记忆依赖会话数据；在输出被截断的情况下，终端会从当时已知的尺寸继续解释后续内容，极早之前的画面可能无法完整还原。
- 当前公开制品若仍为 ad-hoc、未公证分发，则只能按上述 DMG 方式手动升级，应用内自动安装升级可能不可用。

## 发布验证

公开 Release 只有在固定候选通过以下门禁后才会创建：

- 候选提交的类型检查、构建与打包检查通过。
- 桌面应用在 macOS 13.0 及以上环境可正常启动，数字员工新增与终端相关交互可用。
- 产物命名与目标版本一致，并完成发布所需的分发检查。
