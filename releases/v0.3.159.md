# Zeus 0.3.159 更新内容

## 会话与处理过程的阅读体验

- 处理过程的展开入口现在只显示整轮操作总数（例如「5 项操作」），耗时信息移到统一位置，不再和数量挤在同一个按钮里；展开后的阶段分组不再重复显示每段数量，减少了重复层级。
- 处理过程改为按需补页：展开时只读取尚未加载的内容，出现「加载更多过程」「加载更早过程」按钮由你明确点击才继续读取；已读的范围在折叠、重新展开、重新打开会话后保持不变，重复展开不会隐式触发更多读取。
- 多行思考内容不再使用移动扫光，改为在段首显示状态小点，长文本的对比度更稳定；单行摘要仍保留原有扫光效果。启用「减少动态效果」或高对比度时扫光关闭，状态点静态显示。
- 修复了同一条回复在历史分页、实时事件和缓存之间可能被显示成两条正文的问题；不同轮次复用相同条目编号时仍会保留为两条独立输入。

## 会话输入与评论

- 输入框移除「上下文容量」覆盖项，新建会话统一继承项目容量设置。
- 回答上的选区评论入口统一改称为「评论」，出现在鼠标松手位置的右上方；正向和反向跨行选择都会跟随松手点定位，接近会话边界时自动夹紧，不再溢出。
- 待发送评论摘要显示合计条数，鼠标悬停或键盘聚焦时展开只读详情，可查看被选中的原文、代码位置和评论内容；发送后的用户消息中也统一以「评论」名称展示。
- 排队消息在活跃轮次进行中会立即出现在输入框排队卡片里，不需要等待服务端回执。
- 未提交的提问仍会占用底部回答区；已提交或正在等待送达的回答不再占用普通输入区，可继续正常输入。

## 稳定性与设置

- 界面发生错误时，恢复页改为「重新加载窗口」，只重载当前窗口，后台仍在运行的工作不受影响，不再提供退出或重启整个应用的选项。
- Codex 更新在会话仍在进行时不再直接报「忙」：更新进入等待状态，界面显示「等待当前工作安全结束」，等已有轮次、目标和授权自然收口后自动继续；等待期间不会接纳新的写入。
- 修复了后续状态事件省略资源字段时，已展示的图片等会话资源被清空的问题；每日用量数据在官方瞬时缺少时保留最近一次成功结果。
- 菜单栏用量窗口的顶部时间只显示读取时间，过期状态继续以卡片提示表达；来源下拉选择后不再叠加多余焦点描边，浏览器设置中的「批注」文案统一为「评论」。
- 缓存恢复会拒绝包含重复显示身份的旧数据，避免旧窗口遗留状态在首次渲染时触发界面错误。

## 如何升级

- Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- 手动升级：下载 `Zeus-0.3.159-arm64.dmg`，打开后将 Zeus 拖入「应用程序」覆盖安装。当前制品为 ad-hoc 签名、未公证，需手动完成安装，应用内自动安装暂不可用。

## 系统要求与已知限制

- macOS 13.0 及以上，Apple 芯片（arm64）。
- 当前公开制品未公证，首次打开可能需要右键「打开」或在系统设置中允许。
- Codex 运行时代码的在线更新在会话进行中会先等待现有工作结束，等待时间取决于当前轮次长度。
- 处理过程的更早内容需要手动点击补页按钮才会继续读取。

## 发布验证

公开 Release 只在固定候选提交通过以下检查后创建：lint、typecheck、构建、桌面打包均通过；产物完成签名与公证校验（若当前仍为未公证的 ad-hoc 构建，则仅提供手动升级的 DMG）；版本号在根包、桌面包与发布标签之间一致；候选范围内提交的回归探针通过。任一门禁未通过时不会创建公开 Release。
