# Zeus 0.3.16 更新内容

## 任务看板模式

- 任务页新增看板视图，可按项目独立切换列表/看板，支持拖拽移动任务卡片、折叠列、调整卡片尺寸等操作。
- 看板支持按管理状态或自定义字段分组，并可通过设置调整分组、排序、过滤和列颜色。
- 任务详情现在可以以右侧抽屉、居中弹窗或全页三种方式打开，满足不同浏览需求。

## 会话与交互改进

- 消息队列区域会完整展示待发送消息，不再因空间不足而省略内容；阻塞性交互会紧跟当前会话过程，并自动滚动到最新位置。
- 计划模式确认消息得到修正，确认实施或修订后不会因迟到事件回退为可操作状态；等待处理时队列会明确标识为“计划操作”。
- 助手生成的图片等交付资源会作为独立条目保留在会话中，不再折叠进工具过程。
- 回答批注编辑浮层会跟随所选文本锚点出现，并附有原文引用，便于添加评论。

## 更新与系统行为

- 更新窗口不再在后台刷新进度时抢占其他窗口的键盘焦点，只在显式点击检查/提醒时激活。
- 内置浏览器打开资源时，标签和浏览器工作面优先进入可交互状态，页面继续异步加载；加载失败会保留标签并显示错误。
- 命令执行历史弹窗尺寸加大（宽度上限 1320px，高度 720px），日志复制操作改为纯图标按钮，复制成功状态约两秒后恢复。
- 归档会话恢复逻辑加固，对状态漂移进行更可靠的恢复，拒绝无效路径时不会阻断整条会话。

## 其他优化

- 代码交付页支持按文件分组多仓库操作，左侧文件区加宽并增加仓库状态栏。
- 会话用量信息增加“缓存未命中”和“本轮用量”显示，费用估算更清晰。

## 如何升级

推荐通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从版本发布页下载 `Zeus-0.3.16-arm64.dmg` 手动升级。当前公开构建仍是手动升级方式，应用内自动安装暂不可用。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 看板模式为新增功能，可能仍有交互边界问题，请以实际使用为准。
- 归档会话恢复在 Provider 不可用时可能仍会失败，需要稍后重试。
- 更新窗口在辅助进程异常重启后可能不会自动聚焦，需要再次点击更新入口。
