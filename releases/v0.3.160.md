# Zeus 0.3.160 更新内容

## 代码交付页更省空间、更好定位

代码交付页重新排布了仓库、文件与差异区域的侧栏宽度和工具栏，把标题与即时操作收进同一行，减少重复占高，让差异预览获得更多可见区域。文件树采用贴近 IDE 的平面目录与文件类型标记，并将连续的单子目录合并显示；勾选框、审阅焦点与差异工具栏按钮的样式区分更加清晰，便于快速确认改动范围。仓库名称旁的复制分支名改为图标按钮，长分支名更容易识别。冲突与无法合入的提示改为单行摘要，需要时再展开查看原因和文件清单。

## AI 生成提交说明

代码交付页的提交步骤新增“AI 生成”入口，会根据当前勾选的待提交文件生成提交说明，并复用源码提交入口已记住的模型偏好。生成过程可随时“停止生成”，生成结果仍可在提交前手动修改或重新编辑。生成期间会按任务身份读取对应的工作树，只把本次真正可提交的勾选文件交给模型；如果生成过程中任务工作树被回收、切换分支或勾选内容发生变化，旧结果不会写回提交框。

## 独立差异窗口采用系统标题栏

独立打开的差异窗口改用系统标题栏，恢复可发现的拖动、缩放、最小化、最大化与全屏入口，正文不再为拖动区域预留空白，差异内容随窗口正确填充。在任务交付页中，文件身份与差异操作被合并到同一行显示，工具栏不再层层堆叠。

## 已有环境按原有仓库继续工作

继续已有任务环境时，Zeus 只恢复该环境已经登记的仓库，不再因为项目新增仓库而要求先补入。需要在新任务中使用新增仓库时，可以在任务推送界面按需将仓库补入当前环境，补入结果通过重新读取权威成员清单确认。新建环境仍按原有流程使用项目仓库。测试构建的应用图标与运行时 Dock 图标保持一致，便于区分开发与正式版本。

## 如何升级

通过 Homebrew 升级：

```
brew upgrade --cask imchenway/tap/zeus
```

也可以手动升级：下载版本化 DMG `Zeus-0.3.160-arm64.dmg`，打开后把 Zeus 拖入“应用程序”完成替换。当前公开制品未经过公证，应用内自动安装不可用，请使用上述手动方式升级。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本；本版本为 Apple 芯片（arm64）构建。
- 公开制品未经过公证，首次打开可能需要按系统提示在“系统设置”中允许运行。
- 应用内自动安装不可用，请通过 Homebrew 或版本化 DMG 手动升级。
- AI 生成提交说明需要先在设置中配置可用的模型连接；没有可用模型时会提示配置后重试。
- 文件很多时，提交说明可能被省略或截断，生成后会提示核对完整性。
