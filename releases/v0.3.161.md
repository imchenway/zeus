# Zeus 0.3.161 更新内容

## Computer Use 后台控制更安全

- 受控应用的输入改为窗口后台投递，不再把目标窗口抬到最前或抢用你的键盘焦点。
- 当你主动操作受控应用（点击、拖动、滚动或打字）时，Zeus 会自动暂停对该应用的输入，并停止共享；继续操作需要新的指令和重新观察。
- 关闭窗口共享、窗口被关闭或屏幕共享被系统停止时，会立即停止该应用的输入并提示重新观察，旧流程不会自动重放。
- macOS 上的点击使用观察结果中的语义控件（element_token 或 element_index）。无法安全后台执行的像素定位输入、会激活窗口的菜单操作会在派发前拒绝。
- 虚拟光标改为放大的紫色箭头与白色描边，并带有 Zeus 会话标识，按显示器分别绘制，多屏和不同缩放下的位置更可靠。

## 窗口观察与画面一致性

- 成功观察窗口后建立真实的单窗口后台共享流，截图取自已共享的画面，不再额外走单帧或命令行回退。
- 会话预览只显示真实采集到的新帧，并在画面未变化时不重复传输图片，显示的是实际捕获时间。
- 每会话同时只控制一个应用；切换应用会先结束旧共享再重新观察。
- 用于减少冲突和重复图片传输；代价是持续共享会产生额外的系统采集开销，具体性能取决于真实硬件。

## 代码、源码与 Git 页面体验

- Git 页面、源码页面、文件预览与代码对比等界面做了布局和视觉优化，浏览、对比和审阅时信息更清晰。
- 新增按文件类型显示的文件图标，文件预览与外观更易辨认。
- 冲突处理页和任务视图做了布局一致性调整，操作区域更整齐。

## 会话与运行状态

- 异步问答（答题卡）的选项卡行为得到修正，等待回执、结果待确认与已确认等状态在同一目录身份下过渡更准确。
- 加载过程的展示得到优化，运行中会出现常驻的停止入口。
- 应用自身图标恢复显示。

## 如何升级

- 使用 Homebrew：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载版本化磁盘映像并拖入“应用程序”替换旧版本：

  ```
  Zeus-0.3.161-arm64.dmg
  ```

本次公开制品为 ad-hoc 签名、未公证，请使用上述手动方式升级；应用内自动安装不可用。

## 系统要求与已知限制

- macOS 13.0 及以上，Apple 芯片（arm64）。
- 首次启用 Computer Use 需要在系统设置中授予辅助功能和屏幕录制权限；权限缺失或被撤销时相关操作会停止并提示补齐。
- 部分没有辅助功能控件的应用可能无法自动完成操作；这类情况需要你手动处理或改用其他方式。
- 从源码构建需要 Rust/Cargo 才能编译原生控制 worker；首次编译会较慢，后续按补丁与架构复用构建缓存。
- 用户接管某个受控应用后，该应用会暂停后台输入；要继续需给出新指令并重新观察目标窗口。
