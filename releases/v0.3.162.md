# Zeus 0.3.162 更新内容

## 会话过程与命令执行体验优化

- 会话中的“处理过程”入口现在优先显示真实的操作数量（例如“3 项操作”），并且数量文案在展开、收起或重新打开后保持不变，方便快速判断这一段过程包含多少操作。
- 展开处理过程时不再自动打开其中的操作列表，也不会自动加载命令输出或图片；每一段操作都需要用户单独展开，重复展开和收起仍保持消息顺序、分组身份与数量不变。
- 加载更多历史过程改为显式操作：只有用户主动点击“加载更多过程”才会继续读取，展开或重新挂载已读内容不会隐式补页，读取失败时提供“重试加载”。
- 命令执行记录的布局经过调整，历史记录列表与终端详情各自独立滚动，并保持固定的窗口高度。选中记录改用与全局一致的中性底色，不再使用侧边色条；运行状态固定在详情标题旁展示，运行中的命令继续提供“停止”按钮。

## 命令行产物与日志导出改进

- 命令执行的终端工具栏新增操作入口：“复制日志”可复制完整日志内容；“导出日志”可分别导出原始日志和整理日志；“输出文件”用于下载命令生成的普通文件，入口会显示文件数量。
- 导出按下拉菜单组织，菜单在终端上方打开，不占用终端正文高度；导出过程中按钮会显示进行状态，失败时在菜单内提示“导出失败，请重试。”
- 命令运行失败时，失败原因改为终端内的可折叠提示：默认显示单行摘要，展开后可查看完整内容，不必再回到日志之外单独寻找。
- 终端正文可以继续独立滚动，继续沿用尾部跟随与上滚暂停跟随的交互，并支持键盘聚焦。

## 界面细节与选择状态统一

- 列表类界面的选中态（会话、项目、设置、数字员工、冲突文件、源码预览等）统一使用中性底色，不再依赖侧边色条或强调色，深色与跟随系统深色时同样如此。
- 数字团队节点、任务看板卡片、自动化收件箱等处的强调色边条被移除；未读结果改用标题加粗区分，拖放指示线改为中性色，冲突文件与文件树的图标和路径排布更紧凑，长路径会在剩余宽度内省略。
- 会话中的“文件更改”摘要使用稳定的“文件更改”标题，并在标题旁以次级文字标明“已撤销”“不可撤销”等状态；文件数量、增删统计和展开更多文件的操作集中在标题右侧，展开按钮改为轻量箭头。
- 命令与外层过程的展开箭头方向统一：收起时指向右侧，展开后指向下方。

## 如何升级

通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从公开发布页面下载版本化 DMG 手动安装：`Zeus-0.3.162-arm64.dmg`。

当前公开制品仍为 ad-hoc 构建且未经过公证，应用内自动更新尚不可用，请使用上述手动方式升级。

## 系统要求与已知限制

- macOS 最低版本要求为 13.0。
- 当前公开制品为 ad-hoc 构建且未经过公证，首次打开可能需要手动允许；应用内自动安装更新不可用，需要手动升级。
- 处理过程与命令详情默认收起，需要逐段手动展开；已读历史过程不会自动补页，需要点击“加载更多过程”。
- 版本号信息：候选提交为 640dd932，构建配置的系统最低版本为 13.0。

## 发布验证

公开 Release 只有在固定候选提交通过仓库既有的发布门禁后才会创建；这些检查在发布工作流中执行，包括：

- `pnpm verify:publish` 所定义的与本地一致的发布前检查；
- `pnpm verify:release` 所定义的正式产物校验；
- 对 CUA 原生编译成品先做工具链摘要与来源预检，只有精确命中且通过来源预检的成品才会被复用或缓存；未精确命中的成品会被清理，不会参与复用。

正式产物在该候选提交通过上述检查后才会被上传并创建公开 Release。
