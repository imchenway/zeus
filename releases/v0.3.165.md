# Zeus 0.3.165 更新内容

## 附件粘贴与导入反馈

- 在会话输入框、任务创建、任务详情和补充说明等位置粘贴文件或截图时，会先在输入框中显示待导入的卡片，再等待宿主完成授权与保存，不再出现长时间的空白等待。
- 导入中的卡片会标明“正在导入”，此时不能打开、移除或恢复；导入完成后，图片类型可继续使用本地缩略图预览，无需再次读取同一文件。
- 从剪贴板同时粘贴“文件路径加说明文字”时，已识别为附件的路径会从文本中移除，其余说明文字仍保留在输入框。
- 附件仍在导入时，会话发送、任务提交、切换问题以及任务字段保存会暂时不可用，避免正文先发出而附件随后落回草稿。
- 若部分附件无法读取，可读取的附件仍会正常加入，并提示未能读取的数量。

## 会话过程展示

- 命令运行、文件读取、目录浏览、搜索、上下文整理、编辑以及工具调用等会话过程行，改用更贴近含义的图标，使同一类别在实时记录与历史记录中保持一致外观。
- 过程行的图标与标题顶部对齐，标题较长换行或展开详情时，图标仍停留在标题首行，不再随详情高度移动。
- 计划摘要中的下载、复制、展开等操作使用更清晰的图标，同时保留原有操作语义。
- 编辑消息、连接重试等提示图标与既有界面风格统一。

## 命令中心

- 项目命令页标题简化为“命令”，项目名称继续由工作区导航标明，页面不再重复展示项目名。
- 命令列表改为紧凑的可展开行：展开后可查看命令说明、脚本、别名、超时和 Telegram 开关；编辑与删除使用轻量图标操作，运行仍保留醒目按钮。
- 运行确认窗口只展示需要填写的参数，每个参数旁可展开查看字段名和说明；项目目录与超时上限固定显示在顶部，命令详情可展开查看。
- 高风险命令继续在运行前标明具体影响范围，确认按钮保持醒目样式。

## 文件与交付树外观

- 源码树、会话资源、任务交付树以及快速操作中的文件图标统一为一套图标，并针对 TypeScript、JavaScript、JSON、HTML、Vue、Python、SQL、文档、表格、演示、压缩包、音视频等类型区分显示。
- 目录统一使用常规轮廓的文件夹图标，源码树与 Git 工作台中的文件夹不再使用填充风格。
- 任务交付树不再为常见源码类型绘制文字徽标，改为使用与会话、源码树一致的文件图标。

## 如何升级

- 使用 Homebrew：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 或手动下载版本化安装包进行升级：`Zeus-0.3.165-arm64.dmg`。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品若仍为 ad-hoc 签名、未经过公证，应用内自动安装可能不可用，需要按上述方式手动升级。
- 附件导入期间，发送、提交、切换问题以及任务字段保存会暂时不可用，待导入结束后恢复。
- 长文本粘贴在保存失败时仍会以原文回填输入框，不会丢失内容。

## 发布验证

公开 Release 只在固定候选通过以下检查后才会创建：

- Release Workflow 由维护者手动运行，只构建候选；公开发布需要显式选择 `publish_release`。
- Linux 执行 `pnpm verify:publish --checks-only` 静态检查；macOS 同时完整构建源码并打包。
- 两者通过后才公开发布并同步 Homebrew，且发布的标签、Release 说明、安装包清单与 Homebrew Cask 必须与同一候选提交一致。
- 本地等待 Release Workflow 以单调时钟计时，进入等待时以及随后每分钟回验公开标签、Release、安装包清单及 Homebrew，全部一致即可成功收尾。
- 已结束的发布可执行 `VERIFY_PUBLISHED_ONLY=1 RELEASE_VERSION=<版本> RELEASE_COMMIT=<完整候选提交> pnpm release:publish` 只读回验，并生成独立凭证；该入口不触发 Workflow 或修改旧命令历史，且不能同时设置 `APPLY_REMOTE=1`。
- 回验要求当前 Homebrew Cask 仍指向该版本。
