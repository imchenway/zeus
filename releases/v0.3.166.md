# Zeus 0.3.166 更新内容

## 终端搜索

项目终端和会话终端现在都支持搜索输出内容。点击终端工具栏中的放大镜按钮即可打开搜索框，也可以使用 `Command+F`（macOS）或 `Ctrl+F` 打开。输入文字即可在当前终端缓冲区中查找，使用上下箭头或回车在匹配项之间前后跳转，未找到时会给出提示。搜索框覆盖在输出上方，不会改变终端尺寸。打开搜索时按 `Escape` 会先关闭搜索，不会触发其他工作区操作。

## Codex 点数与费用展示更清晰

Codex 账户概览新增点数余额和点数状态，可直接查看官方返回的可用、无点数、无限或未知状态，并附有官方扣费规则说明。菜单栏用量浮窗中，Codex 订阅的本地费用统一标注为“等价费用”，明确它是按已知模型费率估算的本地金额，并非实际扣款；同时显示官方剩余点数（仅在余额为正时展示）。API 供应商的展示保持不变。设置中新增“管理官方用量”入口，可跳转至 OpenAI 官方用量页面进行点数和扣费管理。

## 对话处理过程展示更稳定

在运行中的一轮对话里，隐藏的思考状态摘要和多智能体协调事件不再打断可见操作的分组，同一输入下连续的工具与命令操作会保持为一个整体。冷读或补页加载时，操作组身份保持稳定，不会因为阶段编号变化而重新拆分。已有会话的耗时摘要仍可回看，最终正文位置不变；失败或中断的轮次继续按原规则展示进展。此外，单边涉及文件变更时，文件增删计数只在有新增时才占用最右列，不再留下空白的删除列。

## 数字员工与模型图标

“数字员工”入口的图标改为人物头像样式，与名称含义更一致。会话输入框在窄宽度下收起为模型图标时，改用新的极简模型图标，颜色跟随按钮前景色，方便识别当前模型选择。

## 如何升级

Homebrew 用户执行：

```sh
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.3.166-arm64.dmg`，打开后手动拖入“应用程序”完成升级。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc 签名、未公证，应用内自动安装不可用，请使用上述手动方式升级。
- Codex 点数状态与余额来自官方回包；缺少官方字段时显示为未知，不使用本地金额推断。
- “等价费用”为本地估算，仅供参考，实际扣费以 OpenAI 官方账户为准。

## 发布验证

公开 Release 仅在固定候选通过全部发布门禁后创建。门禁包括：类型检查、构建与打包成功；桌面端启动与关键交互检查通过；终端搜索、Codex 点数与费用显示、对话处理过程分组等本次变更相关的探针与行为校验通过。任一检查失败时，不创建对应公开 Release。
