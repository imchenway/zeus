# Zeus 0.3.168 更新内容

本次更新让代码交付在多仓库、多分支场景下更清晰、更可控，并统一了任务会话与普通会话的操作入口。

## 代码交付窗口统一

- 任务和普通会话现在共用同一套代码交付窗口：无论从任务还是从会话的交付按钮进入，都会打开相同布局、相同操作步骤的原生窗口。
- 同一范围重复点击会唤回已打开的窗口，不会重复创建；窗口在创建时就固定归属的项目或任务，不能切换到其他范围。
- 关闭窗口、读取当前会话上下文、打开文件差异等操作都按创建时的真实范围校验，避免跨范围操作。
- 当运行环境无法打开交付窗口时，界面会直接显示真实错误，而不是退回到其他交付界面。

## 交付页面更清晰

- 交付页面按“分支 → 仓库 → 目录/文件”组织：仓库选择控制合入和推送，文件选择只控制提交，审阅焦点与勾选互不影响。
- 支持在“本机未提交”和“已提交成果”两个范围之间切换；已提交成果与真实上游对比得出，未配置上游时不会伪造来源分支。
- 目录支持批量勾选，并呈现全选、半选状态；双击文件可在独立窗口查看差异，单击只更新下方差异。
- 提交、合入、推送的结果按仓库分别显示成功、跳过、待处理、失败，单个仓库失败不会撤销其他仓库的成功；操作中的提示可展开查看逐仓明细。
- 冲突仓库会标记冲突文件数量并给出处理入口，未解决的冲突不会被提交。

## 会话代码交付可在独立窗口打开

- 普通会话的交付按钮现在打开独立原生窗口，沿用与任务相同的文件审查、提交说明、合入与推送步骤。
- 会话窗口只读取其绑定的项目或会话仓库，不会套用其他任务的数据。
- 提交说明生成与任务交付共用同一模型入口，生成结果需要你确认后才会覆盖草稿。

## 体验与界面修正

- 终端字符网格不再把边框计入尺寸，留白与实际可绘制区域一致，终端排版更稳定。
- 顶部拖拽层与可点击控件的层级关系更准确：顶部工具栏按钮可正常点击，同时保留其他区域的窗口拖动。
- 系统共享状态面板不会被当作可接收文档键盘输入的窗口，减少后台输入落到系统面板的可能。

## 如何升级

- Homebrew：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载版本化安装包 `Zeus-0.3.168-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。

当前公开制品为手动升级方式，不提供应用内自动安装。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 代码交付窗口固定创建时的任务或会话范围，窗口打开后不能切换到其他项目。
- 未配置上游分支的仓库不会显示“已提交成果”范围；未配置远端时不会提供推送。
- 存在冲突或未结束合入状态的仓库不会被提交或开始新的合入。
- 首次加载失败时页面保留真实错误并提供重新读取，不会把未加载显示为“没有变化”。

## 发布验证

公开 Release 只有在固定候选完成以下检查后才会创建：

- 与本地一致的发布前门禁通过，包括类型检查、构建与打包流程。
- 打包产物健康检查通过：应用包内包含完整的 Computer Use 原生组件（SDK 入口、权限入口、绑定依赖、原生 worker 与宿主原生库），任一项缺失或摘要不符即不创建公开 Release。
- 原生组件缓存按 SDK 与 worker 成套校验，摘要不匹配时重新生成，不复用不完整产物。
- 发布流程仅使用解析出的主缓存键保存构建产物，不写入宽泛备用键。
