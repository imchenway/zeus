# Zeus 0.3.171 更新内容

## 数字员工配置更清晰

本次更新把数字员工拆分为“全局身份”和“项目工作要求”两部分，减少重复填写和配置冲突。

- 全局员工只保留身份、角色、提示词和经验偏好等通用信息，不再逐个维护模型、权限、Skills、自动领取等执行细节。
- 模型、Skills、权限等执行设置改为统一使用执行默认，员工工作、自动化和项目任务都按同一套默认执行。
- 项目成员不再复制一份完整员工配置，只需补充“项目补充要求”和“是否读取个人经验”，避免同一员工在不同项目里各有一套互相打架的设置。

## 旧项目员工需要确认后迁移

对于历史项目员工，本次更新提供明确的迁移路径：

- 旧的员工名称、角色、业务领域、头像和提示词会保留在项目员工详情中，供你查看和对照。
- 在确认改用全局员工配置前，该员工的旧配置仍会展示，确认时会提示旧项目差异将被替代，项目补充要求和经验记录继续保留。
- 如果这些旧职责需要独立保留，可以先据此创建新的全局员工，再为项目选择全局配置。

## 数字团队与自动化表单调整

- 数字团队中的员工节点把“研发流程设置”收进可选折叠区，普通分工默认按任务目标和员工职责执行，只在需要代码验收或隔离代码修改时才展开配置。
- 自动化的动作选项不再提供“普通会话”，改为“员工工作”和“处理项目任务”，并新增“重复触发时”的处理方式，可选择依次执行、跳过新触发或替换待执行项。
- 处理项目任务时可以按任务状态、任务类型和所需标签筛选处理范围。
- 本轮会话中 @ 数字员工只表示接收成员，成员共用当前会话设置，不再在输入框内单独调整该成员本轮配置。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以从公开 Release 下载 `Zeus-0.3.171-arm64.dmg`，手动拖入“应用程序”完成升级。

当前公开制品仍为手动升级方式，请以上述命令或 DMG 手动安装为准。

## 系统要求与已知限制

- macOS 最低版本：13.0。
- 已存在的旧项目员工在进行全局配置迁移前，其旧项目差异仍会保留展示；未确认迁移可能暂缓该员工的新工作。
- 员工旧身份、旧提示词与全局配置并存的情况需要你确认后才会被替代。

## 发布验证

公开 Release 仅在固定候选通过以下门禁检查后才会创建：

- 类型检查、代码规范检查与桌面应用构建成功。
- 桌面应用打包成功，并生成版本化 DMG 制品。

只有上述检查全部通过，才会对外发布本次候选版本。
