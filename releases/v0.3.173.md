# Zeus 0.3.173 更新内容

## 数字员工：更专注的身份与经验管理

- 数字员工页面精简为定义员工身份：名称、岗位、工作要求和可选说明，低频的领域、说明、头像和经验偏好收进可展开区域。
- 列表新增搜索框，可按姓名、岗位或领域快速筛选；同名员工仍分别保留，互不影响。
- 保存状态直接显示在编辑区，修改后自动保存；保存失败时可就地重试。
- 删除员工身份时，已完成工作的记录继续保留。

## 数字团队：统一的团队目录与更清晰的协作表达

- 团队定义统一来自全局团队目录，不再区分项目模板；项目角色改为“任务运行项目”，只决定协作任务的运行位置。
- 画布节点直接展示成员的实际工作要求，连线表达“先完成的分工”，检查器中的成员配置改为“成员分工”，并明确显示工作权限（只读、隔离工作区修改代码等）。
- 团队设置折叠为“团队设置”，集中放置团队说明、复制团队、放弃修改和删除团队等低频操作；新建团队与保存等主操作保持原位。
- 节点检查器中的任务状态联动与研发设置按需展开，完成标准与工作要求填写更直接；遇到状态或研发配置错误时会自动展开对应设置。
- 损坏或结构不完整的旧团队定义以安全视图展示，原内容保留，需明确点击“重新配置成员”后才能保存为新定义，避免误覆盖。
- 团队名称、状态等术语统一，状态目录改为所有项目共用。

## 项目设置：仅保留资源连接与授权

- 项目设置不再包含独立的默认工作模式、语言、依赖、Telegram 等偏好，只维护数据库连接名与 Shell / Git 写入授权；作为对照，其他连接与授权仍按项目单独保存。
- 任务列表布局、任务状态筛选和视图模式改为全局共用，保存任务列表布局不再弹出作用范围选择，直接保存到全局。
- 任务状态配置不再按项目分别维护，改为所有项目统一使用同一套状态。
- 移除项目侧边栏设置入口与项目数字员工面板，数字员工配置集中在全局数字员工页面。

## 会话与任务推送

- 任务模型推送不再读取项目级服务档位偏好，改为使用统一执行默认，减少跨项目配置不一致。

## 如何升级

### Homebrew

```
brew upgrade --cask imchenway/tap/zeus
```

### 手动安装

如果尚未接入 Homebrew Tap，或需要指定版本，可下载 `Zeus-0.3.173-arm64.dmg`，打开后按提示拖入“应用程序”完成手动升级。

当前公开制品按现有发布方式提供，暂不支持应用内自动安装更新。

## 系统要求与已知限制

- macOS 最低版本：13.0。
- 当前为 arm64 桌面制品；其他架构需等待相应制品。
- 如需保留旧的项目级任务状态、任务筛选或视图偏好，升级后这些偏好将统一使用全局配置，旧的按项目覆盖不再生效。
- 旧的项目模板或项目数字员工数据仍会保留在本地，但新界面不再提供项目级维护入口。
