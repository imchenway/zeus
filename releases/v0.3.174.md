# Zeus 0.3.174 更新内容

## 数字团队草稿可以随时切换

- 在数字团队中编辑流程时，未保存的修改会自动暂存在本地，直接切换页面、返回任务或切换项目后，回到该团队仍可继续编辑。
- 每个团队和新团队分别保留各自的编辑内容，切换团队不会丢失此前输入。
- 保存成功后会清除对应草稿；保存后团队才能用于任务。
- 当本地暂存不可用时，界面会提示保存流程，窗口内仍保留当前修改。

## 待分配员工不再作为错误处理

- 团队中尚未选择执行员工的分工显示为“待分配员工”，不再标红报错，也不影响正常保存草稿。
- 校验面板会按问题类型合并同类提示并显示数量，未分配员工单独提示“还有 N 个分工待分配员工”，可一键定位到对应节点。
- 只有实际不可用的员工（例如已被删除或停用）才显示为错误。
- 未分配员工或引用了不存在员工的团队可以保存，但不能作为任务运行入口。

## 员工与任务状态的迁移修正

- 数字员工删除现在会在同一事务中停用闲置的项目关联；存在运行中或待交付工作时不能删除，已完成工作的历史记录继续保留。
- 员工目录不再显示旧项目自动迁出的内部身份，只保留用户主动创建的可编辑员工；同名员工仍分别保留。
- 修正内置任务状态迁移中可能产生的重复副本，将看板分组、筛选、隐藏泳道等设置中的旧标识统一到规范状态，重复启动不会再次写入。
- 旧项目看板与历史原文继续保留，已有运行、事件和冻结规则不变。

## 会话提醒与后台同步更稳

- 会话问候提醒只在窗口前台、内容可见且连接正常时确认；断线或校准期间保留提醒，恢复后只确认当前实际可见的最新版本。
- 后台同步失败不再显示为明确的用户操作错误，仅在控制台保留脱敏诊断；重试只在下一次状态校准成功后进行。
- 实时刷新与提醒确认的迟到回执不会回退运行状态或清除较新的提醒。

## 如何升级

已安装 Homebrew 的用户可以执行：

```
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载并安装版本化 DMG：`Zeus-0.3.174-arm64.dmg`。当前公开制品为 ad-hoc 签名、未公证版本，升级需要手动完成，不支持应用内自动安装。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 数字团队的未保存修改保存在本机暂存中；本地存储不可用时只能在当前窗口内保留，重新打开前需要保存流程。
- 存在运行中或待交付工作的数字员工无法删除，需要先处理相关工作。
- 未分配执行员工或引用了不可用员工的团队可以保存草稿，但不能用于任务运行。
- 后台同步的自动重试依赖连接恢复后的状态校准，校准完成前提醒或刷新可能暂时延迟。

## 发布验证

公开 Release 只有在固定候选完成以下检查后才会创建：

- 按仓库脚本完成 lint、typecheck 与 build。
- 运行工作管理命令行为验证，确认员工身份迁移、目录过滤、活动工作删除保护与历史快照保留符合预期。
- 完成桌面打包并校验生成的 arm64 制品。
- 产出的 `Zeus-0.3.174-arm64.dmg` 与版本号一致。
