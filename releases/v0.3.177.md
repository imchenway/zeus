# Zeus 0.3.177 更新内容

## 数字团队只读运行的说明更准确

- 只读运行的提示现在明确描述“本次运行仅执行只读工作，未安排代码修改”，不再把历史分工理解为当前可编辑流程的能力。
- 当一次只读运行失败且需要改动代码时，提示会引导你先调整分工再重新开始，并说明返工会沿用原来的只读设置。
- 相应位置提供“调整分工”入口，可直接打开对应的流程草稿进行修改。

## 会话内的团队进展展示更一致

- 完整会话页与任务内嵌会话页共用同一份当前会话的团队进展，减少两处显示不一致的情况。
- 从内嵌会话跳转到数字团队运行记录时，会先关闭任务详情弹层，避免旧弹层遮挡已打开的运行记录。

## 如何升级

- Homebrew：

```sh
brew upgrade --cask imchenway/tap/zeus
```

- 手动下载安装：下载 `Zeus-0.3.177-arm64.dmg` 并打开，将 Zeus 拖入“应用程序”完成覆盖安装。当前公开制品若仍为 ad-hoc、未公证，升级需要通过上述手动方式完成，应用内自动安装可能不可用。

## 系统要求与已知限制

- macOS 13.0 及以上。
- 仅提供 arm64 制品（`Zeus-0.3.177-arm64.dmg`）。
- 冒烟测试未覆盖手动升级，手动升级流程的实际表现可能因环境而异。
- 当前公开制品若仍未公证，首次打开时可能需要按系统提示手动允许运行。

## 发布验证

公开 Release 只有在固定候选提交通过以下门禁后才会创建：

- `pnpm typecheck` 通过。
- `pnpm lint` 通过。
- `pnpm test` 通过。
- 桌面端打包（生成 arm64 DMG）成功。
- 打包产物完成冒烟验证。
