# Zeus 0.3.179 更新内容

## 任务沟通与团队协作导航

- 任务内的沟通面板改为左侧员工导航加右侧会话正文：同一任务下的团队执行、每位数字员工的会话记录都能分别查看，重试或返工产生的独立会话仍作为单独入口保留，不会再被合并成一个难以辨认的列表。
- 员工会话会显示后端真实状态（进行中、已完成、失败、受阻等），承接换人交接时会先等待新执行人真正产生会话再定位，避免看起来像卡住或指向错误的人。
- 面板较窄时员工导航会自动收起，可随时手动展开，正文和输入区不会被持续压缩。

## 数字员工默认执行配置与记忆管理

- 新增数字员工的「默认执行配置」，可设置模型、上下文容量、推理级别、速度、工作模式和权限模式，并可为员工选择 Skill；修改后作为新工作的默认值，已开始的工作保留原有配置。
- 派发工作前可单独覆盖本次执行配置，并在「执行预览」中逐项核对最终生效值、配置来源，以及本次拟采用的员工记忆；被否决或与目标无关的记忆不会静默带入。
- 员工记忆集中在「管理员工记忆」中：可查看候选经验、治理记录，以及最近派发时记忆加入或未加入输入的原因，任务总结不会自动保存为个人经验。
- 员工面板简化为名称、岗位和提示词，业务领域等内容不再作为必填项干扰配置。

## 质量与稳定性修复

- 修复电脑控制在取消操作时的时序问题，精简原生工具返回结果，并针对后台路由被拒绝、疑似无效动作、树被截断等情形给出明确的下一步提示，而不是让模型反复尝试同一条失败路径。
- 修复桌面会话过期后的恢复：原生会话被回收时，会先要求重新观察目标窗口再继续，不会自动重放上一次操作。
- 修复任务会话导航、员工改派与图片恢复相关问题，隔离新旧线程状态，并修复停止后恢复的边界情况。
- 修正按计费条件统计价格周期的口径。

## 启动、模型设置与提交信息

- 优化启动加载：首页项目查询不再等待 Git、集成服务或历史任务正文；会话显示缓存改为按会话分文件、异步读写并原子落盘，缓存损坏只影响首屏加速，不影响数据加载。
- 启动界面会显示当前真实阶段（如准备本地数据、连接本地服务），不再用超时或百分比推断。
- 模型设置拆分为独立模块，配置体验保持一致。
- 新增提交信息生成设置，可在生成提交说明时指定模型、推理与速率等参数。
- 自动化表单改为双栏布局并统一权限文案。

## 如何升级

当前公开下载的磁盘映像仍为未公证制品，无法在应用内自动安装，请手动升级：

- Homebrew：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动下载：从发布页下载 `Zeus-0.3.179-arm64.dmg`，将 Zeus 拖入「应用程序」文件夹覆盖旧版本后重新打开。

## 系统要求与已知限制

- 支持 macOS 13.0 及以上（Apple 芯片）。
- 当前公开制品未公证，首次打开时可能需要在「系统设置 → 隐私与安全性」中手动允许；无法通过应用内自动安装完成升级。
- macOS 上电脑控制的后台输入路径被原生驱动拒绝时，会明确停止该输入路线，不会回退到前台输入或像素级操作。
