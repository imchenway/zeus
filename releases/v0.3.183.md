# Zeus 0.3.183 更新内容

## 图标悬停提示更统一

本次更新把界面中的图标悬停提示统一为一套应用内气泡：

- 会话输入区、权限模式、速度切换、目标模式、附件入口等图标，悬停时会显示与当前操作一致的提示。
- 工作区导航、任务看板、代码与 Git 相关页面的图标按钮提示改为同一套气泡样式，不再使用系统原生提示，风格更接近桌面应用的紧凑排版。
- 禁用状态的图标按钮也能显示用途说明，便于在按钮不可用（例如未勾选文件、窗口过窄）时理解原因。
- 键盘聚焦图标同样会显示提示，按 Escape 只关闭提示，不会误触其他操作。
- 部分常见按钮（如图片缩放的加减、关闭对比）仍保留系统原生提示，避免多余气泡。

## 上下文用量与复制反馈更清晰

- 上下文用量浮层改为标题列加右对齐值的明细列表，所选容量与引擎回报的可用空间使用统一的数字格式，精确值可在悬停时查看。
- 引擎回报的可用空间与所选容量不一致时，会说明其中已扣除引擎保留空间。
- 复制分支名、复制路径等操作只在写入成功时显示“已复制”确认，复制失败会如实报错，不会显示成功反馈。
- 计划卡片的下载、复制、喜欢/不喜欢等操作提示按当前状态更新，例如已喜欢后提示“取消喜欢”。

## 菜单栏与评论提示更准确

- 菜单栏图标提示会说明当前点击动作（查看用量 / 收起用量），并跟随用量窗口的显示状态和界面语言更新。
- 网页评论浮层内的按钮提示与应用内保持一致，评论标记悬停时显示对应的评论编辑说明。
- 语音输入按钮在不可用时会提示聚焦输入框后使用系统听写，录音中则改为说明停止操作。

## 如何升级

- 通过 Homebrew 升级：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载 `Zeus-0.3.183-arm64.dmg`，打开后按提示把 Zeus 拖入“应用程序”完成替换。

当前公开制品为手动升级方式，尚未提供应用内自动安装。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 目前公开制品未经过公证，首次打开时可能需要在“系统设置 > 隐私与安全性”中允许运行。
- 上下文用量浮层中，切换到新的上下文容量需要等到下一轮对话生效；使用 Codex 时引擎回报可能延迟约一分钟。

## 发布验证

公开 Release 只在固定候选通过以下检查后才创建：

- 类型检查与代码规范检查通过。
- 桌面端构建与打包成功，产物包含 `Zeus-0.3.183-arm64.dmg`。
- 应用在 macOS 13.0 及以上可正常启动并完成基本交互。
- 产物版本号与 `0.3.183` 一致。
