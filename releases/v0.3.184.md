# Zeus 0.3.184 更新内容

## 新对话也能先浏览网页并提交批注

在创建新对话时，可以直接打开内置浏览器浏览网页、添加批注和截图，并把它们作为首条消息一起发送，无需先建立会话。

- 新对话界面提供与已有会话一致的浏览器工作面，支持打开/关闭（快捷键 ⌘⇧B / Ctrl+Shift+B）、分栏阅读和全宽展开。
- 网页批注和截图会累积到同一份待发送内容，重复确认同一批注时保留最新正文，删除批注时同步移除对应截图。
- 只提交网页批注、不填写正文也可以开始对话；系统会把批注和提示内容一并发送。
- 若同时附带你自己的文件附件，网页截图会与它们合并去重后一起发送。

## 草稿网页在会话建立后自动接管

新对话创建成功后，当前窗口里的浏览器草稿标签会自动归属到新建的真实会话，网页实例、标签顺序、当前选中项和已提交的批注都会保留。

- 只有当前窗口自己创建的草稿标签会被接管，属于其他窗口的草稿不会被误迁移。
- 如果接管过程出现异常，不会撤销已经受理的对话创建，你仍会进入新会话。

## 草稿恢复更完整

返回创建界面或切换任务草稿时，浏览器状态会随输入草稿一起恢复：包括是否打开浏览器、草稿批注内容和对应截图，不需要重新添加。

## 如何升级

推荐使用 Homebrew 升级：

```sh
brew upgrade --cask imchenway/tap/zeus
```

也可以从发布页下载版本化 DMG 后手动安装：

- `Zeus-0.3.184-arm64.dmg`

当前公开制品未经过公证，macOS 可能会阻止自动打开。请手动拖入“应用程序”完成安装，应用内的自动安装/自动更新不可用。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 当前公开制品为未公证版本，仅支持手动升级，应用内自动安装不可用。
- 浏览器草稿的接管只作用于创建它的当前窗口；其他窗口的草稿标签不会被迁移。
- 网页截图会作为附件参与发送并做去重，删除批注会同时移除对应截图。

## 发布验证

公开 Release 只有在固定候选提交通过以下门禁后才会创建：

- 依赖安装、类型检查和构建通过。
- 桌面应用打包成功。
- 会话首发命令行为验证通过，包括项目与任务两个入口接受网页批注字段并返回受理。
- 网页批注合并逻辑验证通过：重复确认更新正文并只保留新截图。

只有全部门禁通过，才会对外创建 0.3.184 的公开 Release。
