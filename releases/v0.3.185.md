# Zeus 0.3.185 更新内容

## 源码与 Git 工作台整合

- 项目代码区的源码文件树与底部 Git 工作台改为共享同一份仓库快照，文件状态标记不再单独扫描仓库，避免两处状态不一致。
- Git 底栏可以展开和收起，展开后源码区与底栏之间保留可拖动的分隔条，高度比例会沿用你调整过的结果。
- 原来位于 Git 侧栏的分支控件移到了文件标签顶行，收起底栏时仍能查看和切换分支；长分支名会截断，完整名称通过原控件提示显示。
- Git 命令工具栏改为紧凑图标按钮，提交、拉取、推送、抓取、分支、合并、贮藏、操作和刷新都保留悬停提示与辅助技术名称。
- 之前嵌在源码侧栏里的“更改”面板已移除，提交与文件选择统一由底部 Git 工作台承载。

## 网页评论的展示与发送

- 网页评论的编辑浮层只采集评论正文，编辑与保存过程不再修改被评论的网页内容；旧的已存调整信息仍会保留显示。
- 输入框中的待发送网页评论改为数量摘要气泡，悬停或键盘聚焦后查看评论原文与批注内容，展开方式与回答评论一致。
- 历史消息中的网页评论作为消息正文保存和恢复，首屏、分页和全文补载都会保留，不再回退成 JSON 包装层；评论没有正文时也不会显示 JSON。
- 文字、元素和区域评论都会保留批注当时引用的内容，不依赖当前网页状态；只有截图需要展开查看。

## 附件与图片预览

- 图片附件改为固定尺寸预览占位，加载前后不再跳动，较宽的截图也不会挤走其他附件。
- 图片缩略图在导入、读取和解码阶段统一显示骨架，不再先显示成普通文件图标。
- 图片预览失败时停止加载动画，显示“预览不可用”，并保留原有的打开入口和明确提示。
- 任务和会话输入中的附件改为自动换行显示，所有附件都能被发现，而不再依赖横向滚动。

## 如何升级

- 通过 Homebrew 升级：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载版本化 DMG 文件 `Zeus-0.3.185-arm64.dmg`，打开后把 Zeus 拖入“应用程序”完成替换。
- 当前公开制品未经过公证，安装或替换时 macOS 可能提示来源不明，需要在“系统设置 → 隐私与安全性”中手动允许打开。应用内自动安装暂不可用，请按上述两种方式之一手动升级。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本（最低系统版本配置为 13.0）。
- 当前公开制品为 ad-hoc 签名且未公证，可能触发 Gatekeeper 拦截，需要手动在“隐私与安全性”中放行。
- 应用内自动更新不可用，只能通过 Homebrew 或版本化 DMG 手动升级。
- 图片附件如果自身或目标格式无法解码，会显示“预览不可用”而非缩略图，附件本身仍可打开。

## 发布验证

公开 Release 与 Tap 更新只有在固定候选提交通过以下门禁后才会创建：

- 依赖安装与锁文件在干净环境中可重现。
- lint 与 typecheck 在候选提交上通过。
- 桌面端构建与打包在候选提交上成功，并产出 `Zeus-0.3.185-arm64.dmg`。
- 打包出的应用能够启动，且源码与 Git 工作台整合、网页评论展示与发送、附件与图片预览相关交互在真实桌面环境中可用。
- 制品签名状态与系统要求与本文档描述一致。

只有以上检查全部通过，才会创建 v0.3.185 的公开 Release 并同步 Homebrew Tap；否则不会发布该版本。
