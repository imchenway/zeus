# Zeus 0.3.186 更新内容

## Mermaid 图表展示修复

- 图表现在会跟随应用主题自动切换明暗配色，不再固定使用浅色样式。
- 长流程图可以完整展示，不再受固定高度限制被截断，短图也不会保留多余空白。
- 源码块与图形共用同一卡片外观，长代码行仍在卡片内部滚动，边界更整齐。
- 当 Mermaid 语法不完整或无效时，会明确提示语法问题并保留源码可复制，而不是静默显示空白或含糊的渲染失败。

## 附件卡片布局与预览调整

- 会话问答、自由回答和计划修改中的附件改为显示在输入框上方，附件与输入内容的阅读顺序更符合操作逻辑。
- 移除文本附件的内嵌内容摘要预览，附件卡片统一显示文件名与类型信息，打开方式由文件预览承担。
- 窄问答框中的提交操作区允许按钮换行，避免附件与自由输入被挤成一条细缝。

## 如何升级

本次发布为手动升级，应用内自动安装当前不可用。

方式一：Homebrew

```
brew upgrade --cask imchenway/tap/zeus
```

方式二：手动安装 DMG

下载 `Zeus-0.3.186-arm64.dmg`，打开后将 Zeus 拖入“应用程序”目录完成替换升级。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前提供的 DMG 为 Apple Silicon（arm64）版本。
- 由于当前公开制品为 ad-hoc 签名且未公证，升级需要手动完成，应用内自动安装可能不可用。
- Mermaid 语法无效时图表会以源码形式保留，需要修正语法后重新渲染。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 构建与打包成功，生成的 DMG 与预期版本一致。
- 桌面端在目标系统版本上完成安装与启动检查。
- 生成的制品符合既定的签名与公证要求。
- 发布门禁全部通过后，公开 Release 与 Homebrew Tap 才会同步。
