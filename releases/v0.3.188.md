# Zeus 0.3.188 更新内容

## 任务详情改为常显阅读布局

任务详情不再把说明、属性、项目操作和活动记录折叠进多个抽屉，而是把任务说明与会话放在主阅读区，属性、任务关系、活动记录和移动复制集中在右侧信息列常显。窄窗口下信息列会改为上下排列，内容保持完整可达，不会藏进独立滚动区。

## 会话、待办与工作在同一页展开

数字员工面板不再通过“沟通 / 工作 / 成果 / 运行记录”页签切换。原会话、待我处理的待办、工作安排、成果和运行记录会按上下文在同一页面展示，原来的发送控制器和草稿继续保留，查看工作安排不会卸载正在阅读的会话。

## 团队成员与执行历史改为直接列出

任务沟通侧栏不再依赖下拉选择器：多份分工在成员姓名下直接列出，执行历史和多条任务会话以可点击列表展示，当前项有明确选中态。窄面板下成员列表会排列在会话上方，而不是覆盖式弹出侧栏。

## 结果与操作入口调整

所选分工的结果会在会话下方直接展示，不再切换“查看结果 / 查看原会话”视图，原会话保持挂载。任务详情右上角原“更多”图标按钮改为带“任务操作”文案的下拉入口；“重新创建”操作在对应会话已存在时不再重复提供“打开会话”。

## 如何升级

- Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- 手动升级：下载并安装 `Zeus-0.3.188-arm64.dmg`

当前公开发布的制品为 ad-hoc 签名、未公证，应用内自动安装不可用，请使用上述方式手动升级。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- 公开发布制品为 ad-hoc 签名且未公证，首次打开可能需要手动允许，且不提供应用内自动安装。
- 窄窗口下任务信息与成员列表改为顺排展示，页面会整体滚动，阅读位置可能需要向下滚动才能看到信息列。

## 发布验证

公开 Release 只会在固定候选完成以下检查后创建：

- 通过 lint、typecheck 与项目的构建检查。
- 成功打包桌面制品，并生成 `Zeus-0.3.188-arm64.dmg`。
- 制品签名与公证状态符合本次发布策略，并据此确定升级说明。
- 桌面应用可启动，任务详情、任务沟通与数字员工面板的关键交互可正常使用。
