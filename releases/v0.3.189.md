# Zeus 0.3.189 更新内容

## 连接中断后的自动恢复更可靠

当模型响应因网络波动或供应商连接中断而失败时，Zeus 现在会在确认上一次尝试已经停止后，自动从原请求的中断处继续完成，而不是把整轮对话直接判定为失败。恢复使用同一线程、同一模型和同一权限设置，不会重复执行已经完成的工具操作。自动恢复最多尝试五次，两次尝试之间逐步延长等待时间，给网络和供应商留出自愈空间。

单次模型响应的等待时间上限为一分钟，但只针对模型输出本身：运行较长工具或等待你回复人工提问时不会消耗这个时间窗口。如果五次恢复都未成功，会话会停止并保留失败原因，你可以检查网络后手动重试。

在自动恢复过程中，界面会显示正在连接的状态，并保留停止入口；此时不会额外弹出错误卡片。恢复成功后，原始消息的发送状态会正常结算。

## 消息发送失败反馈更明确

发送前检查或运行内核明确拒绝的消息，现在会直接显示为“消息尚未发送”，并在原消息旁提供重试入口，而不再被退回普通排队卡片。重试会保留这条消息的身份并清除上一轮失败提示，避免连接期间仍然显示旧错误。

任务首次推送的消息在模型尚未连接时也会使用原消息上的反馈与重试入口，不再单独弹出创建失败错误。只有真正送达状态未知的消息才继续提示“暂时无法确认消息的发送状态”，并提供核对入口。窄窗口下，发送状态、错误摘要和重试按钮会保持在同一行，错误详情仍可展开查看。

## Codex 模型配置问题修复

修复了 Codex 模型发送时报 `model_providers contains reserved built-in provider IDs: openai` 的问题。Zeus 不再为内置供应商写入重试参数，只保留关闭无限重连的设置，其余连接参数沿用 Codex 原生默认值。遇到配置装载明确失败时，界面会提示具体原因并允许你修正配置后手动重试，不会把这类未发送的消息当成结果未知。

## 其他改进

- 会话目录读取在页面切换或连接更新时被取消，不再弹出用户无法处理的错误；连接换代时会自动读取当前目录。
- 会话标题变更等关键事实会被更及时地同步到本地状态。

## 如何升级

Homebrew 用户运行：

```
brew upgrade --cask imchenway/tap/zeus
```

也可以从发布页手动下载 `Zeus-0.3.189-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成升级。当前公开制品为 ad-hoc 签名、未经公证，首次打开可能需要在“系统设置 → 隐私与安全性”中允许，应用内自动安装不可用。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 仅提供 arm64（Apple 芯片）制品。
- 当前公开制品为 ad-hoc 签名且未公证，需手动下载 DMG 升级。
- 自动恢复只处理可判定为瞬时的模型响应/网络故障；认证、额度、配置等永久性错误不会自动重试，会直接提示原因。

## 发布验证

公开 Release 只在固定候选通过以下检查后才会创建：

- 工作区无未提交变更，候选提交与目标版本一致。
- lint、类型检查与构建全部通过。
- 桌面应用完成打包，产出与目标版本一致的 arm64 DMG。
- 打包产物完成签名与公证检查，符合当前发布策略。

只有以上门禁全部通过，对应版本的公开 Release 才会被创建。
