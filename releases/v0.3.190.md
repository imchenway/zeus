# Zeus 0.3.190 更新内容

## 源码效果预览

项目源码页新增文件效果预览入口，可对 HTML 与 Markdown 文件在编辑器中直接查看渲染结果：

- 文件路径行右侧提供“源码 / 预览 / 分栏”三种显示方式，普通代码文件保持原有编辑体验。
- 预览使用当前未保存的草稿内容，切换显示方式不会丢失编辑草稿、滚动位置或撤销历史。
- HTML 在独立沙箱页面中渲染，页面脚本可以自行运行，但不能访问桌面桥接能力。
- Markdown 预览沿用会话中的文档渲染，相对图片和本地文件链接只在当前项目的授权范围内解析；外部链接走原有外部打开流程。
- 预览内置刷新入口，可在不保存文件的情况下重新读取项目内的相对资源。

## 队列恢复与连接续接

会话在连接中断、模型交接或重启后可以更稳定地恢复：

- 中断后暂停的消息队列会显示“已暂停”状态，并提供“继续发送排队消息”，按原顺序恢复发送。
- 模型连接失败后可从原失败轮次续接，恢复作为系统操作展示，不会生成额外的用户消息气泡，也不会消耗正在编辑的草稿。
- 消息已保存但模型尚未接手时，底部继续显示准备状态，不再错误地显示为空闲。
- 连接恢复过程使用独立的“正在准备发送”表述，模型输出恢复后提示会自动收口。

## 数字员工会话定位

任务中的数字员工入口现在按当前团队展示成员：

- 每位执行人显示头像与姓名，点击可直接定位到对应员工的原会话，并保留员工和团队身份。
- 会话尚未建立时入口保持等待状态，不会猜测或打开其他成员的会话。
- 顶部成员按钮支持换行，长姓名不再挤压任务详情宽度。

## Git 工作区与源码布局

源码与 Git 工作区的排版和操作入口做了整理：

- Git 工具栏上移到工作区顶行，跨整个 Git 工作区，并为提交、拉取、推送、抓取、分支、合并、贮藏、操作和刷新提供 `Cmd+Alt+1` 至 `9` 快捷键。
- 源码目录的分支与工作区入入口合并到侧栏顶行，搜索框与新建文件、新建目录并排显示，目录保持常驻展开。
- 源码目录的拖拽调宽面延伸到工作台顶部，拖拽时不再被顶栏截断。
- Git 分支树和目录树使用更紧凑的行高，减少纵向占用。
- 任务推送的模型、思考档位、工作模式、权限、上下文容量和技能选项按项目记忆，切换项目时不再沿用其他项目的选择。

## 如何升级

通过 Homebrew 安装：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载版本化安装包 `Zeus-0.3.190-arm64.dmg`，打开后按提示将 Zeus 拖入“应用程序”完成升级。

## 系统要求与已知限制

- macOS 13.0 及以上。
- 当前公开制品未经过公证，需要手动下载安装包完成升级，应用内自动安装不可用。
- 源码效果预览仅支持 HTML 与 Markdown 文件，且只读取当前项目目录内的相对资源。
- Git 工具栏快捷键需要工作区处于可见状态，弹窗或输入法组合状态下不会触发。

## 发布验证

公开 Release 只在固定候选提交通过以下门禁后才会生成并发布：

- 仓库发布流程在该候选上完成类型检查、构建与打包验证。
- 打包产出的应用与版本化安装包可正常启动并通过发布流程定义的冒烟检查。
- 通过队列恢复、事件流与渲染器事件流的既有验证脚本。

只有上述检查全部通过，对应版本的 Homebrew Cask 与公开 Release 才会创建。
