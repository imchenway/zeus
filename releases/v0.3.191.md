# Zeus 0.3.191 更新内容

## 输入建议
- 在“设置 → 通用 → 输入建议”中开启“回复后的输入建议”，并选择一个专用模型。该功能默认关闭，模型独立于会话模型。
- 开启后，一轮回复结束时，空输入框可显示浅灰文字建议；光标位于输入框内时按 Tab 采纳，采纳后仍需按原有流程发送，按 Escape 可清除。
- 只有主会话输入框使用该功能；附件、评论、目标输入或会话忙碌时不会生成建议。
- 生成建议会增加所选专用模型的用量；若未选择模型或所选模型不可用，则不生成建议。

## 会话预览与过程
- 会话的历史目录在打开时与首屏正文并行读取；较长的多轮会话中，历史发言与轮次更完整地呈现，无需先滚动到更早历史。
- 回复过程的分组按持久操作组展示：即使目录晚于展开到达，展开状态与操作数量仍保持一致，不再出现分组错位或数量跳变。
- 当前进展提示只在同一轮、未失败且含有可读摘要文字时接管展示，空摘要继续显示运行提示。

## 文件与资源操作
- 文件面板的“打开”按钮现在直接显示首选编辑器的真实图标与名称，菜单先列出首选编辑器、默认应用与终端。
- 文件操作新增“系统预览”“打开所在文件夹”“另存为…”，均使用当前会话已授权的文件，不会读取渲染层拼接的本地路径。
- 文件标签新增打开本会话文件的入口，并优化了 Markdown 文件正文与代码的排版。
- 会话活动中的“已查看图片”记录现在可折叠，缩略图更大，点击后可查看完整画面。

## 屏幕控制与环境信息
- 屏幕控制画面以独立预览呈现，悬停或键盘聚焦时显示“停止”和详情入口；暂停、异常等状态始终可见。
- 点击缩略图可查看完整屏幕画面，画面加载失败时就地提示，仍可停止控制。
- 环境信息卡与屏幕画面在布局上分层，窄窗口下操作区可换行，保持完整文案与点击范围。

## 如何升级
- Homebrew：
  ```
  brew upgrade --cask imchenway/tap/zeus
  ```
- 手动升级：从发布页下载 `Zeus-0.3.191-arm64.dmg`，退出正在运行的 Zeus 后打开该 DMG 并将 Zeus 拖入“应用程序”。

## 系统要求与已知限制
- macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc 签名、未公证，因此只能手动升级，应用内自动安装不可用。
- 输入建议为可选功能，默认关闭；开启后会持续消耗所选专用模型的用量。
- 本次候选提交中根包与桌面包的 `package.json` 版本仍为 0.3.190，与 0.3.191 版本号不一致；这属于当前证据可见的版本字段状态，可能影响升级识别或发布标识，安装前请留意。
