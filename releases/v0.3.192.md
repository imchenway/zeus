# Zeus 0.3.192 更新内容

## 自动化运行通知中心

- 侧边栏标题区新增通知入口，铃铛按未读数量显示角标，超过 99 条时显示 99+。
- 自动化运行完成后，会为当次运行的每个产品会话分别生成提醒；同一会话可以再次产生新提醒。
- 通知列表按会话逐条列出自动化名称、会话标题、所属项目、运行结果和时间，并支持分页加载更多。
- 打开有会话的提醒会跳转到对应会话；只有确认真正看到最新正文后才会标为已读，不会因跳转动作本身误判。
- 没有可用会话的异常也会保留提醒，并提供“标为已读”；对仍可继续的运行提供“继续剩余项目”。

## 会话与处理过程阅读

- 完成轮次的处理过程在展开时先补齐预览再显示操作数量，避免数量递增带来的跳动。
- 展开处理过程时使用更稳定的阅读锚点，异步内容到达后高度连续过渡，不再出现折叠高度跳变。
- 输入建议在输入框下方显示生成中、无合适建议、超时或失败等状态，状态文案不会写入草稿或被发送。

## 文件预览与变更审阅

- 变更文件列表支持目录分组与折叠，连续单层目录会合并展示，目录宽度可拖拽调整，也可用键盘调整或双击恢复默认。
- 新增、删除文件只显示实际存在的一侧，不再保留空白旧行号列。
- 源码预览新增文件内查找面板，支持查找、替换、匹配导航及区分大小写等选项，文案跟随界面语言。
- 会话文件引用显示真实文件名，行号位置按当前语言单独标注；带目录的引用按完整路径匹配，不同文件的相同行号标签不会互相带入。
- 通用文本预览也会持续标出引用范围，便于对照。
- “打开方式”菜单可显示本机真实应用图标，并新增 IntelliJ IDEA、Rider、WebStorm 等编辑器选项；未安装的应用不会展示。默认应用使用文件夹符号区分。

## 如何升级

- Homebrew 用户执行：

  ```shell
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：从发布页下载 `Zeus-0.3.192-arm64.dmg`，将 Zeus 拖入“应用程序”后替换旧版本。
- 当前公开制品为临时签名、未公证的 ad-hoc 构建，可能需要在“系统设置 → 隐私与安全性”中手动允许打开，需要手动下载覆盖升级，应用内自动安装更新不可用。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc、未公证，首次打开可能被 Gatekeeper 拦截，需在系统设置中放行。
- 自动更新仅提供手动下载安装路径，应用内自动安装更新不可用。
