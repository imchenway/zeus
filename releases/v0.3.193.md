# Zeus 0.3.193 更新内容

## 输入建议与草稿润色增强

- 输入建议设置新增推理深度选择，默认使用最低档位；模型列表会自动更新，加载失败时可以重试。
- 回复结束后，空输入框可自动显示灰字建议；关闭自动建议后仍可通过输入区右上角的星光按钮手动生成。
- 输入框有草稿时，点击星光按钮会对草稿进行润色。润色结果先在输入框上方预览，点击“采用”才会替换原文，并且替换后可以撤销；选择“保留原文”则不作改动。
- 当润色结果未能保留原文中的引用标签，或原文已经变化时，采用会被拒绝并给出提示，避免悄悄丢失执行意图。
- 生成状态（生成中、超时、无合适建议、模型不可用等）会显示在输入框下方；生成最多等待 20 秒，不会自动重试。
- 会话输入区与新建会话草稿输入都支持该入口。

## 界面与主题统一

- 深色主题统一为正文与控件两层中性灰：会话正文、标题、代码块和静态卡片使用同一底层表面，侧栏、输入框和浮层使用上层表面，整体观感更一致。
- 设置页统一为浅边框圆角卡片样式，卡片内边距和行分隔由设置样式统一提供，各设置子页（含 IM 机器人设置）保持同一套布局与宽度。
- 文件审阅入口调整：打开引用默认先阅读文件内容，如有 Git 改动，可通过工具栏中的“查看改动”按钮进入比较，增删行数统计并入文件工具栏，不再单独占用一行。
- 文件预览在深色主题下使用实色表面背景，避免内容与背景对比度不足。
- 通知中心弹层改为挂载在当前主题壳层，隔离侧栏导航样式；通知中的异常原因支持换行完整显示，未读角标在深浅主题下样式一致。
- 会话正文流式呈现节奏调整：正常片段以更平滑的节奏显示，积压内容会快速追赶，完成时立即显示剩余内容，并减少淡入时间对阅读的影响。
- 代码注释光标由问号改为普通箭头，减少阅读干扰。
- 会话与项目侧栏布局对齐，会话标题与项目文字起点一致。

## 资源与用量显示修复

- 修复会话中资源链接的归属问题：资源按服务端登记的归属挂接到对应消息，同轮次同名的附件不会被错误关联到其他消息，缺失的项目相对路径或非法 URL 不再生成无效的可点击项。
- 修复资源链接在流式过程中偶发显示为不可用的问题，已完成解析的链接不会被流式标记遮挡。
- 修复 Codex 用量展示相关问题。

## 如何升级

- Homebrew：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：从发布页下载 `Zeus-0.3.193-arm64.dmg`，打开后按提示将 Zeus 拖入“应用程序”完成替换。当前公开制品未经过公证，应用内自动安装不可用，请使用上述方式手动升级。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本，Apple 芯片（arm64）。
- 输入建议与草稿润色需要先在“设置 → 通用 → 输入建议”中选择专用模型；每次生成会增加专用模型用量。
- 生成最多等待 20 秒，超时后不会自动重试，可保留原文后再次点击生成。
- 润色采用时若原文已变化或引用标签未完整保留，替换会被拒绝，需要重新生成。
- 当前公开制品未经过公证，应用内自动安装不可用，升级需通过 Homebrew 或手动安装 DMG 完成。
