# Zeus 0.3.194 更新内容

## 自动化通知更易于查看与整理

- 通知列表改为更紧凑的布局，标题、项目名和时间等信息在有限空间内更整齐，过长内容会以省略号显示，并在悬停时提供完整说明。
- 通知面板标题栏新增“全部已读”操作，可一次确认全部未读通知，包括尚未加载到当前列表中的分页通知；操作成功后各窗口的未读数量会同步刷新。
- 调整了“恢复自动化”的操作说明。恢复会继续本次运行中尚未启动的项目，已经启动的项目会先核对已有结果，不会重复启动，同时重新启用后续自动化排程。

## 输入建议状态集中到图标提示

- 输入建议的加载、失败、超时、空结果等状态不再占用输入框下方的额外行，而是集中到输入区右上角的星光图标提示中。
- 生成失败时，图标会以警告样式显示，点击可打开详情并查看失败原因；如果输入建议仍可用，详情中会提供重试入口。
- 生成过程中仍可通过同一图标取消，取消操作本身不会触发新的生成。

## 任务详情与共享记录保持一致

- 打开任务详情时，完整任务记录会同步到共享任务集合，避免后续在会话中选择任务时，用摘要覆盖掉完整正文。

## 如何升级

可通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载版本化 DMG 安装包 `Zeus-0.3.194-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成升级。当前公开制品未经过公证，因此本版本仅支持手动升级，不提供应用内自动安装。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品以 ad-hoc 方式构建、未经过公证，首次打开时可能需要在系统设置中允许。
- 由于制品未公证，应用内自动安装不可用，请使用 Homebrew 或手动下载 DMG 升级。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 构建产物与固定候选提交一致，版本号与发布目标版本一致。
- 候选版本通过类型检查与打包流程，桌面端应用可正常启动。
- 输入建议图标的离线检查通过，覆盖加载、失败、超时、空结果和正常入口等状态，确认没有新增底部状态段落或重复按钮。
- 自动化通知的“全部已读”与“恢复自动化”行为经过接口与界面检查，确认写入成功后再刷新通知状态。
