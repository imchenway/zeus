# Zeus 0.3.195 更新内容

## 任务截止时间与提醒

- 创建任务和任务详情新增“截止时间”字段，可设置日期，并可选具体时间；日期会按你所在时区保存。
- 每条任务可单独配置提醒方式：提前提醒、截止时提醒或关闭提醒。未设置截止时间时不能设置提醒。
- 任务列表、看板和详情中会显示截止时间，已逾期的任务会明确标记“已逾期”。
- 任务列表新增按时间筛选：全部、已逾期、今天截止、未来 7 天、未设截止；该筛选与当前项目和搜索条件共同生效。
- 通知中心新增“任务提醒”分类，与自动化通知共用铃铛入口并显示未读总数，两类通知的已读操作相互独立。
- 任务提醒会在应用启动、系统恢复和连接重连后补读没有送达的提醒，不会因为应用暂时不活跃而丢失。
- 点击系统提醒可打开对应任务；当只有一条提醒时直接打开该任务，多条提醒时打开通知中心的“任务提醒”分类。
- 在任务详情真正显示后才把该提醒标为已读，避免只点开列表就被认为已经处理。

## 输入建议持续生成

- 输入建议的生成不再依赖输入框是否显示：会话完成后即使你正在浏览其他页面，建议也会在后台完成，回到会话时直接可见。
- 建议结果按会话、模型和轮次分别保存，切换页面不会丢失正在生成的结果，也不会把某个会话的结果显示到其他会话。
- 星光按钮的结果改为紧凑浮层展示，浮层会标注候选相较原文的改写词段；点击候选文本即可采用，采用可通过原有编辑撤销恢复。
- 空输入中的灰字建议可直接点击发送按钮发出；已有正文时发送按钮优先发送正文。
- 主会话运行期间也可以手动生成或采用草稿润色建议，不再要求先等会话空闲。
- 当输入框处于输入法组合、目标输入或附件处理中时，仍会阻止自动建议，避免打断当前输入。

## 其他改进

- 修复搜索类工具在返回空结果时可能被错误识别的问题，包括 Codex 明确返回空输出以及通过 shell 包装执行的 ripgrep 命令。
- 过滤临时思考摘要中不应出现的分组入口，减少过程展示中的干扰项。

## 如何升级

- Homebrew：

  ```
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动安装：从发布页下载 `Zeus-0.3.195-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。当前公开制品为 ad-hoc 签名且未公证，升级需要通过上述方式手动完成，应用内自动安装不可用。

## 系统要求与已知限制

- 仅支持 macOS 13.0 及以上版本，且为 Apple 芯片（arm64）。
- 当前公开制品未经过 Apple 公证，首次打开时可能需要在“系统设置 → 隐私与安全性”中允许打开。
- 任务提醒依赖 Zeus 本地服务运行；如果应用完全退出，系统提醒会在下次启动后补发，可能晚于预定提醒时间。
- 系统提醒的显示受系统通知权限和勿扰设置影响，可能被系统暂时抑制。
- 采用输入建议需要原文与引用标签保持一致；如果生成期间原文已变化，采用会被拒绝并提示重新生成。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 代码检查：lint、类型检查与单元测试在候选提交上全部通过。
- 构建与打包：桌面端能够完成生产构建并生成 `Zeus-0.3.195-arm64.dmg`。
- 门禁脚本：任务截止时间与输入建议相关验证脚本通过。
- 桌面交互检查：已在候选构建上进行桌面交互验证，导航、任务提醒点击和输入建议入口按预期工作。
