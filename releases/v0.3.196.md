# Zeus 0.3.196 更新内容

## 会话错误与重试更集中

- 会话中的错误提示不再分散在输入框、目录角落和消息旁：附件处理、消息提交、会话目录读取、历史正文读取等故障会作为 Zeus 系统消息记录在会话正文里，保留在首次发生的位置，后续消息不会把它挤到列表底部。
- 系统消息会随会话持久保存，切换会话或重新打开应用后仍能看到原记录；已经恢复的提示会保留原错误内容，不会消失或替换成恢复状态。
- 消息送达状态提示被精简：无法确认送达时只显示简短说明和“重试”入口，不再同时出现多条含义相近的提示；重试会先核对原请求，只有确认未发送才再次发送，不会把失败内容当作一条新消息重复提交。
- 输入建议生成失败时，按钮变为可点击的重试入口，点击后直接重新生成；失败原因仍可查看，不会在输入框下方额外堆一行错误。
- 会话目录或历史正文读取失败会原位显示提示并提供重试，不再单独占用正文角落的浮动状态条。

## 通知中心统一

- 自动化通知和任务提醒合并到同一个铃铛入口，未读总数统一显示，不再在两个分类之间手动切换。
- 通知列表按来源合并排序，保留原有身份：自动化通知仍可跳转到对应会话并显示执行结果，任务提醒仍可跳转到任务详情并显示截止时间。
- 每条通知可以单独标为已读，也可以一次全部标为已读；标为已读只影响未读状态，不会启动、恢复或重跑任何自动化。
- 打开通知并真正看到对应内容后才会确认已读，取消跳转或未加载完成时保持未读。

## 会话正文与图片显示

- 修复中文加粗解析：正文中的中文粗体标记能够正确渲染，不再因解析差异漏掉或错位。
- 修复会话图片归档：图片按原始引用匹配，说明文字相同的不同图片不会被错误地指向同一份资源；缺失的图片会明确显示为引用未登记，而不是笼统的加载失败。

## 任务创建与归档显示

- 新建任务时不再要求填写截止时间，减少创建表单的必填负担；已有任务的截止时间与提醒仍照常工作。
- 归档会话时，会话行末尾会显示归档进行中的状态，完成后恢复该会话自身的运行状态。

## 如何升级

仍建议手动升级，应用内自动安装暂不可用。

- Homebrew 用户：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：下载 `Zeus-0.3.196-arm64.dmg`，打开后将 Zeus 拖入「应用程序」覆盖旧版本。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc 签名、未公证，因此只支持手动升级，应用内自动安装可能不可用。
- 系统消息会保存在本地，若本地存储暂时不可写，记录仍会保留在内存中并在恢复后继续补写，但修复前重启应用可能导致尚未同步的提示丢失。
- 通知中心的批量已读只更新未读状态，不会改变自动化本身的运行或后续排程。

## 发布验证

公开 Release 只会在固定候选通过以下检查后创建：

- 仓库内发布证据指定的版本号与候选提交一致，且提交范围完整覆盖 v0.3.195 到该候选。
- 类型检查、Lint 与构建通过。
- 桌面应用打包成功，DMG 文件名符合 `Zeus-0.3.196-arm64.dmg`。
- 系统消息、图片归档与中文加粗相关验证脚本通过。
- 发布产物手动安装后可以启动。
