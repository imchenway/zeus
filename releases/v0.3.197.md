# Zeus 0.3.197 更新内容

## 输入建议与评论附件

- 输入建议现在会结合当前任务描述、已确认的项目与全局偏好、近期对话原话以及相关记忆来生成，更贴合你正在做的事。
- 当你发送新的要求或调整发送方向时，已有建议会立即失效，避免旧的补全内容继续停留在输入框里。
- 待发送的代码评论与网页评论附件改为统一交互：悬停时短暂停留后展开详情，点击或键盘聚焦仍会直接查看，并按 Escape 关闭。

## 提示气泡统一

- 全应用范围内的图标、按钮、标签和代码编辑器的悬停提示统一为同一个延迟显示的气泡，需要连续停留约 0.8 秒才会出现，避免只是移动鼠标就频繁弹出。
- 同一条提示内的子节点之间移动鼠标不会重新计时；点击、键盘聚焦、切换页面、按 Escape 都会取消尚未显示的等待。
- 长提示支持在气泡内滚动阅读，超出屏幕时不会再被裁切；键盘用户面对的说明与对应控件保持关联。
- 提示文案保留原有的纯文本换行，多行内容（如提交说明、路径、分支关系）显示更完整。

## Git 与任务视图

- 分支、标签、提交记录、文件树、差异对比、暂存与提交等位置的说明文字改用统一气泡，读起来更稳定。
- 交付反馈、用量日历、菜单栏用量窗口等处的悬停详情也改为延迟显示，鼠标经过不再立刻弹出费用或用量明细。

## 系统要求与已知限制

- 支持 macOS 13.0 及以上版本。
- 本次发布以手动升级为主要路径；当前公开制品可能仍是 ad-hoc、未公证版本，应用内自动安装更新可能不可用。
- 提示气泡的延迟时长统一为约 0.8 秒，不同入口不再单独设置时长。

## 如何升级

使用 Homebrew：

```
brew upgrade --cask imchenway/tap/zeus
```

或从发布制品手动升级：下载 `Zeus-0.3.197-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。

## 发布验证

公开 Release 只在固定候选提交通过以下门禁后才会创建：仓库内的 lint、typecheck、构建与打包检查通过，桌面应用可完成启动与基本交互验证，版本号与制品名和候选一致，且发布制品与候选提交一一对应。任一检查未通过时不会创建公开 Release。这些条件对 0.3.197 及其后续补丁版本长期有效。
