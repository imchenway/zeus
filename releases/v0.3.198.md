# Zeus 0.3.198 更新内容

## 会话导航悬停体验优化

- 调整了会话目录刻度的悬停触发时机：在预览完全关闭后，首次停留在某个刻度上会等待短暂时间再弹出预览，减少鼠标扫过时误触发预览的情况。
- 当预览已经打开时，在刻度之间连续移动不再重新计时，切换目标可以立即显示对应预览，浏览更连贯。
- 键盘操作依然即时显示预览，不受上述等待时间影响。
- 刻度与预览卡片之间移动时保留容错，不会因为短暂经过间隙而立刻关闭。

## 如何升级

- Homebrew：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：从发布页下载 `Zeus-0.3.198-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。

当前公开制品为 ad-hoc 签名且未公证，应用内自动安装不可用，请通过上述方式手动升级。
