# Zeus 0.3.2 更新内容

## 冲突处理工作台改进

- 冲突处理界面改为更符合代码审查习惯的布局：左侧为紧凑文件列表，右侧为三栏代码对照，顶部提供冲突导航、视图切换和处理操作，减少界面噪音。
- 冲突处理前的新会话创建流程优化：确认权限后立即进入会话界面，会话在后台建立，减少等待时间。
- 改进冲突会话的用户反馈，处理过程中显示明确的连接状态，失败时提供重试入口。

## 会话切换与导航增强

- 修复了切换会话时可能出现空白页的问题。切换会话时，旧会话内容会保留，直到新会话加载完成，避免闪烁。
- 增加“跨项目会话导航”稳定性，确保切换会话时项目和会话不分离，避免错位。
- 新增项目工作区快捷键：`Cmd+1` 至 `Cmd+5` 快速切换“任务、Git、源码、图谱、命令”五个工作面。
- 会话右侧的上下文面板（浏览器、源码、计划等）现在支持 `Cmd+W` 关闭当前标签，与 macOS 习惯一致；焦点不在面板时仍关闭窗口。

## 消息发送状态可见性

- 发送消息后，消息旁会显示明确的状态：“正在发送”“排队中”“已接收”等，让用户清楚消息是否已交给模型。
- 当发送失败时，消息显示“发送失败”和原因，原内容自动回到输入框，可修改后重发，不会自动重复，避免重复消息。
- 当发送结果不确定时，显示“发送结果待确认”，Zeus 不会自动重发，防止重复投递。
- 所有会话类型（普通、任务、代码审查、冲突处理）统一使用此反馈机制。

## 其他修复与优化

- 修复打开 Git 页时报错的问题。
- 修复冲突处理的会话无法继续对话的问题。
- 修复引导消息删除后卡在会话中的问题。
- 修复代码审查点击确认后卡死的问题。
- 修复冲突处理页面的布局优化和性能问题。
- 优化选项框自定义输入高亮，与预设答案样式一致。
- 会话标题栏支持直接修改任务状态，与任务列表、任务详情保持一致。
- 修复会话刚创建时的体验，连接提示更准确。

## 如何升级

**Homebrew 用户：**

```bash
brew upgrade --cask imchenway/tap/zeus
```

**手动升级：** 从官方发布渠道下载版本化 DMG 文件 `Zeus-0.3.2-arm64.dmg`，打开后拖拽 Zeus 到 Applications 文件夹替换旧版本。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 当前公开制品为手动升级方式，应用内自动安装暂不可用。
- 若从旧版本升级，Codex 登录状态可能需要重新确认。
