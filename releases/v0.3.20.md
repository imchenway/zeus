# Zeus 0.3.20 更新内容

## 模型路由与认证设置

第三方模型连接现在可以为每个模型单独选择请求协议：OpenAI Chat Completions 或 Anthropic Messages。对于 Claude 模型，使用 Anthropic Messages 协议可启用缓存断点，并正确显示缓存写入与缓存读取的用量统计。认证方式独立配置，支持协议默认、`Authorization: Bearer` 和 `x-api-key`（仅 Anthropic 协议可选），避免请求头混淆。现有模型默认保持原协议，不会自动切换；已配置的 Claude 模型如需使用原生缓存，请在设置中手动改为 Anthropic Messages。

## 会话模型选择与稳定性修复

修复了切换模型后输入框静默回退到首选模型的问题。当所选模型暂时不可用时，界面会显示“当前选择不可用”并阻止发送，直到你主动选择其他模型，不会悄悄替换你的选择。同时修复了切换运行分段时可能出现的“Codex native conversation was not found”错误，确保 Pi 与 Codex 分段之间的续接稳定。

## 会话过程展示优化

长轮次中的工具活动按类型分组展示：命令、MCP、网页、图片和文件变更各自独立，不再混合计数；命令组最多显示 32 条，失败或用户命令会立即截断。进行中的思考摘要只显示最新一条，最终回答后历史摘要自动隐藏，减少纵向噪音。过程行间距收紧，同一视口可查看更多信息。

## 如何升级

### 通过 Homebrew 升级

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

下载最新版本 DMG `Zeus-0.3.20-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹。若旧版本正在运行，请先退出再替换。

## 系统要求与已知限制

- 最低 macOS 版本：13.0
- 第三方 Claude 模型需在连接设置中手动选择 Anthropic Messages 协议才能使用缓存功能；未修改的现有模型继续使用 OpenAI Chat Completions。
- 自定义 Responses 模型暂时无法使用 Codex Remote Control 远程宿主，会使用本地隔离的 App Server。
- 会话中已保存的模型若被删除或禁用，需要重新选择。

## 发布验证

公开 Release 会在通过以下检查后创建：格式检查、`pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm package:mac` 通过，并完成严格的签名校验与隔离运行验证。
