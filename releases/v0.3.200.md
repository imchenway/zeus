# Zeus 0.3.200 更新内容

## 输入建议质量改进

- 主动点击“生成输入建议”时，会更倾向围绕你最近明确提出、但尚未解决的问题起草一句具体的追问、纠偏或补充要求；任务进行中也会尝试给出这类回应，而不是笼统提示“继续”。
- 自动建议在没有可靠下一步时才保持无建议；助手列出计划或表示“正在处理”不会被直接当作问题已解决，也不会因此排除可以起草的具体追问或验收要求。
- 主动点击只代表表达起草意愿，不会被当作对候选内容中新增决定或执行操作的用户授权。
- 生成结果为空、为明确的“无建议”标记或为正文时，界面与本地服务会分别归类和记录。

## 屏幕预览与状态提示

- 屏幕预览截图按原始清晰度呈现，使用细边框与轻阴影，不再使用模糊副层；预览尺寸与位置更紧凑。
- 控制按钮缩小并右对齐，悬停、键盘聚焦或展开详情时显示；无图或读取失败时始终保留停止入口。
- 状态说明不再显示在缩略图下方，而是保留在控制详情与读屏说明中；停止屏幕控制失败时给出明确错误。
- 控制详情中，只有错误状态按错误展示；用户接管等正常说明保持原意。

## 诊断日志

- 新增输入建议诊断日志，记录请求各阶段的状态、枚举、耗时与字数，写入本机正式日志目录。
- 日志只包含有界元数据，不记录草稿、建议正文、模型原始报文或凭据；字段经白名单过滤，疑似凭据会替换为 `[REDACTED]`。
- 界面与本地服务分开写文件，每个文件约 2 MiB，最多保留当前文件与两份历史文件，磁盘异常时不会无界占用内存。
- 诊断不可用或写入失败不会影响你的生成操作与结果；正常关闭时会等待已接收记录落盘。

## 其他修复

- 侧栏来源列表长文件名改为在列内省略，不再撑开面板或产生横向滚动条。
- 本地日志目录统一使用本次运行的数据布局，不再按数据库文件名拼接旧路径。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

或下载版本化 DMG 后手动安装：`Zeus-0.3.200-arm64.dmg`。该制品为 ad-hoc 签名、未公证，首次打开可能需要在“系统设置 → 隐私与安全性”中放行；这是手动升级方式，不提供应用内自动安装。

## 系统要求与已知限制

- 仅提供 Apple Silicon（arm64）构建，最低系统版本为 macOS 13.0。
- 输入建议默认关闭，需要在设置中选择模型后启用。
- 输入建议为可选功能，失败或超时不会影响会话正文；其诊断日志仅用于本机排查。
- 屏幕预览需要系统授予相应的屏幕录制权限；停止屏幕控制失败时会显示错误提示，但已授权的截图可能仍会短暂停留在界面上。
