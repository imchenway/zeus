# Zeus 0.3.201 更新内容

## 组合式 Git 代码交付

- 会话与任务的代码交付入口现在提供“运行组合”操作，可以把提交、合入、推送按顺序一次配置后交给后台执行，执行进展会在原交付面板中持续显示。
- 组合操作按项目保存偏好（提交 / 合入 / 推送、是否在出现合入冲突时交给 AI、AI 的权限模式与使用的 Skill），任务入口还可以在全部步骤成功后把任务状态变更为指定状态。
- 各仓库独立执行；只有全部成功时才更新任务状态。遇到合入冲突时可以在原三栏冲突编辑器中处理，AI 接管需要你明确选择权限模式。
- 交付步骤可能处于“需要处理”或结果待核对状态，可以手动继续未完成步骤，已成功的步骤不会重复执行。若某一步涉及任务结束清理，会先展示受影响的工作区、活动会话和活动运行数量，确认后才会继续。

## 输入建议与润色

- 输入框内可用 Tab 采用或生成建议，Escape 取消；Escape 后紧接的一次 Tab 会恢复为普通焦点导航。
- 生成或润色期间可以继续输入，结果会以预览形式保留并说明这是替换当前输入的可撤销操作；采用时会核对当前原文，若原文已变化或引用标签未被保留则保留你的输入并提示重新生成。
- 生成过程中若遇到临时网络或服务端故障，会在有限次数内自动重试，并在同一图标位置说明重试进度；单次尝试超时后仍保留原文。
- 通用设置中新增输入建议的“生成速度”选项，可选择标准或 Fast；Fast 可降低延迟但可能增加用量或费用，是否可用取决于所选模型。

## 会话状态与提醒

- 侧栏会为存在异步待回复问题的会话显示待回复状态，即使会话未打开或历史尚未载入；会话内回复后状态随之更新。
- 修复了会话重试与虚拟列表高度相关问题：最新一轮的失败卡会保留并可显式续跑，已被后续轮次接管的旧续接错误不再占用空白高度。
- 网络失败卡现在可以像其他错误一样查看原因详情，并提供手动重试入口。

## Codex 更新与安装来源

- 后台更新只针对 Zeus 管理的 Codex 安装；由你自行安装的 Codex 会在设置中说明需要按原方式更新，Zeus 不会修改它。
- 受管 Codex 的后台自动更新只在应用处于后台时发起，会先持久化安装意图再提交；同一程序路径与目标版本不会自动重发，失败或断线后保留记录，可在设置中手动检查。
- 若自动更新记录无法读取，将只进行检测和提示，不会自动安装。

## 如何升级

- 使用 Homebrew 升级：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 也可以下载 `Zeus-0.3.201-arm64.dmg` 手动安装。当前公开制品仍为 ad-hoc 签名且未公证，请通过手动方式完成升级，暂不支持应用内自动安装。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc 签名且未公证，首次打开可能需要在“系统设置 > 隐私与安全性”中允许；请使用上述 Homebrew 或 DMG 方式手动升级。
- Codex 后台自动更新仅覆盖 Zeus 管理的安装；自行安装的 Codex 需要按原安装方式更新后重新检测。
- Fast 速度模式的可用性取决于所选模型，不可用时保持可见但不可选。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 类型检查、Lint 与构建通过。
- 候选范围内的发布验证脚本通过，包括输入建议上下文、输入建议控件、组合式 Git 交付和异步待回复提醒相关检查。
- 桌面打包成功，产物版本与 `0.3.201` 一致。

以上条件为公开 Release 的长期门禁；只有全部满足时才会发布对应制品。
