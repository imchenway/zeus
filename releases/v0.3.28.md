# Zeus 0.3.28 更新内容

本次更新修复了在 ChatGPT iOS 上选择答案后，Zeus 会话历史无法显示具体选择的问题。

## 改进

- **同步 iOS 端选择答案**：当你在 ChatGPT iOS 上完成询问并选择答案后，Zeus 现在会自动同步该选择到会话历史，无需额外操作。
- **增强答案回填机制**：Zeus 会从本地 Codex 会话记录中安全地恢复答案，仅在确认匹配时才写入，避免错误或猜测。
- **明确同步状态提示**：若因故无法获取具体答案，Zeus 会明确显示“答案同步失败”的提示，而非误导性显示“已回答”，确保信息透明。

## 如何升级

- **通过 Homebrew 升级**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：下载 `Zeus-0.3.28-arm64.dmg`，打开并拖拽 Zeus 到“应用程序”文件夹，替换旧版本。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本（Apple Silicon）。
- 已知限制：答案同步依赖本地会话记录，若文件缺失或格式不兼容，可能无法恢复答案，此时将以“答案同步失败”状态显示，并可能显示警告图标。
