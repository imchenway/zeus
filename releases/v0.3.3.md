# Zeus 0.3.3 更新内容

## 主要改进

### 侧边栏与项目导航
- **按任务状态分组会话**：侧边栏新增“按任务状态分组”功能，可在“平铺”和“按任务状态分组”两种组织方式间切换，并记住你的选择。
- **项目不再显示会话聚合提示**：移除了项目行的红点、未读数量等聚合指示，单条会话的运行状态更直接、清晰。

### Git 工作台增强
- **显示当前分支**：Git 页面顶部的分支切换器现在清晰显示当前分支，并在多仓库项目中展示各仓库的当前状态。
- **新增“更新项目”操作**：支持以合并、变基或重置方式更新全部仓库，重置前需确认丢弃未包含在远端中的本地提交。
- **支持签出标签或提交号**：可直接输入标签、分支或提交号签出，进入游离提交状态，并可从该位置新建分支。

### 会话与任务管理
- **新会话执行上下文选择**：新建项目对话时，输入框上方直接展示项目与分支选择器，可切换真实项目目录和 Git 分支，并支持创建新分支。
- **任务终态即时收口**：任务变为“已完成”或“已取消”时，相关会话立即从侧边栏活跃列表退出，但工作区仍保留只读历史，可随时查看。
- **冲突处理会话标题优化**：冲突处理会话统一显示为“冲突处理：当前任务名称”，不再使用分支名作为标题。

### 交互与细节优化
- **界面文字选择更精准**：应用层不再允许整页或跨容器选中，但输入框、正文、代码和终端日志等真实内容区仍可正常选字复制。
- **终端日志一键复制**：命令中心新增“复制全部日志”按钮，复制完整日志内容，并明确反馈复制状态。
- **动效与响应优化**：会话切换、消息发送、新项目列表出现等动效更流畅，操作即时响应，不被动画排队阻塞。
- **Ctrl/Cmd+W 关闭层级**：现在按顺序关闭最顶层模态框、活动会话标签和窗口，避免误关整个应用。

## 如何升级

### 通过 Homebrew

运行以下命令即可升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级（DMG）

从官方渠道下载 `Zeus-0.3.3-arm64.dmg`，双击打开并将 Zeus 拖入“应用程序”文件夹。若已安装旧版本，请先退出 Zeus，再覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 主窗口最小宽度调整为 640px，以保证询问、授权等操作的行内控件可用。
- 侧边栏按任务状态分组功能默认关闭，可在项目标题右侧切换。
- 当前公开制品为手动升级，暂不支持应用内自动更新。
