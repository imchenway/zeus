# Zeus 0.3.33 更新内容

本次更新主要修复了会话切换与历史查看中的体验问题，并优化了长内容的加载方式。

## 会话切换与历史查看优化

- 修复了快速切换多个历史会话后，侧栏部分会话永久显示“转圈”或“重新连接”的问题。现在侧栏只反映会话的真实运行状态，不再受到视图加载过程的干扰。
- 打开历史会话时，默认只加载本地快照，不再自动建立实时连接；只有会话真正处于运行中或用户发送消息时才建立实时订阅，空闲时会话会自动释放连接。
- 发送消息时，即使会话处于空闲状态也会自动建立连接并发送，无需手动点击“重新连接”。

## 历史消息与正文自动加载

- 打开历史会话后，滚动到顶部时会自动加载更早的消息，不再需要反复点击“加载更早消息”按钮。
- 不可见的内容（如较长正文、工具结果、处理过程、资源与变更）在滚动到可视区域时会自动加载，减少了手动点击操作。
- 对于超过单页限制的极长内容，保留“展开剩余内容”按钮，避免自动加载过多数据。
- 修复了部分长内容因内部标识过长而无法读取的问题，现在这类内容可以正常显示。

## 内部数据展示修复

- 修复了部分命令执行或工具调用的内部 JSON 结构被直接显示在会话正文中的问题，现在只显示面向用户的文本摘要，不再暴露内部原始数据。
- 对于截断的命令详情，现在能正确显示为可读的命令摘要，而不是原始 JSON。

## 如何升级

### 通过 Homebrew 升级

如果你已通过 Homebrew 安装 Zeus，可直接运行以下命令升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级（DMG）

若未使用 Homebrew，可从发布页面下载最新的 DMG 安装包，手动替换应用。本版本对应的 macOS 磁盘映像文件名为：

```
Zeus-0.3.33-arm64.dmg
```

下载后，打开 DMG 并将 Zeus 拖入“应用程序”文件夹（或替换旧版本）。

请注意，当前公开制品可能仍为 ad-hoc 签名，升级后首次打开若提示安全警告，请通过“系统设置 → 隐私与安全性”允许运行。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本（包括 Apple Silicon）。
- 空闲历史会话在无实时订阅时，不会自动同步其他客户端对会话所做的修改；重新进入该会话或发送消息时会获取最新状态。
- 部分新增的自动加载功能是客户端与服务端共同配合实现的，请确认桌面端与本地服务组件均已升级到本版本。
- 本版本未包含应用内自动安装能力的改进，升级仍需通过上述手动方式完成。

## 发布验证

公开 Release 只有在满足以下条件时才会正式创建并标记为发布：

- 代码通过 `pnpm lint`、`pnpm typecheck` 与 `pnpm build`。

- 通过会话事件流行为探针，验证空闲历史不建立实时连接、发送消息自动建连、活动会话保持订阅、空闲后释放连接，以及内部 JSON 不进入消息正文等行为。
