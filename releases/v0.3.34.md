# Zeus 0.3.34 更新内容

## 会话体验改进

- 活动轮次中的命令、文件读取/搜索、网页搜索、技能和工具现在合并为一个稳定的过程组，新增操作会追加到组内明细，不再反复新增顶层摘要行；轮次完成后过程默认收起，展开后可查看详细列表和图片缩略图。
- 最新的思考摘要固定在所有过程项之后显示，模型仍在工作时底部始终保留“正在思考”或“正在启动处理”的状态行；计划、命令、文件等语义图标保持静止，只有专用加载环旋转，并修正了加载环被拉成椭圆的问题。

## 会话切换与历史加载修复

- 修复了切换会话或升级重启后，历史消息可能一直显示“加载中”的问题：本地读取请求现在有 8 秒超时，超时后会刷新连接并重试一次；主进程在 Core 交接期间也会等待交接完成后再返回新端口。
- 空闲的历史会话不再显示“连接失败”或“重新连接”提示，只有发送消息或存在运行中的轮次、队列、待处理请求时才建立实时连接；重新进入会话或发送消息时会自动读取最新内容。
- PLAN 模式的开发计划现在会随会话快照一起恢复，轮次完成、切换会话或重启后仍能看到最近的有效计划。

## 配置与推送约束

- 历史会话恢复后会保留之前设置的推理强度（如 `xhigh`）和协作模式，不再错误显示为模型默认值。
- 推送任务时，如果所选模型不支持当前选择的推理强度，会直接提示重新选择，不再静默降级。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从发布页面下载 `Zeus-0.3.34-arm64.dmg`，打开后按提示将 Zeus 拖入“应用程序”文件夹覆盖旧版本。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前官方制品为手动安装包，尚不支持应用内自动更新；请使用上述方式升级。
