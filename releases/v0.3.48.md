# Zeus 0.3.48 更新内容

## 本次更新

- 修复 PLAN 模式确认实施时，控制面 `thread/read` 被慢过程投影反向阻塞、消息长时间排队后超时的问题。
- 精简消息投递异常提示：待确认与明确失败使用不同状态，默认只显示可理解的原因，错误码和原始方法名收入“技术详情”。
- 将“正在读取更早消息…”移出消息正文流，改为滚动区顶部覆盖提示，不再撑开空白或改变历史消息高度。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.48-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- 当前正式包为 ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证；首次启动可能需要按 macOS 提示手动确认。
- 超时且投递结果无法确认的消息仍不会自动重放，需要用户确认后手动重试。
