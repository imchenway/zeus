# Zeus 0.3.50 更新内容

## 本次更新

- 会话最后一轮在思考或执行尚未正常结束时被意外中断，重新启动并打开会话后，该轮处理过程现在默认展开；正常完成轮次仍默认折叠，用户手动收起或展开的选择继续优先。
- PLAN 自定义回答完成本地持久化后立即收敛确认卡和队列投影，完整会话水合改为后台执行；`account/read` 等附属读取失败不再把已接受回答改判为失败。
- PLAN 派发前的 `thread/turns/list` 权威对账使用控制优先级，不再被同一 app-server 的慢过程投影反向阻塞；同一 submission 的本地消息、队列状态和迟到投影合并为一个用户气泡。
- “推送到新会话”的任务工作区、Git 仓库和 Worktree 能力读取不再同步等待 Codex `account/read`；Codex 账户通道超时时，DeepSeek 等非 Codex 模型和 Git 表单仍可正常完成加载。
- 任务推送加载文案改为“正在读取任务工作区与 Git 仓库…”。选择 Codex 且提交时确认需要登录，仍会进入既有登录流程，不会循环创建。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.3.50-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0，仅提供 Apple Silicon 版本。
- 当前正式包为 ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证；首次启动可能需要按 macOS 提示手动确认。
- 本轮没有重放截图中的失败 PLAN submission，也没有自动重发任何结果未知的 Provider 提交。
- 三类问题已覆盖真实 Renderer、应用边界和测试包结构验收，但没有在正式 Provider 中重演意外退出、PLAN 自定义回答或实际创建任务 Worktree；这些结果不冒充正式 Provider 端到端验收。
