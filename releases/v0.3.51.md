# Zeus 0.3.51 更新内容

## 代码高亮与查看体验

- 会话中的文件预览、代码变更、项目 Git 差异以及任务冲突处理界面现在都带有语法高亮，覆盖多种常见编程语言和配置文件。代码编辑器也继续支持这些语言，打开文件时按需加载，避免拖慢启动速度。
- 差异对比（包括项目 Git 差异、任务审查与交付差异）中，新增和删除的行会根据语言着色，同时保留原有的行号、增删背景和滚动操作。
- 修复了在暗色主题下语法颜色可能被其他样式覆盖的问题，现在明暗主题都使用统一的颜色方案。

## 会话稳定性与展示修正

- 修复了在处理 Git 冲突时，点击“AI 处理冲突”可能导致同一轮会话内容（包括用户提示词和助手过程消息）在界面中重复显示的问题。现在每个消息条目只显示一次，即使经过分页加载或在应用重启后。
- 会话中的显式交付资源（如文件卡）现在会出现在该轮最终回答之后，不会再错误地出现在处理过程中间或正文上方。
- 运行详情面板重新排版：模型、推理强度、服务层级、Token 用量和费用分组显示，缺失数据统一显示为“-”，鼠标悬停可查看原因；线程 ID 和 JSONL 路径现在可以直接复制。
- 修复了 PLAN 自定义回答提交后可能因后续读取操作失败而被错误标记为失败的问题。

## 如何升级

- **Homebrew（推荐）**：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- **手动安装**：从发布页面下载 `Zeus-0.3.51-arm64.dmg`，打开后将 Zeus 拖入“应用程序”文件夹。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0，仅提供 Apple Silicon 版本。
- 当前正式包为 ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证；首次启动可能需要按 macOS 提示手动确认。
- 本次版本未对历史会话数据做自动迁移，但兼容已存在的旧数据。

## 发布验证

公开 Release 仅在固定候选提交通过所有预检、类型检查、正式 macOS 打包、DMG 完整性校验以及更新清单与 Homebrew Cask 一致性校验后才会创建。公开资产必须与 GitHub 服务端摘要、更新清单和 Homebrew Cask 保持一致。
