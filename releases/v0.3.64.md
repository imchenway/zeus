# Zeus 0.3.64 更新内容

## 会话处理过程调整为单轮单入口

每个模型轮次现在只显示一个“处理过程”入口。运行中的轮次默认展开，展示各阶段摘要（如 A、B、C）及其对应的命令、工具、文件、网页和思考过程；用户可以手动收起为只显示“正在思考”。当最终正文到达时，处理过程会自动收起，完成态只保留最终正文、交付文件和处理耗时，点击入口后才会展开完整阶段过程。这一交互在普通会话和 Subagent 中保持一致，不再为每个阶段生成独立入口。

## 修复单轮过程展开状态残留

修复了在运行过程中手动展开或收起处理过程后，最终正文到达时状态可能残留的问题。现在完成态会始终回到默认的收起状态，避免折叠器沿用运行期的交互覆盖。

## 改进 Markdown 分栏预览空间利用

右侧 Markdown 分栏的横向内边距缩小（20–36px），正文上限放宽到 64rem，使半屏宽度的分栏能更充分地利用可用空间，减少大面积空白。全宽模式下仍保留 64rem 上限，避免单行过长。

## 清理未引用的快照数据

修复了同一 Provider 文件变更多次更新时，旧捕获快照未被回收的问题。现在每次捕获后都会按数据库引用清理变更集目录中不再被引用的快照文件，避免长会话中快照数据持续累积。清理不会削弱 Undo/Reapply 历史能力，已捕获且仍被引用的快照全部保留。

## 如何升级

- **Homebrew**：执行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从发布页下载 `Zeus-0.3.64-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹覆盖旧版本。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品为手动升级包，应用内自动更新尚不可用。
- 右侧分栏的 Markdown 正文在宽面板下可能较长，这是为了提升空间利用率，全宽模式仍保留限宽。

## 发布验证

公开 Release 只有在以下固定候选通过检查后才会创建：
- `pnpm lint`、`pnpm typecheck`、`pnpm build` 均通过。
- `pnpm package:mac` 成功生成应用包。
- 独立 `Zeus Test.app` 真机启动健康：`/health` 返回应用、数据库、运行时均正常，SQLite `quick_check=ok`。
- 浏览器组件验收覆盖：单轮单入口、阶段摘要、手动收起、final 自动收起、完成态折叠等交互。
