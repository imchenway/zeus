# Zeus 0.3.68 更新内容

## 项目设置优化

- 项目设置页现在直接进入数字员工管理，不再展示仓库状态、代码图谱摘要和扫描/查看变更等重复信息，也不再自动打开旧项目配置抽屉。

## 数字员工配置改进

- 数字员工的“模型”“推理强度”“服务层级”改为下拉选择，并依据当前项目的真实模型能力联动。选定模型后，推理强度和服务层级只显示该模型支持的值；模型改变时会清空上一模型的推理强度和服务层级，避免跨模型残留。
- 未选定模型时，推理强度和服务层级仅显示“跟随模型默认”；历史旧值不受当前模型支持时会显示为禁用状态，不再允许用任意文本绕过能力目录。
- 项目员工主从区改为可视高度受限的内部滚动，操作栏（保存/停用/移除）保持在右侧编辑区底部，修改字段后随时可见。

## 会话归档与推送稳定性修复

- 修复了推送任务失败后留下的本地排队会话无法归档的问题。这类“未绑定 Provider”的会话现在可以安全地取消本地队列并归档，之后可在“已归档会话”中恢复回原任务。
- 修复了恢复未绑定归档会话时错误要求 Provider 或 worktree 前置条件的问题；恢复只还原本地归档标记，不再伪造外部写入。
- 修复了会话同步事件在相同毫秒内因内容不同却使用同一事件身份导致的冲突；现在事件身份会结合投影内容指纹，同时保留幂等重放。
- 修复了单条会话增量失败污染整个进程、导致其他任务推送被阻断的问题；冲突增量会被隔离并由权威快照恢复，不再影响其他会话。
- 修复了已接受的交互回答因后续 UI 增量发布失败而被误报为“结果未知”的问题；进行中的明确拒绝也会被归类为明确拒绝，不再伪装成外部结果未知。

## 如何升级

- Homebrew：运行 `brew upgrade --cask imchenway/tap/zeus` 升级。
- 手动升级：从版本化 DMG 安装，文件名为 `Zeus-0.3.68-arm64.dmg`。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品为手动升级方式，应用内自动安装暂不可用。
- 若 Provider 尚未就绪或项目没有可用模型，数字员工模型选择只能使用“跟随项目默认”，无法用文本绕过能力目录。
- 未绑定会话恢复后不会自动重发旧消息，避免未确认重放。

## 发布验证

- 公开 Release 只有在固定候选通过 `pnpm lint`、`pnpm typecheck` 和完整打包构建后才会创建。
- 打包构建会验证代码签名（Designated Requirement）和磁盘校验和。
- 发布后，Homebrew Tap 会同步更新至该版本。
