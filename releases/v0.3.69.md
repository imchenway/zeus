# Zeus 0.3.69 更新内容

## 修复与改进

- **修复会话归档和推送错误**：修复了任务推送时可能出现的同步事件冲突，以及归档当前会话时可能出现的“结果未知”错误。归档操作现在会先卸载正在读取的正文，避免过期请求干扰，失败时会恢复选择。同时，业务提交和界面更新分层处理，业务成功不再被界面投影失败覆盖。
- **改进重启和退出流程**：完整重启现在会先停止遗留工作，再关闭旧版 Core，确认旧进程和数据库写租约释放后启动新版本，避免新界面连接到旧版 Core。退出时增加了运行时和控制服务的关闭超时，防止应用卡死。重启使用独立接力进程，确保旧 Main 退出后新 Main 正确启动。
- **优化错误提示和日志**：移除了全局运行期错误弹窗，技术细节经脱敏后只写入本机运行日志，界面只显示可理解的操作结果。启动失败时显示统一的“启动失败”页面，提供“重新启动”和“退出”选项，不再叠加原生弹窗或全屏蒙层。
- **修复重启后会话状态显示**：如果重启后发现某轮已暂停，旧运行状态会收口为“中断”，界面不再显示“正在思考”。会话快照只会在 Provider 状态确认为活动时显示活动回合，避免矛盾状态。
- **修复旧版会话正文显示**：旧版 DeepSeek 会话中缺少阶段标记的助手消息不再被折叠进“处理过程”，而是直接显示为普通正文，避免隐藏真实答案。

## 如何升级

- **Homebrew**：
  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```
- **手动升级 DMG**：请下载 `Zeus-0.3.69-arm64.dmg` 并替换当前安装的版本。安装完成后，请完全退出并重新启动 Zeus，以应用完整重启流程。

> 注意：如果是从旧版本升级，重启时会先停止遗留工作，请确保没有正在进行的任务。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 已知限制：更换版本后首次重启会停止未完成的工作，不会自动继续。无法确认 Provider 是否仍在远端运行时，本地会保守显示“已暂停”或“已中断”。
- 升级前请保存当前工作，升级后需要手动重新启动未完成的任务。

## 发布验证

只有以下检查全部通过后，才会创建公开 Release：
- 源码通过 lint、类型检查和构建检查。
- 桌面应用完成打包并验证签名。
- 数据库一致性检查（PRAGMA quick_check）通过。
- 独立测试包通过界面、退出、重启、归档和旧版本迁移场景的验证。

只有这些固定候选通过后，才会发布到公开渠道。
