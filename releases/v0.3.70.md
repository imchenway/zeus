# Zeus 0.3.70 更新内容

## 消息发送与恢复

- 修复了突然全部消息无法发出，重启后部分会话仍无法继续发送消息的问题。现在遇到发送中断时，界面会清晰提示每一条未发送消息，并支持逐条重试或取消。
- 修复了重启后任务无法继续的问题：重启前正在执行的轮次会在恢复后自动继续，并保留之前的工作状态。
- 改进了消息发送超时的处理：当请求超时，Zeus 会自动重试，并显示当前重试进度（第几次/共几次），避免误以为发送失败。

## 会话历史与长消息

- 修复了会话打开时历史消息加载不完整的问题。现在打开会话只会定位到最新消息，只有你主动向上滚动阅读时才会加载更早的历史，并保持当前阅读位置不跳动。
- 修复了长消息被截断的问题。现在长回答会自动加载完整正文，如果加载失败会明确提示并允许重试。

## 数字员工协作

- 数字员工现在可以按“方案规划 → 实施 → 代码审查”的阶段协作处理任务。你可以在每个阶段选择不同的数字员工，并在阶段完成后预览完整输出，确认后交接给下一位员工，或要求继续完善。
- 失败的阶段会保留失败记录，你可以选择新的数字员工创建独立的新尝试，而不会覆盖历史。
- 旧版单会话执行仍然清晰标记，不会伪造阶段和交付物，你可以选择将其输出作为交接起点。

## 其他改进

- 修复了创建会话时连接失败的错误栏：失败后只显示错误和重试入口，不再显示“正在思考”等误导状态。
- 改进审批界面：当无法确认文件目标（如文件不在项目内、授权范围超出审计边界）时，只提供“拒绝”或“取消”操作，并解释原因，避免误授权。
- 项目模型速度偏好现在归属于项目配置：你可以在项目会话或任务推送中选择 Standard 或 Fast，并保存为项目级偏好，后续会自动应用。
- 应用更新重启前会明确提示将停止哪些活动工作（如正在执行的轮次、等待交互等），你确认后才会进行重启和更新。

## 如何升级

**Homebrew 用户**

```bash
brew upgrade --cask imchenway/tap/zeus
```

**手动升级**

从 Zeus 官网或 GitHub Releases 下载最新版本磁盘映像文件 `Zeus-0.3.70-arm64.dmg`，打开后将 Zeus 拖入“应用程序”文件夹覆盖旧版本。手动升级不会自动保留登录状态，请重新登录。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品为 ad-hoc 签名且未公证，首次打开时请在“系统设置 → 隐私与安全性”中允许来自未知开发者。
- Homebrew 升级会自动替换应用；手动升级需自行拖拽覆盖。

## 发布验证

公开 Release 只有在以下检查全部通过后才会创建：

- 单元测试、类型检查、构建全部通过；
- 桌面端打包成功，应用可正常启动；
- 发布验证脚本通过，包括数字员工阶段交接、设置命令行为等关键流程；
- 安装包签名和公证完成（目前为手动升级方式，未提供自动更新）。

以上条件满足后，GitHub Release 才会发布；当前版本尚未发布。
