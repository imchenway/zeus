# Zeus 0.3.72 更新内容

## 功能改进

- 修复了消息发送中断与重启恢复流程中的问题，提升了消息发送的可靠性。
- 优化了应用重启后的恢复交互，确保在恢复卡中确认“恢复成功”后，消息能正确续接，避免伪答或错误推断。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从 GitHub Release 下载 `Zeus-0.3.72-arm64.dmg`，打开并拖拽 Zeus 到“应用程序”文件夹。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开制品为 ad-hoc 签名且未公证，可能无法通过 Gatekeeper 自动验证；若系统拦截，请在“系统设置”>“隐私与安全性”中允许其运行。

## 发布验证

只有当候选版本通过以下检查后，才会创建公开 Release：
- 代码通过静态构建与测试。
- 数据库副本恢复探针验证通过。
- 真实 Remote Control 跨连接中断与 Test GUI 端到端恢复作答验收通过。
