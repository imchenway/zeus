# Zeus 0.3.77 更新内容

## 数字员工管理驾驶舱

- 数字员工协作面板升级为任务工作管理驾驶舱，提供「概览」「协作」「交付物」「证据」四个页签，集中展示工作项状态、待处理事项、正式交付物与运行证据。
- 新增「指派数字员工」抽屉：可先预览实际影响（解析入口、冻结模型、Skill、上下文与命令参数），再创建工作项。
- 工作项以卡片列出，支持查看 Agent 会话证据、命令运行证据，以及重试或取消工作项。
- 新增「待我处理」收件箱，集中呈现需要你处理的内容，包括补充信息、授权请求、交付物验收、命令确认、命令失败与结果未知。
- 交付物独立版本化，每个版本保留验收状态与内容哈希；会话结束不再等于验收，需要你明确接受。
- 命令运行可查看终端日志与命令产物，便于核对执行现场。

## 数字员工配置重构

- 数字员工现在必须选择明确的「主执行入口」：Agent（独立会话）或 Command（项目命令）。
- Agent 入口需要配置提示词，并可设置允许的 Skill、模型策略（默认模型、推理强度、服务速率及允许覆盖范围）与权限工具上限。
- Command 入口直接执行项目命令，不创建模型会话；敏感参数不会进入工作项快照或日志。
- 移除了「自动交付授权链」的隐含联动；提交、推送、合入、部署、结束任务权限都改为独立显式开关，且会话完成后不会自动触发隐藏的提交、部署或完结流程。
- 员工新增「身份说明」字段，用于描述员工职责。

## 工作区导航与交互改进

- 离开工作区时，若有未保存的任务列表布局或工作区修改，会依次弹出确认；导航与关闭应用都会走统一确认流程，避免重复弹窗或丢失修改。
- 从任务列表打开会话、或创建新会话草稿时，会先检查未保存状态，用户确认后才离开当前工作区，防止误丢未保存布局。

## 任务列表布局保存范围选择

- 保存任务列表布局时，现在可以选择「仅当前项目」或「全部项目」，并明确提示影响范围。

## 如何升级

- **Homebrew**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从发布页面下载 `Zeus-0.3.77-arm64.dmg`，打开并拖入 Applications 文件夹完成替换。

## 系统要求与已知限制

- 要求 macOS 13.0 或更高版本。
- 当前公开制品为 ad-hoc 签名，未进行公证；首次打开时请在「系统设置 → 隐私与安全性」中允许来自未知开发者，或右键打开。
- 数字员工 Command 入口尚未支持应用内自动安装，升级后请通过上方命令手动安装。

## 发布验证

- 只有以下长期有效的候选门禁全部通过后，才会创建公开 Release：
  - lint、typecheck、build 与桌面打包通过；
  - 桌面交互验证通过，包括数字员工指派、工作项管理、交付物验收与命令证据查看；
  - 对 DMG 进行 ad-hoc 签名（如适用）并完成必要的公证检查；
  - 在干净环境安装并启动一次，确认无阻断性错误。
- 本版本不包含自动更新机制，请使用上述手动升级方式。
