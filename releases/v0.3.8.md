# Zeus 0.3.8 更新内容

## 冲突处理会话现在可以连续对话

冲突处理不再使用临时隔离目录，每次点击“AI 处理”都会创建一条命名冲突分支（如“任务分支名-merge”）和对应的持久工作区，会话绑定这条分支。AI 解决并暂存冲突后，分支、工作区和会话都会保留，你可以继续对话、修改和再次交付，不会再因为目录被回收而发送失败。交付时 Zeus 会先合入最新的来源分支和任务分支，如果出现新冲突，会保留现场并回到原会话继续处理。

## 模型服务连接错误提示更清晰

获取模型列表失败时，不再只显示“fetch failed”。现在会根据失败阶段给出具体提示：地址协议不匹配、证书不受信任、主机无法解析、连接拒绝、连接超时、连接中断等都有对应的中文说明和恢复建议。例如，如果服务地址使用 HTTPS 但端口实际是明文 HTTP，会提示核对端口或改用 http:// 地址；不会自动降级协议，也不会关闭证书校验。

## 如何升级

推荐通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以手动升级：从 GitHub Releases 下载 `Zeus-0.3.8-arm64.dmg`，打开后将 Zeus 拖入“应用程序”文件夹完成替换。

## 系统要求与已知限制

- 需要 macOS 13.0 或更高版本。
- 当前公开制品未完成 Developer ID 签名和 Apple 公证，手动升级时系统可能提示安全警告，请右键打开或前往“系统设置 > 隐私与安全性”允许运行。
- 冲突处理会保留更多本地分支和工作区目录，需要你稍后自行清理。

## 发布验证

公开 Release 只在固定候选提交通过类型检查、正式打包、DMG 完整性和更新清单一致性校验后创建；公开资产必须与 GitHub 服务端摘要、更新清单和 Homebrew Cask 保持一致。当前产物更新清单中会如实标记签名和公证状态。
