# Zeus 0.3.83 更新内容

本次更新修复了恢复与调度问题，并完善了 Telegram 远程任务操作，同时提升了会话续聊和附件展示的稳定性。

## 会话恢复与消息派发更可靠

- 修复了重启会话后可能继续报错的问题，改善了等待用户输入和错误反馈的体验。
- 改进消息队列调度，在消息已保存但派发未完成时，界面会明确提示，并提供“重新恢复”操作，避免用户重复发送消息。

## 历史会话与附件显示修复

- 修复了打开历史会话时附件（如图片和文件）可能不显示的问题。
- 修复了历史会话中输入框可能被意外禁用，导致无法继续输入或添加附件的问题。

## Telegram 远程任务操作增强

- 消息轮询改为连续模式，收到新消息后能及时响应，不再有固定 30 秒延迟。
- 任务列表改为每页 8 条，并加入按钮导航，便于在手机上快速查看和操作。
- 任务详情提供操作按钮，可直接启动、暂停、继续任务，编辑标题或描述，或推送到新会话/当前会话。
- 修改项目状态时只显示非终态选项，避免误触清理操作；取消任务增加二次确认。

## 错误提示更清晰

- 登录 Codex 未完成时，会显示明确的登录指引。
- 队列调度失败等错误会说明消息已保存，并引导用户执行恢复操作。

## 如何升级

推荐通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以手动升级：下载 `Zeus-0.3.83-arm64.dmg`，打开后拖拽 Zeus 到“应用程序”文件夹，替换旧版本即可。

## 系统要求与已知限制

- 系统要求：macOS 13.0 或更高版本。
- 手动升级时请先退出正在运行的 Zeus 应用。
- 通过 Telegram 远程修改任务的项目状态时，完成或取消类终态操作仍需回到桌面端处理。
