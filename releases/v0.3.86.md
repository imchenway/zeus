# Zeus 0.3.86 更新内容

## 新会话附件修复

在新会话中附加通用文件（如 JSON）时，附件信息现在会以结构化形式一并提供给模型，包含资源类型、文件名和本地路径，确保模型知道附件存在并可按需读取。此前这类附件仅以引用形式出现，模型可能无法感知其存在。图片附件的行为不变。

## IM 任务操作增强

Telegram 对话中的任务操作新增“处理此任务”入口，支持选择新建任务会话或该任务已有的历史会话，确保任务、会话与 IM 绑定身份一致，避免投递到错误上下文。任务列表中的“新建任务”流程也得到完善。

## 如何升级

### Homebrew

```bash
brew upgrade --cask imchenway/tap/zeus
```

### 手动升级

下载最新版本 DMG 并替换当前应用：

- 下载 `Zeus-0.3.86-arm64.dmg`
- 打开 DMG，将 Zeus 拖入“应用程序”文件夹
- 若 Zeus 正在运行，请先退出再替换

## 系统要求与已知限制

- 最低系统版本：macOS 13.0
- 当前公开制品为手动升级包，应用内自动安装暂不可用
- 附件内容不会在请求前自动展开，模型需主动读取文件

## 发布验证

公开 Release 将在固定候选通过以下检查后创建：
- 静态检查（Prettier、ESLint、TypeScript）和架构治理通过
- 生产构建与 macOS 打包成功
- 打包产物通过代码签名验证（测试签名，非 Developer ID）
- DMG 校验通过

候选必须完成上述门禁才能发布。
