# Zeus 0.3.87 更新内容

## 消息与交互改进

- **长消息展开查看**：会话中超过 640 字符的用户消息现在默认显示为紧凑预览，并在正文下方提供常驻的“展开全文”按钮；点击后可查看完整内容，并可以再次收起。不再依赖悬浮操作栏中语义含糊的图标。
- **修复消息无法发送的问题**：应用重启后如果上一条消息已接受但尚未完成状态同步，新消息发送可能被阻塞。现在系统会先自动同步权威快照，确认旧消息已完成后才继续发送，按回车和点击发送按钮均可正常使用。
- **修复会话消息偶发缺失**：修复了程序化滚动到底部时虚拟列表与真实视口不同步，导致部分消息被跳过需要滚动才显示的问题。现在自动跟随、发送消息、快速完成和返回最新时都会同步虚拟视口，消息显示更可靠。
- **修复底部向上滚动受阻**：当会话停留在底部时，向上滚动可能被自动跟随的收敛循环抵消，需要多次滚动才能阅读历史。现在首次向上滚动即暂停自动跟随，并保留已越过阅读门槛的位置，回到底部或点击“返回最新”可恢复跟随。
- **修复中途引导消息位置**：会话中点击“引导”成功后，消息现在会显示在真实引导发生的时间点，而不是被移动到整轮过程之后，保持与上下文一致。

## 图片与界面优化

- **图片统一预览**：会话中的所有图片（包括推送任务提示词中的图片、Markdown 图片、生成图片和资源图片）现在点击后统一在 Zeus 附件预览弹窗中放大查看，不再打开右侧浏览器或其他应用。非图片资源仍保留原有打开方式。
- **项目侧栏图标优化**：侧栏“项目”标题旁的“按任务状态分组”和“平铺显示会话”图标改为统一的线条风格，视觉重量一致，并保留原有提示和点击行为。
- **Markdown 表格样式修复**：修复了会话中 Markdown 表格列宽拖动手柄被误渲染为圆角块的问题，拖动调整列宽功能不受影响。
- **24 小时制显示**：命令中心的执行历史时间现在固定使用 24 小时制，不再根据系统区域显示 AM/PM。

## 任务与工作流改进

- **代码交付更稳定**：修复了代码交付页“合入来源分支”经常失败的问题。来源工作区存在无关未提交改动时，Git 会安全快进并保留本地改动；只有可能覆盖本地改动时才会拒绝，且结果会保留待处理状态，从同一按钮可重试。同时优化了逐仓结果布局，长错误信息不再被截断。
- **提交入口更友好**：当没有暂存文件时，从顶部或“操作”菜单点击“提交…”现在会进入“本地变更”页，并提示先勾选左侧文件暂存，不再打开显示“0 个仓库”的无效提交弹窗。
- **Telegram 任务列表优化**：Telegram 中的 `/tasks` 默认显示“未完成”任务，并可在列表顶部按“全部”或具体项目状态筛选；任务按最近更新时间倒序排列，状态和编码优先显示，从详情返回时保持之前的筛选和页码。

## 稳定性与网络恢复

- **修复网络问题导致卡死**：遇到网络异常时，心跳失败不再阻塞后续续租，避免恢复流程被慢请求拖住；同时延长了界面租约的超时容忍度，并为会话状态同步增加“暂未同步，正在后台重试”的降级显示，避免永久停留在“同步中”的假死状态。

## 如何升级

- **Homebrew 用户**：执行以下命令升级：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- **手动升级**：从发布页面下载 `Zeus-0.3.87-arm64.dmg`，打开并拖动 Zeus 到“应用程序”文件夹，覆盖现有版本。

## 系统要求与已知限制

- 最低系统版本为 macOS 13.0。
- 当前公开 DMG 为手动安装方式，应用内自动更新暂不可用。
- 会话图片预览改为弹窗后，图片不再提供“打开方式”菜单；非图片资源不受影响。
- Telegram 任务列表筛选新增在列表顶部，项目自定义状态较多时可能增加几行按钮；详情返回后保持原筛选。
- 代码交付来源分支存在无关未提交改动时，快进后本地改动仍保留，但查看 `git diff` 的基线会变化，这是 Git 原生行为。
