# Zeus 0.3.98 更新内容

## 本次更新

- **修复会话结束后消息仍排队的问题**：当模型已生成正式回复后，继续发送消息可能被错误地排队或引导到已完成的处理流程。现在系统会识别正式回复或计划已交付的轮次，新消息将自动转入下一轮发送，并正确显示“发送前检查未通过，消息尚未发送”等明确状态。
- **优化会话详情与批注视觉**：调整了批注编号标签和评论框样式，使其更轻量、不干扰正文阅读；同时优化了会话详情中的缓存命中率等字段排版，避免标签错位。
- **修复内置浏览器打开 HTML 卡在加载态的问题**：从会话中点击 HTML 文件时，现在能直接显示已加载的页面，不再因等待额外状态同步而停滞。

## 如何升级

- **Homebrew 用户**：执行 `brew upgrade --cask imchenway/tap/zeus`。
- **手动升级**：从发布页面下载 `Zeus-0.3.98-arm64.dmg`，打开后拖拽 Zeus 到 Applications 文件夹，并按 macOS 提示完成首次启动确认。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0（仅 Apple Silicon）。
- 当前公开包未配置 Developer ID 签名和 Apple 公证，首次启动时 macOS 可能弹出安全提示，需手动确认打开。
- 修复后，若模型已产生正文但后台仍在收尾，新消息可能短暂进入排队状态，待当前轮次正式结束后会自动续发。
