# Zeus 0.4.0 更新内容

## 输入建议更贴合当前输入

- 空输入时根据会话起草下一句；已有文字时整理、润色和适度扩写。Codex 与 API 模型共用全局和项目规则，保持用户对助手说话的视角。
- 自动和手动生成都要求提供可发送的正文，信息不足时围绕缺失资料提出具体澄清。无效输出显示失败并提供手动重试，不为补充正文追加模型调用；原文无需修改时给出明确反馈。
- 修改文字、粘贴或开始中文组合输入时，立即取消当前请求并清除候选。迟到结果和旧候选不会恢复，清空输入也不会补发自动请求。
- 星光按钮始终根据当前输入重新生成；关闭预览即放弃候选。采用前核对当前草稿和引用，替换可以撤销，不自动发送。
- 精简悬浮提示：常态显示“输入建议 · Tab”，生成时显示“生成中...”，候选正文显示“点击或按下 Tab 采用，可撤消”。

## Git 交付状态与提交说明

- 项目 Git 交付状态在多个入口同步显示，便于持续查看正在执行和需要处理的交付步骤。
- 组合交付可使用 AI 生成提交说明，沿用现有交付流程和用户配置。

## 界面提示与提醒

- 调整图标提示与文件按钮布局，计划进度条支持悬停展开。
- 移除部分懒加载文字占位，减少界面中的临时提示。
- 已结束的异步问题不再继续触发待回复提醒。

## 如何升级

使用 Homebrew 升级：

```sh
brew upgrade --cask imchenway/tap/zeus
```

也可以从本次 Release 下载 `Zeus-0.4.0-arm64.dmg`，退出 Zeus 后手动安装。

## 系统要求与已知限制

- 本次 macOS 安装包面向 Apple Silicon，要求 macOS 13.0 或更高版本。
- 公开 macOS 制品沿用 ad-hoc 签名且未公证，请使用 Homebrew 或 DMG 手动升级，不承诺应用内自动安装。
- Windows 平台支持已进入源码；Windows 安装包通过独立流程构建、签名和发布，不属于本次 macOS 制品回验范围。
- 输入建议的表达质量取决于所选模型。取消、超时和生成失败仍会如实反馈，候选内容由用户确认后采用。

## 发布验证

公开 macOS Release 以固定提交为候选，必须通过格式、Lint、架构边界、类型检查、生产构建和安装包校验。发布完成后核对标签、Release 正文、安装包清单与 Homebrew 版本和校验值的一致性。

这些发布门禁不代替真实模型质量和原生界面交互验收。
