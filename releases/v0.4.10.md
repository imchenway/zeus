# Zeus 0.4.10 更新内容

## 退出与重启更可靠

- 退出 Zeus 时，未完成的请求不再阻塞进程，退出流程可以正常走到结束。
- 当有后台工作正在进行时，Zeus 会等待工作停止确认完成再退出；等待上限已覆盖正常停止所需的处理时间，减少误取消退出的情况。
- 如果无法确认后台工作状态，或停止工作未被确认，Zeus 会提示“退出未完成”，保持运行并在提示中说明原因，而不是默默留在后台。
- 重启失败时的提示同样会说明 Zeus 仍保持打开，便于你检查日志后再操作。

## 外部浏览器连接更稳定

- Zeus 开始退出后，外部浏览器发来的迟到请求会被直接拒绝，不再重新登记连接或派发命令。
- 浏览器结果返回时如果 Zeus 已在退出，这些结果不会再加入等待队列，避免关闭过程中出现异常。

## 打包版项目根目录修复

- 打包版从 Finder 或其他方式启动时，Zeus 现在使用真实的安装资源目录作为默认项目根目录，不再把项目扫描定位到系统根目录等错误位置。
- 如果你通过环境变量指定了项目根目录，该设置仍然优先生效；开发模式下继续使用当前工作目录。

## 如何升级

Homebrew：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS 手动升级：下载 `Zeus-0.4.10-arm64.dmg`，打开后将 Zeus 拖入“应用程序”覆盖旧版本。

Windows 手动升级：按系统架构选择安装包，x64 系统使用 `Zeus-0.4.10-win32-x64.exe`，ARM64 系统使用 `Zeus-0.4.10-win32-arm64.exe`。安装前请先退出 Zeus，再运行安装程序完成升级。当前公开制品为手动安装方式，暂不支持应用内自动安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。
- Windows：按系统架构选择对应的 EXE 安装包。
- 签名与系统安全提示以各平台实际发布清单为准。若系统弹出安全提示，请按平台常规方式确认后继续安装。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 单元与行为验证检查通过，包括退出清理、停止命令等待与项目根目录解析。
- 桌面端与相关包的构建、类型检查通过。
- 对应平台的安装包按发布清单生成并核对。

以上条件为创建公开 Release 的固定门禁，只有全部满足时才会发布对应版本。
