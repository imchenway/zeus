## 更完整的文件类型图标

代码浏览与文件预览中的文件标识得到扩展：Zeus 现在按文件类型显示对应的图标，覆盖常见的编程语言、框架、配置文件、构建工具、文档与媒体格式等。识别不到具体类型时仍会回退到通用文件图标，不影响打开与查看文件。

## 源码视图的 Git 改动提示与差异查看

源码编辑器中的 Git 改动标记得到增强，行内改动提示会随改动状态更新；同时新增了源码改动的差异查看窗口，可以更直接地对照当前文件与已有提交之间的变化。差异视图的工具栏也做了相应调整，便于在审阅改动时切换与关闭。

## 仓库与交付操作的整理

Git 仓库相关的控件和交付工作区做了整理，涉及仓库控制、交付运行控制与相关设置的交互细节。会话快捷操作区域与资源面板也一并调整，属于使用体验层面的优化，具体表现以实际界面为准。

## 如何升级

macOS：

- 使用 Homebrew 升级：`brew upgrade --cask imchenway/tap/zeus`
- 或手动下载 `Zeus-0.4.101-arm64.dmg`，打开后按提示将 Zeus 拖入「应用程序」完成替换。

Windows：

- 按系统架构选择安装包：64 位 x64 系统使用 `Zeus-0.4.101-win32-x64.exe`，ARM64 系统使用 `Zeus-0.4.101-win32-arm64.exe`。
- 安装前请先退出 Zeus，再运行对应 EXE 完成安装。

当前公开制品为手动升级方式，应用内自动安装不可用，请按上述方式手动完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名与公证状态以 macOS 平台实际发布清单为准；若系统提示无法验证开发者，请在「系统设置」中按提示允许打开。
- Windows：签名与系统提示以 Windows 平台实际发布清单为准；若出现 SmartScreen 提示，请核对来源后选择继续。
- 应用内自动更新在当前制品形态下不可用，升级需按“如何升级”中的手动方式进行。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：候选提交范围与版本信息一致；lint、类型检查与构建通过；桌面应用打包成功并生成 macOS 与 Windows 对应架构的制品；制品与发布清单一致。任一检查未通过时不会创建公开 Release。
