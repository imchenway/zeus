# Zeus 0.4.13 更新内容

## 代码差异视图更清晰

- 新增、删除和修改使用统一配色：新增为浅绿，删除为中性灰，修改为浅蓝，深色主题下使用对应的低亮度颜色。
- 双栏差异中，修改区块的空白一侧不再整片填充颜色，改为在两栏之间绘制连接色带，便于对照两侧实际对应的内容。
- 折叠未修改内容后，波浪边界更紧凑，行数信息通过悬停和读屏获取，仍可点击或使用键盘展开。
- 恢复改动入口统一为细线图标，位于对应区块内，避免在浅色底上不易看清或超出区块。
- 可编辑差异与只读差异采用一致的外观和恢复语义；三方冲突仍沿用原有冲突处理方式。

## 项目提交改用代码交付弹窗

- 在项目 Git 工作台中点击提交、处理冲突或选择子目录范围时，会直接打开代码交付弹窗，使用与任务、会话交付相同的窗口。
- 同一仓库范围重复打开时复用已存在的窗口，并保留窗口尺寸记忆和关闭流程。
- Git 工作台本身保留提交历史、贮藏和操作记录等浏览页面，不再在页面内嵌入整套交付视图。

## 交付操作栏更聚焦当前进度

- 交付操作栏只显示进行中、需要处理或结果待核对的步骤，已完成的历史不再占用操作空间。
- 冲突处理、需要处理和结果未知状态仍会直接显示，并可继续打开冲突会话或处理冲突。
- 提交区域保留“提交文件”“合入分支”“推送到远端”等功能分组标题。

## 会话正文账本指标保留

- 修复了会话正文中的账本指标在更新后丢失的问题，正文可继续显示会话用量相关信息。

## 如何升级

- Homebrew 用户执行：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- macOS 也可下载 `Zeus-0.4.13-arm64.dmg` 手动安装。
- Windows 请按系统架构选择 `Zeus-0.4.13-win32-x64.exe` 或 `Zeus-0.4.13-win32-arm64.exe`，先退出正在运行的 Zeus，再运行安装程序。
- 当前公开制品采用手动升级方式，不提供应用内自动安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0，提供 arm64 DMG。签名与系统提示以 macOS 发布清单为准，首次打开如遇系统提示，请按系统说明处理。
- Windows：提供 x64 与 arm64 两种安装包，请选择与系统架构匹配的版本。签名与系统提示以 Windows 发布清单为准。
- 双栏差异的折叠行数改为悬停或读屏获取，中缝连接会随窗口分栏和滚动更新，在极窄布局下可能需要拖动分栏查看。
- 项目提交通过代码交付弹窗完成，原工作台内的变更页不再提供。

## 发布验证

公开 Release 仅在同一固定候选版本通过以下检查后创建：类型检查、构建、桌面打包，以及针对本次候选的发布校验。未通过上述检查的候选不会生成公开 Release。
