# Zeus 0.4.2 更新内容

Zeus 0.4.2 修复了会话恢复时上下文容量处理的若干问题，让再次打开已有会话的行为更符合预期。

## 恢复已有会话更可靠

- 重新打开一个尚未单独设置过容量的会话时，Zeus 只恢复对该会话的订阅，不再因为连接换代而把空闲会话卸载，因此不会额外打断其他仍在运行的会话。
- 对已经设置过单独容量的会话，仅恢复订阅不会把它改回默认容量，此前设定的容量记录会被保留。

## 容量切换按实际状态生效

- 把一个已设置单独容量的会话改回默认容量时，Zeus 会先确认会话确实完成卸载再更新记录，避免记录与实际状态不一致。
- 指定新的上下文容量时，只有在会话空闲时才会卸载并重新加载；会话处于活跃状态时不会被卸载。
- 活跃期间未生效的新容量不会被提前记为已生效，后续空闲时会再按实际状态处理。

## 如何升级

- Homebrew：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- 手动升级：从 Release 下载 `Zeus-0.4.2-arm64.dmg`，打开并拖入“应用程序”完成替换。由于当前公开制品为未经公证的临时构建，应用内自动安装不可用，请使用上述手动方式升级。

## 系统要求与已知限制

- macOS 13.0 或更高版本。
- 本次公开制品为未公证的临时构建，首次打开可能需要手动放行；应用内自动更新安装不可用，需要按上面的 Homebrew 或 DMG 方式手动升级。
- 只有显式指定容量的会话会触发卸载与重新加载；未指定容量的恢复只恢复订阅，可能因此保持原有上下文窗口不变。
