# Zeus 0.4.3 更新内容

本次更新主要面向 Windows 平台，让 Zeus 可以在 Windows 上完成安装、升级和原生组件加载，并对安装包身份与原生组件完整性做了更明确的区分。

## Windows 安装与升级支持

- 现在可以在 Windows 10 22H2 和 Windows 11 上安装和使用 Zeus Test 内部安装包，按当前用户安装，无需 WSL。
- 内部安装包与正式版使用独立数据目录，可以和正式版本共存而不互相影响。
- 安装器会在开始前检查 Zeus 是否仍在运行；如果检测到未退出，会提示先停止工作并退出，再重新运行安装器。
- 独立卸载器不再携带安装专用逻辑，安装和卸载的流程边界更清晰。

## 原生组件与安装包身份更可靠

- Windows 打包时会完整收集 Zeus 依赖的原生组件和浏览器扩展资源，避免出现安装后组件缺失的问题。
- 原生组件在 Windows 构建使用固定的换行方式，减少因换行差异导致的构建失败。
- 安装包会按当前是否配置签名凭据生成对应的包：正式发行始终要求可验证签名，未配置凭据时生成独立的未签名内部包，并保持 Zeus Test 产品身份。
- 内部包中的运行时组件仍会写入正确的组件名，便于系统识别。

## 文档与发布说明

- 安装说明重新整理了 macOS 与 Windows 两条路径，Windows 部分说明如何从 GitHub Actions 附件下载 x64 与 ARM64 内部安装包。
- 文档保留了早期版本的历史内容，便于对照升级差异。

## 如何升级

macOS 用户推荐使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

当前公开版尚未经过 Apple 公证，自动安装条件可能不足；也可以手动下载 DMG，体验与应用内自动安装的行为一致。手动升级时请结束工作并退出 Zeus，将新版拖入“应用程序”完成替换。Apple Silicon 手动安装包文件名为 `Zeus-0.4.3-arm64.dmg`。

Windows 用户当前使用未签名内部安装包。请先退出 Zeus Test，解压附件 ZIP 后双击安装包运行；系统可能提示未知发布者，请确认文件来源后继续。手动升级前请关闭正在运行的 Zeus Test。

## 系统要求与已知限制

- macOS 版本要求 macOS 13 或更高版本，当前 Homebrew 安装包支持 Apple Silicon Mac。
- 当前公开的 macOS 版本尚未经过 Apple 公证，首次打开时系统可能提示无法验证 Zeus。可在“系统设置 → 隐私与安全性”中允许打开，或按提示手动确认。
- 当前公开制品为 ad-hoc、未公证，应用内自动安装可能不可用，请按上述方式手动升级。
- Windows 内部安装包未签名，系统可能提示未知发布者；该包与正式版使用独立数据目录。

## 发布验证

公开 Release 只有在固定候选通过完整发布门禁后才会创建：静态检查与构建检查全部通过；Windows 正式安装器必须配置可验证的 Authenticode 签名凭据，安装器、主程序及原生组件均验签通过且发布者一致；未配置签名凭据时只生成未签名内部安装包，且必须保持 Zeus Test 产品身份与正确的组件名。macOS 候选需要完成正式签名与公证校验。以上条件通过后，公开发布与 Homebrew 同步才会执行。
