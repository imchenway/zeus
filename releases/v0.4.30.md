# Zeus 0.4.30 更新内容

## 文件剪贴板复制更可靠

在 macOS 上从 Finder 复制一个或多个文件后，Zeus 现在更准确地识别这些文件引用：只读取系统剪贴板中明确标记为文件的项目，不再尝试把普通文本误当成文件路径。复制多个文件时也能逐项识别，解析失败时会给出明确的错误提示，而不会静默忽略。

## 屏幕控制详情浮层交互修复

会话中的屏幕控制详情改为独立浮层展示：打开后不再挤压或遮挡预览画面，靠近窗口边缘时会自动向可用方向展开，内容过长时可在浮层内滚动。

同时修复了按 Esc 关闭浮层时会连带关闭环境信息卡、工作区或触发会话中断的问题；现在 Esc 只关闭当前打开的详情浮层。消息失败提示中的图标与文字对齐也已调整，显示更整齐。

## 如何升级

Homebrew 用户可执行：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可下载 `Zeus-0.4.30-arm64.dmg` 手动安装。当前 macOS 制品为本地构建、未经过公证，安装时可能需要在系统设置中手动允许打开；该方式为手动升级，不提供应用内自动安装。

Windows 请按系统架构选择安装包，安装前先退出 Zeus：

- x64：`Zeus-0.4.30-win32-x64.exe`
- arm64：`Zeus-0.4.30-win32-arm64.exe`

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。当前 DMG 未经公证，首次打开可能触发系统安全提示，需要手动确认。
- Windows：提供 x64 与 arm64 两种安装包，请按实际系统架构选择；安装前需退出 Zeus。
- 两端签名与系统提示以各平台实际发布清单为准。
- 本次为手动升级，不提供应用内自动安装。

## 发布验证

公开 Release 仅在固定候选版本通过以下检查后才会创建：候选提交范围与版本信息核对一致；类型检查、构建与桌面打包通过；macOS 与 Windows 安装制品按发布清单生成并可校验。任一检查未通过时，不创建公开 Release，也不更新发布渠道。
