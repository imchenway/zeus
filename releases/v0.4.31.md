# Zeus 0.4.31 更新内容

## 项目更新更集中

- “更新项目”对话框现在只让你选择整合方式：合并传入的更改，或将当前分支变基到传入的更改之上。
- 更新执行过程和冲突结果改为在 Git 工作台中显示，不再堆叠在对话框里。
- 新增“不再显示”选项。勾选后，通过快捷键触发的项目更新会直接使用已保存的更新方式；分支菜单中仍可重新打开对话框进行选择。

## 用快捷键更新当前项目

- 在 macOS 上按 `Command+T`，在 Windows 上按 `Ctrl+T`，可直接对当前项目发起更新。
- 提交编辑器、终端或已打开的模态窗口会优先处理键盘输入，此时该快捷键不会抢占。
- 即使 Git 面板尚未加载或处于收起状态，快捷键也能打开更新流程；如果 Git 加载失败或项目中没有可用仓库，会引导你打开 Git 面板查看。
- 多仓库更新期间不会启动第二轮更新；遇到失败或冲突会停止后续仓库，可在工作台继续处理。

## 会话队列与失败恢复

- 一轮对话结束（包括失败）时，界面会同时接收结算后的队列状态，减少失败后仍被已结束的待发送消息拦住的情况。
- 队列中的消息因暂停或状态变化无法发送时，会给出明确的队列原因并保留恢复提示。
- 当消息已不再处于待发送状态时，提示改为“消息状态已更新，请重新检查发送结果”，而不再一律表述为已取消或替换。

## 应用内更新的下载检查更严格

- 应用内更新下载会逐次核对重定向目标，只允许进入受信任的 GitHub 产物域名；若安装程序处于隔离测试模式，仅额外允许跳转到本机 HTTP 测试服务。
- 下载会沿用系统与应用代理，并在十分钟期限内完成；HTTP 状态异常或超时会报告为下载中断或被拒绝。

## 如何升级

本次公开制品仍为未公证的 ad-hoc 构建，请手动升级，应用内不会自动安装。

- Homebrew：
  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```
- macOS：下载 `Zeus-0.4.31-arm64.dmg`，打开后将 Zeus 拖入“应用程序”。如果系统提示来源或安全警告，以该平台实际发布清单中的签名与提示说明为准。
- Windows：按系统架构选择 `Zeus-0.4.31-win32-x64.exe` 或 `Zeus-0.4.31-win32-arm64.exe`。安装前请先退出 Zeus，再运行安装程序完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。
- Windows：提供 x64 与 arm64 两种安装包，请按系统架构选择。
- 当前公开制品为 ad-hoc、未公证构建，因此需要手动下载或通过 Homebrew 升级；应用内自动安装不可用。系统安全提示和签名情况以各平台实际发布清单为准。
