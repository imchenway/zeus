# Zeus 0.4.35 更新内容

本次更新主要整理了项目对外的说明文档与下载入口，帮助新用户更快了解 Zeus 的工作方式并完成安装。

## 更清晰的入门指引

- 用一张总览表说明任务管理、源码、Git 和自定义命令各自能做什么。
- 新增“开始使用”步骤：添加本地项目、配置模型接入、创建任务或会话、检查源码与 Git 差异并完成交付。
- 说明 Zeus 采用本地优先方式，使用外部模型、插件或集成时会按配置与相应服务通信。

## 更明确的下载与安装说明

- 按系统与架构列出应选择的安装包，并说明如何确认 Windows 系统类型。
- 补充 macOS 首次打开遇到安全提示时的处理步骤，签名与公证状态以对应版本的发布清单为准。
- 为 Homebrew 用户和手动安装用户分别说明升级方式。

## 面向贡献者的补充

- 说明本地开发所需的 Node.js 24.x 与 pnpm 10.31.0，以及桌面构建所需的平台工具链。
- 补充统一的提交前检查命令与问题反馈、代码贡献、安全问题报告的入口。

## 如何升级

Homebrew 用户：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 手动升级：先从最新发布页下载 `Zeus-0.4.35-arm64.dmg`，退出 Zeus 后打开安装包完成升级。

Windows 升级：先退出 Zeus，再按系统架构下载并安装对应安装包——Intel / AMD x64 选择 `Zeus-0.4.35-win32-x64.exe`，ARM64 选择 `Zeus-0.4.35-win32-arm64.exe`。可在「设置 → 系统 → 关于」中确认系统类型。

当前 macOS 公开制品若仍为 ad-hoc 签名且未经公证，不支持应用内自动安装，请按上述方式手动升级。

## 系统要求与已知限制

- macOS：要求 macOS 13 或更高版本，当前 DMG 面向 Apple Silicon。签名与公证状态以该版本发布清单为准；如系统提示无法验证 Zeus，可在「系统设置 → 隐私与安全性」中按提示选择「仍要打开」。
- Windows：支持 Windows 10 22H2 和 Windows 11，无需 WSL，按当前用户安装。签名状态以发布清单为准；未签名时系统可能提示未知发布者，请确认文件来自正式发布页后再运行。
- 使用外部模型、插件或集成时，相关内容会按配置与相应服务通信，模型能力与可用选项取决于所选接入方式。

## 发布验证

公开 Release 仅在固定候选通过以下检查后才会创建：冲突与空白检查、变更文件格式检查、lint、架构边界检查、类型检查和生产构建，并将发布包与发布清单核对一致。发布清单会如实标记各平台的签名与公证状态。
