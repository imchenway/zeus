# Zeus 0.4.36 更新内容

## 内置浏览器支持网页翻译

- 在内置浏览器中可对网页开启中英对照，支持一键恢复原文。
- 提供 Google 与微软两个免费翻译服务，也可在翻译服务菜单里选择已配置的模型作为翻译来源。
- 翻译按段落分批处理，可为长正文分段翻译；切换页面、关闭标签或恢复原文时会停止翻译。
- 当前翻译适用于 HTML 网页正文；遇到 PDF 或图片内文字时会提示暂不支持。
- 开启了翻译的网页中，批注仍会对应到原文位置，恢复原文后批注锚点不会失效。

## 对话输入获得草稿补全

- 在输入框中停顿约一秒后，会根据当前草稿生成末尾补全，以灰字显示。
- 补全不会自动发送，也不会自动替换你已写的内容；按 Tab 采用后才追加到正文。
- 没有输入时仍可获取下一条消息草稿建议；空输入建议与末尾补全分别保存，互不覆盖。
- 主动操作仍可对已有文字进行整理、润色和适度扩写。

## 代码交付支持推送后运行项目命令

- 在全部所选仓库推送成功后，可按你选择的顺序运行已配置的项目命令。
- 命令使用自己的项目目录、解释器和默认参数；任一命令失败时会暂停后续命令。
- 只有全部命令成功后才更新最终任务状态。

## 会话与网页操作的稳定性改进

- 会话任务可创建工作树交付，并新增了中断后可恢复的工作树处理与草稿标题生成。
- 消息按顺序接纳，排队消息的展示更稳定；发生冲突时保留并切换到草稿视图。
- 内置浏览器的页面观察会绑定到当前标签和文档，过期元素引用会提示重新读取快照，而不是误操作其他元素。
- 浏览器与桌面自动化若在等待或传输中断，会提示动作结果未知并建议先检查目标，不会自动重放。
- 外部扩展命令在过期后不会被送达；尚未发送的动作会取消并给出明确提示。

## 如何升级

macOS：

- 使用 Homebrew 升级：`brew upgrade --cask imchenway/tap/zeus`
- 或手动下载 `Zeus-0.4.36-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。

Windows：

- 按系统架构选择 `Zeus-0.4.36-win32-x64.exe`（64 位）或 `Zeus-0.4.36-win32-arm64.exe`（ARM64）。
- 安装前请先退出正在运行的 Zeus，再运行对应 EXE 完成安装。

当前公开制品与安全提示以各平台实际发布清单为准，签名和系统提示可能因平台而异；本次升级为手动升级方式。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。应用签名与公证状态、首次打开时的系统提示以实际发布清单为准。
- Windows：请按系统架构下载对应 EXE，安装前退出 Zeus。签名与系统提示以实际发布清单为准。
- 网页翻译目前面向 HTML 网页正文，PDF 和图片内文字暂不支持；翻译由本机 Core 请求所选服务，网页本身不会获得服务凭据。
- 推送后命令按所选顺序串行执行，任一失败会暂停后续命令。

## 发布验证

公开 Release 仅在固定候选通过以下检查后才会创建：

- 类型检查与构建通过，桌面端可正常打包。
- macOS 与 Windows 的发布制品按目标架构生成并核对完整清单。
- 桌面桥与原生界面通过格式、通道和资源清单的严格复核。
- 发布附件包含相应源码与许可证信息，供用户查阅。
