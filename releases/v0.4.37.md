# Zeus 0.4.37 更新内容

## 用量价格的来源与补价更清晰

- 内置浏览器的“翻译服务”改为原生子菜单，不再显示会遮挡网页的浮层；免费翻译（微软、Google）立即可选，Codex 与自定义供应商模型在菜单内按来源加载。Codex 未登录时会提供“登录 Codex”入口。
- 每条请求的价格现在记录它使用的费率来源和获取时间；之后价格目录更新，不会改动已经计入的金额。
- 对于原本没有金额的历史请求，可以按当时可用的公开价格补算。补算会标记补算时间和所使用的价格来源，这属于估算，不代表恢复了历史实际账单。
- 用量明细中的费用行会显示价格来源链接；没有金额时会区分“价格同步失败”和“价格条件未确认”，方便判断缺价原因。
- 价格同步状态与账户用量刷新分开记录：即使价格同步失败，也不会影响 Token 用量的记录与展示。
- 自定义模型连接保存后更新价格目录时，会为可精确对应到该连接的缺价请求补齐估算金额，已有金额不会被覆盖。

## 工作区 Git 状态切换更顺畅

- 会话卡片首次显示时会优先使用仍有效的缓存快照，并在后台重新核对；切换会话后短时间内回到同一工作树时，不需要重新初始化 Git 监听。
- 无订阅的工作树监听会短期保留，并限制保留数量，避免浏览大量会话后资源持续增长。

## 任务与运行操作的稳定性

- 取消或交接工作项时，会重新核对当前运行和版本；如果停止期间运行已经变化，或存在未知外部结果，操作会提示刷新核对，而不会误取消新的运行。
- 重复提交同一次取消请求会返回原有回执，不再重复停止外部执行；后台恢复扫描改为分页轮转，避免一次只处理最早的若干条记录。

## 新建会话与设置文案

- 新建会话上下文中的“创建任务”开关改名为“自动创建任务”，与行为一致，并去掉了多余的外层底色和边框。
- 模型连接设置中的“价格来源”会优先使用已配置的价格页面。

## 如何升级

本次构建产物仍是手动升级，应用内自动安装暂不可用。

macOS：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.4.37-arm64.dmg` 后手动安装。

Windows：根据系统架构下载 `Zeus-0.4.37-win32-x64.exe` 或 `Zeus-0.4.37-win32-arm64.exe`，退出 Zeus 后运行安装程序完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。应用签名与系统安全提示以本次各平台实际发布清单为准。
- Windows：按系统架构选择对应的 EXE 安装包；签名与系统安全提示以实际发布清单为准。
- 当前公开制品若仍为 ad-hoc 签名且未公证，需要手动下载并安装，不支持应用内自动更新。
- 用量金额均为估算，不是实际账单；历史补价按补价时可获取的价格估算。
- 价格同步依赖公开文档的页面结构。结构变化或网络失败时可能暂时缺价，并会显示对应的同步状态。
- 当公开价格表新增无法识别的列时，需要本机 Codex 已启动并登录，才能辅助识别字段含义；否则相关条目可能暂时缺价。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 仓库类型检查与构建通过；
- 桌面端按各平台架构完成打包，安装包与清单一致；
- macOS 与 Windows 的签名和系统提示符合该平台实际发布清单；
- 发布清单中的文件名与本说明引用的一致（`Zeus-0.4.37-arm64.dmg`、`Zeus-0.4.37-win32-x64.exe`、`Zeus-0.4.37-win32-arm64.exe`）。
