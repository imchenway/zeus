# Zeus 0.4.38 更新内容

## Windows 安装包构建稳定性

改进 Windows 正式安装包与原生辅助程序的构建流程：构建缓存现在与正式发布和任务构建相互隔离，原生编译结果只有在完整匹配架构、源码、补丁和工具链时才会被复用，减少不一致的中间产物进入安装包的风险。

Windows 安全助手和运行时助手改为并行独立编译，并在两者全部结束后统一组装；任一编译失败都会阻止打包，避免在错误状态下继续生成安装器。

## Windows 构建缓存与下载复用

Windows 构建流程新增 Electron、打包工具以及 Cargo 依赖的下载与编译缓存，并在缓存未精确命中时清理旧的原生成品。缓存不包含签名证书或 Cargo 凭据，正式发布缓存仅由主分支的成功构建写入，任务构建缓存继续按分支隔离。

## Git 推送后步骤的重试与结果处理

推送后的命令步骤现在每次尝试使用独立的运行身份，重试不会复用上一次的确认和启动回执；命令中心在写入前拒绝参数校验失败时，不再被标记为未知外部结果，而是进入需要关注的普通状态。这有助于减少因误判未知结果而导致的步骤卡住或重复确认。

## 如何升级

Homebrew 用户可执行：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可从 Release 页面下载 DMG（例如 `Zeus-0.4.38-arm64.dmg`）后手动安装升级。当前公开制品未经过公证，可能触发系统安全提示，请按系统提示手动允许打开。

Windows 请按系统架构选择安装包：`Zeus-0.4.38-win32-x64.exe` 或 `Zeus-0.4.38-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应 EXE 完成升级。

## 系统要求与已知限制

- macOS：最低支持 macOS 13.0；当前 DMG 为未公证制品，安装时可能需要手动放行。
- Windows：提供 x64 与 arm64 两种安装包，请选择与系统架构匹配的版本。
- 签名与系统提示以各平台实际发布清单为准；当前不提供应用内自动安装。

## 发布验证

公开 Release 仅在固定候选通过完整的发布门禁后创建，门禁包括：lint、类型检查、构建、桌面打包与安装包生成、对应平台的原生辅助程序编译，以及 macOS 签名与公证结果检查。任一检查未通过时不会创建公开发布。
