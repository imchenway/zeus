# Zeus 0.4.39 更新内容

## 合入可自选目标分支

在代码交付与全目录交付流程中，原先固定合入来源分支的步骤改为可按仓库选择本地目标分支。每个仓库会保留创建时记录的来源作为默认值，多仓交付时可分别指定各自的合入目标；界面会逐仓显示选择器，并在目标不可用、当前分支为分离状态或存在冲突时阻止本次合入。

改动同时修复了在两个入口之间不一致的合入执行问题：单独合入现在与组合交付使用相同的文件范围、目标分支和提交快照，不会再因为单独操作而丢失提交参数或目标分支信息。合入前会再次确认所选目标分支在仓库中真实存在。

## 来源分支记录更完整

创建会话工作树时会保留该分支的创建来源，并在会话环境与 Git 工作台中按仓库展示。多仓库工作区会分别列出各仓来源，不再把第一个仓库的来源当作整个工作区的来源；历史工作区中未记录来源的仓库会标为未记录，而不是推测其来源。

## 翻译菜单更稳定

浏览器页面的翻译服务菜单在弹出前会等待可选模型列表加载完成，免费服务与已登录供应商仍保持立即可选。模型读取失败时菜单会显示对应不可用提示，而不会影响其他服务选择；页面在加载期间被关闭或导航时，旧菜单请求会被丢弃。

## 如何升级

macOS 可通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.4.39-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成手动升级。

Windows 请按系统架构选择安装包：x64 使用 `Zeus-0.4.39-win32-x64.exe`，ARM64 使用 `Zeus-0.4.39-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应的 EXE 完成覆盖安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。当前制品可能仍为 ad-hoc 分发且未完成公证，首次打开时可能需要在系统设置中确认，升级以手动安装 DMG 为准。
- Windows：按 x64 或 ARM64 选择对应 EXE，安装前退出 Zeus。
- 具体签名状态与系统提示以各平台实际发布清单为准。

## 发布验证

公开 Release 仅在固定候选版本通过以下检查后创建：源码检查、类型检查、构建与桌面打包验证通过，产物完整性与版本号核对一致，且测试结果与发布记录可追溯。只有满足这些条件的候选才会对外提供下载。
