# Zeus 0.4.40 更新内容

## 清理嵌套工作树时保护本地改动

当会话工作区中包含嵌套的 Git 工作树（例如子仓库或子模块目录）并进入清理流程时，Zeus 现在会先确认父工作树没有未经授权的本地改动。

- 如果父工作树仍有你未确认保留的改动，清理会停止并保留该目录，不再直接删除，避免丢失尚未提交的内容。
- 只有在子仓已在本轮清理中成功回收、且父工作树剩余变化仅来自该回收时，才会继续完成父工作树的删除。
- 已成功回收的工作树会保留可恢复记录，便于之后识别和恢复。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 用户也可以从 Release 页面下载 `Zeus-0.4.40-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成手动升级。

Windows 用户请按系统架构选择安装包：x64 使用 `Zeus-0.4.40-win32-x64.exe`，ARM64 使用 `Zeus-0.4.40-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应的 EXE 完成升级。

当前公开制品可能仍为 ad-hoc 签名且未公证，应用内自动安装不可用，请按上述方式手动升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名和系统提示（例如首次打开时的安全提示）以 macOS 实际发布清单为准。
- Windows：支持 x64 与 ARM64，请选择与系统架构匹配的安装包。签名和系统提示以 Windows 实际发布清单为准。
- 清理包含嵌套工作树的会话工作区时，如果父工作树存在未确认的本地改动，相关目录会被保留而不是删除。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 源码检查：lint、类型检查与构建通过。
- 桌面验证：应用可正常启动，关键交互（包括会话工作区清理流程）按预期工作。
- 制品检查：macOS 与 Windows 对应架构的安装包成功生成，且签名/公证状态与发布清单一致。

以上检查全部通过，才视为满足创建公开 Release 的条件。
