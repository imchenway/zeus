# Zeus 0.4.41 更新内容

## 价格目录地址自动补全

- 在模型连接设置中，如果连接已经关联价格目录、但尚未单独填写价格地址，打开或保存编辑时会自动使用价格目录中的地址补全价格地址字段。
- 刷新价格成功后，价格地址会同步为最新可用的地址，减少字段留空或与价格目录不一致的情况。

## 价格来源链接展示简化

- 模型连接设置和菜单栏用量费用明细中不再单独显示“价格来源”链接，价格信息展示更集中。

## 如何升级

macOS（Homebrew）：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS（DMG 手动升级）：

1. 下载 `Zeus-0.4.41-arm64.dmg`。
2. 打开 DMG，将 Zeus 拖入“应用程序”，覆盖现有版本。
3. 启动 Zeus。

Windows：

1. 按系统架构选择安装包：`Zeus-0.4.41-win32-x64.exe`（x64）或 `Zeus-0.4.41-win32-arm64.exe`（ARM64）。
2. 完全退出 Zeus 后运行安装包完成安装。

当前公开制品可能仍为 ad-hoc、未公证构建，请按上述方式手动升级；应用内自动安装不保证可用。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。实际可用的安装方式、签名与系统安全提示以本次公开 Release 的 macOS 制品清单为准。
- Windows：请按系统架构选择对应的 EXE 安装包。实际签名与系统安全提示以本次公开 Release 的 Windows 制品清单为准。
