# Zeus 0.4.42 更新内容

## 会话工作树的代码交付比较更准确

从会话工作树打开代码交付时，“已提交成果”现在会与该工作树创建时记录的来源分支进行比较，不再一律以仓库配置的上游分支为基线。这样，文件清单、目录树计数和差异预览使用同一比较范围，看到的内容更符合当前会话的实际改动。

如果来源分支信息不可用，界面会明确提示无法读取已提交成果，而不会静默地改按推送上游展示，避免把不同范围的变化误认为会话成果。

## 从任务打开代码交付时自动定位来源会话

对于从会话创建、但尚未指定工作区的任务，打开代码交付时会自动读取该任务保存的来源会话，并沿用其工作目录和窗口身份，而不再猜测最近会话或第一条开发线。

- 若来源会话使用会话工作树，交付窗口继续按该会话范围读取历史和比较。
- 若来源会话属于直接工作目录，则按项目范围打开。
- 若来源会话信息缺失或与当前任务不匹配，会给出明确错误提示，并建议从目标会话打开代码交付。

## 差异窗口保持同一读取范围

从代码交付窗口打开单个文件的差异窗口时，会话工作树的历史、比较和刷新会沿用原会话的读取范围，不再退回到项目默认范围。

## 如何升级

本次公开制品仍为手动升级，应用内自动安装不可用。

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 手动升级：下载 `Zeus-0.4.42-arm64.dmg`，打开后将 Zeus 替换到“应用程序”目录。

Windows 手动升级：根据系统架构选择 `Zeus-0.4.42-win32-x64.exe` 或 `Zeus-0.4.42-win32-arm64.exe`，先退出 Zeus，再运行安装程序完成覆盖安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。当前公开制品未公证，首次打开时可能触发系统安全提示，需要按系统提示手动允许。
- Windows：支持 x64 与 arm64 两种架构，请选择与系统匹配的安装包。
- 签名、公证与系统提示以各平台实际发布清单为准。
- 当前制品为手动升级，不提供应用内自动安装。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 代码检查与类型检查通过。
- 构建与桌面应用打包通过。
- 各平台安装包按发布清单生成并核对架构与文件名。
- 发布清单中的签名与公证状态与实际制品一致。

未通过上述检查时，不创建公开 Release。
