# Zeus 0.4.43 更新内容

## 新建会话与任务联动

- 新建会话时会立即显示你发送的消息内容，不必等待会话创建完成才有反馈；如果创建失败，已输入的正文、附件和引用仍会保留。
- 新建会话时“同时创建关联任务”和“使用项目目录或在新建工作树中运行”的选择会按项目记住，切换项目或重新打开创建入口时恢复该项目的最近选择。
- 由会话创建的任务现在会携带会话中的附件，描述区的附件数量上限与任务编辑保持一致。
- 任务详情新增会话列表，按创建顺序展示与该任务关联的会话，包括已归档会话，可直接打开；加载失败时可重试。
- 任务详情标题区新增推送会话入口，推送检查中或失败时分别显示为“检查中”和“重试”，已处于完成或取消状态的任务不会触发推送。

## Git 工作区布局与成果比较

- 任务 Git 交付区改为左侧文件区、差异区和右侧操作区，操作区宽度与上下分栏都可拖动调整；窄窗口下差异区移到下方，文件区与操作区并列，操作不再被隐藏。
- 项目 Git 差异窗口的文件列表宽度可拖动，分支菜单等弹层会跟随所在窗口的尺寸与键盘操作。
- 已提交成果统一以当前分支创建时的固定提交作为比较起点，之后推送或合入不会改变成果范围；缺少创建记录时会提示无法确定范围，而不是显示错误结果。
- 比较尚未完成或失败时，“已提交成果”计数显示为占位符而不是 0。

## 窗口恢复与系统窗口

- 窗口最大化或全屏状态在最小化后仍会保留，重新打开时还原到此前使用的屏幕；退出应用时会保存最终窗口尺寸。
- 从子窗口打开的系统窗口会在其所属窗口关闭时一起关闭，不再残留空白窗口。
- 系统工作窗口在缩小时页眉页脚允许换行，阅读内容保持独立滚动。

## 如何升级

- macOS（Homebrew）：

  ```
  brew upgrade --cask imchenway/tap/zeus
  ```

- macOS（手动）：下载 `Zeus-0.4.43-arm64.dmg`，退出当前 Zeus 后打开并完成安装。当前公开制品为手动升级方式，应用内自动安装不可用。
- Windows：按系统架构选择 `Zeus-0.4.43-win32-x64.exe`（x64）或 `Zeus-0.4.43-win32-arm64.exe`（ARM64），退出 Zeus 后运行安装程序。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0；签名与公证状态、系统提示以该版本在公开 Release 中实际提供的制品清单为准。
- Windows：提供 x64 与 ARM64 两种安装包，请按系统架构选择；签名与系统安全提示以该版本在公开 Release 中实际提供的制品清单为准。
- 应用内自动更新依赖已公证且可被系统信任的公开制品；当前公开制品仍为未公证的临时分发，因此需要按上面的手动方式升级。
- 会话创建的任务附件沿用任务描述附件上限，超出数量时创建会失败并返回错误。
- 通过推送或合入改变了分支历史、且没有保留分支创建记录的仓库，可能无法确定已提交成果的比较起点。
