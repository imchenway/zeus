# Zeus 0.4.44 更新内容

## 会话工作区新增仓库处理

- 当会话工作树或普通目录中新增了独立的 Git 仓库时，这些仓库现在可以正常识别和操作，不再让已有仓库失效。
- 新增仓库使用自身的 Git 身份，不会被误认为来自原项目来源。

## 归档与任务结束时的目录保留

- 结束任务或归档会话时，新增仓库以及包含新增仓库的父工作树会被保留，避免连带删除未受管的代码。
- 身份无法确认、归属未经登记的目录同样会被保留，而不会阻止任务正常结束。
- 被保留的目录及保留原因会记录在任务事件中，便于后续单独清理。

## Git 状态显示更准确

- 会话快捷操作卡片遇到 Git 状态读取失败时，会明确显示“Git 状态读取失败”。
- 在任一目录模式下存在多个仓库时，分支位置会显示“多个仓库”，不再把首个仓库的分支当作整个工作区的分支。
- 只有在确认为非 Git 目录时，才会显示“非 Git 目录”。

## 如何升级

Homebrew 用户执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可以下载 `Zeus-0.4.44-arm64.dmg`，打开后按提示手动拖拽安装。

Windows 请根据系统架构选择安装包：

- x64：`Zeus-0.4.44-win32-x64.exe`
- arm64：`Zeus-0.4.44-win32-arm64.exe`

安装前请先退出 Zeus，再运行对应的 EXE 完成安装。

## 系统要求与已知限制

- macOS：最低支持 macOS 13.0。签名与公证状态以 macOS 发布清单为准；若发布说明标注为 ad-hoc 或未公证，系统可能提示无法验证开发者，此时需要手动完成安装升级，应用内自动安装不可用。
- Windows：提供 x64 与 arm64 两个安装包，请按系统架构选择；签名与系统提示以 Windows 发布清单为准。
- 被保留的工作区目录需要以后单独清理，不会在任务结束或会话归档时自动删除。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：lint、typecheck、构建、桌面打包，以及针对工作区 Git 行为的验证脚本。上述条件为创建公开 Release 的前置门禁；未全部通过时不会创建公开 Release。
