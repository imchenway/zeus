# Zeus 0.4.45 更新内容

## 冲突会话保留原任务关联

当 Git 交付遇到合并冲突并自动创建冲突会话时，该会话现在会继续归属原任务。你可以在原任务中查看和继续处理冲突会话，不会因为冲突而多出一项独立任务。对已经存在、此前未关联任务的冲突会话，也会按交付记录补齐任务关联。

## 从冲突会话返回原交付

在冲突会话中执行交付或使用相关入口时，会返回冲突所属的原交付会话继续操作，而不是从冲突隔离目录再次发起一次交付。冲突隔离目录仍按对应交付步骤识别，避免误用其他目录。

## 隔离目录不可用时的提示

如果冲突隔离目录已被回收或无法再访问，冲突会话不会再被当作可继续使用的隔离现场，并会提示工作目录不可用。你仍可从冲突会话追溯对应的原交付会话。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可以从发布页下载 `Zeus-0.4.45-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成手动升级。

Windows 请按系统架构选择安装包：x64 系统使用 `Zeus-0.4.45-win32-x64.exe`，ARM64 系统使用 `Zeus-0.4.45-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应安装包完成升级。

## 系统要求与已知限制

macOS 端要求 13.0 及以上版本。Windows 端请使用与系统架构匹配的安装包。

当前公开制品若为 ad-hoc 签名且未公证，升级需按上述方式手动完成，应用内自动安装可能不可用。签名、公证及系统安全提示以各平台实际发布清单为准。

## 发布验证

公开 Release 仅在固定候选通过以下检查后创建：代码检查、类型检查、构建与桌面打包、发布所需制品的完整性校验，以及本次新增的冲突会话关联与隔离目录验证。上述检查未通过时不会创建公开 Release。
