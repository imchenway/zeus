# Zeus 0.4.46 更新内容

## 会话与任务展示改进

- 任务推送和自动化任务在会话中显示你实际写下的需求正文，不再把内部拼接的模型上下文混进对话展示。回复和历史记录会沿用同一份显示内容。
- 新建会话时输入的系统消息草稿会先在草稿状态正常显示，不再因为尚无会话身份而丢失或错位。
- 会话标题生成只依据你发送的消息内容，避免把规则、技能说明或环境信息误当作会话主题。
- 读取模型凭据改为按需进行：选择具体来源或模型时只读取对应连接的凭据，减少一次读取全部供应商凭据带来的等待。

## 只读会话与新建入口

- 已结束任务的会话改为在输入区位置提供“重新打开任务”按钮，操作失败原因紧贴按钮显示。历史记录仍可完整查看，输入区不再被单独的只读提示占据。
- 旧版工具的会话记录在底部标注“旧会话 · 只读”，并直接提供新建会话入口，不再占用顶部横幅。
- 目标面板仅在存在实际状态限制或处于创建引导时显示说明文字；正常查看已有目标时界面更简洁。

## 布局与细节调整

- 窗口恢复时先进入最大化状态再显示，减少普通尺寸窗口先闪现再跳转到最大化的观感；macOS 全屏仍沿用系统全屏切换流程。
- 任务 Git 交付页的文件区、操作区与差异区统一由横向分隔条调整占比，窗口较窄时也保持同一布局。
- 智能体列表和会话的空状态只保留一条状态文字；内联文件引用的位置标注统一为英文行号格式，文件图标与首行文字垂直居中。

## 如何升级

macOS 可通过 Homebrew 升级：

```
brew upgrade --cask imchenway/tap/zeus
```

也可下载 `Zeus-0.4.46-arm64.dmg` 手动安装：退出正在运行的 Zeus，打开 DMG 并将 Zeus 拖入“应用程序”，再启动新版本。

Windows 请按系统架构选择安装包：64 位系统使用 `Zeus-0.4.46-win32-x64.exe`，ARM64 系统使用 `Zeus-0.4.46-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应 EXE 完成安装。

当前 macOS 制品若为 ad-hoc 签名且未公证，首次打开可能触发系统安全提示，需要按提示允许打开；此情况属于手动升级，不提供应用内自动安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名、公证状态与首次打开提示以该平台实际发布清单为准。
- Windows：支持 x64 与 ARM64，请选择与系统架构匹配的 EXE。签名与系统安全提示状态以该平台实际发布清单为准。
- 旧版工具产生的会话记录保持只读，只能查看，需要继续对话时请新建会话。
- 已结束任务的会话在重新打开任务前不可继续输入。

## 发布验证

公开 Release 只在固定候选版本通过发布所需的检查后创建，包括项目既定的构建与打包检查，以及对应平台制品与发布清单核对。发布说明中的升级方式与制品名称以该候选对应的实际发布清单为准。
