# Zeus 0.4.47 更新内容

## 代码交付页更快呈现差异

交付页现在先读取文件清单和增删统计，再只为当前选中的文件加载完整补丁正文。打开交付页时可以看到布局骨架占位，切换文件时差异区域显示局部加载状态，而不是等待整仓库补丁一起读完。已提交成果沿用分支起点作为比较基准，工作区比较包含暂存和未暂存改动；重命名文件按原路径与新路径共同识别，不会把改名误报为新增。

## 附件预览校验更一致

任务附件缩略图、完整预览以及文件打开使用同一套授权和路径校验：会话附件按授权凭据解析真实路径，任务附件继续限制在任务附件目录内，并拒绝经符号链接指向目录外的文件。

## 会话草稿与阅读位置修复

- 新会话不再自动带上项目之前记住的 Skill；只提交输入框中显式选择的 Skill 和插件，记住的 Skill 仍按原方式用于任务推送表单。
- 创建前系统消息按本次草稿的身份迁移到新会话，重开同一草稿会保留错误记录，不同草稿之间不再互相带走提示。
- 恢复历史阅读位置时，只在停留在静态历史的情况下补读缺失轮次；连接重建后沿当前分页继续加载，跟随最新消息时不会误触发旧位置恢复。
- 联想建议的失效判断改为按实际生成的资料内容与本次检索条件比较，记忆或任务的更新时间等存储元数据变化不会单独使建议过期。

## 如何升级

Homebrew：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 手动升级：下载 `Zeus-0.4.47-arm64.dmg`，打开后将 Zeus 拖入“应用程序”，替换现有版本。

Windows 手动升级：按系统架构选择 `Zeus-0.4.47-win32-x64.exe`（x64）或 `Zeus-0.4.47-win32-arm64.exe`（ARM64），先完全退出 Zeus，再运行安装程序。

当前 macOS 制品为手动安装方式，应用内自动安装不可用。

## 系统要求与已知限制

- macOS：最低系统版本 13.0。签名与公证状态以该平台实际发布清单为准；若系统提示来源未验证，请按 macOS 的隐私与安全提示手动确认打开。
- Windows：按系统架构选择对应 EXE；签名与系统提示以该平台实际发布清单为准。

## 发布验证

公开 Release 只有在固定候选版本通过以下检查后才会创建：版本与变更范围核对、代码检查与类型检查、构建与桌面打包，以及各平台制品的签名与发布清单核对。检查未通过时不会创建公开 Release，也不会同步 Homebrew Tap。
