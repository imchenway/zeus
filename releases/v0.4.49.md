# Zeus 0.4.49 更新内容

## Markdown 输入更稳定

- 在使用输入法组合输入（例如中文、日文等）时，Markdown 表格的编辑不再因输入过程中格式刷新而打断。上屏前的原始文字会保持可编辑状态，确认输入后再恢复正常排版。
- 当光标移到表格原文位置时，方向键会整块跳过表格，不再停在不可见的表格源码中，减少误操作。

## 会话工作树恢复更可靠

- 恢复了“父仓检出后生成空的子模块目录”这类工作树的会话恢复能力：空的子模块目录会按原计划重建，不再被误判为目录被占用。
- 非空目录仍必须确认是原来的 Git 工作树根目录；文件或符号链接不会被当作恢复目标，避免写入其他目录。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可下载 `Zeus-0.4.49-arm64.dmg` 手动安装。

Windows 请按系统架构选择安装包：

- x64：`Zeus-0.4.49-win32-x64.exe`
- ARM64：`Zeus-0.4.49-win32-arm64.exe`

安装前请先退出 Zeus。当前公开制品为手动升级方式，应用内自动安装可能不可用。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名与公证状态、系统首次打开提示以对应平台的公开发布清单为准。
- Windows：请选择与系统架构匹配的安装包。签名与系统提示以对应平台的公开发布清单为准。
- 升级前建议先退出正在运行的 Zeus。
