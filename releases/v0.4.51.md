# Zeus 0.4.51 更新内容

## Kilo 账户用量与余额展示

- 新增 Kilo 账户用量支持：在菜单栏用量窗口中，Kilo 连接会单独展示账户可用余额，并在存在 Kilo Pass 时显示本周期剩余额度、续费时间与已用/总额度。
- 余额与 Pass 额度分别计量；查询失败或数据过期时会给出提示，并保留上次成功读取的数据，不会把缺失值显示为零。
- Kilo 账户查询不依赖 Codex 登录状态，可与其他用量来源分别刷新。

## 新增 Kilo 模型连接

- 在模型连接设置中可选择 Kilo 模板，自动填入官方网关地址，并可直接从在线模型目录读取可用模型。
- Kilo 模型可手动展开编辑模型定义；其价格按官方公开的美元/Token 单价读取，不套用其他供应商同名模型的价格。

## 模型认证方式更明确

- 模型连接的认证方式统一为明确的请求头：默认使用 `Authorization: Bearer`，Anthropic 协议下可选择 `x-api-key`。
- 设置页会直接标注默认认证方式；旧配置在读取时按 Bearer 处理，避免排队任务沿用旧认证头。

## 会话环境卡片与 Git 状态读取

- 会话快速操作卡片改为在打开或切换会话时按需读取 Git 状态，只显示“有未提交更改”“工作区干净”或“非 Git 目录”，不再展示文件数与增删行数。
- 切换项目或会话时会先清除旧状态，避免把上一个工作区的更改状态带入当前会话。
- 嵌套仓库场景下，父仓库不会因嵌套仓库的未跟踪占位而被误判为有未提交更改。

## 如何升级

- Homebrew：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- macOS：下载 `Zeus-0.4.51-arm64.dmg`，打开后按提示完成手动升级。
- Windows：按系统架构选择 `Zeus-0.4.51-win32-x64.exe` 或 `Zeus-0.4.51-win32-arm64.exe`，先退出 Zeus，再运行安装程序完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。
- Windows：请按系统架构选择对应的 EXE 安装包。
- 签名、公证与系统安全提示以各平台实际发布清单为准。若当前公开制品尚未完成公证，macOS 上需要手动升级，应用内自动安装不可用。

## 发布验证

公开 Release 只有在固定候选通过发布门禁检查后才会创建，包括但不限于：类型检查、构建、桌面打包，以及各平台制品签名与公证状态符合发布要求。未通过上述检查的候选不会作为公开版本发布。
