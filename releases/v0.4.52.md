# Zeus 0.4.52 更新内容

## GitHub Copilot 接入

- Zeus 现在支持将 GitHub Copilot 作为新的 Agent 来源。登录后可以在模型选择器中看到当前 Copilot 账号实际可用的模型及其推理强度与上下文窗口信息。
- 在账户设置中新增 GitHub Copilot 账号区块：可以通过 GitHub 设备码流程登录、取消登录和退出登录，并查看当前可用模型数量与官方额度（若账号返回了权威额度数据）。
- Copilot 账号只取自托管 SDK 的登录状态，与 Codex 账户和自定义模型连接相互独立；退出 Copilot 不会影响其他来源。
- 当 GitHub 策略禁用某个模型或账号尚未配置该模型时，对应模型会标记为不可运行，并在选择路由时提示刷新账号和模型目录。
- Copilot 会话同样支持目标（Goals）、上下文容量提示、跨来源历史迁移与 Codex/Pi 共用的话术流程；由于 SDK 不提供发送前精确 token 预检，发送前的容量提示可能不精确。
- Copilot 暂无独立权限审查，需要人工处理工具审批；「替我批准」权限选项在 Copilot 模型下不可用。
- 如果 Zeus 在 Copilot 轮次尚未确认终态时重启，该轮次会保留为暂停，需要核对原生历史后再继续，不会自动重发请求。

## Mermaid 图表显示修复

- 会话中的 Mermaid 图表现在与表格一样使用整列宽度展示，在普通阅读和展开状态下的宽度表现一致。

## 网络与价格提示修复

- 已登录并恢复网络后，旧的网络错误提示会清除，不再残留到新请求。
- 模型价格获取失败时仍会显示缺少价格的提示，不会被一并清除。

## 如何升级

Homebrew（macOS）：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS 手动升级：下载 `Zeus-0.4.52-arm64.dmg`，打开后将 Zeus 拖入「应用程序」，替换旧版本。

Windows 手动升级：根据系统架构下载对应安装包——`Zeus-0.4.52-win32-x64.exe` 或 `Zeus-0.4.52-win32-arm64.exe`；完全退出 Zeus 后运行安装程序覆盖安装。

当前公开制品为手动升级渠道，应用内自动安装不可用；升级前请确认已退出正在运行的 Zeus。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名与公证状态以本次 macOS 发布清单为准，系统可能显示相应安全提示。
- Windows：提供 x64 与 arm64 两种安装包，请选择与系统架构匹配的文件。
- Copilot 模型能力取决于 GitHub 账号的订阅与策略；未登录时 Copilot 模型不会出现在模型选择中。
- Copilot 不支持修改会话上下文容量，仅报告模型窗口上限。
