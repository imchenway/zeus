# Zeus 0.4.53 更新内容

## 代码交付通知更可靠

- 代码交付通知现在只确认你当时看到的这条结果。如果该交付在你点击前又更新了状态，旧通知的确认不会把新结果一并标记为已读，避免新出现的“需要处理”被误当作已查看。
- 对于较早打开的通知列表，确认某条交付通知时该条可能已被新状态取代，此时它会保持未读，并在刷新后以最新状态再次出现。

## 交付通知列表加载更稳定

- 通知列表中的代码交付条目改为按统一分页边界读取，并单独统计未读数量。当通知较多、需要翻页时，交付通知的排序与未读计数和任务、自动化等其他通知保持一致。

## 如何升级

- macOS（Homebrew）：`brew upgrade --cask imchenway/tap/zeus`
- macOS（手动）：下载 `Zeus-0.4.53-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。
- Windows：根据系统架构选择 `Zeus-0.4.53-win32-x64.exe`（x64）或 `Zeus-0.4.53-win32-arm64.exe`（ARM64），先退出 Zeus，再运行安装程序完成安装。

## 系统要求与已知限制

- macOS：最低支持 macOS 13.0，安装包为 Apple 芯片（arm64）版本。
- Windows：提供 x64 与 ARM64 安装包，请选择与系统架构匹配的文件。
- 当前公开制品未经过公证或签名保护时，系统可能显示安全提示，需按平台提示手动允许运行；此情况只能使用上述手动方式升级，应用内自动安装不可用。签名与系统提示的具体情况以各平台实际发布清单为准。

## 发布验证

公开 Release 仅在固定候选版本通过以下检查后才会创建：

- 类型检查、代码检查与构建通过。
- 桌面应用打包成功，并产出 macOS 与 Windows 对应架构的安装制品。
- 制品名称、版本号与候选提交一致。
