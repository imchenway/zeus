# Zeus 0.4.54 更新内容

## Codex 统一使用 Zeus 受管程序

- Codex 的检测、登录、执行和修复不再依赖系统中全局安装的 Codex CLI，也不再读取过去保存的外部程序路径，统一使用 Zeus 专属目录中的受管 Codex 程序。
- 普通登录与远程接管现在共用同一份受管程序：远程接管不再要求单独安装另一份 Codex，设置过程中的行为更加一致。
- 当受管 Codex 尚未准备完成、路径不可用或程序无法识别时，界面会给出对应的说明，并展示在 Zeus 专属目录中准备或修复程序的命令；你可以复制该命令自行执行，随后回到 Zeus 重新检测。

## 设置页简化 Codex 程序准备

- 设置中的 Codex 程序准备区域移除了“手动指定程序路径”入口，不再允许填写任意本机 Codex 路径；界面会依据受管目录给出安装指引与检测结果。
- 检测失败时的提示统一围绕 Zeus 管理的程序说明问题与修复方式，不再出现“所选程序”这类与手动路径相关的措辞。
- 如果你的运行设置中曾保存过 Codex 的全局程序路径，该路径不再参与运行，Codex 一律以 Zeus 受管程序为准。

## 如何升级

macOS 可通过 Homebrew 升级：

```
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.4.54-arm64.dmg` 手动安装。当前公开制品可能仍为 ad-hoc 签名且未公证，此时属于手动升级，不提供应用内自动安装。若系统提示无法验证开发者，请在“系统设置 > 隐私与安全性”中允许打开，具体以该平台实际发布清单为准。

Windows 请按系统架构选择安装包：64 位系统使用 `Zeus-0.4.54-win32-x64.exe`，ARM64 系统使用 `Zeus-0.4.54-win32-arm64.exe`。安装前请先退出 Zeus，再运行安装程序完成升级。签名与系统提示以实际发布清单为准。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。安装包是否经过签名与公证，以该平台实际发布清单为准。
- Windows：请根据系统架构选择对应 EXE，签名与系统提示以实际发布清单为准。
- Codex 仅使用 Zeus 受管目录中的程序，不再支持通过设置页指定其他本机 Codex 路径；如需更新或修复，请使用界面提供的命令在受管目录中处理。
- 当前公开制品若仍为 ad-hoc、未公证，升级需手动完成，可能在系统层面出现安全提示。
