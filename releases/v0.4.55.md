## CDN 加速下载

Zeus 0.4.55 的安装包与更新清单新增官方 CDN 分发，同时保留 GitHub 作为备用来源。macOS 与 Windows 的更新检查会优先访问 CDN，在 CDN 网络不可用或返回临时错误时自动回退到 GitHub；如果清单内容校验失败或跳转到非官方地址，则不会通过备用来源绕过检查。Homebrew 升级时也会优先从 CDN 预取与当前版本、摘要一致的安装包，传输中断时才交回 Homebrew 自带下载继续。

Release 正文会固定列出本版本的加速下载地址，安装包地址绑定具体版本号，不同版本之间不会混用。

## 下载中断后的恢复

更新下载在连接超时或传输中断时，会先清理未完成的暂存文件，再尝试同一版本的另一官方来源继续下载；如果已下载内容的大小或摘要不匹配，则直接停止，不会安装被篡改或不完整的文件。下载过程中持续低速时可手动重连，重连只结束当前来源的连接。

## 如何升级

Homebrew 用户执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可以从官方发布页手动下载 `Zeus-0.4.55-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成升级。

Windows 用户请根据系统架构选择 `Zeus-0.4.55-win32-x64.exe` 或 `Zeus-0.4.55-win32-arm64.exe`，退出正在运行的 Zeus 后运行安装程序完成升级。

当前公开制品为 ad-hoc 签名、未公证，桌面端不提供应用内自动安装，请按上述方式手动升级。

## 系统要求与已知限制

- macOS：需要 macOS 13.0 或更高版本，当前仅提供 Apple Silicon（arm64）安装包。由于制品未公证，首次打开时系统可能提示来源未验证，需要在系统设置中允许打开，具体签名与系统提示以实际发布清单为准。
- Windows：提供 x64 与 arm64 两个架构的 EXE 安装包，请选择与系统架构匹配的版本；签名与系统提示以实际发布清单为准。
- 更新检查优先使用 CDN，CDN 不可用时自动回退 GitHub；受网络环境限制，个别情况下检查更新可能需要更长时间。

## 发布验证

Zeus 的公开 Release 只有在固定候选通过以下检查后才会创建：代码规范、架构边界、类型检查、CDN 分发与双来源更新验证、生产构建，以及 macOS 与 Windows 对应架构安装包的构建与身份核对。发布时需要校验分发身份与 CDN 配置，并确认两端公开更新清单与候选内容一致；任一安装包上传或核验失败，稳定更新清单都不会被切换到新版本。
