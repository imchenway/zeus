## 数字团队工作流原语

数字团队的流程编排新增了一组通用节点，可以在画布上直接拖入并配置：

- **调用**：可调用已激活的工具、固定修订的子流程，或进行结构化数据映射。
- **等待**：可等待人工回应、外部事件或指定时长后恢复，并设置超时处理方式。
- **路由**：按输入字段的比较条件选择出口，支持默认出口，未匹配时也可设为失败。
- **汇合**：等待已选分支完成后继续。

这些节点与员工节点共用统一的输入、输出契约配置。输入可绑定常量、任务字段、上游输出或固定成果，配置时会给出 JSON 校验提示。运行中的“等待”节点可以直接在检查器内提交结构化回应或批准工具调用，画布与详情页使用一致的节点状态名称。

## 代码交付进度与操作区

代码交付现在会在会话的环境卡片中显示真实的后台交付进度，包括已完成的步骤数、当前执行的提交/合入/推送动作以及对应仓库。需要处理、等待回应或结果待核对的步骤会单独标注，关闭交付窗口也不会中断执行。

交付操作区重新整理了布局：提交、合入、推送各自成为独立分组，“组合交付”集中放在底部，可选择提交、合入、推送的组合，并设置是否由 AI 生成提交说明、是否由 AI 处理合入冲突。推送后命令改为多选下拉，可在一个面板内调整执行顺序，最多选择 50 项。

## GitHub Copilot 登录

Copilot 设备码登录流程中，验证码现在可以一键复制；打开 GitHub 授权页时会自动附带当前验证码，若自动打开失败仍保留手动入口和验证码，便于重试。

## 其他改进

- 数字团队中修正了会话资源身份匹配，避免把其他会话的资源错误关联到当前会话。
- 等待工作分工全部停止后才判定整体结果，减少过早结束判断。
- 合入等其他节点类型现在也支持发起返工，而不只限于员工与代码集成节点。

## 如何升级

macOS 可通过 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 macOS 安装包后手动安装：`Zeus-0.4.56-arm64.dmg`。请先退出正在运行的 Zeus，再打开 DMG 并拖入“应用程序”完成替换。

Windows 请按系统架构选择对应安装包：

- x64：`Zeus-0.4.56-win32-x64.exe`
- arm64：`Zeus-0.4.56-win32-arm64.exe`

下载后先完全退出 Zeus，再运行所选 EXE 完成安装。

当前公开制品可能仍为 ad-hoc 签名、未经过公证，因此请按上述方式手动升级，不要依赖应用内自动安装。

## 系统要求与已知限制

- macOS：最低要求 macOS 13.0。未公证的构建在首次打开时可能触发系统安全提示，需要在“系统设置 → 隐私与安全性”中手动允许；实际签名与提示以 macOS 发布清单为准。
- Windows：提供 x64 与 arm64 两个安装包，请选择与系统架构匹配的版本；安装程序的签名与 SmartScreen 提示以 Windows 发布清单为准。
- 数字团队工作流原语属于新能力，复杂子流程与外部事件的组合行为可能仍需要在使用中逐步完善。
