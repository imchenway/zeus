## Homebrew 更新更可靠

当 Zeus 通过 Homebrew 进行应用更新时，后台的 Homebrew 索引同步偶尔会在下载公共索引阶段失败，即使官方 Tap 中的 Zeus Cask 已经同步完成，也可能导致更新流程中断。

本版本调整了这一处理方式：同步过程报错后，Zeus 会先核对本机实际获取到的 Zeus Cask 是否完整、是否与当前安装的应用身份匹配、是否对应目标版本。只有这些核对全部通过，才会接受已经落地的同步结果并继续更新；任一项不通过时，更新仍会以失败处理，避免在不一致的状态下继续。

此行为只影响通过 Homebrew 执行更新的场景，不改变其他安装方式。

## 如何升级

通过 Homebrew 安装的用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 用户也可以从发布页下载 `Zeus-0.4.57-arm64.dmg`，打开磁盘映像后按提示将 Zeus 拖入“应用程序”完成手动升级。

Windows 用户请根据系统架构选择安装包：`Zeus-0.4.57-win32-x64.exe`（x64）或 `Zeus-0.4.57-win32-arm64.exe`（ARM64）。安装前请先退出正在运行的 Zeus，再运行对应 EXE 完成安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。当前公开制品为 ad-hoc 签名、未公证，升级需按上述方式手动进行，应用内自动安装不可用；首次打开时系统可能显示安全提示，具体签名状态与提示以 macOS 平台实际发布清单为准。
