## 设置导入导出更安全

- 导出的设置快照现在只包含模型选择、程序路径和受限的运行偏好，不再携带可能含凭据的环境变量、CLI 参数或启动脚本文本。
- 导入设置时，快照中省略的执行配置会保留本机已有值，不会用空值覆盖本机凭据。
- 仅在设置文件真正保存后，界面才显示导出成功；取消导出或取消选择文件时会直接结束本次操作，不会写入配置。
- 导入只恢复可迁移的界面偏好，任务分支前缀等偏好可随设置迁移，本机路径继续由服务端管理。

## 自动化删除后的行为更明确

- 删除自动化规则后，尚未开始的排队运行会标记为已取消。
- 已经接纳的执行工作不会被提前撤销，仍按原引用结算结果；尚未被接纳的目标会标记为已取消，并记录原因。
- 删除后若仍有接纳结果无法核对，该运行会标记为结果未知，而不是误报成功或取消。
- 删除规则后对历史运行的核对仍会正常进行，不会因规则已被删除而缺少结果记录。

## 安装包下载入口更稳定

- Homebrew Cask 与 README 的安装包改为通过官方固定下载入口分发，版本目录保持不变。
- 固定下载入口保持一分钟缓存，并在发布前核对安装包摘要、大小、来源提交和下载文件名，确保下载到的安装包与当前候选一致。
- Homebrew Tap 校验会同时核对版本、摘要、下载来源和架构，来源不一致时不会判定通过。

## 如何升级

- Homebrew 用户执行：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- macOS DMG 手动升级：先退出 Zeus，下载 `Zeus-0.4.58-arm64.dmg`，打开后将 Zeus 拖入「应用程序」覆盖旧版本。
- Windows 手动升级：先退出 Zeus，按系统架构选择 `Zeus-0.4.58-win32-x64.exe`（Intel / AMD x64）或 `Zeus-0.4.58-win32-arm64.exe`（ARM64），双击安装包完成安装。
- 当前安装包为手动升级方式，应用内自动安装不在此版本范围内。

## 系统要求与已知限制

- macOS：需要 macOS 13 或更高版本，仅支持 Apple Silicon（arm64）。
- Windows：需要 Windows 10 22H2 或 Windows 11，支持 Intel / AMD x64 与 ARM64；可在「设置 → 系统 → 关于」中确认系统类型。
- 各平台签名与公证状态以对应版本的发布清单为准。macOS 若提示无法验证 Zeus，可在「系统设置 → 隐私与安全性」中按系统提示选择「仍要打开」。
- 设置快照不再包含可能含凭据的执行文本；依赖这些执行配置的迁移需在本机重新确认。
- 自动化删除后，未决的接纳结果可能显示为结果未知，需要据记录进一步核对。
