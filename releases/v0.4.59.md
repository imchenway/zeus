## 更新窗口反馈更快

- 从菜单或界面手动检查更新时，更新窗口会先显示“正在检查”，不再等待后台记录或版本请求完成后再出现，点击后的反馈更及时。
- Windows 上会提前在后台准备好更新窗口，减少首次打开时的等待；如果后台准备失败，手动点击检查更新时仍会正常重试。
- 如果在等待检查期间关闭了更新窗口，不会因为检查推进而再次被强制弹出。

## Windows 未签名旧版升级更顺畅

- 当前仍使用未签名旧版 Zeus 的 Windows 用户，在发现已签名的新版本后，会按手动安装流程处理，不再等到下载完成后才被拦下。
- 自动安装仍要求更新包与当前应用来自同一受信任发行者；签名无效或发行者不一致的更新不会进入自动安装或恢复流程。
- 对于明确未签名的两端产物，只有在来源与摘要核对通过后才交由用户手动安装；损坏或不可信的签名不会被当作未签名处理。

## 如何升级

### macOS（Homebrew）

```bash
brew upgrade --cask imchenway/tap/zeus
```

### macOS（DMG 手动升级）

下载 `Zeus-0.4.59-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。升级前请先退出正在运行的 Zeus。

### Windows

请先退出 Zeus，再根据系统架构选择安装包：

- Intel / x64 系统：`Zeus-0.4.59-win32-x64.exe`
- ARM64 系统：`Zeus-0.4.59-win32-arm64.exe`

下载后运行对应 EXE 完成安装。当前公开制品未经过公证或为临时构建时，更新属于手动升级，不提供应用内自动安装。

## 系统要求与已知限制

- macOS 最低系统版本为 13.0。
- Windows 需根据系统架构选择对应的 EXE 安装包。
- 签名状态与系统安全提示以各平台实际发布清单为准；未签名或未公证的制品可能触发系统提示，需要用户手动确认。
- 当公开制品仍为未签名或未公证时，应用内自动安装不可用，请按上方方式手动升级。

## 发布验证

公开 Release 只有在固定候选通过以下检查后才会创建：

- 代码静态检查与类型检查通过。
- 应用构建与桌面端打包成功。
- 目标平台安装包按发布清单产出并可被下载核对。
- 版本号与发布清单、制品文件名一致。

任一门禁未通过时，不会创建对应的公开 Release。
