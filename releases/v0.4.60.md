## 仓库与文件勾选同步更一致

- 在 Git 变更审阅中勾选或取消整个仓库/分支时，工作区视图会同步选中或清空该仓库下的文件，让仓库勾选与实际提交范围保持一致。
- 批量勾选多个仓库或分支时，只更新本次涉及的仓库，其他仓库已选中的文件不会被意外清空或覆盖。
- 手动勾选文件时，会同步勾选其所属仓库；取消仓库勾选后再重新选文件，不会恢复此前隐藏的旧文件选择。

## 任务合并弹窗选择行为更可预期

- 在任务合并弹窗中勾选多个分支时，工作区范围下的子文件会一并选中；取消勾选时对应当前分支的文件选择也会被清空。
- 单仓勾选与分支批量勾选现在使用同一套级联规则，减少不同入口之间选择结果不一致的情况。

## 如何升级

- Homebrew：执行 `brew upgrade --cask imchenway/tap/zeus`。
- macOS：下载 `Zeus-0.4.60-arm64.dmg` 后手动安装升级。
- Windows：按系统架构选择 `Zeus-0.4.60-win32-x64.exe` 或 `Zeus-0.4.60-win32-arm64.exe`，先退出 Zeus，再运行安装程序完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。应用签名与系统提示以 macOS 发布清单中列出的实际签名状态为准。
- Windows：提供 x64 与 arm64 两种架构的安装包，请按设备架构选择对应文件。
- 当前桌面安装包采用手动升级方式；若发布清单未标注签名或公证，应用内自动更新安装可能不可用，需要按上述方式手动下载并安装。

公开 Release 只会在固定候选提交通过以下检查后创建：版本与发布清单一致、lint 通过、typecheck 通过、构建与桌面打包通过，并且 macOS 与 Windows 制品按各平台实际发布清单完成签名/公证核对。
