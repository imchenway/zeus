## 会话输入更稳定顺滑

- 新建会话时输入区保持可见，提交后不会因等待草稿切换而闪走，失败时仍可恢复原文和附件。
- 模型选项目录会在后台复用已有结果刷新，打开新会话时不再因为等待目录而阻塞输入；切换项目时不会误用上一个项目的模型选项。
- 会话列表在成员或顺序变化时平滑移动位置，状态图标刷新不会触发行重排动画；系统开启“减少动态效果”时直接显示结果。
- 发送与执行状态现在分开表达：消息已送达但尚未开始执行时显示为连接/准备反馈，“正在执行”只在真正开始一轮回复后出现。

## 输入建议更可靠

- 自动输入建议改为由本地服务持续保存和处理，切换页面或暂时离开会话不会中断生成，返回后仍能读取当前结果。
- 自动建议与手动润色各自独立进行，同一会话中同时操作不会相互覆盖。
- 网络断开时建议生成会暂停并提示“联网后继续”，恢复连接后自动继续，不额外消耗重试次数。
- 自动建议会持续对临时故障重试，手动操作仍保留原有两次重试上限。

## 图片预览支持复制与另存

- 在文件预览和会话资源预览中，图片支持右键菜单及键盘菜单（`Shift+F10` / 菜单键）操作。
- 可复制当前图片像素到系统剪贴板；没有本地文件的截图也可另存为 PNG，图片会按原始像素保存而不是预览缩放尺寸。
- 有本地文件身份的图片还可“打开文件”和“定位文件”，操作失败会在预览内提示。
- 从 macOS 文件引用（如文件 ID）粘贴的图片和文件，现在能正确解析为实际路径并作为附件读取。

## 更新与手动安装体验

- 检测到匹配的新版本后可直接下载安装包，不再需要额外一轮检查或等待下个周期。
- 下载完成的系统通知会区分“重启安装”与“手动安装”；Windows 的手动提示改为按安装包引导，macOS 保持拖入“应用程序”的说明。
- 安装目录不可写时会转为手动安装提示，而不是凭空报错；应用未签名时仍只提供打开安装包的手动安装方式。

## 如何升级

Homebrew 用户可执行：

```
brew upgrade --cask imchenway/tap/zeus
```

macOS DMG 手动升级：下载与当前 Mac 架构匹配的 `Zeus-0.4.61-arm64.dmg`，打开后结束工作并退出 Zeus，将新版应用拖入“应用程序”完成替换。

Windows 手动升级：按系统架构选择 `Zeus-0.4.61-win32-x64.exe` 或 `Zeus-0.4.61-win32-arm64.exe`，退出 Zeus 后运行安装包，按提示完成安装。

当前公开制品若仍为 ad-hoc 签名且未公证，请按上述方式手动升级，不要依赖应用内自动安装。

## 系统要求与已知限制

- macOS：需要 macOS 13.0 或更高版本。首次打开未公证或 ad-hoc 签名的应用可能触发系统安全提示，需在“系统设置”中允许，具体以本次发布清单的实际签名状态为准。
- Windows：提供 x64 与 arm64 两种 EXE，请按设备架构选择；未签名安装包可能触发 SmartScreen 提示，需手动确认，具体以发布清单为准。
- 自动建议仅在设置中启用后才产生模型请求；关闭后本地服务不会继续生成。
