## 会话切换更顺畅

- 切换会话时直接显示目标正文，不再先播放整页过渡动画，减少切换过程中的视觉闪动。
- 最近访问过的会话会保留其页面状态，切回时正文立即可读，阅读位置与输入草稿得以保留。
- 后台刷新与预取在有限范围内进行，已在使用的页面不会被后台淘汰或覆盖。
- 侧边栏会话（子会话）现在会明确恢复其所属的主会话和工作区，列表中也会以“侧栏”标识区分同名会话。
- 历史会话中的失败轮次可在继续输入时直接续跑，续跑后沿用同一会话连接。

## Git 交付与差异预览更快

- 打开 Git 交付窗口、选择文件时，会在后台提前准备差异和文件正文，点击后更快看到内容。
- 文件列表支持悬停或键盘聚焦预读，已读文件再次切回时复用同一快照结果，不重复读取。
- 差异视图在正文就绪前先显示已有补丁，加载时显示明确的读取提示，不再出现空白占位。
- 代码编辑器首次显示时即应用已有语言高亮与样式，减少先显示纯文本再着色的跳变。
- 代码差异中可继续选择并复制文本；文件预览的提交归属改为按需读取，正文返回不再等待 Git 历史遍历。

## Windows 更新安装流程改进

- 当 Windows 更新支持原位安装时，应用内的更新入口会走同一套安全重启安装流程；当前安装目录不可写时，按钮改为“定位安装包”，并提示退出 Zeus 后从文件管理器运行安装器。
- 交互安装会保留安装器界面；用户取消、安装失败或安装器提前退出都会留下明确结果，不会让下一次升级一直等待旧状态。
- 未通过签名校验或发布清单未启用自动安装时，Windows 会要求明确的交互安装，不会静默替换应用。

## 如何升级

- macOS（Homebrew）：`brew upgrade --cask imchenway/tap/zeus`
- macOS（手动）：下载 `Zeus-0.4.62-arm64.dmg`，打开磁盘映像后将 Zeus 拖入“应用程序”完成替换。
- Windows：按系统架构选择 `Zeus-0.4.62-win32-x64.exe` 或 `Zeus-0.4.62-win32-arm64.exe`，先退出 Zeus，再运行对应的 EXE 完成安装。
- 当前公开制品若仍为 ad-hoc、未公证，请按上述方式手动升级，应用内自动安装可能不可用。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。
- Windows：提供 x64 与 arm64 两种架构的 EXE，请按实际系统架构选择。
- 各平台的签名与系统安全提示以对应平台实际发布的清单为准。
- Windows 在某些安装位置无法原位升级，需要退出 Zeus 后手动运行安装器。
- macOS 自动替换依赖签名、公证与执行宿主协议门禁，任一条件不满足时需手动升级。

Zeus 0.4.62 的公开 Release 只有在固定候选提交通过以下检查后才会创建：

- 候选提交与发布范围一致，制品摘要与发布清单一致。
