## 浏览器密码管理与自动填充

内置浏览器现在可以接入 KeePassXC 的凭据进行登录填充。Zeus 设置中新增了浏览器密码相关配置，用于管理是否启用密码自动填充。字段识别、站点规则和填写逻辑沿用 KeePassXC-Browser 的上游实现（1.10.4.1 版本），扩展自身的界面、保存密码、TOTP、通行密钥和自动提交默认关闭。

凭据桥接只作用于顶层 HTTP(S) 页面；对于使用封闭 Shadow DOM 的页面，无法像 Chrome 扩展那样访问其内部字段，相关站点上的识别可能不完整。自动填充在识别出错时可能写入不合适的输入框，建议按需启用。

## 浏览器自动化与故障上报

内置浏览器的自动化能力已接入电脑操作驱动，可用于页面内操作。浏览器打开请求在被打断或异常后可以恢复状态；新增的故障上报会收集诊断信息，便于定位问题。相关检查脚本已随代码加入，用于校验浏览器打开请求和故障上报的数据格式。

## 会话与工作区体验

- 会话工作区可以安全恢复；会话合并新增 squash 方式供选择。
- 虚拟列表在图片加载和阅读状态下更稳定，滚动时正文与图片不再频繁跳动。
- 双栏阅读会跟踪正文可见性，后台读取失败不再中断正文阅读。
- 侧栏开闭状态会被保留；文件工作区工具栏布局统一为单独组件。
- 下拉浮层被限制在触发区域附近，避免越界显示。
- 首发消息与输入框状态保持同步，发送时的输入状态更一致。

## 稳定性与清理

- 用户操作（键鼠接管）不再自动暂停正在进行的电脑控制；停止和画面预览仍按轮次归属。
- 已进入终态的任务不能再被启动或重试；启动失败的子进程会被回收。
- 退出时会清理执行主机和本地服务，并减少残留进程。
- Git 操作失败时保留失败原因，并统一仓库锁定行为。
- Windows 平台的全局规则投影和启动诊断得到修正。
- 超时诊断信息增强，连续区间聚合更合理。

## 如何升级

macOS 使用 Homebrew 时执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.4.63-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成手动升级。

Windows 请按系统架构选择安装包：`Zeus-0.4.63-win32-x64.exe`（x64）或 `Zeus-0.4.63-win32-arm64.exe`（ARM64）。安装前请先退出 Zeus，再运行对应 EXE 完成安装。

当前公开制品为 ad-hoc 签名、未经公证，应用内自动安装不可用，请按上述方式手动升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。未公证的 DMG 首次打开时可能触发系统安全提示，需在“系统设置 > 隐私与安全性”中允许打开；签名与提示以本版本 macOS 发布清单为准。
- Windows：提供 x64 与 ARM64 两个安装包，请与系统架构匹配；签名与系统提示以本版本 Windows 发布清单为准。
- 内置浏览器的密码自动填充仅覆盖顶层 HTTP(S) 页面，封闭 Shadow DOM 内的字段可能无法识别。
- 自动填充在字段识别错误时可能写入不合适的输入框，请按需启用。
