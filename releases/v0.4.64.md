## 网络代理统一跟随系统

- 网络设置中的默认模式现在显示为“跟随系统代理”，浏览器、模型请求和后台请求统一使用同一套系统代理规则。
- 系统代理支持按目标地址判断直连、HTTP/HTTPS 代理以及 SOCKS4/SOCKS5 代理，也会遵循系统配置的绕过规则和自动配置脚本。
- “手动配置代理”和“强制直连”仍可独立覆盖系统设置。
- 网络连接检查能区分“代理自身连不上目标”与“目标已可达”，代理连接失败时会如实提示，而不是误报为连接成功。

## 发送与写入更可靠

- 消息发送、自动化规则创建/修改/运行等写操作在连接暂时中断后，会保留同一次操作的身份，重试不会重复创建内容。
- 若写操作超时或传输中断，界面会提示“暂未取得操作结果，操作可能已执行”，引导先核对状态再重试，而不是直接当作失败。
- 会话连接恢复改为先快速重试，之后转入低频后台恢复，并在网络恢复或窗口重新获得焦点时立即尝试续接读取；恢复过程只重新读取，不会重放已提交的操作。
- 待发消息不再必须等待实时连接就绪才发出，排队发送的等待提示也更贴近实际状态。

## 会话显示与自动化界面修复

- 修复部分历史会话在 Provider 已确认接收后，轮次关联指向不存在的记录、导致内容显示异常的问题；升级时会自动修复有唯一证据的悬空关联，不改动正文和消息顺序。
- 会话内容读取失败时会给出更准确的错误与重试判断，非临时性错误不会反复自动重连。
- 自动化页面读取目录失败时只提示“目录暂未更新”，不会覆盖已确认的保存结果；切换页面后迟到的旧操作回执也不会改写当前页面。
- 移除了服务等级按钮上“已记住，当前不可用”的附加文字提示。

## 如何升级

Homebrew 用户：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS 手动升级：下载 `Zeus-0.4.64-arm64.dmg`，打开后将 Zeus 拖入“应用程序”替换旧版本。

Windows 手动升级：按系统架构下载 `Zeus-0.4.64-win32-x64.exe` 或 `Zeus-0.4.64-win32-arm64.exe`，先完全退出 Zeus，再运行安装程序完成升级。

当前公开制品未经过公证，请按上述方式手动升级，不使用应用内自动安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0，当前提供 arm64 的 DMG 安装包。
- Windows：提供 x64 与 arm64 两种 EXE 安装包，请按本机架构选择。
- 签名与系统安全提示以各平台实际发布清单为准；若系统提示来源未验证，请按平台常规方式确认后再安装。
- “跟随系统代理”依赖操作系统当前代理配置；系统代理或 PAC 配置本身不可用时，网络请求会失败并提示检查系统代理配置。

## 发布验证

公开 Release 仅在固定候选提交通过发布门禁后创建，门禁包括：依赖安装与工作区一致性检查、类型检查、构建与桌面打包、目标平台制品校验，以及发布清单与校验值核对。任一检查未通过时不会创建公开 Release，也不会同步 Homebrew Tap。
