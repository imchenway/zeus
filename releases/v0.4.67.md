## 操作模型可独立配置

在设置中，你可以分别为 Browser Use 和 Computer Use 指定操作模型。选择“跟随当前会话”时，操作继续使用主会话模型；指定其他模型后，主会话在需要操作网页或桌面时会把完整任务委派给对应的操作智能体执行，执行结果再交回会话继续处理。操作智能体以普通子代理的形式出现在当前会话中，便于查看进度与结果。

## 操作任务可以停止和补充

当操作智能体正在运行时，可以从智能体面板或会话快捷操作中停止它。停止会取消尚未发送的补充指令，并中断仍在执行的轮次，已有的结果和正文会保留。你也可以向已有操作智能体补充新的要求，而不改变它创建时选择的模型。

## 网络代理保存后立即生效

网络设置中的代理模式、地址和绕过规则保存后会立即切换出口，不再需要完全退出并重开 Zeus。切换时会断开现有网络连接，随后新的模型请求、内置浏览器请求和检查请求都使用新配置。网络页现在只展示当前正式生效的代理，读取失败时会明确显示“无法读取”，不会把未生效的配置当作已生效状态显示。

## Zeus 自有窗口支持后台文本输入

在 macOS 上，操作智能体向 Zeus 自己的文本输入控件输入或替换文本时，可以通过后台通道完成，不会激活或抬升窗口，并会读回控件内容确认是否写入成功。如果无法确认结果，会提示先观察窗口，不会盲目重复输入。该能力只用于 Zeus 自有窗口，其他 Electron 应用的后台输入限制不变。

## 如何升级

Homebrew 用户可执行：

```
brew upgrade --cask imchenway/tap/zeus
```

macOS 用户也可以下载 `Zeus-0.4.67-arm64.dmg`，打开磁盘映像后将 Zeus 拖入“应用程序”完成手动升级。

Windows 用户请根据系统架构选择安装包：x64 系统使用 `Zeus-0.4.67-win32-x64.exe`，ARM64 系统使用 `Zeus-0.4.67-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应的 EXE 完成安装。

当前公开制品若仍为未公证的本地构建，Windows 和 macOS 可能显示系统安全提示；签名和系统提示以各平台实际发布清单为准。

## 系统要求与已知限制

- macOS：需要 macOS 13.0 或更高版本。
- Windows：支持 x64 和 ARM64 架构，安装包按系统架构区分。
- 代理设置在保存后立即生效，生效时会断开现有网络连接。
- Zeus 自有窗口的后台文本输入目前仅在 macOS 桌面端提供；其他应用的后台输入能力仍受各自平台与 Electron 安全限制。
- 当公开制品为未公证的本地构建时，只能通过手动下载 DMG 或 EXE 升级，应用内自动安装不可用。
