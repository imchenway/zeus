本次更新带来操作模型委派、浏览器与桌面后台文本输入、网络代理即时生效，以及浏览器翻译和浮层体验的改进。

## 可以给网页和应用操作指定独立模型

Browser Use 与 Computer Use 现在可以各自选择一个操作模型，与主会话模型分开保存。未选择时仍跟随当前会话。

- 主会话可以把完整的网页或桌面任务交给已配置的操作模型，任务以可见的智能体形式在当前会话中运行，完成后结果会自动交回主会话继续处理。
- 可以对已有操作任务补充要求，或直接停止任务；停止时未执行的补充指令会被取消，已产生的结果会保留。
- 停止屏幕控制或会话轮次时，相关的子任务也会一并停止。

## 浏览器翻译与浮层的体验改进

- 使用 Google 免费翻译时，多个标签页的请求会按顺序排队；相同原文会复用已有译文，遇到限流时会提示建议重试的秒数，并支持在翻译服务菜单中切换其他服务。
- 翻译失败时，页面和提示会明确显示失败原因与重试入口，不再把同一失败重复弹出。
- 打开菜单、弹窗等浮层时，内置网页会保留一帧当前画面作为背景，浮层关闭后恢复正常交互，减少内容短暂消失的感觉。

## 网络代理保存后立即生效

- 修改网络代理后无需完全退出并重开 Zeus，保存即切换；切换会断开现有网络连接，之后的请求走新配置。
- 代理模式下，内置浏览器和模型请求的“检查连接”都使用当前正式生效的配置，避免出现检查通过但实际请求仍走另一套代理的情况。
- 代理页面只展示当前生效状态，连续修改按顺序应用，较早的保存不会覆盖较新的配置。

## 后台文本输入支持 Zeus 自身

在 macOS 上，对 Zeus 自身的窗口执行后台文本输入或替换控件内容时，会通过私有通道写入并在页面内校验结果，不需要切换窗口焦点。如果结果无法确认，界面会提示先重新观察，避免重复输入。

## 如何升级

- 使用 Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- macOS 手动升级：下载 `Zeus-0.4.68-arm64.dmg`，打开后将 Zeu s 拖入“应用程序”，替换现有版本。
- Windows 手动升级：根据系统架构选择 `Zeus-0.4.68-win32-x64.exe`（多数设备）或 `Zeus-0.4.68-win32-arm64.exe`（ARM 设备），先完全退出 Zeus，再运行安装程序。

当前公开制品为手动安装方式，请在升级前退出正在运行的 Zeus。

## 系统要求与已知限制

- macOS：需要 macOS 13.0 或更高版本，安装包为 arm64 架构。签名与系统提示以本次实际发布的安装包清单为准。
- Windows：提供 x64 与 arm64 两个安装程序，请按系统架构选择。签名与系统提示以本次实际发布的安装包清单为准。
- 同一会话同一时间只执行一个操作任务；需要并行控制不同窗口的分工暂未支持。
