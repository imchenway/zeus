## 后台文本输入与浏览器翻译

- 涉及桌面自动化时，Zeus 自有窗口现在支持在后台完成文本输入：助手可以在不把窗口切到前台的情况下，向已识别的输入框或文本区域写入文字，并在写入后读回确认。若结果无法确认，会明确提示先重新观察窗口，而不是重复投递输入。
- 浏览器翻译失败时不再额外弹出重复错误提示，翻译状态只在页面内展示，减少打断。

## Git 交付与文件预览

- Git 交付运行可以中途终止，运行进度区域新增对应的操作入口，方便在发现方向不对时及时停止。
- 文件预览会在文件发生修改、删除后重建或原子替换时自动刷新，无需手动关闭再打开。

## 网络代理与自动化设置

- 保存网络代理设置后立即生效：桌面端与内置浏览器统一走 Core 的固定出口，切换代理不再依赖重启应用。代理连接检查会复用正式运行出口，检查结果更贴近实际请求路径。
- 新增自动化操作模型的委派设置，可选择在自动化流程中使用的模型；暂停自动化后，系统不再接纳新的自动化工作。
- 会话恢复与重连状态改为延迟展示，减少短暂网络抖动带来的状态闪烁。

## 故障现场保存与上报

- 应用卡死、窗口无响应或进程异常退出时，独立的故障监控会限时保存当时的进程状态与线程栈，并在原生窗口中提供“仅重启”“上报故障并重启”等选择。
- 上报前可以补充复现步骤或最小示例（可选，最多 4000 字符），补充内容不会自动读取界面里的其他输入。报告与附件只有在你主动点击上报时才会上传到私有诊断存储；这些材料可能包含业务数据。
- 如果上报未完整确认，故障现场仍保留在本机，可在重启后补报；选择立即重启会取消正在进行的上传。
- 全局菜单新增“上报故障…”，可在没有弹窗、没有错误码的情况下主动提交问题。

## 如何升级

macOS（Homebrew）：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS（手动）：下载 `Zeus-0.4.69-arm64.dmg`，打开后把 Zeus 拖入“应用程序”完成替换。

Windows：按系统架构选择安装包，先退出正在运行的 Zeus，再运行安装程序：

- x64：`Zeus-0.4.69-win32-x64.exe`
- arm64：`Zeus-0.4.69-win32-arm64.exe`

当前公开制品为手动升级包，不提供应用内自动安装；升级时请按上述方式手动替换或安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0；本次提供 arm64 DMG。签名与公证状态以该版本公开 Release 的制品清单为准，首次打开若出现系统提示，请按清单说明处理。
- Windows：提供 x64 与 arm64 两个 EXE，请选择与系统架构一致的安装包；安装前需退出 Zeus。签名状态以该版本公开 Release 的制品清单为准。
- 故障现场中的原生线程采样和进程转储可能包含路径、线程内存及业务数据，仅在主动上报时上传到私有诊断存储。
- 后台文本输入仅覆盖可识别的文本输入控件；若页面控件发生变化或无法读回确认，需要重新观察窗口后再操作。
