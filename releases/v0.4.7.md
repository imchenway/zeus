# Zeus 0.4.7 更新内容

## 本次更新

- 代码交付与 Git 差异可切换两侧全文，保留差异高亮；全文与补丁不一致时提示刷新。
- 源码和差异视图显示逐行提交人，可在行号区右键切换提交人和软换行；左右视图在换行后继续对齐。
- 文件预览增加编辑入口，打开当前工作区对应文件，复用源码编辑与未保存保护。
- 修复只读代码拖选的选区显示，并补齐 CRLF、macOS 路径别名和 Markdown 分隔线的读取处理。

## 如何升级

- Homebrew 用户可执行 `brew upgrade --cask imchenway/tap/zeus`。
- 也可以下载 `Zeus-0.4.7-arm64.dmg`，退出正在运行的 Zeus 后覆盖安装。
- Windows 用户根据系统架构下载 `Zeus-0.4.7-win32-x64.exe` 或 `Zeus-0.4.7-win32-arm64.exe`，退出 Zeus 后运行安装包。

## 系统要求与已知限制

- 最低系统版本：macOS 13.0。
- Windows 支持 Windows 10 22H2 和 Windows 11，提供 x64 与 ARM64 安装包。
- 若公开清单显示应用尚未完成 Developer ID 签名或 Apple 公证，首次启动可能需要按 macOS 提示手动确认。
- 若 Windows 清单标记为未签名，系统可能提示未知发布者；请核对官方来源后手动安装。

## 发布验证

- 公开 Release 只在固定候选提交通过静态检查、macOS 与 Windows 双架构正式打包及安装包完整性校验后创建；两端更新清单与安装包摘要核对一致后公开。
- 公开资产必须与 GitHub 服务端摘要、更新清单和 Homebrew Cask 保持一致。
