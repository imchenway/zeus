## 会话中展示 AGENTS.md 规则更新

- 当 Codex 原生会话在运行中读取或替换 AGENTS.md 规则时，Zeus 会在会话处理过程中显示一条“AGENTS.md 规则更新”，并保留规则正文与替换说明。
- 规则更新和命令、工具活动一样归入“已处理”过程，不会被误当成面向用户的最终回答；实时查看与重新打开历史回看显示的是同一份内容。
- 较长的规则正文可以按需展开查看全文，不再只显示预览或要求再次展开。

## 故障处理流程调整

- 崩溃后的故障窗口把“上报故障”和“仅重启”拆成两个独立操作：上报成功、失败或取消都不会顺带重启；只有单独选择重启才会结束旧进程。
- 上报过程中关闭窗口会取消本次上传，本机保存的故障现场保持不变；上传未完整确认时会留下待补报记录，下次可以补报。
- 窗口文案与按钮名称相应调整，中英文界面都明确区分“上报”和“重启”。

## 其他改进

- 队列中等待工作目录准备的首发消息，会在目录就绪后自动解除等待并继续派发；如果消息送达状态尚未确认，会给出明确提示而不是长时间挂起。
- 用量概览接口会等待统计数据就绪后再返回，避免刷新状态与供应商统计字段丢失。
- 修复 Windows 上从菜单栏唤起用量浮窗时的焦点处理，使其在 Windows 上正确聚焦当前浮窗。
- 发布在打包阶段失败后，可以接续同一候选的原运行并保留成功制品；失败输出会附带 GitHub 的具体作业注释，便于区分执行机调度与构建错误。

## 如何升级

- Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- macOS：下载 `Zeus-0.4.70-arm64.dmg` 后手动安装升级。
- Windows：按系统架构选择 `Zeus-0.4.70-win32-x64.exe`（x64）或 `Zeus-0.4.70-win32-arm64.exe`（ARM64），先退出 Zeus，再运行安装程序。

当前桌面安装包为 ad-hoc 签名、未经过公证，请以上述手动方式升级；应用内自动安装不可用。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。
- Windows：支持 x64 与 ARM64 两种架构，请按本机架构选择对应安装包。
- 由于安装包未公证/未正式签名，macOS 首次打开时可能触发系统安全提示，需要手动允许；Windows 上可能显示 SmartScreen 提示。具体签名与系统提示以各平台实际发布清单为准。
