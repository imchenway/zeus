## 文件预览与内容查找

- 在文件预览工具栏中新增查找入口，支持在当前文件内搜索并跳转匹配内容；`⌘F`（Windows 为 `Ctrl+F`）可直接唤起查找栏，`⌘G`/`F3` 跳转到下一处，`⇧⌘G`/`Shift+F3` 跳转到上一处。
- 差异视图的双栏和可编辑差异共用同一个查找栏，可在旧版本与当前版本之间切换查找范围。
- PDF 现在使用独立阅读区展示，支持在阅读器内进行文字查找、区分大小写，并显示当前匹配与总数。
- Excel 表格预览支持查找单元格内容，匹配项会在表格中高亮，并自动滚动到当前匹配。
- 文本交付物查看原文时也可直接查找全文，阅读模式与原文切换时保留查找入口。
- 当文件在磁盘上被修改、替换或重新创建时，预览会更及时地提示并刷新可读取的版本。

## 会话与任务

- 新增更快的速度档位选择，替换原有的双态开关；当所选模型不支持当前速度时，会给出明确提示而不是静默降级。
- 在会话列表中悬停或经过某条会话时，Zeus 会优先在后台准备该会话的可读内容与资源，减少打开后的等待。
- 会话内容中的图片和图表资源会提前预载，首屏展示更连贯。
- 会话重新连接或短暂切换时，状态行会继续显示当前执行摘要，不再出现空白状态。
- 任务成果阅读器支持在当前修订与对照修订之间切换查找。

## Git 交付操作

- 调整了 Git 交付操作栏布局：交付执行按钮固定在操作栏底部，设置项可在中间区域滚动查看。
- 推送后执行命令、交付后设置任务状态或归档会话等选项集中展示，错误信息会滚动到可见位置。
- 合入方式（Merge / Squash）移到合入操作附近，目标分支选择保持独立。
- 使用项目原目录的会话首次打开交付操作栏时，默认组合为生成提交说明、提交并推送，且不启用合入。

## 如何升级

- Homebrew：执行 `brew upgrade --cask imchenway/tap/zeus`。
- macOS 手动升级：下载 `Zeus-0.4.73-arm64.dmg`，打开后将 Zeus 拖入“应用程序”覆盖旧版本。
- Windows 手动升级：按系统架构选择 `Zeus-0.4.73-win32-x64.exe`（x64）或 `Zeus-0.4.73-win32-arm64.exe`（ARM64），先退出 Zeus，再运行安装程序完成安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名与公证状态以本次公开 Release 的制品清单为准；若提示来源不明，请在“系统设置 > 隐私与安全性”中确认。
- Windows：支持 x64 与 ARM64 两种架构，请下载与系统匹配的安装包。签名状态以本次公开 Release 的制品清单为准；若出现 SmartScreen 提示，请核对发布者信息后选择继续。
- 当前公开制品为手动升级方式发布，应用内自动安装升级可能不可用，请按上文手动安装。
- PDF 阅读器在文件解析失败或加载超时时会提示改用“打开文件”在系统应用中查看；受保护或加密的 PDF 可能无法在预览中查找。
