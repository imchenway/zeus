## 会话导航随系统播放节奏律动

在 macOS 14.2 及以上系统中，会话左侧导航刻度会跟随系统正在播放的音频显示频谱律动，让侧栏反馈更贴合当前声音。该效果需要用户授权系统播放采集权限；未授权、浏览器预览环境或系统版本不支持时，刻度保持静态显示，不影响会话操作。采集仅用于生成频谱能量与音量数据，不保留音频样本。

## 排队消息更易操作

输入框上方的排队消息现在支持逐条独立处理：可单独编辑、删除、上移或下移某一条，而不会让整块卡片一起进入忙碌状态。编辑中的内容在消息离开队列后仍会保留，方便复制；调序、删除和引导操作带有平滑过渡，并在失败时就地显示原因。仅队首消息和可引导的当前回复会显示引导入口，减少误操作。

## Git 差异预览与失败草稿更稳

检测到差异读取失败时，差异窗口会在当前文件附近显示错误并提供重试，重新请求只作用于当前文件，不必重新选择仓库或文件。新建会话时，项目分支快照会被复用，重新打开同一项目可直接显示已有信息。若发送或读取因本机断网失败，未发送的草稿会保留，联网后可继续，而不必重新输入。

## 浏览器与更新流程改进

内置浏览器的密码自动填充改为在用户选定账号后按登录框所在页面填回，跨页面或页面变化时不再把密码交给已失效的文档；同源子页面也能识别自己的登录框。关闭最后一个网页标签时，会先收拢承载它的分栏并交还焦点。退出与跨版本升级时，后台宿主会按更明确的顺序停止并释放资源；更新检查在退出开始后不再响应新的打开请求，避免清理过程中弹回失效入口。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可手动下载并打开 `Zeus-0.4.74-arm64.dmg` 完成升级。Windows 用户请先退出 Zeus，再按系统架构选择安装包：`Zeus-0.4.74-win32-x64.exe`（x64）或 `Zeus-0.4.74-win32-arm64.exe`（ARM64），运行安装包完成覆盖安装。当前公开制品可能仍为 ad-hoc 分发且未公证，应用内自动安装不可用，请按上述手动方式升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。会话导航随系统播放律动的效果仅在 macOS 14.2 及以上且授予播放采集权限时可用；其他情况刻度保持静态。
- Windows：提供 x64 与 ARM64 两种安装包，请按系统架构选择。
- 各平台的实际签名状态与首次打开时的系统提示，以对应发布清单为准。未公证的 macOS 制品首次打开时可能需要在系统中手动允许。
