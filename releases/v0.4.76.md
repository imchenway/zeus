## 源码与文件浏览

- 文件预览路径改为可逐级点击的目录导航，点击其中任一级目录即可在代码目录树中定位并聚焦对应文件夹，窄窗口下会自动打开目录抽屉。
- 源码页的路径导航同样支持目录定位，长路径可横向滚动，不再被截断而无法触达中间层级。
- 优化文件树加载：目录会先显示缓存内容并在后台与磁盘核对，连续展开多个目录时共用同一次读取，减少等待。
- 打开新文件时先切换选中态并显示“正在读取文件…”，读取期间仍可切换到其他文件，最后一次打开的请求才会生效。
- 目录抽屉关闭时会恢复键盘焦点，支持用 Esc 关闭。
- 行尾提交归属摘要保留作者、相对时间和提交说明，移除了额外的悬停完整信息提示。

## 会话与排队消息

- 排队消息卡片在点击“引导”或删除后立即收起，写入失败时会在原位置恢复并显示原因；同一条消息的重复点击会被去重，其他卡片仍可继续操作。
- “引导”会携带点击时显示的当前轮次提交，避免入队回执到达后发到错误轮次。
- 输入框直接引导新消息需要连接就绪；排队卡片的引导交由服务端核对当前轮次是否能接收。
- 输入建议按钮在跟随会话模型或已指定模型时都视为已配置。

## 模型、速度与用量

- 速度档位选择按模型目录实际提供的档位显示，单个加速档可直接切换，多个档位使用共享菜单；文案与下拉选项保持一致。
- 同步 Codex 推理档位，速度档位标识与用量统计使用统一的档位目录。
- 扩展模型价格支持：新增结构化价目、价目配置文档与回执、用量计价等能力，模型连接设置中可配置自定义价目与价格凭据。
- 新增 OpenAI 图片生成协议支持，模型连接可声明该协议族。
- 时间显示统一走同一日期时间格式化，任务、通知、Git 日志、用量窗口等处的中英文时间格式更一致。

## Git 交付

- 交付设置入口移到当前窗口标题栏，合入方式（保留提交／压缩为一个提交）与冲突处理选项集中在此设置。
- 单步合入按钮会直接标明合入方式，压缩合入时显示为“压缩合入”；单步合入与组合交付共用同一合入方式。
- 推送后命令与任务状态改为独立勾选，取消勾选不会清除已选值，重新启用时沿用先前选择。
- 交付文件树的勾选、目录展开和审阅焦点拆分处理，切换审阅文件时减少整棵树的重新渲染。
- Git 提交生成设置支持完整的 Codex 速度档位标识。

## 如何升级

Homebrew：

```
brew upgrade --cask imchenway/tap/zeus
```

macOS DMG 手动升级：下载 `Zeus-0.4.76-arm64.dmg`，退出 Zeus 后打开镜像并把 Zeus 拖入“应用程序”覆盖旧版本。当前公开制品为 ad-hoc 签名、未公证，可能需要手动确认系统提示，应用内自动安装不可用。

Windows 手动升级：按系统架构选择 `Zeus-0.4.76-win32-x64.exe` 或 `Zeus-0.4.76-win32-arm64.exe`，退出 Zeus 后运行安装程序。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。当前公开制品未公证，首次打开可能需要手动在系统设置中允许。
- Windows：提供 x64 与 arm64 两种安装包，请按系统架构选择对应 EXE。
- 签名、公证与系统提示状态以各平台实际发布清单为准。
- 当前发布制品为 ad-hoc、未公证时，仅支持上述手动升级方式，不提供应用内自动安装。

## 发布验证

公开 Release 只在固定候选提交通过以下检查后才会创建：版本与打包配置一致；lint、类型检查与构建通过；macOS 与 Windows 制品按架构完成打包；桌面端关键交互冒烟通过；发布清单记录各平台签名与公证状态。任一检查未通过时不会创建公开 Release，也不会同步包管理 Tap。
