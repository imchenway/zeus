## 源码工作区可以直接定位目录

- 文件预览、会话审阅和源码页的路径面包屑中，目录部分现在可以直接点击。点击后会切到对应工作区并展开文件树、选中该目录。
- 文件树操作改为先在界面上立即展开或切换，再与真实文件系统核对，外部改动后打开目录更不容易卡住。读取目录或文件期间会显示等待状态，连续点击不同文件时只保留最近一次打开结果，避免标签和内容错乱。
- 窄窗口中打开的文件树抽屉支持按 Esc 关闭，关闭后焦点回到目录按钮，键盘操作更连续。

## 会话与队列

- 排队消息的“发送到当前回复”和“删除”会立即让卡片进入退出过渡；操作被拒绝时会恢复原位置并就地显示原因，其他排队卡片仍可继续操作。
- 引导排队消息时会固定点击时所在的轮次，避免队列回执到达后把消息引导到其他轮次。
- 输入框“发送到当前回复”仅在连接就绪时直接引导，其余情况继续进入排队，减少不可用入口。
- 会话中的时间显示统一为应用日期时间格式，消息、目标、通知、数字员工记录和 Git 历史在不同界面间保持一致。
- Blame 行尾提示不再额外弹出提交归属悬停卡，改为直接显示作者、相对时间和提交说明，阅读源码时干扰更少。

## 模型连接与用量

- 模型连接设置支持为价格来源单独填写自定义价目与回执配置以及认证令牌，便于按供应商提供的价格信息校准用量费用。
- 用量定价覆盖更多模型，并对结构化价格、内置价格和回填流程做了调整，用量概览中的费用信息更完整。
- 速度档位选择与当前模型提供的档位保持一致，单档位快速切换和多档位菜单共用同一套档位名称，数字员工和 Git 提交生成也沿用相同选择。
- 会话模型建议默认启用，未单独指定模型时可直接跟随当前会话模型。
- 模型连接新增图片生成协议支持，并改进模型目录能力探测。

## Git 交付

- 交付设置移入标题栏，可在其中选择合入方式：保留提交或合成一个提交；单步合入与组合交付共用该选择，按钮会直接显示“合入”或“压缩合入”。
- 推送后执行命令、修改任务状态和交付后归档会话改为独立开关，关闭开关不会清空已保存的选择；只有启用推送时才能选择推送后命令。
- 交付文件树按变更列表分组时保留未跟踪文件分组，切换审阅文件或展开目录时减少整棵树重绘，勾选和展开状态更稳定。

## 如何升级

本次为手动升级版本，应用内自动安装不可用，请按平台选择以下方式。

- macOS 使用 Homebrew 时执行：

  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```

- macOS 手动升级：下载 `Zeus-0.4.77-arm64.dmg`，打开后将 Zeus 拖入“应用程序”覆盖旧版本。
- Windows 按系统架构选择安装包，安装前请先退出 Zeus：
  - Intel / AMD 64 位系统：`Zeus-0.4.77-win32-x64.exe`
  - Windows on Arm 系统：`Zeus-0.4.77-win32-arm64.exe`

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。安装包签名与公证状态以该平台实际发布清单为准；如系统提示来源或安全确认，请在“系统设置”中允许后再打开。
- Windows：支持 x64 与 arm64 两种系统架构，请安装对应架构的 EXE。安装包签名状态以该平台实际发布清单为准；如系统出现 SmartScreen 提示，请确认来源后继续。
- 当前公开制品为手动下载升级，不提供应用内自动安装。
- 目录定位依赖本地工作区文件仍可访问；目录被移出工作区或路径不存在时，文件树可能无法定位并会给出提示。
