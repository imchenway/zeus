## 菜单栏用量总览可按周期查看

- 菜单栏用量浮窗的“All”总览新增统计周期切换，可在今日、近 7 天、近 30 天和全部之间选择。
- 顶部本机 Token 合计、活跃供应商数，以及右侧各供应商的 Token 与费用估算，现在都与所选周期保持一致。
- 供应商列表的柱状趋势仍展示近 7 天，表头会标明当前统计周期。

## 代码交付窗口的打开体验改进

- 任务交付窗口预热时不会提前加载提交范围，待用户正式打开后才初始化本次任务的会话范围与文件列表。
- 默认勾选状态会更稳妥地保留：用户已开始选择文件后，后续加载完成的仓库不会重置其提交范围。

## 第三方 GPT 推理档位匹配更稳定

- 第三方接入的 GPT 型号会结合本机 Codex 缓存与随包提供的档位目录进行匹配。
- 运行目录暂时缺少某个型号的档位信息时，仍可沿用缓存或随包目录中的有效档位清单，减少推理档位显示为未知的情况。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可从发布页下载 `Zeus-0.4.79-arm64.dmg`，打开后拖入“应用程序”完成手动升级。由于当前公开制品为 ad-hoc 签名且未经公证，应用内自动安装不可用，请按手动方式升级；若系统提示安全确认，请按实际发布清单中的说明处理。

Windows 请按系统架构选择安装包：`Zeus-0.4.79-win32-x64.exe` 或 `Zeus-0.4.79-win32-arm64.exe`。安装前请先退出 Zeus，再运行安装程序完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。当前公开制品为 ad-hoc 签名且未经公证，首次打开可能需要手动确认；具体签名与系统提示以发布清单为准。
- Windows：提供 x64 与 arm64 两种架构安装包，请选择与系统匹配的版本；签名与系统提示以发布清单为准。
- 菜单栏用量数据依赖本机已记录的用量，缺失数据的周期会按下限展示。
