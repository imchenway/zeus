# Zeus 0.4.8 更新内容

## 项目内代码全文搜索

- 在项目源码工作区新增“搜索代码”入口，也可使用 ⇧⌘F（Windows 为 Ctrl+Shift+F）打开当前项目的文件内容查找弹窗。
- 支持区分大小写和整词匹配，并可按输入内容高亮命中位置；结果按文件分组，显示行号与列号。
- 使用方向键在结果间移动、Enter 打开对应位置，Esc 关闭；打开后直接定位到源码中的命中行列。
- 搜索范围限定为当前项目已保存的 UTF-8 文本。会跳过 `node_modules`、`dist` 等依赖或生成目录、符号链接以及超过 1 MiB 的文件。
- 由于存在读取上限，部分较大项目的结果可能不完整，弹窗会明确提示；此时使用更具体的关键词重新搜索可减少遗漏。

## Git 文件状态与差异预览

- 项目源码目录、Git 工作台、交付清单、推送预览和差异窗口现在统一按真实 Git 状态区分新增、修改、删除、重命名、未跟踪、冲突等文件。
- Git 工作区和交付清单会把未跟踪文件单独归入“未跟踪文件”分组，避免与已暂存的新增文件混淆；仍可对整组文件执行选择和暂存操作。
- 文件状态用颜色和图标区分，具体状态说明保留在悬停提示与无障碍标签中。
- 在 Git 差异和会话交付差异中，开启逐行归属后可看到每行对应的日期与作者；未提交或空白对齐行保持空白。
- 工作区中按改动片段操作时，改为通过片段选择器在连续差异视图中定位要暂存或放弃的片段，不再把每个片段拆成独立编辑器。
- 相关差异只在能取得完整且一致的正文时显示逐行归属；正文与补丁不匹配时会提示刷新，而不是展示可能错位的提交信息。

## 会话历史与内容定位

- 发送新消息时，对话正文的首条内容会立即显示，不被历史加载流程重新隐藏或重新播放整段淡入动画。
- 自动贴底只滚动对话正文自身的滚动容器，不再连带移动外层工作区。
- 从搜索结果或 Git 打开源码时，可以准确定位到目标行列；长代码行会横向滚动到命中位置。
- 同一行重复打开时也会重新触发定位。

## 项目工具与终端布局

- Git 面板和项目终端改为覆盖在工作区底部的面板，展开 Git 或调整高度不再压缩主页面，也不改变页面滚动位置。
- 项目终端可通过项目工具栏的终端按钮打开或收起；收起只隐藏显示，不结束后台 shell。
- 终端高度按项目记忆，但重新进入项目时不会自动展开终端。
- Git 与终端共用底部区域，打开其中一个会收起另一个。
- 在会话环境卡中可直接切换内置浏览器和会话终端；缺少终端能力时不显示对应入口。

## 如何升级

- Homebrew：

  ```bash
  brew upgrade --cask imchenway/tap/zeus
  ```

- macOS：下载 `Zeus-0.4.8-arm64.dmg` 后手动安装。
- Windows：按系统架构下载 `Zeus-0.4.8-win32-x64.exe` 或 `Zeus-0.4.8-win32-arm64.exe`，先退出 Zeus，再运行安装程序。

## 系统要求与已知限制

- macOS：最低支持 macOS 13.0。
- Windows：提供 x64 与 arm64 两种安装包，请按系统架构选择。
- 本版本公开制品可能未经过自动签名和公证。若系统提示来源未知或阻止运行，需按各平台实际发布清单的说明手动处理；此时升级需通过手动下载或 Homebrew 完成，不能依赖应用内自动更新。
- 项目代码搜索只覆盖已保存的 UTF-8 文本，会跳过依赖目录、生成目录、符号链接和超过 1 MiB 的文件，结果可能因读取上限而不完整。
- 逐行提交归属依赖完整的文件正文；当正文与补丁不一致或文件编码不受支持时，该部分行可能不显示归属。

## 发布验证

公开 Release 只在固定候选提交通过完整门禁后创建，门禁包括：依赖安装、类型检查、静态检查、构建与桌面打包，以及对应平台的制品检查。macOS 与 Windows 的产物命名、架构覆盖和签名状态以各平台实际发布清单为准；未通过上述检查的候选不会生成公开 Release。
