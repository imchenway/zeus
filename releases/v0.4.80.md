## 会话命名更贴合实际内容

新会话会先用首条输入或附件名生成一个临时标题，随后在模型给出可读摘要或完整回复后自动替换为更贴合的短标题。自动命名会参考会话已有的理解，只提炼业务主题，不会把过程消息当成结论。手动修改过的标题不会被自动命名覆盖；如果模型暂时无法给出结果，会话会继续保留可识别的临时标题，而不会停留在通用占位。

## 用量统计可按速度档位拆分

菜单栏用量窗口新增“速度档位”列，输出速率会同时按模型和请求速度档位（如标准、快速、超快）分别显示，便于比较同一模型在不同速度设置下的实际表现。缺少请求级档位依据的样本会归入未知档位，仍计入总量。

## 数字员工交付与任务状态展示

数字员工完成任务后提交正式交付物时会一次性完成交付清单冻结、待验收待办和任务事件记录，减少中途状态不一致；会话输出没有可沉淀内容时会明确提示。任务状态在任务表格、任务详情、会话头部和 Git 交付设置中统一使用配置的状态名称和颜色，内置状态会跟随界面语言显示，禁用时仍能分辨已选状态。

## 输入、失败提示与后台连接

输入框允许仅携带附件或仅携带网页提交与批注发送消息，普通附件也可以和自动建议同时存在；存在附件时发送按钮使用当前草稿，需先采纳灰字建议。网络失败结束后会像其他失败一样显示在该轮次的失败提示中。Windows 上 Codex 守护进程启动会使用当前 Zeus 的网络出口，并在代理切换未确认时按需重试；应用退出与完整重启会先关闭旧 Core 和 Zeus 专属 Codex 进程，再继续安装或重启流程。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可从 Release 下载 `Zeus-0.4.80-arm64.dmg` 手动升级：打开 DMG 后将 Zeus 拖入“应用程序”覆盖旧版本。

Windows 请按系统架构选择安装包：x64 使用 `Zeus-0.4.80-win32-x64.exe`，ARM64 使用 `Zeus-0.4.80-win32-arm64.exe`。安装前请先完全退出 Zeus，再运行对应 EXE 安装。

当前公开制品仍为 ad-hoc、未公证，升级以手动下载和安装为主，应用内自动安装可能不可用。

## 系统要求与已知限制

- macOS：需要 macOS 13.0 或更高版本；本次提供 ARM64 DMG。系统签名与提示以实际发布包为准，未公证版本可能触发系统安全提示，需要按系统指引放行。
- Windows：分别提供 x64 与 ARM64 安装程序，请选择与系统架构匹配的版本；签名与系统提示以实际发布包为准。
- 使用 Codex 远程控制时，Zeus 会通过本机受管代理接管连接；若此前已存在旧的 Codex 守护进程，切换网络出口时可能需要重新启动该守护进程，切换结果未确认时应用会提示并允许重试。

## 发布验证

公开 Release 只在固定候选通过既定发布门禁后才会创建：候选需通过格式检查、类型检查、构建与桌面打包，并生成与目标版本匹配的 macOS DMG 和 Windows x64/ARM64 安装程序；发布清单需确认各平台制品与版本号一致。任何一项门禁未通过时，不会创建公开 Release，也不会更新 Tap。
