## 新增源码变更标记与分支来源选择

- 项目源码编辑器现在会在行号旁显示相对当前分支最新提交的变更色块：新增、修改和删除各有区分，删除提示出现在相邻行边界；编辑、撤销或保存草稿时会自动更新，切换文件或 Git 状态刷新后重新比较。
- 新建会话时，来源分支选择改为在展开菜单后按需读取分支列表，菜单中会显示加载状态或读取失败反馈，并提供重试入口；本地与远程来源在收起和展开状态下都以文字标签区分。
- 来源分支菜单在多仓库场景下显示各仓库共有的来源分支，并标出当前草稿选中的那一项。

## 智能体会话与对话界面改进

- 智能体面板改为与会话顶栏共用标题区域，进入详情或返回列表时焦点落在标题上；列表和详情共用更紧凑的状态提示，正在读取或运行时才显示进度。
- 子任务在没有可显示消息时，单独展示已保存的任务说明；启动失败时直接显示错误信息。
- 侧边栏会话列表中，工作区类型尚未取得时不再暂时显示为项目目录图标，避免误标。
- 项目会话列表的展开与收起使用了更贴合该区域的过渡时长。

## 故障恢复与网络提示改进

- 对核心服务的健康探测改为绕开系统代理的独立本机请求，并结合最近一次控制通道回执判断是否真正无响应，减少代理配置导致的误判恢复。
- 故障报告补报时会沿用你已保存的网络代理设置；上传未能完整确认时会明确提示可重试。
- 后台刷新遇到网络问题时只记入诊断，不再打断当前操作；主动发送时离线或结果未确认的提示沿用统一文案。
- 内部协作会话不再出现在普通会话导航或来源恢复路径中。

## 内置浏览器本地文件预览

- 智能体在内置浏览器中访问本地文件时，仅限当前会话可访问的源码文件与 HTML 预览产物；超出范围或文件不存在时给出明确提示，其余网页访问行为保持不变。

## 如何升级

- Homebrew：`brew upgrade --cask imchenway/tap/zeus`
- macOS：下载并打开 `Zeus-0.4.81-arm64.dmg`，按 DMG 内提示手动完成升级。
- Windows：按系统架构选择 `Zeus-0.4.81-win32-x64.exe` 或 `Zeus-0.4.81-win32-arm64.exe`，先退出 Zeus，再运行安装程序。

当前公开制品为 ad-hoc 签名、未公证版本时，请按上述方式手动升级。

## 系统要求与已知限制

- macOS：要求 macOS 13.0 或更高版本。
- Windows：支持 x64 与 arm64 架构，请选择与系统架构匹配的安装程序。
- 签名状态、公证状态与系统安全提示以各平台实际发布清单为准；在未公证情形下，系统可能要求手动确认打开。
- 当前制品未提供应用内自动安装，升级需通过 Homebrew 或手动安装包完成。
