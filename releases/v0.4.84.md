## 内置浏览器下载与扩展入口

- 新增下载面板：可直接看到当前会话的文件下载进度、已暂停、已中断与失败状态，并支持暂停、继续、取消，以及完成后在文件夹中显示文件。下载记录会随浏览器数据保留，重启后已中断的传输不会自动继续。
- 自动保存时若目标目录已有同名文件，会自动使用带序号的新文件名，避免覆盖已有内容。
- 工具栏新增扩展程序入口，可在当前浏览器资料中打开扩展管理页和 Chrome 网上应用店。

## 密码填充与密码管理

- 在登录框点击填充时，改为在当前网页上方显示账号候选面板，可直接看到站点来源并选择账号；关闭、切换页面或窗口失焦时候选面板会自动收起。
- 候选面板标题会根据页面实际可填字段显示为填充用户名和密码、只填用户名或只填密码。
- 密码设置新增逐条查看密码：仅在设置窗口处于前台并主动展开某条账号时读取该条密码，切换窗口或收起后不再显示；也新增了逐条删除账号的入口。
- 导入密码文件时，统计改为区分新增、覆盖、相同、文件内冲突和无效记录；同一账号在同一文件中提供多个不同密码时仍需要你选择一条。

## 操作模型可选择速度

- Browser Use 和 Computer Use 的模型设置现在除了选择模型，还能为支持的模型选择速度档位；切换模型时从标准速度开始，避免沿用上一个模型的档位。
- 模型选择列表与会话模型列表共用分组、搜索和置顶方式。已设置的固定模型在派发时会连同所选速度一起使用。

## 其他改进

- 回复中的网页资源卡片宽度与正文保持一致，展开图表等宽内容时也能同步调整。
- 会话文件无法访问或超出允许目录时，会给出更明确的中文和英文说明。
- 大量会话历史中的命令输出改为引用归档副本，减少重复存储；工作凭证和任务交付仍能读取完整输出。
- Plugin Hook 的发送前超时判断现在只依据本次消息实际等待的 Hook，避免历史后台超时影响当前发送。

## 如何升级

Homebrew 用户可执行：

```
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可从发布页下载 `Zeus-0.4.84-arm64.dmg`，打开后将 Zeus 拖入“应用程序”替换旧版本。

Windows 请根据系统架构下载对应安装包，并先退出 Zeus 再运行安装：

- x64：`Zeus-0.4.84-win32-x64.exe`
- arm64：`Zeus-0.4.84-win32-arm64.exe`

当前公开制品如为未公证的临时构建，需按上述方式手动下载或通过 Homebrew 升级，不支持应用内自动安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。应用签名与系统提示以该平台实际发布的安装包清单为准。
- Windows：请选择与系统架构匹配的安装包，签名与 SmartScreen 提示以该平台实际发布的安装包清单为准。
- 浏览器下载列表中，已完成或已中断且无法继续的项目只保留记录与状态，暂停/继续/取消仅对仍在本进程中传输的项目可用。
- 密码填充依赖页面被识别出可填写的登录框；页面包含多个登录表单时，需要先点击要填充的登录框。
