## 文件工作区更易浏览

- 已打开文件改为单行标签栏：当前文件始终可见，放不下的标签会收进“更多已打开文件”下拉选择器，不再需要横向滚动查找。
- 标签栏支持方向键循环切换、Home/End 跳转首尾文件，隐藏文件被选中后会自动回到可见位置。
- 路径栏不再重复标签中已显示的文件名，只保留可点击的目录层级；空间不足时优先压缩单个名称并在路径段之间换行。
- 文件操作区变窄时保留按钮的图标、点击范围和完整名称提示，仅收起按钮文字。

## 计划预览与修改反馈

- 计划卡片打开右侧预览后，卡片本身转为明确的“已打开”状态，同一入口可再次点击关闭预览；关闭后焦点回到计划标题。
- 右侧计划工作区的标题和操作并入会话顶栏，与文件预览共用同一套外观；窄面板下自动隐藏分栏切换，只保留关闭入口。
- 提交计划修改意见时，提交按钮显示进行中状态并锁定输入框，避免重复提交；提交被接纳后，底部表单平滑切换回输入框，同时保留原内容直至过渡结束。
- 提交失败时焦点回到修改意见输入框，并保留已输入文字和附件。

## 系统窗口外观统一

- Git 差异、代码交付、更新项目、推送任务等独立窗口改用与内容标题同行的窗口外观，首帧底色和窗口按钮颜色跟随 Zeus 当前明暗主题，切换主题时同步更新。
- “更新项目”对话框改为紧凑的独立小窗，仅包含更新方式选项与操作按钮，保留“不再显示”选择。
- 推送任务窗口标题只显示“推送任务”，当前任务所属项目信息仍保留在窗口正文。
- 关闭按钮改为统一的图标样式。

## 如何升级

- macOS（Homebrew）：
  ```sh
  brew upgrade --cask imchenway/tap/zeus
  ```
- macOS（手动）：下载 `Zeus-0.4.85-arm64.dmg`，打开后按提示将 Zeus 拖入“应用程序”完成覆盖安装。
- Windows（x64）：下载 `Zeus-0.4.85-win32-x64.exe`，先完全退出 Zeus，再运行安装程序。
- Windows（ARM64）：下载 `Zeus-0.4.85-win32-arm64.exe`，先完全退出 Zeus，再运行安装程序。

请根据系统架构选择对应的 Windows 安装包；当前公开制品如未完成公证，应用内的自动安装不可用，请按上面的手动方式升级。

## 系统要求与已知限制

- macOS：需 macOS 13.0 或更高版本。
- Windows：需 64 位 Windows（x64 或 ARM64），并按上述架构选择安装包。
- 各平台的代码签名、公证状态与系统安全提示，以对应平台实际发布清单为准。
- 计划预览的“扩展为全宽/恢复分栏”入口仅在窗口宽度足够时显示；窗口较窄时只能在分栏模式下阅读计划。
- 文件标签超过可见数量时，隐藏文件只能通过标签栏的“更多已打开文件”选择器打开，不会自动滚动到视图内。
