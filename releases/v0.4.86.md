## 会话变更审阅更顺手

本轮变更审阅新增独立文件栏开关：可以从顶栏随时收起或展开左侧变更文件栏，隐藏时目录、滚动位置与当前文件都会保留。打开审阅时，首次进入默认全宽显示，此后尊重你选择的分栏模式；窗口太窄时会自动固定为全宽，避免差异正文被挤得过窄。

文件列表与源码文件树统一了行高、图标、状态色和键盘焦点样式。文件栏头部会同时显示文件数量与增删行统计，当前文件标题优先显示文件名、父目录在空间不足时截断，窄区域下“打开当前文件”仍保留图标和提示。

## 新建会话的来源与仓库选择更清晰

工作树模式下，来源分支选择器在收起状态会直接显示各仓库采用的来源分支名称；来源相同时合并显示，来源较多时逐项收缩，不再用“多个来源分支”笼统概括。混合来源可以直接回到“全部仓库”编辑范围，刷新远程分支的操作也移到搜索行旁。

直接模式切换实际 HEAD，工作树模式编辑来源：两种模式的仓库切换范围分别按真实签出范围和来源范围收敛，降低在子模块或嵌套仓库中误操作的可能。仓库被移除后编辑范围自动回到仍可用的仓库列表。

## 交付收尾偏好与任务工作处理更稳

Git 交付中“推送后执行命令”和“修改任务状态”的勾选、已选命令与目标状态现在按项目独立记忆，切换任务和会话时仍会恢复上次的选择；交付开始后只记录后台实际接纳的组合。

任务详情新增工作待办处理入口：失败或被阻塞的独立工作可重试或进入对应处理弹窗；Agent 结果未知时可从“核对结果”打开待办绑定的原会话，确认后按结论恢复成果收集。正式成果、阶段成果与工作项分别加载并各自提供重试，读取失败时保留已显示内容；终态任务保持只读。结果核对期间待办发生变化或读取失败，弹窗与已填写的意见会保留并提示原因。

## 其他改进

- 启动页进度改为贯穿整条轨道的光带，配合“第 N 步，共 3 步”和已等待时间，不再用分段填充暗示未知耗时。
- 浏览器密码自动填充的候选列表定位到真实登录框，支持子框架内多层嵌套的登录表单；手动按键会取消仍在读取的自动候选。自动建议只在登录框可见时出现，点击弹层外会先收起候选并把原点击交给网页。
- 音频可视化提高安静片段的响应，低音量时也能看到明显的波形起伏。
- 会话源码编辑在重新读盘期间若已有新草稿，会标记为外部修改，避免绕过外部变更检查。任务状态直接切换前会先核对后台最新版本，冲突时给出提示而不覆盖。

## 如何升级

Homebrew 用户可执行：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可以从发布制品下载 `Zeus-0.4.86-arm64.dmg`，打开后按常规方式将 Zeus 拖入“应用程序”完成手动升级。

Windows 请按系统架构选择 `Zeus-0.4.86-win32-x64.exe` 或 `Zeus-0.4.86-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应 EXE 完成手动升级。

当前公开制品不是经过公证的自动分发版本，请以上述手动方式升级，不要在应用内依赖自动安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名、公证与首次打开时的系统提示以本次发布清单为准。
- Windows：支持 x64 与 arm64，请下载与系统架构匹配的安装包。安装前须退出 Zeus。
- 手动安装的 macOS 版本在首次打开时可能出现系统安全提示，按系统指引允许打开即可。
