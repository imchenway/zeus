## 代码交付窗口的打开与关闭更快、更稳定

- 代码交付窗口现在会在内容真正可读后再呈现，减少打开时先看到空白或半绘制画面的情况。
- 已打开或刚关闭的交付窗口再次唤回时，会沿用既有实例，避免长时间空白等待。
- 关闭交付窗口时使用统一的退出过渡，并在必要时把焦点交还给原来的入口，减少窗口闪烁与焦点错位。
- 如果系统开启了减少动态效果，窗口会直接显示或隐藏，不播放淡入淡出。

## 可查看已回收工作树中的已提交成果

- 当会话工作树已被回收、但保留了恢复记录时，代码交付仍可列出已提交的仓库与文件，并查看历史差异。
- 这类历史查看为只读模式：不显示“本机未提交”范围，不提供勾选提交、推送和跳转到源码等操作，文件区会使用更宽的布局。
- 已提交成果的比较基于固定提交进行，不会为缺失的本地对象触发自动拉取。

## 返工意见的交接更明确

- 当管理者要求修改时，新一轮工作会通过固定的返工意见读取路径拿到当次意见，并按页读完，方便核对前次成果正文与附件。
- 返工意见与前次成果文件使用相同的交接授权，未授权的内容依然不可读取。
- 审查操作与成果导出分离：审查状态先保存，导出仅在数据提交后写入，避免中途失败留下不一致。

## 如何升级

macOS（Homebrew）：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS（DMG 手动升级）：下载 `Zeus-0.4.87-arm64.dmg`，打开后将 Zeus 拖入“应用程序”覆盖旧版本。

Windows：退出正在运行的 Zeus，根据系统架构下载并运行安装包——`Zeus-0.4.87-win32-x64.exe`（Intel/AMD 64 位）或 `Zeus-0.4.87-win32-arm64.exe`（ARM64）。

由于当前公开制品的签名与公证状态有限，升级需要按上述方式手动完成，应用内自动安装不保证可用。

## 系统要求与已知限制

- macOS：需要 macOS 13.0 或更高版本；实际签名、公证与系统提示以本平台发布清单为准。
- Windows：提供 x64 与 ARM64 安装包，请按系统架构选择；实际签名与 SmartScreen 等系统提示以本平台发布清单为准。
- 已回收工作树的历史查看为只读，不能在该视图中提交、推送或跳转到源码。
- 历史比较只读取本地已有的 Git 对象；本地缺失的对象不会自动从远端补齐，相关差异可能无法显示。

公开 Release 只在固定候选通过发布门禁后才会创建。门禁包含 lint、类型检查、构建与打包检查，并要求产出的 macOS 与 Windows 安装制品与候选提交一致。发布验证章节描述的是长期有效的公开条件，不表示任何检查结果或发布动作已经完成。
