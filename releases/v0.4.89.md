## 代码差异视图的折叠与配色更一致

- 双栏差异模式下，两侧的“未修改内容”折叠现在保持同步：在任一侧展开或折叠、通过查找定位、跳转或查看评论时，两侧都会一起展开对应位置，避免左右视图错位。
- 折叠的上下文行数与最短折叠长度在双栏和统一视图之间保持一致。
- 修改块中较短一侧的空白补位现在与对侧真实变更行对齐着色，行号区域与正文的颜色带更连贯，真实行号仍保留自身样式。
- 切换折叠模式或刷新正文后，已有评论所在片段会重新展开，评论不会因折叠而被隐藏。

## 提交与合并时的文件选择更符合实际操作

- 在仓库交付页面与任务合并窗口中，文件与仓库的默认勾选只在你尚未手动调整时自动生效；一旦你手动勾选或取消，后续刷新只会移除已经不存在的条目，不会覆盖你的选择。
- 重新打开窗口或切换会话时会重新采用默认勾选；在同一组仓库内切换会话则保留你已做出的手动选择。
- 后台刷新后，已移走的仓库或文件不会继续保留在提交范围中。

## 如何升级

macOS 可使用 Homebrew 升级：

```bash
brew upgrade --cask imchenway/tap/zeus
```

也可以下载 `Zeus-0.4.89-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成手动升级。

Windows 请按系统架构选择安装包：x64 系统使用 `Zeus-0.4.89-win32-x64.exe`，ARM64 系统使用 `Zeus-0.4.89-win32-arm64.exe`。安装前请先退出 Zeus，再运行安装程序。

## 系统要求与已知限制

- macOS：最低支持 macOS 13.0。签名与公证状态以本次公开发布清单为准；若系统提示来源或安全相关警告，请按系统提示处理。
- Windows：请根据系统架构选择对应的 x64 或 ARM64 安装包。签名状态以本次公开发布清单为准。
- 当前公开制品可能仍为临时构建且未完成公证，升级可能需要手动下载并安装，应用内自动安装可能不可用。

## 发布验证

Zeus 的公开 Release 只在固定候选通过以下检查后才创建：代码检查、类型检查、构建与桌面打包、以及各平台发布制品清单校验。只有这些门禁全部通过，才会生成对应版本的公开制品与发布记录。
