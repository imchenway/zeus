## 交付进度与失败提示更清晰

- 交付进度会标出用户主动终止的步骤，已完成的步数仍按实际进度显示。
- 交付因异常停下时，进度卡片内直接显示所属阶段和具体原因，窄侧栏下也能完整阅读。
- 结果待核对时会提示先核对推送结果，并可将操作按钮理解为「继续交付」，避免把它当成普通失败重试。
- AI 生成提交说明失败时，会明确说明本次 Git 提交尚未执行，便于换用其他说明或重试。

## 重新打开系统窗口后内容正常显示

- 修复系统窗口关闭后再次打开可能不显示内容的问题；重开后内容、标题与关闭操作按新窗口生效。

## 文案与显示统一

- 差异审阅中的显示范围选项简化为「差异」。
- 会话速度档位与用量明细统一使用英文档位名（Standard、Fast、Ultrafast）。

## 如何升级

- macOS 可通过 Homebrew 升级：`brew upgrade --cask imchenway/tap/zeus`。
- macOS 也可手动下载 `Zeus-0.4.90-arm64.dmg`，打开后将 Zeus 拖入「应用程序」完成覆盖安装。
- Windows 请按系统架构选择安装包：64 位 x64 使用 `Zeus-0.4.90-win32-x64.exe`，ARM64 使用 `Zeus-0.4.90-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应 EXE 完成安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。
- Windows：按系统架构选择对应安装包。
- 当前公开制品可能仍为 ad-hoc、未公证，应用内自动安装不可用，请按上述方式手动升级。
- 签名与系统提示以各平台实际发布清单为准；若系统提示应用来源未知，请以发布清单中的说明处理。
