## 会话可以打开工作区外的文件链接

- 对话回复中的普通文件链接即使指向项目工作区之外，也可以直接打开。
- 这类目录外链接只提供系统默认打开、在访达或资源管理器中显示、复制路径三种操作，不提供 Zeus 内的预览、编辑器或终端入口，避免绕过工作区授权。
- 目录外文件在点击时才会核实路径；文件或所在目录已不存在时会给出明确反馈。
- 同名但位于不同路径的链接会分别登记、分别打开，不再相互串链。

## 任务返工与重试可新建分支

- 当原任务运行环境已被关闭（例如已合入或放弃），返工和重试按钮会明确显示为“新建分支并返工”或“新建分支并重试”，并按项目默认来源创建新的任务分支。
- 原环境仍可用时，按钮保持原来的返工与重试行为，不额外提示。
- 审批返工或确认重试时，若原环境刚被交付关闭，界面会刷新可用动作并保留失败提示与审批草稿。
- 交付状态变化也会触发相关任务面板刷新。

## 任务状态新增“待发布”

- 任务状态配置新增“待发布”状态，位于当前完成状态之前；升级后会随资料更新引入一次，之后可由用户自行调整。
- 任务列表的快捷筛选保留原有选项，并补上“待发布”入口，便于直接查看等待发布的任务。
- 自定义同名状态时会使用配置中的实际状态标识进行筛选。
- 当状态配置尚未加载时，任务表与筛选回退到内置状态列表。

## 源码与 Git 工作台的稳定性改进

- 已删除的工作树在对应窗口内会被清理：项目源码页不再保留其目录缓存，Git 工作台也只展示仍可核验的仓库，并在原状态区域提示哪些工作树已失效、交付前需要修复。
- 目录被移走或删除时，正在恢复的同路径标签一并排除；编辑器草稿独立保留。
- 从源码页切回仍存在的工作树会复用已有目录快照；切到新的根目录则重新读取。
- 展开目录改为后台逐个恢复，先显示根目录，不再整页等待。
- 文件保存、新建、另存、重命名、移动、删除等操作的错误提示改用应用统一错误反馈；“磁盘内容已变化”的操作按钮移入底部状态栏，窄窗口下仍可操作。

## 菜单栏用量费用明细更清晰

- 费用明细按模型分组，同名模型的多个计费档位合并在一行模型名称下展示。
- 模型按名称升序排列，数字段按数值比较。
- 档位与长上下文信息单独成列（无相关数据时不显示），同一模型下先按速度档位、再按长上下文排序。
- 金额、单价等列在各窗口宽度下更易对齐阅读，窄浮窗中允许换行。

## 如何升级

macOS 可使用 Homebrew 升级：

```sh
brew upgrade --cask imchenway/tap/zeus
```

也可以手动下载并安装 macOS 安装包 `Zeus-0.4.91-arm64.dmg`，打开 DMG 后将 Zeus 拖入“应用程序”。当前公开制品若仍是 ad-hoc 签名、未完成公证，需按此方式手动升级，应用内自动安装不可用。

Windows 请按系统架构选择安装包：Intel/AMD 处理器使用 `Zeus-0.4.91-win32-x64.exe`，ARM 设备使用 `Zeus-0.4.91-win32-arm64.exe`。安装前请先退出 Zeus，再运行对应的 EXE 完成安装。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名、公证状态与首次打开时的系统安全提示以本次各平台实际发布的清单为准。
- Windows：按系统架构选择 x64 或 arm64 安装包；签名与安装时的系统提示以实际发布的清单为准。
- 目录外文件链接只提供系统级打开操作，不支持在 Zeus 内预览或编辑。
- 已失效的 Git 工作树只会在工作台中提示，需修复后才能进行交付；其保存的提交历史仍可查看。
