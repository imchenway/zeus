## 新增 Google Antigravity 模型接入

- 模型供应商设置页新增 Google Antigravity 订阅账号入口，可与 Codex、GitHub Copilot 一起集中查看连接状态。
- 通过官方 Google 账号完成浏览器授权，授权过程在浏览器中进行，Zeus 不复制其他应用的账号或密钥。
- 尚未准备 Antigravity CLI 时会先提示准备程序，并在设置页展示下载与安装进度；完成后可刷新状态并选择当前账号可用的模型。
- 新会话的模型接入弹窗中也可直接选择 Google Antigravity，登录后回到草稿继续配置。
- 使用 Antigravity 模型时，会话运行中不支持中途引导输入；离线时会阻止发起需要远端服务的请求。

## 模型接入与账号管理体验改进

- 模型接入弹窗重新组织为按供应商选择：Codex、GitHub Copilot、Google Antigravity 与自定义供应商各自展示品牌标识和当前账号状态。
- 订阅账号接入完成后可在同一步骤中选择本次要使用的模型，并沿用会话选择器的排序与显示名。
- 设置页的订阅账号区域改为统一分组展示，窄窗口下自动堆叠，操作按钮与状态文字保持可读。
- Codex 首次安装可在应用内发起，安装与升级共用分阶段进度展示；未检测到受管程序时提供安装入口，不再要求先手动准备。
- GitHub Copilot 与 Codex 的登录、用量、退出等操作在分组卡片内集中呈现，登录后可继续选择模型。

## 交付命令记录可直接查看

- 代码交付进度中的命令步骤现在可以点击查看对应的执行记录，执行详情在原有弹窗中打开，不会切换当前会话或丢失未保存内容。
- 交付失败摘要优先展示阶段、具体文件与首条诊断原因，完整日志仍保留在执行记录中。
- 交付窗口会保留当前仍在关注或尚未结束的交付记录，已完成的旧记录不再重复出现。
- 侧栏中未归入用户项目的会话统一显示为“无项目”，不再使用临时会话名称，右键菜单与项目菜单在该分组下保持不可用。

## 界面与视觉调整

- 菜单栏用量窗口与用量明细窗口改用更清晰的实色面板和描边，深色主题下不再透入系统模糊背景。
- 模型供应商品牌图标、字体与许可文件随应用一同分发，离线时也能正确显示。

## 如何升级

Homebrew 用户可执行：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可以从发布页下载 `Zeus-0.4.93-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成手动升级。

Windows 请按系统架构选择安装包：x64 使用 `Zeus-0.4.93-win32-x64.exe`，ARM64 使用 `Zeus-0.4.93-win32-arm64.exe`。安装前请先退出 Zeus，再运行所选 EXE 完成升级。

当前公开制品为手动升级方式，应用内自动安装更新不可用；请通过上述 Homebrew 命令或下载对应安装包完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名与公证状态以对应 macOS 发布清单为准；若系统提示来源或安全相关提醒，请按清单说明处理。
- Windows：按系统架构选择 x64 或 ARM64 安装包；签名与系统提示以对应 Windows 发布清单为准。
- Google Antigravity 的托管安装支持 macOS 与 Windows 的 x64、ARM64，其他平台可能无法在应用内准备该程序。
- 使用 Google Antigravity 模型时，会话运行中不支持中途引导输入。
- 账号暂无可用模型时，设置页会提示当前账号无可用模型。
