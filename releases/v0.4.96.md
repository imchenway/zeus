## 命令执行历史支持分页加载

- 命令执行历史现在按每页 50 条分批加载，滚动到列表末尾会自动读取更早的记录，也可以使用「加载更多」按钮手动翻页。
- 读取失败时会保留已加载的记录和出错位置，可以重试同一页，不会丢失已读内容。
- 从通知或交付入口直达某次执行时，会直接打开对应命令的历史并定位到该次记录；即使该命令已被删除，也能通过执行时的快照查看原始结果。
- 运行中的记录数量会实时更新，停止一次执行后只刷新该条记录，已加载的历史分页和当前选择保持不变。

## 手绘流程图配色与布局优化

- 手绘风格流程图使用新的蓝灰配色，节点、分组、连线和文字的对比度更清晰，深色与浅色主题分别适配。
- 当流程图节点使用了作者自定义的强调色时，预览会保留该强调色，同时调整斜纹、轮廓和文字颜色，兼顾辨识度与可读性。
- 横排流程图在窗口较窄时会自动切换为纵向排列，避免节点文字过小；窗口重新变宽后会恢复横排布局。
- 手绘字体优先使用系统手写字体，中文优先使用楷体，缺字时回退到系统界面字体。

## 自定义模型供应商自动获取网站图标

- 未手动上传图标的自定义模型供应商，会根据已保存的连接地址自动获取网站图标，并显示在连接列表、选择器和应用菜单中。
- 同一站点只下载并缓存一份图标；下载失败后会在短时间内避免重复请求。
- 手动上传的图标仍然优先显示；自动获取的图标与用户选择的图标分开保存，不会覆盖手动上传的结果。

## 对话阅读与输入体验修复

- 打开较早的历史对话时，正文会稳定停留在上次阅读的位置，滚动加载更早内容时不再出现跳动。
- 展开或收起对话中的过程详情时，入口按钮会保持在屏幕内的原位置，减少内容高度变化带来的位移。
- 目标输入模式与普通消息共用同一份草稿：在目标模式中输入或退出时不会清空已写内容，正文、附件和引用在模式切换后保持一致。
- 目标模式下的输入法组词、引用标签位置和提交内容得到统一处理，避免切换模式后丢失草稿或引用错位。
- 侧边栏会话条目不再单独显示模型名，标题区域更简洁。

## 如何升级

- **Homebrew（macOS）**：运行 `brew upgrade --cask imchenway/tap/zeus`。
- **macOS 手动升级**：下载 `Zeus-0.4.96-arm64.dmg`，退出正在运行的 Zeus 后打开磁盘映像并按提示安装。
- **Windows 手动升级**：根据系统架构选择 `Zeus-0.4.96-win32-x64.exe` 或 `Zeus-0.4.96-win32-arm64.exe`，退出 Zeus 后运行安装程序完成升级。

当前公开制品若仍为 ad-hoc 签名、未完成公证，升级需要按上述方式手动完成，应用内自动安装可能不可用。

## 系统要求与已知限制

- **macOS**：要求 macOS 13.0 或更高版本；请根据芯片架构选择对应 DMG。签名和系统提示以 macOS 实际发布清单为准。
- **Windows**：提供 x64 与 arm64 两种安装包，请按系统架构选择；签名和系统提示以 Windows 实际发布清单为准。
- 自动获取的自定义供应商网站图标依赖目标站点可公开访问；站点未提供图标或读取失败时，会回退到字母或内置图标。
- 横排流程图自动切换纵向布局仅适用于使用 Zeus 默认手绘主题的流程图；作者显式指定主题或自定义样式的图表保持原有渲染方式。

## 发布验证

Zeus 的公开 Release 只有在固定候选提交完成以下检查后才会创建：

- 针对该候选提交执行的代码检查、类型检查和构建通过。
- 桌面端打包成功，并产出与本文档一致的 macOS 与 Windows 安装包。
- 发布清单中的制品名称、平台架构和签名状态与公开 Release 记录一致。

只有上述条件全部满足，才会创建公开 Release；任一检查未通过时不会对外发布该候选。
