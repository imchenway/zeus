## Antigravity 可在更多场景中使用

Google Antigravity 不再只限于普通项目会话。任务阶段、数字员工和代码审查都可以选择已接入的 Antigravity 模型，并按所选模型的真实运行时执行；任务阶段的执行记录也会保存实际使用的运行时。

对已有阶段和员工记录做了兼容处理：旧的裸模型名仍按原供应商范围解析，不会因为选择列表合并而把配置误指到其他供应商。是否切换 Antigravity 供应商或模型，不再通过旧会话的固定限制拦截；需要全新上下文的场景仍以各入口的提示为准。

相关设置页也做了统一：Codex、Copilot 与 Antigravity 账号卡片都会以一致的名称和顺序展示当前可用模型。账号刷新、重新登录或冷却后，模型选择与任务、阶段、员工表单会在后台更新选项，尽量保留已经填写的配置，减少需要重新选择的次数。

## Pi 自动摘要用量计入账单

Pi 在长对话中触发的自动摘要现在会单独登记为一次供应商请求，并在收到结果时记录用量与费用估算，不再把摘要消耗混入用户消息的上下文占用。这样可以更清楚地看到同一会话里由自动压缩产生的额外调用。

摘要请求的回执会绑定到发起它的那一轮对话；如果账号或模型连接发生变化，导致摘要归属的对象不一致，会被明确拒绝，而不会记到其他会话上。供应商返回拒绝或超时只影响当前请求，不再因此中断整个 Pi 工作进程。

## 系统行为与稳定性改进

- 在模型目录、账号登录状态或连接配置更新后，已经打开的会话、任务和审查窗口会在后台刷新可选项，而不是一直保留旧列表。
- Pi 会话在模型连接变化后，会在空闲时按最新目录和凭据继续使用，同时保持原来的会话历史。
- 在只读权限下，Pi 对文件写入和命令类工具请求会直接拒绝，不再交给后续流程判断。
- 团队任务在选择不支持结构化提交工具的运行时启动前会给出明确提示，避免进入流程后才发现无法提交结果。

## 如何升级

使用 Homebrew 安装的用户可以执行：

```sh
brew upgrade --cask imchenway/tap/zeus
```

macOS 也可以手动下载 `Zeus-0.4.98-arm64.dmg` 后安装。

Windows 请根据系统架构选择 `Zeus-0.4.98-win32-x64.exe`（x64）或 `Zeus-0.4.98-win32-arm64.exe`（ARM64），先退出 Zeus，再运行安装程序。

当前公开发布的制品如果仍是临时构建、未经过公证，则只能通过上述手动方式升级，应用内自动安装可能不可用。不同平台实际的签名和系统提示，请以对应发布清单为准。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。首次打开时如果系统提示无法验证开发者，需要按实际发布清单中的签名和公证状态处理。
- Windows：提供 x64 与 ARM64 两个安装包，请选择与系统架构匹配的版本；安装前需要退出 Zeus。
- 自动摘要用量依赖 Pi 返回的请求结果，因此在供应商未返回完整用量时，费用估算可能不完整。
- Antigravity 的可用模型取决于当前账号状态；账号尚未完成验证或未返回模型时，相应入口不会提供可运行模型。
