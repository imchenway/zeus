## 新增待处理通知与模型连接入口

通知中心现在会汇总待处理事项，并提供进入模型连接的入口，方便你从通知直接前往相关设置或工作区。

## 任务备注与附件管理

任务详情支持备注和附件管理，可以在任务中补充说明、查看和维护与该任务相关的附件。

## Git 工作台与源码历史增强

Git 工作台新增历史操作与日志控制入口，可在仓库中浏览提交历史、筛选日志并执行相关操作。源码工作区同步改进了文件树、差异与行内变更展示，合入续办与换行差异的显示更准确。

## 文件图标与会话交互优化

文件树和下载页使用扩展后的文件与文件夹类型图标，覆盖更多技术栈与目录用途。会话区域调整了顶栏布局、会话切换失败后的队列恢复、退出中断的待发送消息恢复，以及排队交付动画和正文加载占位。网页权限提示与语言支持也有优化。

## 如何升级

macOS（Homebrew）：

```bash
brew upgrade --cask imchenway/tap/zeus
```

macOS（手动）：下载 `Zeus-0.5.1-arm64.dmg`，打开后按提示将 Zeus 拖入“应用程序”完成升级。

Windows：按系统架构选择 `Zeus-0.5.1-win32-x64.exe` 或 `Zeus-0.5.1-win32-arm64.exe`，先退出正在运行的 Zeus，再运行安装程序完成升级。

## 系统要求与已知限制

- macOS：最低系统版本为 13.0。签名与公证状态以 macOS 发布清单为准；若当前制品为未公证版本，首次打开可能需要在系统设置中允许打开，升级以手动方式进行，不提供应用内自动安装。
- Windows：提供 x64 与 arm64 两种安装包，请按系统架构选择对应文件；签名与系统提示以 Windows 发布清单为准。

## 发布验证

公开 Release 只会在固定候选通过发布门禁检查后创建。门禁要求候选提交在 macOS 与 Windows 两条流水线上完成依赖安装、lint、类型检查、构建与桌面打包，并校验生成的 macOS DMG 与 Windows EXE 制品齐全、可与对应系统架构匹配。只有全部门禁检查通过，才会创建公开 Release 并对外提供本页列出的下载文件。
