## 待答问题进入通知中心并可一键定位

当会话中的助手向你提出问题、且该轮次仍在等待答复时，这条提问会以“待答问题”的形式出现在通知中心，并显示所属项目、会话标题和问题摘要。

- 在通知中心点击“回答问题”，会重新确认该问题仍可作答，然后进入原会话并直接定位到对应的提问表单。
- 如果问题已被回答、轮次已结束或原会话不可用，定位会给出明确提示，不会把你带到错误的消息上。
- 问题条目在其真正被答复之前不会因“标记已读”而消失；待答状态只随答复或轮次结束而消除。
- 同一问题从通知再次打开时，表单会重新获得焦点，方便直接作答。
- 当项目目录尚未加载完成时，问题条目仍会显示其真实所属项目。

## 通知中心交互调整

- 通知项按来源提供更贴切的操作名称，例如查看结果、处理代码交付、回答问题。
- 项目名称、标题、摘要与时间改为更清晰的分层布局，长标题最多显示两行，时间保持完整。
- 导航失败或取消时，焦点会回到原来的通知条目，便于键盘用户继续操作。
- 自动化通知仍会显示可用的错误说明和继续操作入口。

## Git 工作台标签栏优化

- Git 视图标签统一了外观，Local Changes、Shelf、Stash、各个 Log 标签以及 Console、Update Info 使用一致的标签样式和选中状态。
- 窄窗口下标签列表可独立横向滚动，选中标签会自动滚动到可见范围，关闭入口保持可点击。
- 较长的 Log 标签名称会被截断显示，悬停可查看完整名称。

## 如何升级

本版本为手动升级，请根据你的平台选择对应方式。

### macOS

使用 Homebrew 升级：

```sh
brew upgrade --cask imchenway/tap/zeus
```

或下载 `Zeus-0.5.4-arm64.dmg`，打开后将 Zeus 拖入“应用程序”完成替换。

### Windows

请根据系统架构下载对应安装包：

- x64：`Zeus-0.5.4-win32-x64.exe`
- arm64：`Zeus-0.5.4-win32-arm64.exe`

安装前请先退出正在运行的 Zeus，再运行安装程序。

## 系统要求与已知限制

- macOS：最低支持 macOS 13.0。
- Windows：支持 x64 与 arm64 架构，请选择与系统匹配的安装包。
- 当前公开制品为手动升级方式，不提供应用内自动安装更新。
- 代码签名与系统安全提示以各平台实际发布清单为准。

## 发布验证

Zeus 的公开 Release 只有在固定候选通过以下检查后才会创建：

- 代码检查：lint 与类型检查通过。
- 构建与打包：桌面端构建、macOS 与 Windows 各架构安装包打包成功。
- 界面与交互：通知中心待答问题定位、Git 工作台标签栏等本次涉及的关键交互在桌面端可用。
- 制品校验：上述所列文件名与平台架构的安装包齐全且与候选一致。

任一检查未通过时，不会创建对应版本的公开 Release。
